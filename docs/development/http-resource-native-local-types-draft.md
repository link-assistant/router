# Original native local type obligation draft

The original binding reader now retains complete let type spans. The lexical
substitution removes those annotations only as explicit obligations, giving
each selected declaration a globally distinct portable name. The whole source
then re-enters the independent body checker. Each obligation must find exactly
one original function/local value with the same checked closed native domain
or actual unchanged generic slot. Incorrect integer widths, incompatible
lifetimes, unknown types and copied metadata cannot weaken the body contract.
Parameters and callback signatures keep their original separate rules.

One traversal of each fresh function flow indexes actual local values inside
this operation; all annotation joins use that index. No source, hash, binding,
owner or result cache survives an invocation. Original source bounds, complete
CST serialization/reparsing and exact inverse histories remain. Unsupported
normalization still returns to the original canonical refusal domain.

The shared native projection also preserves an actual i64 local initializer
through an original qualified target type witness. A positive local value
cannot turn into u64 merely because the enclosing function returns Boolean or
does not use the local later. The actual whole value and native range still
check independently. The existing physical unit path selects the full successor
and retains original native authority bytes and canonical paired behavior.

Five complete original source copies, language/repository substitutions and
full inverses are retained. Independent native/JS/strict TS, 128-declaration
scope, signed-width, borrowed/generic/byte, metadata and refusal cases plus real
native oracle source are drafted and unrun. No tests, experiments, compilers,
translators, preparers, generation, Rust tools, pushes or CI ran. Wider types,
patterns, contextual empty vectors, namespace/producer closure, actual production
qualification/parity and every unfinished bulk requirement remain open.
