# Stored project generated-method review

`reviewStoredProjectGeneratedMethods` independently reviews generated methods
from complete stored project metadata. Its source is copied from the original
`reviewGeneratedMethods` implementation, and the original direct API and its
context factories retain their complete bodies.

The complete concrete component is validated separately before semantic review.
This separation preserves the original metadata object, depth and storage
bounds. It does not grant a namespace, executable or runtime permit.

## Generate the complete source

Run:

```sh
node scripts/prepare-stored-project-review.mjs --emit /tmp/FRESH_PROPOSAL
```

The producer first serializes and reparses the complete source through the CST
extension. TypeScript 5.9.3 then selects the original native function declarations.
The three derived functions have separately ordered `language` and `repository`
literal substitution sequences, complete source/CST records and full inverses.
Root rules attach the existing genuine context APIs, add the derived functions
and select the explicit stored-project consumer. Every original direct function
must retain its complete original native source.

The proposal never installs source. Independently review its original Git and
physical bytes, every copy equation, native grammar, CST and complete inverse.
Install only actual producer bytes and require:

```sh
node scripts/prepare-stored-project-review.mjs --check
```

## Keep fresh joins and every body check

One invocation lazily constructs one genuine original Default context for its
unit, container and Clone reviews. Every reuse rereads the complete original
source set, verifies every original source hash, rejoins actual sealed dependency
identity and compares the complete module layout. Serialized profile data is
normalized through the existing `compilationProfile` parser before comparison
with the normalized graph. A copied dependency or a changed source/profile fails.

Clone composes the existing `createCloneEnclosingSourceContext` issuer with that
genuine Default context and a fresh derive enclosing context. Public flags and
copied source facts cannot replace either private input. The existing nominal,
generic, generated body, ownership, flattened target, source proof, count,
one-to-one and refusal checks remain in the copied reviewer.

The shared context is local to that single synchronous call. No source, owner,
hash, verdict or encoded result is retained for another review invocation.
Original source, Cargo, JSON macro and profile checks remain mandatory; review
does not establish native behavior or full translation parity.
