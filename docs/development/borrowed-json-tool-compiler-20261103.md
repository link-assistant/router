This batch connects the existing unrestricted compatibility predicate to the
actual Host parser/checker/emitter, both original semantic-meta readers, all

implementations. The production caller is the complete private

operations and the standard-map family retain their own domains.

The language rules preserve a shared input, direct parameter-root observation,
boolean evaluation order, immutable boolean locals and complete branches.
Repository rules select the actual qualified native predicate and original
runtime/declaration owners. Only an original imported predicate use can select
an `unknown` TypeScript input; `unknown` itself proves no JSON representation.
An imported `Parameters<typeof predicate>[0]` witness has its actual declaration
owner checked. JavaScript keeps the original JSDoc/paired-source path. JSON
aliases, moves, aggregates, identity/equality, helper calls and unsupported
control flow require further complete family work and continue to refuse.

Complete Rust and JS/TS source goes through the real CST serialization/reparse
boundary before independent private source/type/owner/body qualification. A
public kind, source key, hash, meta node or ABI description cannot issue a
checked type or call. Actual Cargo/default-feature inputs must select the
canonical serde JSON representation. Source context does not establish a
rustc invocation, sysroot or trait-dispatch theorem. Native oracle and runtime
parity qualification remain UNRUN.

`withBorrowedJsonToolProject(options, consume, mode)` is an additive synchronous
compile-and-consume API. Modes are `regular`, `owned-definitions`,
`owned-core-readers`, `flat` and `flat-enclosing`; each invokes its original
project implementation. The consumer may lower deferred declarations and
reparse metadata while original source/type/call associations are live. On
exit all new caller records, type observations and checked-call associations
are cleared. Returned target strings remain DATA. Saved lower callbacks and
decoded metadata cannot extend authority beyond the operation. Recompile from
the complete original sources for another operation. Existing entrypoints
remain available; they do not promise a persistent new-family proof.

Nested reverse analyses of the same complete receiving source Map reuse only
the current live private native receipt. They check its complete native-source
sequence and original receipt at every use and close. Another invocation
reconstructs the complete Rust module graph, original dependency configuration
and private ABI. No source, hash, owner or verdict cache crosses operations.
Caught source failures remain sticky; ordinary application exceptions preserve
their exact thrown value. Every closing check and cleanup is attempted even
when an earlier callback throws a falsy or frozen primary.

The observed predicate has no container-entry, name-byte or whole-tree-depth
cap. Its head-shape guard is not a recursive JSON validator or certificate.
Canonical ordering is an input ABI precondition. Web tool types return without
reading irrelevant names; a present null `function` suppresses top-level name
fallback, while a missing function allows it. Native internals may remain
untranslated behind this explicit compatibility boundary.
