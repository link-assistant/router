# Whole native include-str source draft

The implementation and every new case are UNRUN. Only source construction and
review occurred. No reader, translator, preparer, compiler, test, experiment,
generation, local Rust tool or CI-triggering push executed.

The fresh reader copies the complete existing native input/frame implementation
into an include-str source domain. Sixteen complete inputs preserve twelve
original Rust files, two original source manifests and both licenses. Sixteen
whole callbacks retain exact original names, spans and bytes, including the
include-str handler, single argument/parser/string conversion, path resolution,
file loading, source-map filename and file loader delegation, UTF-8 selection,
string expression construction, literal parsing, eager expansion, visitor and
placeholder paths. Complete builtin registry and core macro source remain.

Each fact read reopens and checks every complete current pinned input, creates
the full Rust CST/inverse and rejoins every callback to the original function
inventory. Literal conversion is selected by its actual original span to keep
the two same-name native functions distinct. Original eight-MiB input and
200,000-cell bounds remain. Requests retain private identity only; no source,
hash, owner, verdict or result cache spans operations.

Language rules retain complete original handler/parser/path/loader/output
premises. Repository rules keep their exact caller, Span, UTF-8/file-loader and
macro-argument conditions. These source premises do not qualify the actual
builtin owner, Rust source-callsite context, native filesystem implementation,
resolved path or global exports. All such fields remain false. In particular,
an archive asset plus a matching include-str spelling cannot supply actual
native Span or owner authority.

Three complete compiler source equations retain whole original readers and
native owner spans, separate substitution sequences and full serialized/reparsed
CST histories. Independent unrun cases cover every full input/callback, the
actual native source chain, fresh reads, private request refusals and source
equations. Joining an actual original attribute to a conditional document
substitution still remains open, along with all wider architecture/namespace,
production/parity, reverse/freshness/CI and receiving requirements.
