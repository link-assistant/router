# Passive builtin macro attribute source draft

A separate full engine/proposer/project copy now carries qualified passive
builtin attributes on original macro definitions and actual generated items.
The source classifier retains the actual original parser, normal Attribute AST,
single-segment name lookup, full registration expansions and custom collector
exclusion for allow/warn/deny/forbid/stable/unstable/automatically_derived.
Ordinary namespace/tool frames retain their earlier three-name domain; already
harmless lint attributes do not add work to those active resolver filters.

One synchronous whole source proposal owns its passive source validation frame.
All original definition items and generated output strings are actual complete
inputs with genuine source views and exact spans. No fabricated placeholder
item supplies a builtin proof. A generated source record has an explicit
expanded domain and never supplies original caller ownership or namespace
permission. Every frame rejoins original sources at exit, including failures;
a retained validator fails after its operation closes. No new source, hash,
owner, verdict or result cache survives between operations.

The copied engine proposes syntactic attribute tokens with false authority.
Before retaining an edit, the actual copied source consumer qualifies every
surviving generated attribute against the private original source frame. Unknown,
derive/cfg/export, raw/qualified and macro-valued forms refuse the complete
original invocation. Generated macro binders, dollar-crate owners, disjoint
identifier hygiene, source ordering, recursive opaque input forwarding and
scoped inheritance retain their original checks. Attributed invocations and
documentation remain refused; their propagation semantics are not guessed.

The copied project re-enters the actual enclosing original Rust frontend,
checked semantic meta and both emitters on expanded source. Original root and
scoped APIs and their refusal workloads remain available. Original-source
equivalence, executable production coverage and runtime parity stay unqualified.
The original macro budgets remain; attributed output inspection uses the
existing 256,000-byte/32,000-token/depth-64 domain and refuses larger inputs.

Five complete original implementation copies, ordered language/repository rules
and full CST/source inverses are retained. Independent definition/output/recursive
scope, original API, source operation lifecycle, hygiene/owner/refusal and whole
project JS/strict TS cases plus an ordinary native macro oracle are drafted and
unrun. No compiler, test, experiment, preparer, translator, generation, Rust tool,
push or CI ran. Complete architecture exports, conditional/derived macro effects,
producer bootstrap, production qualification and every unfinished requirement
remain open.
