# Callback text-body source draft

All implementation and independent case SOURCE is UNRUN. No local parser,
translator, generator, test or compiler ran and CI feedback is uninspected. Full
production translation, parity, synchronization and delivery remain open.

The existing text selector now also supplies callback-body source proposals.
A bounded temporary Rust function wraps the exact original callback body and
finite current lexical input roles. Its complete CST is serialized/reparsed,
and the original text engine selects expressions. Every edit must remain inside
the original body; rebased language and repository substitutions run against
that complete body with its own full CST inverse. The temporary types and
function are explicitly DATA and prove no real function owner, type, binding,
borrow, effect or executable permission. Only the original whole caller reaches
the semantic checker after its actual full source substitution.

The copied close/split functions and ident/text declarations retain their exact
native-selected originals, complete original module, source hash, copied text,
CST identity and fresh descendant guards. The engine itself is reused directly.
Both original callback adopters preserve child histories through following
Option methods and qualify newly introduced text calls in their outer repository
phase. Callback local aliases derive roles chronologically from current rewritten
initializers; written types constrain selection and never manufacture a value.

The shared language source reader also recognizes complete parenthesized
operands. Repository rules handle explicit immutable borrows of actual owning
text source roles, including grouped borrows emitted by the text engine. Mutable,
unknown, mismatched and extra-suffix operands remain unselected. There is no new
runtime ABI and no change to semantic ownership checks or resource limits.
Callback body source is bounded to65536 code units,64 lexical inputs and32
successful body adaptations per function, within the original whole-source
bounds. No cache survives an operation.

Seven complete compiler equations and independent unrun source cover expressions,
blocks, locals and returns, Unicode/comment spans, character patterns, grouped
borrows, copied helper provenance, child and full parent inverses, both original
adopters and9 original callers, bulk JavaScript/strict TypeScript, complete
resource reverse/native inverse, native standard-expression oracles and exports.
Wider nested closures, unknown body syntax/callees, captured owner transfer,
namespace/owner closure and every source/native/production/sync/freshness/parity/
delivery requirement remain OPEN. All eight same-SHA JavaScript gates before
fatal CI-only Rust remain unchanged.
