# Full vector module reinput source draft

SOURCE ONLY. All implementation and cases remain UNRUN. No parser, preparer,
translator, compiler, tests, experiments or CI feedback inspection ran.
Full bulk drafting and every delivery obligation remain OPEN.

The receiving proposal derives a JavaScript module from the complete edited
TypeScript module using a source-derived copy of the existing native AST
annotation-erasure grammar. It retains comments, literal text, ASI-sensitive
newlines and complete erased spans. Unknown executable TypeScript forms refuse.
The unmodified original paired checker independently verifies both whole CSTs,
token streams, native AST topology and each original parameter/local span.
Erasure supplies source text, never type, source-owner or executable authority.

The actual private vector source checker now recognizes complete canonical
scalar input prefixes under the fresh original Rust profile. Every parameter
read binds its actual original checker symbol. Unicode guards resolve through
the actual native runtime import; primitive guard constructors resolve through
unshadowed original lexical resolution. Its noLib checker has no builtin
declaration; any local/imported constructor symbol is refused, while an actual
standard-library declaration is checked if present. Partial, altered and arbitrary effect prefixes
remain refused. Float and text return annotations now select their actual
number/string keyword rather than the integer keyword.

The source proposal rechecks the erased pair, emits its canonical complete
TypeScript, reconstructs that whole module pair and freshly checks it again.
Rust and TypeScript emission must reach an exact fixed point. JSON vector
boundaries copy borrowed/aliased elements, while actual already-owned checked
JSON operations retain their own single copy. Actual imported copy calls and
boundary copies share their native borrow/copy expression; reinput therefore
does not add a new copy layer each cycle. No source-call evidence is invented.

Every actual source context receives closing freshness checks, including on
failure; the primary thrown value is preserved. No cross-invocation source,
hash, owner, result or verdict cache is introduced. Full source input rows,
original JS/TS bytes, CST inverse histories, checked candidate metadata and the
uninstalled native module candidate remain in the DATA proposal. There is no
filesystem installer or native-freshness claim in this API. Native source
replacement, whole project retranslation and synchronization remain separate
OPEN obligations.

Nine complete source equations retain language then repository stages and
both preparation roots. Independent unrun cases cover AST-only type erasure,
comments/inverses, scalar/native float/owned/static text guards, JSON copy fixed
points, malformed/shadowed/partial guards, fresh changed Rust source, edited
metadata refusals and no native installation. Every production/platform/
receiving/performance obligation remains OPEN. Rust remains CI-only after all
eight same-SHA JavaScript gates.
