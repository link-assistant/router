# Original native control spelling draft

The explicit native binding successor now records original conditional and
return token boundaries. A statement if without an else receives an empty else;
a statement else-if chain receives equivalent nested braces. Insertions at a
shared original boundary are combined in semantic order, so an innermost missing
else stays inside every enclosing chain wrapper. All original comments, literal
text and complete source inverses remain retained.

An explicit return becomes an expression tail only at an actual function or
typed callback tail, or its final conditional/lexical subpath. Earlier returns
and returns inside loops keep their function target. Initializer expression
branches never inherit that tail permission. Original patterns, skipped guards,
unknown producers, missing values and unsupported control remain refusals.

These are source substitutions, followed by complete independent source/meta
checking and normalized native token reproduction. They do not issue a source,
type, ownership or namespace capability. Existing local annotation obligations,
lexical moves/roots, current source joins and resource bounds remain. Physical
units retain original native authority bytes and checked canonical paired code.

Three complete original source copies, both rule phases and full inverses are
retained. Independent JS/strict TS/native, every Boolean branch combination,
early/loop/callback return, generic/mutable/Unicode, physical unit/refusal cases
and real native oracle source are drafted and unrun. No test, experiment,
compiler, translator, preparer, generation, local Rust tool, push or CI ran.
Wider expressions/patterns, namespace closure, production adoption/parity and
every unfinished bulk requirement remain open.
