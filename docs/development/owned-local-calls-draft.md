# Complete-module ordinary function call draft

The owned profile now checks ordinary same-module callees before their callers,
using actual native TypeScript symbols and complete original bodies. Hoisted and
chained functions, callback calls, operand-derived numeric widths and returned
loans use the existing private issuer. Borrowed results retain their actual input
roots. Opaque byte/optional input validation is inherited only from a freshly
checked actual callee. Unsupported bodies and recursive components refuse.

Program checking, meta serialization/reparsing and emission require every linked
checked callee, its exact whole module source, declaration span, argument domains
and return domain. One genuine source context is required for executable local
calls. Standalone spelling/metadata/graph helpers issue no semantic authority.
Both independent interpreters execute the already checked complete call set;
there is no across-invocation source, owner, verdict or encoded-output cache.

Canonical Rust source proposals retain function spelling and then require fresh
whole-module checking/reproduction. Original numeric/SSE mirrored runtime type
edges are included in actual paired TypeScript path selection. Five complete
source predecessors, ordered language/repository rules and full CST inverses
compose the earlier source families.

Independent source covers hoisting, call chains, callback calls, numeric limits,
loans, JS/strict TS/interpreters, full Rust inversion, missing/changed/forged
callees, mixed contexts and unsupported recursion. Native Rust oracles cover
actual calls and input-loan identity. All implementation and receiving checks
are **unrun**. Cross-module function imports, declared recursion, generic/class
calls, async effects, full production application and all other bulk rows remain.
