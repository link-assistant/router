# Actual x86 metadata consumer source draft

This implementation and every new case is UNRUN. Only source construction and
review occurred. No consumer, translator, preparer, generation, compiler,
experiment or test ran, and no CI-triggering push occurred. Local Rust remains
forbidden. All unfinished source and later verification obligations remain open.

The additive API copies the complete actual x86 lookup/output pipeline, keeping
the original exact single-path domain. Actual textual lookup premises, root/
definition/caller prefixes, private macro expansion lineage, generated function
frames, positive parser refusals, full output CSTs and every original physical
inverse remain. Existing APIs and their source domains remain unchanged.

The copy joins current source consumers to two explicit domains: complete
original physical files and the complete expanded candidate file. They retain
separate original input strings and full CST roundtrips and inverses. Genuine
physical module views locate root, inner and actual impl/trait member metadata.
Their relative inline paths remain physical source-view paths; the actual Rust
namespace path stays null. No target or Cargo configuration is selected.

The actual documentation-expression, architecture builtin, inner-lint and
module-macro-use scopes consume their supported original metadata. The new doc
family retains private expression frames and whole native visitor premises.
Member metadata always passes the real enclosing source item and actual member
index to those consumers. Comments are observed through the complete original
source lexer and native doc-comment source path. Unsupported attributes, member
grammars and documentation argument macro effects remain explicit pending rows.

Every temporary scope finishes and rechecks its current native inputs, including
when another consumer fails. A complete failure cannot return a partial result.
The outer pipeline reopens all complete original native inputs and rechecks its
existing private generated function frames after metadata consumption. Added
source cells and retained physical bytes use the original outer bounds;
consumer scopes retain their existing independent bounds. No source, hash,
owner, verdict or result cache survives an operation.

Language rules inspect actual root/inner/member source. Repository rules retain
complete source domains, consumer records and unresolved producers. Three full
compiler equations preserve native owner spans and complete CST histories.
Independent unrun actual-source cases retain original/expanded joins, builtin
SIMD metadata, real macro-valued docs, member source association, false authority
flags, input refusals and full source equations.

This joins source consumers; it does not resolve macro ownership, architecture
configuration, wider field/variant/parameter metadata, derivations, global
exports or competing type-prefix absence. All such flags remain false. Current
production admission, parity, regeneration, CI repair and receiving qualification
also remain unfinished; this source batch is not an executable coverage result.
