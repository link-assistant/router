# Primitive parameterized vector reverse source draft

SOURCE ONLY. No parser, translator, preparer, tests, compilation or experiments
executed. CI remains uninspected. No current completion or coverage is claimed.

The explicit vector reverse candidate now captures up to 32 by-value integer/
Boolean parameters from the actual fresh admitted Rust signature. Written and
checked Rust types must agree; fixed/borrowed/unresolved/erased domains remain
refused. Target lowering must retain actual arity. Every JS parameter must resolve
to its unique native parameter symbol and a matching TypeScript parameter/name
with the appropriate scalar keyword type. Defaults/rest/optional/decorated and
destructured parameters remain refused. Full original source and module-view,
paired-source erasure, CST/meta and private reissuance checks remain unchanged.

Scalar aliases and closed block constructions can refer to these actual input
symbols. Each returned input must have the exact original vector element domain;
there is no implicit narrowing, signedness or ownership conversion. Reverse Rust
uses exact native primitive parameter types, including usize/isize, and stable
synthetic internal argument names. It does not project machine integers as u64
merely because the portable execution profile uses 64-bit values.

The reverse TypeScript target checks original input kind/range at entry, including
unused arguments in zero-output construction. The independent evaluator applies
the same closed native bounds. Operator-authored edited input JS/TS are executed
as authored; these guards belong to emitted reverse TypeScript and the evaluator.
No native runtime or erased source metadata grants a new execution permit.

Six complete compiler equations retain physical original inputs, language then
repository phases and complete serialized/reparsed CST inverses. Independent
unrun source covers parameter renaming/alias/IIFE construction, bools, signed,
u128 and machine boundaries, unused input guards, source arity/annotation/default/
rest/borrow/mixed-width refusals, strict TS/evaluator and private meta roundtrip.
General source parameters, arithmetic/calls/control/effects/async, emitted module
packaging and full forward/reverse/sync/freshness/receiving delivery remain OPEN.
All eight same-SHA JavaScript gates must pass before fatal CI-only Rust checks.
