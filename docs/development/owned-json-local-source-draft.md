# Shared owned JSON carrier local source draft

The implementation, complete source equations and independent cases are drafted
and unrun. No current coverage, target/native parity, source-history freshness
or complete translation/synchronization result is claimed.

Both existing owned JSON carrier adapters now use the chronological source
engine for simple immutable aliases and explicit source borrows. Owned/shared
JSON, Option<Json> and Result<Json,String> facts remain distinct. Actual selected
whole direct initializer results can supply later carrier aliases, only after
their original semicolon and within their lexical block. Unknown/annotated/
future/ended-scope locals cannot acquire a role from spelling alone.

The original receiver and default single-use requirements remain. Original
parameter use counts are unchanged; local-use counts exclude their declaration
identifier. Failed new local censuses retain the old parameter-only path. Shared
receivers still require the original explicit clone form before consumption,
and shared JSON defaults cannot replace owned defaults. Whole-function source,
type, ownership, producer and emission checks remain mandatory; candidate DATA
does not prove native Clone, Drop, movement, allocation or executable behavior.
Original false trait/Drop/executable flags remain in every selection.

Both adapters also use real shared neutral language call rules followed by exact
repository prefix rules, bringing sixteen existing adapters onto that planner.
The original core source and freshness checks, complete serialized/reparsed CST
and source inverses remain. The inherited census/token/cell/frame/binder bounds
stay fixed and no source/hash/owner/verdict/result cache crosses an operation.

Five complete equations retain the original helper, selector, both adapters and
history edge. Independent unrun source covers aliases/borrows/scopes/timing,
actual selected result chains, repeated-use/default/unknown refusals, both APIs,
the fixed bulk stage, receiving JS and strict TS, native JSON branch values and
whole source/CST inverses. All wider source/native/production/sync/freshness/
parity/delivery requirements remain unfinished.

The later [shared declaration draft](local-alias-binding-source-draft.md) keeps
unrelated mutable locals opaque while preserving independent immutable alias
facts. It supplies no mutable-value facts or type/owner/executable permission;
all new cases and whole-project requirements remain unrun and unfinished.
