# Shared runtime and ownership integration draft

The current owned-definition, owned-field, retained, native and flat bulk output
families now select the full shared runtime asset builder. The two original
source producers carry the same substitutions, so their complete canonical and
matrix recipes include the matching text modules and bounded integer exports.
The existing legacy host and pinned ASCII sources remain historical inputs.
No generated application output has been regenerated during drafting.

The native ownership walker has a dedicated source-bound text branch. It checks
every actual call and operand, retains the selected receiver's live loan facts
for borrowed strings and optional slices, and treats replacement/repetition
results as newly owned strings. Original source lifetime checking still controls
which input region may escape. The SSE boundary likewise requires its actual
call receipt and its owned JSON result rather than the scalar state fallback.

Complete original flow implementations and bulk source recipes are retained by
`prepare-owned-text-flow-sources.mjs` and
`prepare-text-bulk-runtime-sources.mjs`, with separately ordered language and
repository substitutions. Independent source cases cover native source lifetime
refusals, chained loans, owned local results, legacy integer parsing alongside
new operations, all six current bulk producers and complete source inverses.

Everything remains unrun and unqualified. Complete production application,
broader syntax/effects, synchronization, parity, receiving qualification and CI
repair obligations remain open in the bulk draft ledger. All original workloads,
resource bounds, case deadlines and eight same-SHA JS stages remain required;
Rust runs in CI only after every JavaScript stage passes.
