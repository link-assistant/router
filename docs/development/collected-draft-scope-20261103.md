# Complete collected scope and adoption reconciliation — source draft

The earlier immutable scope reporter carries only exact manual observations;
the separate Rust and target collectors can inspect complete native source but
were not connected to a shared adoption worklist. The additive
[`collect-router-draft-scope-20261103.mjs`](../../scripts/collect-router-draft-scope-20261103.mjs)
connects the actual original Rust and JS/TS collectors to
[`collected-scope-reconciliation-20261103.mjs`](../../tools/translation/collected-scope-reconciliation-20261103.mjs).
All prior collector, reporter, archive, reconciliation and parser APIs retain
their existing implementations, domains, limits and source/refusal checks.

The driver selects every committed physical file under `rust/`, `js/`, `ts/`
plus root Cargo/package inputs at one explicit full immutable revision. It
also selects exact implementation, receiving, case and producer evidence paths
named by the reviewed adoption registry; this adds no claim that these paths
are the compiler's complete dependency closure. Selection precedes Git size
requests. Every parsed original blob is read in full, checked against its
Git object content and strict UTF8, and read again after the consumer. The
complete immutable tree/size sequence also closes. Uncommitted worktree edits
are outside this explicitly committed-source domain. Source identity does not
establish native behavior or semantic admission.

The language sequence invokes each original complete CST/native collector.
The repository sequence joins its observations to the complete physical census
and actual numbered implementation/adoption records. All original language
collector limits remain. The new driver processes at most16 files or512KiB
per ordinary batch, keeping a whole larger file on its original source domain.
It does not slice functions from source, truncate unsupported files, increase
native bounds or turn macro token spellings into executable declarations.
Physical package/build/non-code/generated assets are also delivered. Original
native/grammar/producer refusals and diagnostics remain in their actual result.

Events carry full native observations, exact UTF16/UTF8 spans, owner paths,
configuration, role/producer gaps and reconciliation rows. Overlapping original
declaration and parsed-function observations stay distinct. Same-spelling
trait/impl/inline/nested/cfg items never merge into an invented function count.
The stable observation hash is a DATA locator derived from its complete
physical identity and native observation identity. A changed source loses the
old assignment, even if a function name stays the same. An unchanged blob at
a new revision can keep its bookkeeping association. Neither case supplies
parser, type, owner or executable authority.

Each assignment needs known numbered rows, a real implementation/adoption
attempt path/symbol/span, all four forward-JS/strict-TS/reverse-Rust/sync lanes,
independent case sources or an explicit gap, and complete original physical
origins for every referenced source. A source-specific inapplicable lane needs
its reason. Runtime/type/receiving/case/producer evidence changes or deletion
invalidate the record even when its implementation file is unchanged. Old
assignments that match no current observation stream separately as removed,
changed, refused or uncollected evidence. Newly observed entries remain
unassigned; matching source metadata cannot automatically mark them drafted.
Original role, Cargo-unit, native-scope, feature and unknown-producer gaps are
never cleared by an assignment's public REVIEWED field.

Native/source/input failures propagate immediately through all closing checks.
The driver does not retry a changed compiler or invalid original source for
every remaining batch. A complete result exceeding the new bounded DATA
output domain instead produces one explicit refused-batch event; no partial
observations from that batch are counted. Consumer exceptions are outside
that refusal catch and retain exact falsy/frozen primary identity. Complete
closing checks are still attempted, and invocation-local source arrays and
observation locator sets clear. No source/parser/owner/verdict cache crosses
operations. The caller's adoption registry is cloned before emitted DATA is
frozen, so a consumer cannot mutate the registry through a returned row and
the driver does not freeze the caller's original objects.

The selection is bounded at100000 paths,8MiB per physical file and512MiB of
selected source sizes. Original collectors keep their smaller source/parser
domains. Stream events retain the existing16MiB/2-million-cell/depth160 inert
DATA accounting; observation locators are separately bounded. The CLI reserves
worst-case JSON escaping before allocating its complete32MiB wire event.
Synchronous writes use at most1MiB chunks and4096 progressing writes, avoiding
Node's queued stdout accumulation. Each FD1 write is admitted and closed by
the actual protected native source-writer lease, including stream identity and
active source alias policies under the fixed executing root. There is no new
path installer or overwrite bypass. Pipe/write errors fail instead of polling.

The deferred CLI is for a later authorized observation run:

```sh
node scripts/collect-router-draft-scope-20261103.mjs FULL_COMMIT_SHA [ADOPTIONS_JSON]
```

It streams JSONL and exits2: a completed collection is not a completed
production scope. Summary counts describe native observations, assigned/stale/
unresolved observations and refused batches only. Production function
denominator, translation coverage and drafted-requirement counts stay null.
Complete role/configuration/producer review stays OPEN and semantic authority
stays false. No source count here closes L01/L02 or changes11/70 DRAFTED.

Independent case source includes distinct same-spelling observations, stale
runtime/type/case sources, changed origins, unknown producers, invalid metadata
and accessor refusals. Real temporary Git repositories exercise all three
original language collectors, complete physical/non-code selection, immutable
versus worktree source, extra evidence paths, changed case sources, changed
functions/unmatched assignments, corrupted original blob closing, frozen/falsy
consumer failures and invalid callback preflight. The expected names/behavior
are independently written. Every new test/parser/collector/CLI/receiving
execution is **UNRUN**; no local compilation, Rust command or CI inspection
was performed. Fresh complete inventory data, actual source-role/producer/
configuration review, every production adoption and full translator coverage
remain unfinished and must continue being drafted.
