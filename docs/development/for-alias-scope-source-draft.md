# Ordinary for scopes and immutable alias source draft

All implementation, source equations and independent case source is drafted
and unrun. This is no current executable coverage, full translation, source
freshness, native/target parity or whole-project synchronization result.

The shared local census now selects an actual plain for identifier followed by
in, or an underscore wildcard. Iterator element domains stay unknown. Every
concrete binder joins the original complete no-shadow/protected-name/unique-name
and count bounds; tuple/constructor/ref/mut patterns remain unsupported. Seven
family wrappers run that census for loop-bearing source even without a let.
Actual lexical braces retain the original chronological frames, so body-local
alias facts end with their scope and never become iterator-result permission.

Original text and carrier method selectors no longer discard every for-bearing
function. JSON field/owned-carrier/map/predicate selectors allow independent
alias facts only when their complete loop-bearing census succeeds; failed
censuses cannot fall back to a shadowed parameter. Existing while/general-loop
and callback-body refusals remain. Source rewriting preserves the original
iterator, body, mutation, exits and evaluation order; the full checker still
must prove actual loop semantics, types, ownership, effects and emission.

Both language/repository substitution phases, complete original source/native/
namespace/producer checks, every token/cell/frame/binder/deadline bound and all
eight same-SHA JS gates before fatal CI-only Rust remain. No loop value/type
inference, semantic authority or across-operation cache is introduced.

Eighteen complete source equations retain original implementations and owners,
serialized/reparsed CST and all inverses. Independent unrun sources cover plain
and wildcard patterns, shadow/namespace/repeated/pattern refusals, seven family
trackers, no-let and body-local scope timing, actual ordinary/bulk loop callers,
mutation/count/empty/Unicode/zero boundaries, JS/strict TS receiving, export and
native oracle behavior. All wider source/native/production/sync/freshness/parity/
delivery requirements remain unfinished.
