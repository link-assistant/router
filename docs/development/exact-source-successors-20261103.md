# Reusable exact source-successor composition

SOURCE DRAFT, UNRUN. A shared source-history algebra and repository adapter now
replace the need to invent another prefix/append matcher for each later writer
epoch. The initial fixed index references124 already reviewed whole-source
equations over118 distinct original paths in14 existing source-writer profiles.
It reuses those complete before/after artifacts without copying their payloads.
This is an explicitly partial reviewed history catalogue, not a function/sink
inventory or proof that all source ancestry has been discovered.

The reusable language stage composes only exact whole strings. Equal equations
deduplicate while retaining their distinct provenance IDs. Branches, cycles,
duplicate IDs, mixed native source languages and excessive chains refuse.
Whitespace, dollar patterns and Unicode are never normalized. The repository
adapter selects the pinned complete index and checks each entire original image
against its recorded source identity. It then replays each complete literal
substitution through language then repository stages and the actual lossless
CST serialization/reparse/inverse operation. The whole composed inverse is
retained separately from every intermediate source epoch.

`prepareExactSourceSuccessor` produces DATA for a known source predecessor. Its
target may be newer than the physical module; unrelated physical code remains
explicitly unqualified. It cannot approve that physical code or installation.
The original consumer must still perform its complete original/predecessor/
current source admission and independently verify current native import/binding,
source/CST, type/body and receiving constraints. No public descriptive flag can
replace those checks. `knownExactSourceSuccessor` additionally requires that
the complete current physical bytes equal the terminal afterimage. Unknown
candidate bytes and unknown paths return null; no source prefix or checksum
alone grants a type, namespace, caller or executable receipt.

The fixed index checksum selects a reviewed DATA catalogue, not semantic
authority. Every returned authority/native-binding flag remains false. Existing
producer APIs and their original admission domains are not changed by this
batch. Actual consumer adoption must use complete source successors and retain
their original refusal and fresh current-binding checks. The optional original
class-birth/compiler-execution refusals are not repaired by a history lookup.

The optional synchronous source operation shares only invocation-local index
and complete original text DATA. Its64-depth and16MiB aggregate retained-source
limits include distinct current/image snapshots and index DATA. Existing image
and current-source limits remain4MiB; returned wire DATA keeps the original
reconciliation bound. Every captured source is independently reread through an
actual no-follow FD at operation close, followed by all original file/ancestor
custody closers. A failure does not skip later validators. Caught source failures
invalidate active operations even after restoration; exact falsy/frozen ordinary
callback primaries remain primary. All frame/index/image/source references clear
on every exit. No source, hash, owner, body/verdict or result cache crosses an
operation. Prepare reads must close before legitimate source installation.

Independent cases cover complete chains, duplicate equations, forks/cycles,
Unicode/dollar preservation, unknown sources, bounded own DATA, real complete
native-writer source/CST inverses and operation mutation/restoration/primary
closure. The small source DATA fixture is not a miniature Host or receiving
compiler and supplies no executable authority. Runtime/original producer
adoption, full ancestry closure, receiving/performance and all original gates
remain OPEN. No tests, parser, translator or compiler ran during this draft.
