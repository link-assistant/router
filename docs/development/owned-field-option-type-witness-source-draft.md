# Owned field optional-text type source draft

Eight complete source equations draft actual JSON field ABI witnesses for
optional owned text in both outcome/cancellation translation families. A field
operation whose whole caller/source has just been privately reissued supplies
its actual declaration's ReturnType. The selector rejoins the complete native,
runtime, declaration and public root source before choosing the type name.
It selects once per TypeScript emission and only when a public/helper signature
needs optional owned text. Rust emission performs no unused type-witness scan.

This removes an unrelated Result-core type dependency from field-only callers.
When no actual field witness exists, the original Result/owned-Result fallback
remains. Type spelling or a catalog row does not authorize a caller, body,
namespace, runtime or native source. Public type-source helpers return DATA.
All original domain/ownership and private whole source reissue remain required.

The native inverse considers a field type library only for complete parsed
signatures that actually need Option<String>, and qualifies the full receiving
field source first. The projector has an explicit optional type-library DATA
hint whose default remains the original Result choice; unknown hints refuse.
Fresh complete private JS reissue and reproduction of the entire authoritative
Rust remain mandatory. No body is admitted by selecting a type witness.

Independent field-only caller cases keep Result native cores absent, and cover
nested/flat/last priority, false/zero rejection, empty/Unicode strings, JS and
strict TS, both interpreters, semantic/concrete meta and canonical Rust inverse.
Source controls cover native/runtime/declaration/root requirements, missing or
tampered sources, forged programs and unchanged standalone projector defaults.
All implementation/case/freshness/receiving/performance/platform checks and
Rust CI remain UNRUN. Broader optional-input, original namespace/producer,
production translation, complete parity and whole synchronization stay OPEN.
