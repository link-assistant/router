All implementation, CLI and regression source is drafted and unrun. No planner,
installer, CLI, compiler, test, experiment, source preparation, regeneration,
Rust tool, push or CI ran. Every unfinished [ledger requirement](bulk-draft-requirements.md)
remains open. This source installation draft establishes no executable coverage.

The additive packet planner copies the complete existing readback operation.
It reexecutes every actual selected proposer, compares every original packet,
source, graph, CST and inverse, and rejoins current physical Rust and complete
package/workspace Cargo inputs. It retains the actual Git baseline and exact
changed original/after source files, their modes and complete source inverses.
Two ordered rule sequences package this source-only plan. The original packet
review and proposal APIs keep their existing behavior.

A separate asynchronous transaction copies the complete original synchronous
installer. It awaits its actual producer, compares the complete fresh plan with
the serialized proposal, rechecks source/output inputs and the Git baseline,
then replaces each changed file atomically. Complete target readback remains
required. A later failure rolls back earlier own replacements while retaining
external changes and reporting rollback failures. This keeps the original host
boundary; it does not claim atomic visibility for an entire multi-file batch or
protection against an arbitrary concurrent same-user writer.

Every application reruns the complete physical packet review and every original
proposer. Saved metadata, matching hashes and a prior review result supply no
semantic or installation authority. The source plan retains the original 64 MiB
byte limit and bounded serialized proposal reader; complete packet evidence stays
under the existing 500,000,000-byte task limit. No source/hash/owner/verdict/result
cache crosses invocations. No native tools or dependency installation are invoked.

of `--plan NEW_FILE` and `--apply EXISTING_PLAN`, plus an optional `--root ROOT`.
Packets and newly written plan artifacts stay outside the receiving source tree.
The original 1792 MiB heap, 120-second worker and 8 MiB output bounds remain.
The canonical export entrypoint list includes the new CLI and its complete
dependency/source-profile closure. Reusable source-synchronization exports expose
both planner and guarded application.

Six complete source equations preserve native owners, both phases and full CST
inverses. Independent unrun source requires an actual receiving source change,
rejects edited proposals and changed originals, checks asynchronous waiting,
Git-baseline refusal and rollback, and qualifies the complete exported cold CLI
in an offline receiving fixture. Those cases have not run. The receipt keeps
runtime parity false and executable coverage gain null after source installation.
