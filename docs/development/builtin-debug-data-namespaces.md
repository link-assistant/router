# Original Debug data namespace closure

The private builtin output issuer now joins a source-derived Debug AST grammar
when the existing scalar output route cannot close the original input. Existing
scalar successes remain unchanged. The new route accepts bounded nongeneric
named/unit structs and nonempty unit enums through the pure original data
reader, genuine original invocation/view/profile and independent registered
Serde/Default helper proofs. Repr/packed layouts, generics, conditional fields,
unions, field defaults, macros, enum payloads and discriminants remain refused.

The complete pinned Rust compiler sources provide the TraitDef, single `fmt`
MethodDef, original receiver/Formatter parameter, associated Fn and Impl
builders. All original FmtDebug None/Shallow/Full outcomes remain represented;
both constness outcomes retain the same associated output category. Fieldless
enums follow the actual one-variant and AllFieldlessEnum control flow rather
than generating discriminant or unreachable calls. The latter branch bypasses
the shallow branch and matches actual unit variant paths to literal names.

Named records retain empty, up-to-five and larger field-count outcomes. The
larger branch uses the original two immutable `LocalKind::Init` statements:
names and values arrays followed by the original formatter call. Their
initializers, shared field projections, last-field extra address-of, generated
reference/slice/Debug trait-object types and patterns pass a recursive positive
AST grammar. Every selected expression constructor, Local/Stmt/Block/Fn/Impl
wrapper, type shape and field source span is joined to the original source
recipe/schema; an Impl wrapper alone cannot close a callback body. Actual
parser recipes preserve field visibility-to-type spans and original trait
hygiene. Names remain literal Symbol data, including source attributes with
Unicode or macro-looking text, and Expr/Local/Block token streams stay absent.

This is output confinement, not execution of the Rust compiler, generated
formatting methods or allocator helpers. Existing builder-meta execution
refusals remain explicit. It supplies no type/value namespace completeness,
Copy, no-Drop, const eligibility, pointer identity or ownership permission.
Public/frozen copies, changed sources/profiles/spans, foreign private entries,
getters, unknown/shadowed/inactive helpers and inserted macros cannot issue
namespace authority. Fresh processes reconstruct only from actual sources.

On the unchanged whole standalone `src/model_contract.rs`, all six actual Debug
owners close, including the nine-field ModelTruthDescriptor and callback-bearing
Serde fields in ModelAccessPolicy. This branch observes 46 actual owners,
22 selected outputs and 24 residuals, versus 16/30 after the Eq stage. Bang scope
remains unresolved. The same two functions, four methods and 15 refusals remain;
fmt execution, permits_resolution, Deserialize and upstream ok_or_else remain
unlowered. This is no original executable gain. Independent ordinary matches
fixtures execute emitted JavaScript and separately strict-compiled TypeScript.
