# Owned String vector current ABI and receiving source draft

Five complete source equations add the owned-text-vector current source scope,
descriptor-safe receiving configuration, receiving-root proposal and public
exports. These build on the paired eight-operation core; every implementation,
case and freshness result remains UNRUN. The follow-up
[root activation draft](owned-text-vector-root-activation-source-draft.md) adds
the actual module edge under an exact 24-equation history; it supplies no native
type/caller/namespace qualification. Production caller and delivery work is OPEN.

The scope freshly joins all eight original native/runtime/declaration/validator
inputs and their closing fences. The complete native program must have eight
public operations, the exact five helper names and the 4,096-value declaration.
Its lookup helper must retain the actual Clone/cloned source; Copy/copied cannot
qualify an owned String lookup. Each selected native signature and full body
matches the expected source role. Runtime parsing checks all eight exports,
four private helpers and actual parameter order. Strict native TypeScript
parsing checks the full declared function ABI and both complete vector/owned
optional-text aliases. Runtime `at` and declaration/native `index` parameters
are joined positionally, preserving their independently written spelling.

Consumed/shared roles derive from the selected paired shape: vector and String
arguments move, numeric arguments remain scalar, slice/vector readers borrow,
and get returns an owned optional String with no returned loan. This is a
source ABI observation, not a standard type-owner theorem or private caller
permit. All source/namespace/runtime/type-owner/root/receiving fields stay false.
Names, signature strings, CST spans and declaration aliases cannot supply the
missing original owner, method, namespace, move or helper-graph qualification.

Current receiving maps require exact whole native, runtime and declaration
bytes. The logical native path maps into the physical `rust/src` tree when the
explicit receiving entry selects that layout. The supported entries are the
flat or nested `src/lib.rs` and `src/main.rs` pairs. Root/runtime/declaration
configuration uses own plain DATA without proxies, getters, coercions, unknown
keys, unsafe paths or explicit invalid values. Real source maps use ordinary
Map internal operations, without invoking a caller's overridden `get` or
`Symbol.hasInstance`. Every mirrored runtime/declaration dependency is mandatory.

The receiving-root constructor preserves the complete original module and
source inputs. A language rule adds the required private module edge; a repository
rule publishes the explicit receiving edge. Complete original/intermediate/final
Rust CST is serialized and reparsed, with both inverses retained. Already-present
ordinary public edges produce unchanged source histories. Private, configured,
duplicate or lexical alias/import-shadowing edges refuse. Opaque original
producer source remains DATA: a constructible root does not establish its effects
or absence of competing generated bindings. Root and installation flags remain
false even when the returned source contains an ordinary public edge.

Raw native/TS trees, source spans and maps share only within one active source
operation. Current depth is bounded at 64; complete roots at 64, 2 MiB per root
and 16 Mi retained source/meta text units. Shared source-failure frames retain
their existing aggregate allowance. Closing fences run and clear all retained
trees/maps on every exit. Caught receiving-source failures invalidate active
scopes even after restoration. Ordinary application exceptions preserve their
exact identity and do not become source failures merely by being thrown. No
source, hash, owner, input, verdict or failure cache crosses an operation.

Independent cases cover all eight ABIs and their owned moves/clone roles, both
flat/nested entries and both runtime-root layouts, all receiving source rows,
complete root/meta inverses, idempotent construction, source tampering, private/
configured/duplicate/shadowed roots, opaque-producer false flags, caught failure
restoration, primary identities, depth limits, forged metadata and descriptor
hazards. No case has run. The profile retains full original source, both fixed
phases, current sources and exact inverses through an additive preparer successor.

Next obligations are native root compilation/qualification; genuine caller,
