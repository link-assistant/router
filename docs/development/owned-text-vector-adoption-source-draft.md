# Owned String-vector source adoption draft

Continue the [literal source draft](owned-text-vector-literal-source-draft.md).
Every new source proposal, private receiving check, discovery case, paired
JS/TS case, strict target, inverse and source equation remains **UNRUN**. No
local tests, parser/translator/preparer execution, compilation, Rust tool or
CI/review feedback was used while authoring this implementation.

The full-module proposer copies the existing complete primitive paired-literal
migration and substitutes the actual String-vector caller profiles, literal
and functional push/len operations. Explicit function/local/domain selections
remain candidate DATA. Native TS syntax supplies original coordinates, and
source-span templates compose nested selected edits before the serialized and
reparsed CST boundary. The complete proposed module must then pass its actual
import/type/ownership checks, meta reissuance and Rust/strict TS emission.
Original primitive proposer APIs and refusal domains stay unchanged.

Ordinary inferred empty/dense local arrays become paired literals. Discarded
single-argument pushes become functional assignments, with const changed to let
where needed; length reads become the actual u64-returning core call. Source
array elements and push payloads receive explicit qualified `router_text_to_owned`
copies. This keeps proposed JS/TS, both interpreters and emitted
Rust on the same text validation/copy contract and preserves reuse of original
immutable String values. A domain hint never relabels a bool or arbitrary object
as String; the full proposed module still requires private source/type checks.

These are explicit contract migrations. Results become frozen, lengths become
bigint/u64, vectors have the separate 4,096-value bound and literal source arity
remains at most 64. Explicit text copies retain the existing 1,048,576-byte text
input/output contract. Original input/body equivalence, ordinary array mutation
equivalence, installation, production selection and runtime parity remain false.
No raw original body is overwritten and no generated output is manually edited.

The source templates retain array interiors and individual original element
spans, including comments, whitespace and trailing separators. Push templates
retain argument trivia and move only comments from the replaced receiver/member
region before the new qualified call. Nested edits inside another selected
initializer or payload remain attached to original coordinates and cannot be
silently lost. Complete original text and full inverses are retained.

Ordinary written `string[]`, readonly string arrays and Array/ReadonlyArray of
string locals/results receive actual paired utility-type witnesses. Direct
numeric length results receive the actual len return witness only when every
return directly reads a selected vector's length. Other numeric return shapes
need their own explicit rule and are refused. These written-contract proposals
still cannot supply missing original semantic or namespace authority.

The paired API first requires the complete existing JS to equal the native
annotation projection of its TS source. It changes the written TS once, derives
the corresponding JS, privately checks that exact derived source and retains
both original files, histories and inverses. Differing concurrent JS is a
conflict rather than implicit overwrite. The original TypeScript projection
API, original source paths and runtime/declaration-root mapping remain intact.

Automatic discovery inventories complete requested JS/TS modules, or derives
the application paths while excluding declared runtime roots. It is bounded to
32 modules, 4,096 candidates, 8 MiB original source, 200,000 syntax census nodes
and 32 MiB retained metadata. It reports explicit unsupported syntax and retains
complete changed/unchanged source inverses. Parser, source/host, resource and
inverse failures remain fatal. No caller-supplied proposer is invoked.

Discovery returns syntax-only proposals: no typed program, code admission,
executable coverage or qualified production function count. Original domain and
whole-module semantic reissuance remain required. A separate full-module API
performs that private check; the syntax-only API intentionally exposes no IR
issuer. Observations, false authority fields and public candidate counts cannot
replace the actual source proof. No across-operation cache was added.

Independent source cases cover both profiles, actual original/adopted/strict TS
targets and interpreters, Unicode/NUL, full meta/inverses, nested substitutions,
comments, explicit resource errors, written type contracts, repeated owned
String uses, wrong domains, aliases, consumed/spread/receiver-dependent pushes,
source tampering, discovery qualification boundaries and paired-source conflicts.
All case and receiving execution remains UNRUN.

Original Rust source adoption, captures/aggregates/references, async/network/state
coverage, all original owner/namespace qualification, complete exported receiving
qualification, platform/profile freshness, performance/resource evidence and
full bidirectional synchronization remain OPEN. No current completion or
coverage percentage is established by these source proposals.
