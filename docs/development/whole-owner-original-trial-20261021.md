# Isolated whole-owner original derive trial

This is a source-only trial preparer. It does not change the default creator,
the old canonical trial harness, or any of the original twelve cases. It adds
an explicit two-file overlay trial on top of the existing canonical candidate,
so its eventual result must remain distinct from the failed canonical-only
81,936.854292 ms case and from baseline measurements.

`prepare-whole-owner-original-trial.mjs` mechanically copies the complete
actual `prepare-builtin-canonical-trial.mjs` using installed TypeScript 5.9.3
declaration spans. Its language phase adapts only the actual proposal, packet,
preparation and verification functions to the finite multiple-source equation.
Its repository phase selects a distinct schema and support import. Every
untouched original function has a complete byte inverse; changed functions
retain their full original declarations. The complete runner has a serialized,
reparsed CST, native copied-binding check, both phases and whole-source inverse.
No generated source is edited by hand.

The generated runner keeps the original API names within its separate module.
It retains the complete actual compiler source contracts, installed TypeScript,
all Rust/Cargo/scripts, and the entire original test/import/helper/resource
closure. No unrelated archive is added, no original workload input is removed,
and uncertain dynamic dependencies still refuse. Original per-file 32 MiB,
total-input 256 MiB, 8,192-file, 384 MiB storage and 240,000 ms enclosing trial
bounds remain unchanged. All twelve original bodies and the two declared
60,000 ms case limits remain byte-identical.

The fresh proposal first reissues both actual source producers and the actual
runner source equation. All seven current footprint issuer copies and the
generated crypto wrapper source must already match the actual producer output.
Every such complete input must appear with identical bytes and hash in the
full original frozen vector. Required-input records supplement the original
full discovery; they do not replace it or establish compiler authority.

The two physical source changes in the isolated mirror are:

1. The existing actual canonical candidate occupies `builtin-source-meta.mjs`.
2. The actual complete whole-owner creator copy occupies
   `derive-bang-context.mjs`. Its genuine native declaration of the original
   public `createDeriveBangContext` has its body explicitly routed to
   `createWholeOwnerDeriveBangContext`. Its original private uncached creator
   remains the exact callback/intrinsic fallback. Import relocation retains
   the whole copied issuer closure, so original resolver imports see the same
   physical private creator issuer.

The proposal retains the entire original and candidate sources, original
public function, native body spans, both CST phases, serialized/reparsed CST,
complete inverse and source-producer evidence. Installing the additive copy
without this explicit entry routing would run the old creator and is refused
as the intended trial equation. The default implementation remains unchanged.

Every input has an independently reopened gzip packet. Unchanged trial bytes
are associated with the one complete original payload. Both changed files keep
their complete candidate bytes. The reader reconstructs both versions and
checks the entire packet, original mode/length/hash, candidate bytes, source
association, actual current root and actual mirror. Aliased changed files,
unlisted changes, forged nested fields, extra overlays and missing inputs
refuse. Fresh discovery and source-producer checks run again during inspection
and after execution. No source/verdict/encoded cache is introduced.

Under Root's sole resource lease, after materializing the whole-owner candidate:

```sh

node tools/translation/prepare-whole-owner-original-trial.mjs --check
node --test tools/translation/test/whole-owner-original-trial.test.mjs
node tools/translation/whole-owner-original-derive-trial.mjs --prepare --root "$PWD" --output /private/tmp/FRESH_TRIAL_DIRECTORY
node tools/translation/whole-owner-original-derive-trial.mjs --check --output /private/tmp/FRESH_TRIAL_DIRECTORY
node tools/translation/whole-owner-original-derive-trial.mjs --run-node --output /private/tmp/FRESH_TRIAL_DIRECTORY
```

The unchanged Bun command, full raw streams, actual waited resource receipt and
`--join-bun --output PATH --request REQUEST_JSON` remain separate obligations.
The copied Node/Bun joins retain full original source/deadline associations and
reject missing, duplicate, skipped or over-deadline cases. Four new complete
60,000 ms receiving controls cover source copying, actual entry routing and
unchanged twelve-case identity, full packet reconstruction, and corruption
refusals. All preparation, receiving and original workload execution is unrun
for this source draft. No performance or executable coverage gain is claimed.

The creator's scope excludes later resolver reproofs. A fresh explicit whole
resolver operation requires a separate source equation and trial overlay; it
must not reuse the creator's closed binding frame or surviving private digest.
