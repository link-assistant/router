# Bounded native JSON caller registration source draft

SOURCE ONLY. All implementation and cases are UNRUN. No parser, translator,
preparer, planner/installer, tests, experiments or compiler ran. CI feedback is
uninspected. Full drafting and all delivery requirements remain OPEN.

The bounded JSON call selector is a complete source-derived copy of the existing
Router facade selector. It checks the actual root declaration, physical external
module, complete native source, module views, resolved binding set and active
configuration. Qualified calls also require the actual JSON parser's sealed
locked dependency/feature context, joined to the same original module bytes and
view. Arbitrary std/serde feature configurations cannot acquire this domain from
public flags, a type name or a copied context.

Three deeply frozen contracts register validation, copy and field update in the
existing JSON runtime family. They require private source refinement; generic
host lookup cannot bypass the actual qualified caller/module route. The parser
retains the complete source/CST inverse and the existing original JSON-call
custody. The checker accepts only canonical shared JSON inputs and borrowed str
keys, checks exact arity/result/ownership, and stores the existing private source
receipt. Mutable/nested borrows, nominal lookalikes, missing dependency contexts
and changed native bytes remain refused.

The existing JSON linear-flow checker recognizes the three actual privately
issued calls. Validation returns unit without moving the borrowed input;
copy/update return newly owned canonical JSON while preserving input loans and
caller evaluation order. The actual bounded library source hash is retained in
its source boundary. No cache, saved semantic verdict or new host callback can
supply permission.

Four complete source equations preserve both preparation roots, full originals,
CST inverses and language then repository phases. Independent unrun source covers
shared validation/copy/update, nested owned vectors, exact node/depth/result
bounds, input preservation, frozen contracts, actual dependency/namespace/source
refusals and full source inverses. Native library oracle source remains gated on
eight same-SHA JavaScript stages. No Rust tool ran locally.

Native JSON emitter integration, validation of every native input on empty
branches, exact whole-body reproduction, source-unit synchronization and all
broader namespace/trait/production/receiving/race/platform/performance/CI work
remain OPEN. This source registration is not verified executable coverage or
runtime parity.
