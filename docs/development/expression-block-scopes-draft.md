# Native expression block scope source model draft

All new implementation and independent cases are UNRUN. Only source construction
and review occurred. No source reader, scope model, parser, translator, preparer,
test, experiment, generation, local Rust tool or CI-triggering push executed.

The native source closure copies the complete existing confinement reader and
retains thirteen current inputs, forty whole callbacks and seven full receiver
containers. It includes the original attribute/expansion parser and visitor,
reduced graph visitor, definition collector and parent-module constructors.
The source includes the actual block Item/MacCall predicate, child block module
construction, parent module/textual scope restoration and separate crate-root
macro-export path. Whole original files, licenses, manifests, callback spans,
hashes, receiver text and complete serialized/reparsed CST inverses remain
required under the original 8 MiB and 200000 inventory-cell bounds.

An additive source model consumes only a genuine shared Header expression frame.
It records child module transitions for original blocks with item or statement
macro nodes, local function/import/macro-definition sites, parent restoration and
opaque invocation/attribute obligations. Modeled IDs are explicitly separate from
native resolver/module identities. A final fresh packed-input rejoin checks all
native sources without building a second complete native inventory; the original
header identity/source is checked again. No source, hash or verdict cache crosses
operations.

This source model does not execute the complete native visitor or qualify its
actual receiver, native AST statement mapping, module construction, import/proc
stub behavior or type-namespace isolation. All such fields remain false, as do
source, type, namespace and runtime authority. Unknown expansion bodies and
attribute arguments remain pending. Explicit global bang exports are kept open;
no model result is used to close a production namespace or admit executable code.

Four full compiler source equations preserve the original reader bodies, native
owner spans, ordered language/repository substitutions and physical inverses.
Independent unrun cases cover whole source closure, plain/opaque expressions,
mixed Item/MacCall/Ty/Expr block roles, sibling restoration, local declarations,
source/private refusal and native Rust block type/import/export behavior. The
actual mutable visitor, parent scope and complete native-model bridges remain
implementation obligations, alongside every unfinished production translation,
parity, reverse/sync, freshness/CI and receiving requirement.
