arguments: known normal ungated builtin names and the qualified `rustfmt::skip`
grammar candidate. It checks the complete written header through serialized and
reparsed lossless CST/meta, then applies the positive bounded path/empty-argument

domain and the pending original caller, namespace and semantic obligations.
The existing parser and normal-ungated caller APIs keep their old contracts.

The operation freshly joins twelve complete retained Rust parser callbacks,
their actual containing owners, the original registered-name set and complete
source fences. Every callback has a whole CST inverse. Sharing ends with that
operation; private request identities retain inputs only and rejoin actual
header/source associations on each observation. No source, hash, owner, verdict
or result cache crosses operations. Input bytes are bounded before CST work;
path, nesting, callback cells, total header records and architecture source-cell
limits stay finite. Async/proxy/thenable escape is refused without reading getters.

This is a written-source grammar model, not execution of rustc or qualification
of its opaque/hygienic macro AST inputs. Retaining complete native callbacks
does not establish that the model is a complete translation of those callbacks.
`nativeCallerGrammarQualified`, `originalCallerPresenceQualified`,
`opaqueMacroInputsQualified`, `callerOwnerResolved`, `typePrefixAbsenceQualified`
and namespace/runtime authority remain false. A written `rustfmt::skip` still
