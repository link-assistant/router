# Automatic primitive Option callback adoption draft

Four complete source copies extend the existing method selector, corpus,
compressed packet sequence and fresh selected installer for ordinary `map`,
`and_then` and `unwrap_or_else`. Immutable closed primitive inputs, captured
borrowed text, simple result constructors, literal results, explicit callback
result domains and chains produce qualified compatibility-core proposals.
The callback body is preserved for the independent whole-function checker.
Unknown callback domains, mutable inputs, shadowing and unresolved producers
remain preserved rather than receiving an inferred semantic permission.

The new packet sequence is `primitive-option-callback-methods`. Installation
recomputes the complete current source proposal, checks every selected full
function and its native dependencies, and retains full CST/inverse history.
Original selectors, API names, complete workloads and deadlines remain intact.
All four source copies declare language rules followed by repository rules.

Independent source cases cover actual forward callers and strict TS, nested
chains, captured output lifetimes, false/zero/empty, lazy text ownership, packet
equations, source edits and stale/forged installation. These cases and all new
implementation are unrun. This family does not qualify application coverage,
general closures, Result, other effects or the remaining bulk-draft ledger.
