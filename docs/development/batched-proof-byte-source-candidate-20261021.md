# Explicit batched proof-byte source producer

This source proposal derives a separately named copy of the complete existing
byte producer. Its original standalone API remains unchanged. Native TypeScript
selects the actual nested `whole()` function, its original return record, both
phase sequences, original inverse expressions and unchanged Hash-call guard.
Only CST work moves: all nineteen source files and fifteen physical overlays
finish their original raw/native assembly first. Placeholder CST fields retain
the exact old property order, including the spread copies used for overlays.

The new producer submits complete requests in deterministic groups of at most
three rows to `substitutePrivateConcreteSourceBatches`. Each bounded operation
retains the original 32 MiB aggregate canonical limit, full per-rule
serialize/reparse behavior and both full inverses. Every fragment is parsed and
joined to its unique actual raw source record. All thirty-four results must
exist before return. There is no truncation, cap increase, omitted inverse or
across-invocation cache. An actual over-budget chunk refuses.

The measured current fragment total is 63,488,129 bytes with a 7,817,903-byte
largest row. These measurements informed a conservative schedule; they confer
no source authority and do not replace current bounds. The current operation
still enforces its actual complete byte/node limits. The private parser's full
original substitution implementation is already registered; no bank permission
or new semantic authority is added.

Complete input strings and private parser host checks fence all chunks, and
the original final Hash/source checks remain. Additional provider, copied
producer, bulk API, operations helper and generator source inputs are freshly recorded and
rechecked. The current physical trial includes those exact sources in its
frozen source census. Original thirty-four row fields and every existing plan
field remain equal; `currentProviderInputs` is an explicitly additional source
obligation. The source-cost schedule differs from the standalone producer;
no unrelated callback schedule equivalence or speed gain is claimed.

A native/CST import adapter selects the same explicit current provider in the
whole seven-case byte test, its physical-trial support, and the new Core stream
producer. All seven test bodies and 60000 ms deadlines remain byte-identical.
The support/source-producer adaptations add only the declared source-input
census. Original twelve-case harness bytes stay unchanged.

input emitted by the formatting producer without treating a metadata label as
