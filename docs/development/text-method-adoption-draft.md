# Automatic text method adoption draft

The text corpus producer, compressed packet producer and checked installer are
complete copies of the corresponding integer-method implementation. Their
original sources, native-selected substitutions, separate language/repository
sequences and complete CST inverses are retained by
`prepare-text-method-adoption.mjs`. Every selected complete function must freshly
translate before installation; saved candidates and public operation IDs supply
no semantic, namespace, ownership or original trait-dispatch proof.

The selector drafts immutable written `&str` inputs, explicit simple lifetimes,
borrowed local intermediates and method chains. It covers trim variants,
emptiness, substring/prefix/suffix predicates, literal replacement, closed-count
repetition and replacement, prefix/suffix stripping, and byte/scalar/match counts
with an explicit `u64` cast. Arguments retain source order. Mutable or shadowed
bindings, unknown producers/macros/closures, traits, generic receivers and
effectful or unproved arguments remain preserved for another rule sequence.
Dynamic `usize` conversion, arbitrary iterators and index-option mapping remain
separate obligations. The compatibility core's bounds are explicit API adoption;
the proposal does not assert unrestricted original-method parity.

The receiving asset builder and independent strict-target helpers are complete
source copies too. They package text assets and preserve existing generic integer
exports while reexporting the bounded integer operations from a distinct source
module. Historical pinned host/ASCII producers keep their original source.
Canonical complete bulk output integration remains open.

Independent source cases include complete native callers, both emitted targets,
Unicode boundaries, chained and local operations, lazy Boolean expressions,
source inverses, compressed packets, selected fresh installation and refusals.
All implementation, test and source-preparation code remains unrun. These drafts
do not establish production coverage, parity, receiving qualification or green CI.
