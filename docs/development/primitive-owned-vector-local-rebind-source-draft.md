Status: SOURCE DRAFT ONLY. All receiving, JavaScript/strict TypeScript,
canonical native inverse, freshness, native oracle and performance execution
remain UNRUN. CI feedback was not inspected. Full synchronization is OPEN.

JavaScript and TypeScript let-bound owned primitive vectors can be moved into
a checked functional core operation and rebound to its checked owned result.
The actual lexical symbol, identical domain and absent returned loan are still
required. Rebinding restores availability only after the right-hand expression
has passed checking. Const bindings, aliases used after move, duplicate
consumption, indexed mutation and partial branch reinitialization stay refused.
All eleven primitive domains use the same substitutions in both owned caller
families. Existing scalar and JSON assignments retain their prior rules.

Native mutable initialization requires the existing genuine original let
membership and an actually privately checked owned-vector core call. Native
reassignment uses the actual mutable slot, exact primitive vector type, complete
right-hand move analysis and live-loan checks before/after evaluation. Loop
reassignment remains explicitly refused; callback captures, public Vec inputs
and arbitrary aggregate mutation receive no permission. Native initializers
through ordinary helper calls still need a separate initializer rule.

The existing independent all-domain whole-caller receiving source now includes
mutable construction through emitted JS, strict TS, both interpreters, semantic
and CST/meta reentry, typed reverse translation and canonical Rust inverse.
Native forward receiving source includes move/rebind construction as well.
Additional independent cases cover moved-slot reinitialization and branch
availability. Eight whole source equations preserve frozen original APIs,
ordered language/repository substitutions and exact source inverses. These
cases are unrun obligations, not evidence of completion.
