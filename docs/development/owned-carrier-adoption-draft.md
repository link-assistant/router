# Automatic owned carrier adoption source draft

The separate carrier adopter copies the complete field adopter, bounded packet
producer and freshly checked installation transaction. All three originals stay
unchanged. Its native-selected source preparation retains complete originals,
ordered language/repository substitutions, CST serialization/reparsing and full
source inverses.

Source rules recognize single-use canonical Option/Result inputs with eager
JSON defaults, Result `.ok()`, and literal `ok_or`/`ok_or_else` errors. A shared
carrier input requires its explicit clone in the original source. Parameter
roles come from fully qualified standard types or actual fixed owned-facade
aliases; module/producer/import/Cargo uncertainty is preserved. Unknown error
callbacks, repeated receivers/defaults, generic bodies and unknown effects stay
unchanged. Closed type maps and a charged total scan bound avoid repeated whole
parameter/body searches. No benchmark or speed gain has been measured.

Adoption is an explicit maintainer-owned API proposal. It does not prove the
original method or destructor dispatch, original Drop timing, native parity or
executable behavior. The copied installer recomputes the proposal against actual
physical sources and requires every selected complete replacement function to
pass the fresh private forward checker, semantic meta and JS/TS emission. It
retains exact source/target review before the original bounded transaction.

Use `proposeCoreOwnedCarrierCorpus`, the packet producer's `owned-carriers`
sequence, and `planCheckedOwnedCarrierAdoption`/`applyCheckedOwnedCarrierAdoption`
in their separate modules. Packet/file/total byte bounds and source protection
are retained. No operation applies a saved candidate as compiler authority.

Independent full source, strict target, producer/refusal, packet and selected
installation cases are drafted and unrun. Production application, broader
carrier forms, original-dispatch equivalence, effects, full parity, CI/freshness
and the remaining complete requirement ledger remain open.
