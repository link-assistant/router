# Source-bound wrapping constant draft

This implementation and every new regression are source drafted, unrun. It
establishes no complete translation coverage, source-history qualification,
current freshness, synchronization parity or JavaScript gate result.

The bounded checked-IR constant evaluator now selects wrapping_add/sub for the
ten actual by-value native fixed domains. Its original constant declaration,
private parser source links, checked types, whole-function eligibility and
no-Drop requirements remain. A const flag, pure runtime adapter or method name
cannot qualify another host method. The original Duration lane remains intact.

Selection requires the exact fixed family, canonical monomorphic method ID,
actual primitive owner, receiver, operands, return and runtime width/signedness,
const stability 1.32.0 and the full fresh original primitive member/intrinsic
proof. Serialized metadata receives descriptor-only bounded copying and a fresh
full source comparison. Source/archive failures remain fatal; a changed metadata
premise is an explicit unsupported constant. A unit fixture with unlinked source
still records sourceLinksVerified=false and cannot grant production admission.

Operands evaluate once, left to right, under all original eligibility and value
checks. Checked overflow inside an operand still panics before wrapping begins.
The selected method computes exact BigInt addition/subtraction and interprets
its residue in the proved fixed signed/unsigned range. It executes no emitted
code, caller callback or runtime adapter. Trace entries retain the complete
source profile and exact member/intrinsic hashes. The target profile includes
this real source profile and method list, so private source links bind the
current evaluator contract. No manually substituted golden digest is supplied.

Every evaluation uses the bounded fresh source operation. Only current inputs
can be shared through the eligibility and evaluation passes; all original step,
call depth, node depth, value cells, serialization, source and normalization
limits remain unchanged. No source or result cache crosses evaluations.

Two complete source equations preserve the original evaluator and both
language/repository rule phases with whole source inverses. Independent written
cases cover all ten domains, constant-function dependencies, real source links,
semantic meta, strict TS, signed/unsigned extrema, checked operand overflow,
panic order, exact source/contract premises, ownership/pointer/generic refusals,
non-execution of getters and original low/raised budget controls. Rust constant
oracles are written for later gated CI. Every case and integrated source/export/
freshness/performance/parity obligation remains unrun.
