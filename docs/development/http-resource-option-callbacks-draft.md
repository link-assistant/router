# Actual primitive Option callbacks and source units: source draft

All implementation, receiving cases and native oracle source remain unrun.
Actual Option mapping, chaining and lazy fallbacks now reuse their complete
original primitive callback library, matching runtime/declarations and native
module edges. Scalar/owning output domains use whole inline/helper callback
checking, read-only captures and actual contextual signatures. Borrowed callback
outputs and unsupported numeric domains retain their separate refusal boundary.

The optional native library is qualified only when an actual bound Option
callback operation is imported. Every source/currentness check reissues its
complete native/runtime/declaration census. A private per-analysis selection
flag records which inputs to recheck; it never saves a verdict across calls.
Older caller contexts and required source-unit mapping lists remain intact.

The existing source-unit contract already accepts complete additional native
mappings within its original 32-row bound. A complete copy of the original
private physical receiving setup now supplies that actual optional module and
all unchanged transaction, conflict, runtime mirror and source checks. Its
original four tests remain in their original file; full removed source is
retained in the copied helper's inverse. New independent unrun source cases
exercise successive physical Rust, JS and TS edits, changed native inputs and
forged proposals without altering the original transaction implementation.

Complete original contract, capture and physical setup copies retain native
spans, language then repository substitutions, serialized/reparsed lossless CST
and full inverses. Independent unrun JS/strict TS/native cases cover skipped
None callbacks, exactly-once fallbacks, zero-argument closures and helper items,
Unicode, owning moves, wrong domains and missing sources. The native fixture
joins existing gated CI discovery. Borrowed-output callbacks, generic/method
signatures, namespace/bootstrap, production adoption/parity and every other
unfinished requirement remain open.
