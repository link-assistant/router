# Common operation composition in resource callers

All implementation and independent case source remains unrun.

The complete HTTP source lane now composes the existing matching text,
callback-free primitive Result and JSON carrier libraries. Domain substitutions
retain actual native paths and runtime imports. Wider numeric/callback domains
remain with their original checkers. No callback is erased and no new numeric
domain is inferred from spelling. The original complete text/Result/carrier
native and runtime checks were already required by HTTP source capture and
remain mandatory for every new operation.

Direct Option values have explicit native domains, move once, retain any actual
borrowed string root and may be passed to registered operations or returned
whole. Unguarded payload extraction remains refused. Result constructors,
predicates, owned fallbacks and adapters use actual by-value source flow, so
already consumed containers cannot be reused.

String views retain their original public string/JSON root or named local owned
String root. Views of local Strings may feed operations that produce owned
outputs inside the same function. Such views cannot escape, and their owned
source cannot move while a retained original view is live. This intentionally
conservative loan tracking does not claim general nonlexical lifetime support.
Literal string roots are static. Nested borrowed Result/Option conversions
retain the actual source root through the whole checked call tree.

The existing canonical inverse selects all new actual qualified native paths,
proposes complete JS and reproduces the entire native source through the fresh
caller checker. Both source directions and physical units use the existing
serialized/reparsed CST, checked semantic boundary and full inverse equations.
Complete original registry/flow/lifetime sources and native-selected ordered
substitution recipes are retained.

Independent source cases cover Unicode normalization, borrowed prefixes,
UTF8 lengths, nested Result/Option moves, JSON carriers, local view escape,
moving an owner with a live view, duplicate Result use, unguarded payloads,
native tampering, canonical inverse reproduction and actual JS plus independently
compiled strict TypeScript. A handwritten native oracle is reserved for gated
CI. No runtime, translator, preparer or test was run.

Option guards/branches, generic callbacks, broader mutation/state/async syntax,
namespace/bootstrap closure, production adoption, receiving/CI qualification and
all other unfinished requirements remain open.
