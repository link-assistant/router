# Invocation-local Rust lexical DATA

This is an unexecuted, opt-in source proposal. It grants no source, native grammar, semantic, type, owner or executable authority, and makes no measured performance claim. Existing public project entry points select their existing implementation. The new `translateProjectOwnedDefinitionsLexicalData` facade calls the original `translateProjectOwnedDefinitions` export inside a synchronous lexical scope; its private issuers remain in the original module.

`prepare-rust-lexical-data.mjs` retains the complete original `rustTokens` body as `__originalRustTokens`, binds a distinct private factory to that exact function, and exports a one-argument `rustTokens` wrapper. Outside a scope the wrapper directly calls the private original. `sourceItems` remains byte-for-byte unchanged. Errors are never stored; original lexer errors propagate. This source transformation changes implementation source and call frames; it does not promise historical error-stack coordinates or cold module-bootstrap callback parity.

Within one scope, keys consist of a private factory identity (including the captured exact fallback function) and the exact primitive UTF-16 source string. A separate public factory cannot address the genuine lexer table, even when source strings or callback functions coincide. `createRustLexicalDataFactory` explicitly declares a **new callback schedule**: first qualified result, then detached DATA reconstruction for hits. It is not a purity verifier for arbitrary user callbacks. Only the complete, pinned original lexer supplies the genuine Rust path. A custom factory's fake classifications issue no semantic or owner authority and never enter the real lexer table.

The first original result is returned unchanged. Before returning it, the scope privately copies qualified rows into frozen, unreachable arrays. Every hit returns a fresh ordinary dense mutable array, with fresh ordinary mutable objects whose four own properties are `type`, `text`, `start`, `end` in that order, all enumerable, writable and configurable. No returned object aliases a stored object. Coordinates remain UTF-16; NUL, escapes, lone surrogates and supplementary characters remain distinct exact source keys.

The genuine factory admits only empty or LF-terminated source. A cache hit for a nonempty admitted source replays the exact original final native whitespace test, preserving RegExp legacy statics; non-LF inputs use the complete original lexer without disabling valid entries. The replay expression is checked against the actual native lexer whitespace expression. Empty-source hits perform no regex operation. The public custom factory has its explicitly new callback schedule; arbitrary callbacks receive no claim of regex-state parity.

Admission requires qualified original namespace/static-source, lexing and DATA-freeze intrinsics before and after each scoped lexical operation. Changed operations retain the original fallback. Observing a change clears and disables every active frame; restoring an operation later does not reactivate those frames. Changes made and restored between lexical operations are not claimed to be observable. In the genuine qualified successful lexer there is no external callback during execution. Nonprimitive source inputs keep the original property/coercion behavior and are never admitted. Proxy callbacks, proxy/aliased/accessor/exotic/sparse/extra-field results, invalid coordinate DATA and over-budget results stay on the original callback path. Shape inspection does not invoke getters or proxy traps.

The operation's nested scopes share nonrefundable admission accounting: 4096 entries, 200,000 tokens, and 16 MiB charged storage. Charges include both UTF-16 source bytes, both token text/type bytes, 128 bytes per source/factory entry, 16 bytes per token array slot, and 192 bytes per token snapshot. These are explicit conservative storage charges, not an engine heap/RSS bound. A rejected admission does not widen any existing parser budget or cache an error. Entry/source saturation disables the active stores. Native fallback still computes the complete original result. Nested frames keep separate maps, destroy them in `finally`, and restore their parent. There is no source/hash/owner/verdict/encoded cache across invocations.

Scopes reject proxy, async and generator callbacks before calling them. Return inspection rejects Promise, proxy and own/inherited `then` descriptors without invoking a getter. No frame survives a return or exception; an ordinary callback returning a Promise is rejected after that callback has run, and no scope remains attached to later Promise work. Original synchronous project result objects are returned unchanged.

The producer authenticates each complete source afresh, checks actual native import/function bindings and detached native copies, runs ordered language then repository CST serialization/reparse with complete per-phase inverses and an independent edit inverse, preserves the original Hash/JSON call sites, and rereads every source/archive at EOF. The two authored helper/facade rows use complete identity source equations. There are two proposed existing-file changes: the Rust wrapper and an additive vendor owner predicate. Both original vendor public function bodies remain exact. The owner predicate privately captures trusted native operations only while the existing static-source guard qualifies them; it accepts no caller operations. Each call checks the genuine PUNCTUATORS identity/prototype and every own descriptor/value against the complete native-selected original literal. This closes a real escape: a past overridden Array.find can retain and mutate that private array while current intrinsics are native. The original Rust dispatch cannot reach REGEX_AFTER: native symbol joins account for every reference/call, and the only regexAllowed call is the last conjunct after the genuine language parameter strictly equals JavaScript. Complete original branch/helper bodies remain in the source plan. A subsequent project/guard/source edit must obtain a new explicit source composition; the current producer refuses an unknown predecessor.
