# Shared written immutable local source draft

All implementation, complete source equations and independent case source is
source drafted and unrun. Full translation, executable coverage, current source
freshness, native/target parity and synchronization remain unfinished.

One bounded declaration rule now separates the written type from its actual
initializer, retaining native token coordinates, lifetimes and bracketed array
semicolons. Joint closing-angle/equals punctuation is split only in the
bounded written-type projection, retaining its original punctuation offsets.
Each source operation has a fresh annotation map. General alias
rules delegate the written domain and concrete operand grammar to family rules;
a written type cannot create a value fact. Both concrete operands and selected
whole initializer results must match that domain before their actual semicolon.
Unknown, malformed, overlong, mutable, future, out-of-scope, shadowed and
mismatched bindings retain existing refusals and false semantic authorities.

Seven family adapters reuse this mechanism: fixed integers, text/native counts,
base64, primitive/owned-text carriers, shared JSON field/key/index inputs,
JSON slice/vector inputs and owned/shared JSON carriers. Fixed scalar literals
may use their exact written domain only within its real signed bounds. Native
usize literals retain the existing portable u32 bound. Canonical Json written
types are explicit repository spellings; no custom alias or &mut is inferred.
The existing closed loop prefix rule uses the same bounded declaration reader.
Text adoption also uses it to select complete written String result chains.

Both original substitution phases, every original source/namespace/producer and
whole-function type/ownership/effect/emission check, all source token/cell/frame/
binder limits, original stage membership and all eight same-SHA JS gates before
fatal CI-only Rust remain. No cross-operation source/hash/owner/verdict/result
cache or public metadata permission is added. The old text-only declaration
scanner is removed through its exact native function owner equation.

Eleven complete source equations retain complete original modules, native owners,
serialized/reparsed CST and full inverses. Independent unrun sources cover all
seven families, matching/mismatched/unknown annotations, scope and semicolon
ordering, selected-result equality, array/lifetime syntax, all ten native scalar
boundaries, portable count bounds, five real bulk stages, fresh JS/strict TS,
export receiving and gated native oracle behavior. Earlier refusal cases now
retain explicit mismatches, with new positive cases for supported written forms.
Every wider source/native/production/sync/freshness/parity/delivery requirement
remains unfinished; no qualification or new executable count is claimed.
