# Bulk source-family proposal entrypoint

The additive `tools/translation/bulk-source-family-proposals.mjs` provides stable
names for the three independently drafted 2026-11-01 automation families. All
new implementation and case source remains **UNRUN**. Import/receiving/export
qualification has not been executed. This entrypoint broadens no semantic domain.

| Export | Complete operation and retained limits | Open integration |
| --- | --- | --- |

Complete closing fences, full DATA occurrence budget, inverses and refusal domains remain mandatory. | Arbitrary lazy iterator/capture semantics, actual production adoption, wider collection families, copied compiler receiving and source installation. |

DATA only, never semantic or install authority. | Semantic equivalence, rename/deletion/import/module reconciliation and application behavior are not inferred from equality. |

Each family retains its separately declared `language` then `repository`
sequences and serialized/reparsed CST/meta/source checks. Operation descriptions,
proposal flags, matching names and source hashes cannot substitute for private
source/type/ownership/effect/caller checks. Stable reexports introduce no alternate
parser/checker or relaxed admission path.
