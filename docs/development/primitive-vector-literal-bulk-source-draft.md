# Bulk paired literal source migration

Four complete source equations draft an additive literal migration API and a
reusable language-independent original source template composer. The earlier
empty-only and nested-push literal APIs retain their original source/refusals.
The new proposal explicitly selects each function/local/domain, replaces its
initializer with one paired variadic constructor, maps discarded single push
and length operations, and groups imports by the actual runtime module.

Source templates use literal strings plus explicit spans of original source.
Nested selected edits are composed only within retained source references;
crossing/duplicate/stale/dropped/repeated/surrogate-cut edits refuse. Ordered
references prevent duplicated argument evaluation. The resulting nonoverlapping
root edits still pass through lossless serialized/reparsed CST substitution,
then a complete fresh private JS/TS source recheck. Exactly language and
repository phases remain; no new semantic authority or across-operation cache
is introduced. Source, template/text/render/row/cell/depth bounds are explicit.

This handles selected vector initializers or push operands that read another
selected vector's length in one batch. Before this source draft those nested
original spans overlapped. Within-operation complete source sharing and closing
fences include all twelve core/literal inputs; no hand-written generated output
is installed. Mutable-array/frozen/bigint/resource contract changes remain
explicit: original equivalence, production selection and installation are false.

Independent all-domain both-lane JS/TS/interpreter/native inverse migration
cases, cross-local nested literal/push cases and generic CST/template/data/
budget/refusal cases are SOURCE ONLY and UNRUN. Original production namespace
closure, receiving qualification, freshness, platforms, complete parity and
full repository synchronization remain OPEN.
