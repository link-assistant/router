# Primitive vector expression source draft

Source only; all cases UNRUN. Full translation remains unfinished. This additive
family joins actual owned Vec<bool> and Vec of the ten fixed-width integers with
the existing scalar operators, same-module scalar helpers and guarded failure
continuations. No generated production outputs or Rust compatibility core
internals are hand edited.

Both actual native source-capture copies and native discovery select the family
only when the complete primitive runtime/declaration pair exists. The current
private source context independently authenticates every byte. Original source
signatures, spans, full file digests, lowerer joins, actual element domains,
serialized/reparsed meta/CST and full native census comparisons remain required.
Presence, public profiles, preserved source and observational models are not
semantic authority. Each operation reissues the complete input and closes with
fresh fences; operation-local sharing introduces no cross-operation caches.

The bounded native container observer requires genuine qualified constructors,
finite immutable local aliases, exact scalar element domains and Boolean
branches. Every owned alias consumes its predecessor once. Containers cannot
hide in scalar operands or escape through unsupported borrows/calls. Receiving
source independently enforces the same move restrictions. Even unused containers
retain their element failure events; left-to-right element evaluation and the
first panic stay visible. Continuations sequence guarded elements and remaining
items without evaluating unselected arms.

Shared rules now draft native-to-JavaScript/TypeScript discovery, receiving
source re-entry, reverse emission, ordered body comparison and the interpreter
together. Pure vector branches may normalize into conditional values only after
both branches and their full event prefixes have been checked. Float, owned text,
static text and pointer-sized primitive vectors retain their original literal
lane. APIs without the extended runtime pair retain that earlier lane.

Fifteen complete source equations preserve full originals, exactly language then
repository substitution sequences, lossless CST transport and complete inverses.
Independent all-width JS/strict TypeScript/forward/reverse/interpreter sources,
bulk and discovery cases, malformed/move/source-byte refusals and CI-only Rust
edge oracles have been drafted. No translator, preparer, compiler or case has run.

Still OPEN: arbitrary Vec-returning helpers/new Vec definition bootstrap, general
container mutation/iteration, cross-unit helpers, async/network/resource state,
division/remainder failure round trips, complete source-owner producer closure,
all platform and receiving repository qualification, full generation freshness,
performance and whole Router parity. This is one shared family draft, not a
complete source draft or a measured coverage increase.
