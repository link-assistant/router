# Owned meta uses the existing detached Lino DATA lane

This source-only extension targets the measured parseOwnedCoreMeta slice of the canonical reverse workload. It makes no measured gain claim, and does not claim that removing this scan is sufficient for the original 5000 ms Bun deadline. There are no runtime output edits, caches, new semantic permissions, or changed original workloads/deadlines in the worker draft.

The actual owned parser first checks its byte bound, parses the complete primitive text for header/function syntax, decodes the header JSON, validates or constructs the original source context, calls fromLino on the same text, runs checkOwnedCoreProgram, regenerates canonical checked text with toOwnedCoreLinoProgram, compares that string to the original text, and finally rechecks the current context. The canonical step is string regeneration/comparison, not another syntax reparse. This exact sequence and both original checked-item passes remain. The existing parseMeta path keeps its original syntax/canonical reparse and two semantic passes unchanged.

The same prepare-parsed-lino-data.mjs producer now derives both paths from its unchanged complete four-file original archive. Its original native-bound fromLino return, private itemOf callback and original public fromLino body remain intact. Two small DATA-only IR exports are appended: tryCopyParsedLinoData copies a qualified closed network; tryDecodePreparedOwnedLinoData copies that prepared network again, replays the original syntax parser's final LF whitespace operation, then executes the complete original filter/map/itemOf return with only the parsed-network receiver replaced. The second private copy preserves the original decoder's independent mutable working network. Neither export grants source, native grammar, type, owner or executable authority, and neither retains input/output between calls.

After the original byte bound, the owned parser records native readiness before its first syntax parse and admits only nonempty LF-terminated text. The successful syntax parser has no external success-path callbacks under those qualified String/RegExp/Array operations. The new private working network is captured immediately after that parse, before any header JSON/context/source callbacks. Lowering still occurs at the original fromLino call position. Header callbacks may change unrelated RegExp state or install hooks; the prepared decoder independently qualifies and copies again at that original position, selecting the original fromLino fallback on qualification failure. A non-LF or initial/transient-restored ingress hook keeps the complete original decoder. Existing admission bounds remain qualification limits with original fallback.

The replay is **before** the complete original item decoder, not a replacement for the whole fromLino final state. The native-selected parseLinks whitespace expression tests the final LF before returning the complete network. Replaying that exact operation before the original filter/map/itemOf chain gives JSON/Buffer/Number and private decoder callbacks their original starting state. All subsequent original decoder operations still execute, so they produce the whole final regex state naturally. This uses the genuine original syntax function and lowering body, not a guessed final-state constant or an assumption that decoding has no further effects.

The complete installed null-descriptor v2 images are explicit historical inputs: IR SHA 09f016b58d29ae2b5776fbfe59b5b223f8be4aa83368199c8e4b09495f651677 and translator SHA 1632bc2fd32d7ea24f9262563185f38a15d3f6db25a2c078db553a305e0155b3. The producer derives those full sources from the same original archive and original COPY, checks both complete pins, derives the owned additions by native spans, and requires that original→current and v2→current routes join exactly. Each output retains its complete previousAfter plus a priorLayer with full native copies/bindings, ordered language/repository CST serialization/reparse, per-phase inverses and an independent native inverse. No prefix/suffix allowance or repin is used. Fresh input/archive EOF checks run after every native/CST/Hash operation.

The existing seven parsed-lino-data receiving cases and all original production tests remain unchanged. Six new complete 60-second cases live in js-to-rust/test/owned-parsed-lino-data.test.mjs. They cover exact original/current source histories; actual owned source programs with genuine explicit and reconstructed contexts; native JSON call-site observer tapes, real Hash calls and full RegExp legacy state; header mutation of the instrumented first syntax network; restored hooks; noncanonical/non-LF/malformed inputs; unissued source contexts and changed function metadata; proxy/accessor/exotic DATA; inherited get/set DATA descriptors; and mutation during fresh source hashing.

The observer fixtures native-select actual JSON call sites into an isolated recorder while leaving global native JSON functions intact, allowing the original private source guards to run. They do not claim that the original API admits replaced global JSON methods. Separate controls replace the real global JSON/Buffer operations and require identical original outcomes, callback tapes, and regex state, including any original refusals.
