# Shared primitive reverse operation source draft

Every new source path and regression is UNRUN. A single reusable substitution
reader now handles eager bool/fixed bitwise calls, native integer casts and
checked shifts for all seven reverse profiles. Each caller first resolves its
actual current imported symbol, checks its explicit primitive context, records
complete import/source links and reissues its complete body independently.
Type-only runtime calls and generic helper calls refuse. The shared reader
returns DATA, with no private source, type or executable capability.

Casts require literal registered input/target widths and signs, plus an operand
with the exact written native domain. Shifts require separate literal value/count
domains and an exact written operator. Qualified decimal literals retain their
bounded lexical range checks. No plain bigint inference, pointer-width authority,
coercion, custom operator dispatch or changed declaration is admitted.

A shared emission/evaluation helper validates each newly checked carrier. Rust
binds each operand once in source order; casts use the actual absolute primitive
target and omit redundant same-type casts. Shift counts receive an explicit
unsigned-128 range check before the native operator, including negative signed
counts and an i8 count with a 128-bit value. An already unsigned-128 count avoids
a redundant cast. TypeScript and both interpreter schedules call the exact
current paired runtime with the original literal metadata and error behavior.
The old bitwise checked shape and every original profile/source guard remain.

Seventeen full compiler equations retain whole original modules, native owners,
language then repository rules and complete source/CST inverses. Unrun receiving
cases draft all 100 cast pairs and all 200 value/count/shift combinations in each
of seven source profiles, split into bounded per-input cases. Every case retains
complete document serialization/reparsing and source reissuance. Each profile
also has strict TS 5.9.3 emitted-target cases; normal and available prepared/batch
interpreters retain independent expected results. Boundaries, invalid metadata,
source imports, generic calls, input errors and evaluation order are separate
cases. A new independent native cast/shift oracle is CI-only after all eight
same-SHA JavaScript gates pass. These workload drafts establish no duration or
performance qualification.

No implementation, runtime, parser, translator, preparer, compiler, test,
experiment, generation, Rust tool or CI-triggering push ran. Complete forward
module recognition and canonical Rust inverse projection, wider language and
production native owner closure, all remaining source, source-bank/export
materialization/freshness, synchronization, parity and delivery remain open.
