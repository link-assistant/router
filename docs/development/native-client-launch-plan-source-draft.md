# Native client launch policy and argv draft

SOURCE ONLY; implementation, compiler/translator/preparer and all independent
cases remain UNRUN. This draft does not launch any client or complete temporary
with execution. Process/isolation/credential leases and cleanup remain OPEN.

One shared template produces actual paired JS/TS argv planning. Its eight-client
command inventories, model flags, one-shot flags/aliases, prompt-value rules and
Codex root-option classification are mechanically copied from complete retained
native Rust sources by the source author. The actual source constructor retains
both original files and original metadata pins, transports their complete CSTs
and rechecks current bytes after callbacks. The embedded inventory is rule DATA,
not a generated caller owner, source namespace or executable parity certificate.

Planning preserves native commands and leading -- exact argv, one-shot aliases,
explicit interactive choices, nonterminal behavior and user model choices.
Model prefixes apply only to OpenCode/Agent when the selected id has no provider.
Flag-only launches never consume the next option as a missing prompt for clients
whose one-shot switch requires a value; the existing native note is retained.
Forwarded model conflicts, absent ids, NUL and large argv are explicit refusals.
Strings remain argv data; no shell command or client executable is constructed.
Non-UTF8 native OsString behavior still requires a separate platform boundary.

Claude native cloud/control-plane and Codex Cloud requests retain the exact
native refusal policy and are checked in actual operation dispatch before local
core construction. Temporary configure repeats that preflight before its explicit
remaining-lifecycle refusal. Unknown Codex root options do not guess a following
command. No token is minted or daemon selected for a policy-refused request.
The shared planner is available for the next process/isolation lifecycle draft;
its existence does not certify that lifecycle or change support manifests.

Seven complete source equations retain language/repository phases and full CST
inverses. Independent unrun JS/strict TS/native source covers all eight client
plans, commands/exact argv, models, mode aliases, flags without prompts, blocked
Cloud requests/root options, actual pre-core adapter refusal, Unicode/bounds and
source/export histories. Core construction, startup, isolated config merge,
process cancellation/signals, token lifetime/revocation, rollback, terminal I/O,
full forward/reverse/sync/parity/platform/receiving and delivery remain OPEN.
