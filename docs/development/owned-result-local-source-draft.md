The implementation, complete source equations and every independent case are
drafted and unrun. No current coverage, native/target parity, source-history
qualification, output freshness or complete synchronization result is claimed.

source selector for Result<String, String> aliases, actual selected results,
owned payload captures and closed matching constructors. The shared domain DATA
distinguishes owned text results, borrowed text results and owned text Options;
family operation catalogs still decide which operations exist. A new role string
does not add a callable operation to another family or grant semantic authority.

ended scopes, mutation and shadowing remain unproved. Candidate facts appear
only after the real original initializer semicolon and live inside its lexical
scope. Captured source DATA does not copy the original String or prove native
Drop/move/lifetime behavior. Original declarations and callbacks remain intact;
the entire actual function still needs its independent current source/type/
ownership/emission checks. Original false trait/Drop/executable flags remain.

prefix rules. Fourteen existing adapters now share that planning path. Native
core bodies, final input freshness checks, complete CST/source inverses, cell/
token/frame/binder bounds and fixed bulk-stage membership remain unchanged.

in its explicit repository append rules. No cross-operation cache is introduced.

Five complete source equations retain all original modules, native owners and
both rule phases. Independent unrun cases cover owned Unicode/empty strings,
constructor/error domains, source timing/scope/captures, both APIs, the fixed
bulk stage, whole receiving JS and strict TS, native callback counts/owned moves
and complete source histories. Every wider source/native/production/sync/
