# Fixed canonical map compiler cohort source draft

The candidate map profile and canonical reverse frontend use different original
private contexts. Reexporting the candidate implementation would erase newer
canonical source/runtime-import guards. The canonical source profile therefore
retains complete successors for the original canonical source, operation and
corpus modules separately from the existing fourteen-parent map profile.

After Root's complete source-author integration, normal forward/reverse imports
use the seventeen active original successors directly. Default synchronization
checks their exact source bytes, file epochs and ordinary ancestor identities
before and after work. The DATA check only selects fixed execution; actual
private compiler issuers still establish every source/type/body fact. Directory
clocks may change for legitimate generated outputs, while selected source file
epochs stay exact. No full compiler clone is needed on this installed path.

For a complete unchanged predecessor compiler, the fixed fallback launcher
creates one fresh complete compiler source package per synchronization call. The existing full compact producer transports
every selected source/profile asset and installs the fourteen original map
equations into that private copy. The launcher then checks and installs all
three canonical successors, preserves their modes, reopens actual bytes and
updates their real unborn Git index entries. It never edits the original
compiler checkout or treats packet flags, hashes or transported CST as type,
namespace, body or runtime authority.

Every producer runs in a fresh Node/Bun process using the copied compiler and
the original application's source/output root. Exactly the original canonical
flat CLI or four original producer modules are addressable. All flags, argument
values, producer IDs, workload expressions and matrix selections remain intact;
only the fixed implementation path/import URL changes. Native context, parser,
source/checker/body and SDK facts must be independently reissued by those real
modules after process startup. No private compiler receipt crosses a process.
The actual canonical corpus selects and checks its real map-native source
closure; the launcher cannot manufacture missing inputs or native facts.

On the fallback path one invocation-local operational token names the cohort. It is not a compiler
permit. Complete package files, directory epochs, actual bytes and namespace
are captured after installation/index updates, checked before/after each step
and closed before success. Caught source/admission failures stay fatal, tokens
expire, every physical closer is attempted, and falsy/frozen primary failures
are retained. There is no persistent source/hash/verdict cache. Reuse is within
one synchronization call only, avoiding one full compiler copy per producer.

The original first producer's deadline includes fallback compiler setup. Each producer's
existing timeout also includes its command preparation and closing. The child
gets only the remaining time; overrun is failure. No deadline, workload or
existing complete JavaScript gate command is relaxed. Full package limits stay
256MiB logical/64MiB encoded/384MiB aggregate, with the original per-lease decode
and individual source limits. Hash/stamp snapshots describe current source DATA;
they do not establish measured RSS, elapsed time or native conformance.

On ordinary closure the launcher removes its exclusively created, unchanged
temporary package. If source/namespace checks fail it retains incomplete or
unknown evidence and reports its exact directory. An empty failed setup may be
removed. Independent fault cases explicitly own and clean their test directory.
Synchronization receipts retain original and executed commands, original and
remaining child timeouts, and the setup charge. Cohort closing is pending until
the outer operation succeeds; later closing failure marks the receipt failed.

The receiving source covers full fourteen-plus-three installation, all actual
original synchronization command mappings, unchanged flags/workload bodies,
expired tokens, caught changed/restored compiler data, synchronous callbacks and
expired deadlines. Its complete test file joins existing full forward file
discovery; no original case is filtered or skipped. All these cases, both
compiler source proposers, every child and every performance/resource/platform
observation remain **UNRUN** during bulk drafting. CI is **NOT_INSPECTED**.

The active originals also serve ordinary standalone canonical forward/reverse
imports. The fixed fallback is wired through default sync; standalone fallback
bootstrap, project-unit/owned-unit source closures, complete
receiving feature qualification and strict application parity remain explicit
followups. The original unrestricted BTreeMap query API also needs a separate
source-qualified borrowed view; the bounded map carrier cannot replace its full
input domain. No whole-source synchronization or new function coverage is
