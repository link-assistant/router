# Reusable generic Result carrier rules draft

All implementation and regression source is drafted and unrun. No tests,
experiments, diagnostics, translation, preparation, regeneration, Rust tools,
push or CI ran. Every unfinished [ledger requirement](bulk-draft-requirements.md)
remains open. This batch supplies no measured coverage or parity result.

Option<T> and Result<T,String> now share reusable carrier descriptor rules for
their precise native signatures, symbolic payload domains, qualified ABI queries
and concrete payload extraction. Descriptors remain DATA. Actual imported library
source proofs, real lexical generic slots and complete unchanged-value bodies
independently govern every use. A Result is not widened to bare T or an Option.

The caller captures and rechecks the complete Result ABI sources only when an
actual import selects that signature. Alias-template inspection recognizes that
genuine generic operation. The existing bounded linear and acyclic body theorem
retains all moves, aliases and checked helper calls, with scalar callback and
carrier mismatch refusals. Ordinary signature-only ABI value calls remain
refused; this does not authorize arbitrary generic library calls or body effects.

Native proposal checking, JS/strict TS source capture, native emission, original
local-type obligations and paired physical signatures use the same descriptor
sequence. Explicit call arguments constrain the inner payload while retained
docs describe the whole actual carrier. Borrowed string payloads require an
actual qualified matching operation signature, preserving their input roots
rather than silently choosing owned String. Unsupported borrowed and disposing
domains retain refusals. String-error Result types without a finite return API
can use the actual generic ABI for their supported nested owned signatures.

Thirteen complete source equations retain native owners, language and repository
sequences and full CST inverses. Independent unrun JS/strict TS/native source
covers generic forwarding, opaque success/error values, nested Result<Option>,
written local construction, precise native headers, borrowed roots, physical
paired signatures, type/callback refusals, changed ABI inputs and forged meta.
Actual native ABI drop cases remain separately drafted for gated Rust CI.

General error parameter E, constrained/multiple generics, generic payload
construction and direct imported ABI value-call qualification remain open.
Architecture/producer closure, wider structural/method/effect/drop domains,
production adoption/parity, complete receiving, original source/timing/profile/
reverse freshness repairs and every CI gate remain unfinished.
