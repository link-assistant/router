actual module gaps. Leading inner docs select their module; outer docs require
an actual following ordinary item. It preserves exact Unicode, quotation,
backslash and whitespace payloads in literal doc attributes, original complete
files, CST serialization/reparsing and full inverse equations. Ordinary four
slash and non-doc block comments remain untouched. Source inspection of the
pinned native lexer informed the exact comment classifications.

Actual source-selected attribute scopes check the original enclosing modules
and target headers. Explicit known configuration uses its current native source
plan; unknown enclosing/target producers remain refused. Dangling outer docs,
misplaced inner docs, block/CR/control-bearing docs and documentation outside
module gaps remain unchanged with refusals. Macro-body and function-body docs
still require their separate enclosing consumers. No public source row grants
namespace, owner, type, body, coverage or runtime authority.

The copied project composes original, doc-normalized, configured and expanded
physical source domains before its existing checked frontend/meta/JS/TS path.
All four complete byte domains count against the unchanged raw-source bound;
whole source/profile callbacks are rejoined before and after each transaction.
Native scopes close on every exit and no result survives across invocations.
The original project entry APIs remain available.

configuration, external/inline module, refusal, freshness and native Rust oracle

translator, generator, Rust tool, push or CI ran. Every unfinished source and
