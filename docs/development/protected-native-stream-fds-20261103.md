# Additive native stream descriptors — source proposal

The four operational parent pairs are alias observer, actual common policy, synchronous borrowed-root adapter and general async adapter. Four further complete parent pairs compose the existing general/external/contained named source histories and the complete prior source-error case. The latter retains the historical contained afterimage while following currentAfter and every exact intermediate inverse to the new active epoch. Every previous full image remains immutable; active originals are untouched. All verification is UNRUN.

The original public regular-file descriptor observer and lease.descriptor continue to reject non-file descriptors. The additive assertProtectedNativeStreamWriteDescriptors, policy.allowNativeStreamWrites and lease.streamDescriptor admit genuine native nonregular descriptors while independently inspecting their actual identity against protected logical/physical endpoints and inodes. No caller flag changes the old API. Common policy admission validates the original root association; all numeric descriptor DATA is captured through the existing private validator. Every active/captured sync and async root vetoes and closes its metadata observations through the original general lease machinery.

Actual fstat determines each FD's native kind. Regular files retain their complete existing stamp. Other kinds use dev/ino/mode/uid/gid identity, avoiding ordinary stream traffic clock/size changes as source changes. The same actual kind/identity is checked again at metadata closing. There are no fake FileStats and no public kind assertion. The operation borrows descriptors, preserves callback results and exact ordinary falsy/frozen failures, and never closes borrowed FDs. Original native nesting, metadata nodes/steps/retained-byte/closing bounds remain; no complete source corpus is copied for a chunk admission.

This API proposal does not itself adapt Node stdout/stderr callers. The frozen Node evidence packet deliberately preserves its original pipe/TTY forwarding; an exact whole-source helper/script successor follows only after integration of that packet. Independent case source covers an actual child pipe, the unchanged old refusal, protected regular-FD alias veto across active roots, exact ordinary failures and lexical expiry.

Existing secondary and closing diagnostics are separate actual stderr sinks. In particular protected-native-writers.secondary and reviewed-adoption.secondary call process.stderr.write; alias/common closing helpers can emit diagnostics too. A protected descriptor2 veto can encounter those diagnostic paths. Therefore this proposal does not claim complete stream/FD2 protection, and its protected inherited-FD case deliberately uses stdout1 with distinct stderr2. A further fixed diagnostic strategy must retain secondary error DATA without recursively writing through the denied descriptor; no fatal primary may be normalized or suppressed. The existing diagnostic paths are inventoried separately. Native mkdtemp precreation, Python/Bun inherited files and arbitrary transitive receiving children also remain OPEN. L04/S03 and complete function/writer denominators remain OPEN/UNKNOWN.
