# Separate fresh whole-owner resolver operation

This source draft extends the explicit whole-owner candidate to the later
complete binding-resolution operation. It leaves the default resolver and
default creator untouched. It reuses no closed creator program, owner verdict
or private digest, and has no measured performance result.

`prepare-whole-owner-resolver-candidate.mjs` uses actual native TypeScript
declarations from the complete current `module-bindings.mjs`. It selects the
original public retained-scope wrapper and the actual exported unscoped
resolver, preserves their full source, and adds a separately named wrapper
around the complete original unscoped call. The original copied public wrapper
remains unchanged. The new wrapper enters the same private Serde operation
instance used by the additive creator, then performs the full actual resolver.
Each call captures and hashes a fresh complete original source binding program.

The complete copied `derive-output-effects.mjs` is required as well. It joins
the same private bang-output and builtin-footprint issuers as the copied
resolver. Merely changing a resolver import would leave a foreign effect
issuer; its caught TypeError could retain unresolved type scope. The receiving
positive checks complete output equality, actual type/bang closure and genuine
copied scope consumers rather than merely checking successful return.

The third generated file contains the exact complete original public resolver
wrapper under a new name. It imports the actual original exported unscoped
resolver and the actual original retained-scope import. The bulk operation's
bootstrap calls this private-entry adapter instead of the public resolver.
Consequently a later explicit physical public-resolver trial overlay cannot
recursively reenter itself while capturing the source-only binding program.
The bootstrap preserves original parameter/default evaluation and retained
scope behavior; no unscoped body is reduced or replaced.

All three outputs retain both ordered native/CST phases, the full original
source, selected original function spans, serialized/reparsed CST, native
copied-binding checks, complete inverse and fresh actual input identities.
The source profile and output metadata grant no semantic or namespace permit.
The existing per-owner/declaration/source hashes, complete grammar reissue,
generated-owner checks, unknown attributes/macros/cfg diagnostics and final
whole-source/intrinsic boundary continue to run.
