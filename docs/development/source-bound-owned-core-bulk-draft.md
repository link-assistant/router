This entire source batch is drafted and unverified. Every regression and native
oracle is unrun. No tests, experiments, diagnostics, translation, regeneration,
Rust tools, pushes or CI ran. Every unfinished [ledger requirement](bulk-draft-requirements.md)
remains open; no new executable coverage percentage is available.

Twenty-three complete original adopter/helper modules are copied through native
import-owner substitutions. They select one coherent original-source/derive/tool
context family and the corresponding copied primitive and literal-import helper
modules. Original APIs, type-position selectors, operation rules, source bounds,
public schemas, original trait/body refusals and complete inverse algorithms are
retained. The original default modules remain separate. The routing facade shares
the existing private context issuer and exposes no context-cloning mechanism.

The fixed dispatcher selects 21 actual corpus exports: algebraic and owned
carriers, base64, integer methods, JSON collections/fields/iterations/loops/parse/

Each callable is the actual complete copied proposer. An unknown stage cannot
select an arbitrary module, property or caller callback. This inventory records
source wiring, not qualified behavior or executable application coverage.

The async sequence yields one complete original proposer result at a time.
Every next request uses the preceding complete after map and retains original
before/path equality. Its caller can write or release each complete packet;
the coordinator does not accumulate earlier graphs, CSTs or full proposal
histories. An independent source-string snapshot made before yielding prevents
mutable public packet DATA from changing the next input. Source, Cargo, profile
and stage inputs are checked across asynchronous boundaries. Paths, ordinary
own fields, dense unique stages and existing file/source limits remain bounded.
Ambiguous root `src`/`rust/src` layouts require an explicit entry. The API proposes
source changes only; it does not install files or grant body/trait authority.

ordered language/repository phases and full CST inverses, including the two new
orchestration source files. The synchronization API exports explicit bulk entry
points. Independent unrun cases compose actual text, Option, integer and primitive
producers, check detached output isolation and cross-yield mutation refusals,
retain full source inverses and require independent JS/strict-TS behavior for
Unicode trim boundaries, Option values and unsigned saturation. Native std oracle

Full receiving tests for all 21 stages, performance/resource evidence, source
history freshness, architecture/producer closure, wider language and resource
