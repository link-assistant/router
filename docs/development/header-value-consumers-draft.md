# Genuine shared header value consumer source draft

All new implementation and independent cases are UNRUN. Only source construction
and review occurred. No consumer, native reader, captor, parser, macro expander,
translator, preparer, test, experiment, generation, local Rust tool or
CI-triggering push executed.

Three full existing consumers are copied for the separate genuine Header
equality-expression/input receipt family: conditional literal concat, the exact
original architecture document include-str proposal, and its complete async
macro file-token join. Default/legacy consumers retain their original receipt
families and domains. New copies authenticate the complete actual header/input
association before deriving a proposal and again after native/source work.

The concat copy retains all sixteen original native inputs, full callback source
selection, licenses, source/current checks, ASCII literal domain, 128 argument/
4096 output bounds, both substitution phases and complete physical inverses.
It accepts original documentation expressions on root/inner, function parameter/
generic and data field/variant sites without synthesizing any caller AST.

Include-str still requires the exact pinned architecture file, original literal
argument, complete same-archive Rust source and document, all sixteen native
include inputs and every original callback/CST check. Arbitrary paths and changed
whole sources remain refused. The async copy obtains the actual module view
through the validated nested header options, retains the fifteen native file
inputs and 102 constructor programs, and rechecks original header/input identity
after every await. Native Span/source-callsite, resolver, loader and path
qualification remain separate open obligations.

Every proposal preserves the existing language/repository substitution phases,
serialized/reparsed CST/meta boundaries, output literal and full original source
inverse. Macro/attribute ownership, visitor effects, global exports, original
source/application equivalence and runtime parity remain unqualified; no new
consumer is silently integrated into executable namespace/lowering paths.

Three complete compiler equations preserve original sync/async consumer bodies,
native owner spans and whole inverses. Independent unrun cases cover all genuine
header domains, literal boundaries, same-archive include, async source changes,
private family/accessor/dependency refusal and original native input closure.

synchronization, freshness/CI and receiving qualification remain unfinished.
