# Pure generic deadline callback source draft

The resource caller lane now has an actual executable-source rule for the
qualified generic deadline operation. It checks the complete original async
arrow, its one contextual child cancellation input, whole expression, each
actual operation, independently checked generic identity theorem, live captures
and settled return ownership. The inferred Result slot comes from that whole
body, rather than the generic declaration or a public record.

This first producer accepts one expression or a block with a single return
and original empty statements. Used captures must remain immutable Copy values
or shared immutable inputs. Its operations must belong to freshly source-checked
pure library families; querying this callback's actual child cancellation is
also allowed. Nested collection and outcome callbacks are walked completely.
Named callbacks require the existing independently checked linear identity
body theorem. No ordinary helper gains purity from its return signature.

Owning String captures, mutable captures, opaque resource outputs, borrowed
return roots, callback awaits, nested deadlines, stateful control operations,
unknown helper effects and post-await continuations retain explicit refusals.
This matters because JavaScript can settle an ignored callback after a timeout,
whereas Rust drops its future. Returned scalars, owning text/JSON/vector values
and closed Option/Result containers need no opaque resource cleanup. Broader
callback shapes and real effectful cancellation/cleanup remain open.

Native emission retains the real typed child closure and `async move` future.
The native reader and reverse proposal recover that actual shape and derive its
settled slot from its original expression. The proposal still rechecks the
entire JavaScript source, serializes/reparses checked meta and must reproduce
every original Rust token. Written async return annotations must preserve the
actual native Promise boundary; PromiseLike is not an async syntax substitute.

Seven complete prior implementations, both ordered rule sequences, source/CST
inverses, old refusal evolution and the complete successor chain are retained.
Independent whole JS/strict TS, numeric, ownership, cancellation, child cleanup,
meta tampering and native inverse cases plus real-library Rust oracle source
are drafted. All are unrun. No test, experiment, compiler, translator, preparer,
generation, Rust tool, CI job or push ran during this drafting work. This adds
no runtime parity, namespace/bootstrap or whole Router completion evidence.
