# Paired borrowed text Option fallback source draft

All new implementation and independent cases are UNRUN. Only source construction
and review occurred. No runtime, selector, translator, preparer, test, experiment,
generation, local Rust tool or CI-triggering push executed.

Twelve paired operations compose existing prefix/suffix and first/last split
projection contracts with fallback to the same original value or an empty string.
Every result keeps the original input value lifetime and the existing root-zero
borrow contract. Pattern storage is never retained. Native internals intentionally
remain library calls; JavaScript delegates to the existing validated Option slice
operations. Primitive scalar validation and the unchanged 1 MiB bounds cover both
operands, including misses, empty patterns and Some-empty results.

The shared operation catalogue drives forward/reverse registrations, source
checks, interpreters, declarations and target imports for all twelve operations.
Complete current native and runtime sources are retained. The native append
constructor copies the complete existing two-phase source/CST transaction and
joins adjacent SHA256/ASCII/native histories without replacing their original
stages, source bodies or inverses. No generated targets are edited manually.

The full text selector accepts exact unwrap_or_default after a supported Option
slice or exact split projection. unwrap_or(value) fuses only when the fallback is
the same unchanged immutable borrowed receiver spelling. Different owners,
transformed receivers, arbitrary callbacks and eager fallback effects do not
become new fused operations. Existing partial source proposals may still select
an earlier supported method while preserving the entire unsupported suffix.
Source-producer, type, ownership, Drop, lifetime and whole-function checks still
govern installation; no original dispatch or executable authority is granted.

Eleven complete compiler source equations retain full original modules, native
owner spans, explicit ordered language/repository rules, CST/meta transport and
whole inverses. Independent unrun expected vectors and source cases cover all
twelve operations, Some-empty/None, empty and overlapping patterns, Unicode/NUL,
primitive/bound refusal, actual method bodies, JS/strict TS, checked reverse
interpretation, typed/Rust inverses, changed source refusal and native lifetime
oracles. Source-bank/export freshness, production adoption, native/runtime parity,
whole-source reverse synchronization, CI and receiving qualification remain open.
