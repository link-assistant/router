# Physical async control source-unit draft

The explicit `async-control` profile connects cold cancellation, deadline and
channel callers to physical JS, TS and Rust source paths. The unit adapter is a
complete source copy of the existing cancellation unit adapter, retaining both
ordered substitution sequences, full originals, CST and inverse equations.
All new source and independent receiving cases remain unrun.

The existing source transaction still determines direction from complete Git
baselines, rejects conflicting changes, captures current native/Cargo and both
runtime trees, recomputes complete proposals before installation, and uses its
original atomic replacement/readback/rollback contract. The new profile changes
neither those bounds nor the eight JavaScript gates. Runtime-only installation
does not qualify application code or create a Rust caller.

Rust authority uses the canonical inverse and full source reproduction. JS and
TS authority reenter the source-bound cold resource checker. Missing JS input
annotations can be proposed from the freshly checked complete TS pair, matching
actual function and parameter identities. Native AST selections add collision
free operation imports and JSDoc queries; the entire edited JS body is checked
again. Complete original JS and paired TS source remains in history, and the
authoritative JS source stays unchanged. A paired domain alone grants no loan.

Mirrored native/runtime mappings include the actual async-control module and
its cold helper closure. Source readers distinguish logical native inputs from
physical workspace paths. Independent unrun cases cover all three source edit
directions, paired annotations, actual opaque resource identity, runtime-only
installation, source conflicts, forged proposals and native source changes.

General source inference, broader async functions/callbacks, public numeric
guards, HTTP resources, namespace/bootstrap, production adoption/parity, complete
source-history receiving checks and every remaining ledger obligation stay
open. Native grammar, Rust execution, receiving qualification and parity retain
their false/unrun status until the required gates supply evidence.
