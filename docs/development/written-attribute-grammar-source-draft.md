# Empty and delimited written attribute grammar draft

All code, independent cases and CI-only native oracles are UNRUN. Complete
translation, source-owner closure and the entire requirement draft remain OPEN.

The additive written model supports common delimited forms such as `repr(C)`,
`repr(align(16))`, `allow(dead_code, unused_imports)` and `inline(always)` alongside
the earlier empty profile. It retains complete outer header source, nested
argument spans/trees and a whole serialized/reparsed CST inverse. A bounded
positive ASCII lexical profile admits ordinary identifiers, plain decimal token
spellings, standard punctuation and single-line cooked strings with the simple
Rust escapes. Comments, raw/prefixed/suffixed literals, Unicode spellings,
character/lifetime literals, equality expressions, unsafe/inner headers and
unknown custom paths remain explicit profile refusals.

The native program retains all twelve previous complete Rust parser callbacks
and selects the thirteenth `parse_token_tree` from the actual containing Parser
implementation in the already retained whole `parser/mod.rs`. Its exact source,
span, containing owner, current input digest and whole CST inverse are rejoined.
Nothing is downloaded or executed. This models the written delimited branch;
it does not execute rustc or prove equivalence to its opaque/hygienic AST or
native token-spacing/lexer representation. Native token-tree lexing, original
caller presence/grammar, builtin/tool ownership, argument meaning/expansion,
type-prefix absence and producer/export closure remain unqualified.

New complete copied header and x86 proposal APIs attach those grammar records
and preserve every other header as an explicit refusal. Old empty-only APIs and
their refusals remain unchanged. The native program is retained once per
operation, charged to the existing cell limits, and released on success/failure.
Private request identities store inputs only and rejoin actual current header
associations on every observation. No source/hash/owner/verdict/result cache
crosses operations. Byte/token/depth/record and original whole-proposal bounds
remain mandatory; native/lexical resource exhaustion propagates as a fatal
budget refusal rather than a successful profile record.

Five complete source equations retain whole originals, exact inverses and the
fixed language then repository sequences. Independent unrun cases cover common
argument forms and delimiters, nested groups, all thirteen callbacks and source
containment, old API preservation, lexical/malformed/custom refusals, genuine
header requests, changed source carriers, operation cleanup and actual generated
x86 headers. Native Rust integration sources exercise ordinary attributes and
Copy values, plus a bounded, cleaned-up CI-only compiler oracle for a competing
`rustfmt` module. That negative oracle matters because parsing a tool path does
not establish its type-namespace owner. Rust remains gated on all same-SHA
JavaScript stages and is never executed locally.

Native caller/producer closure, equality argument grammar, remaining lexical
profiles, full function admission, receiving compiler exports, runtime/platform
parity, canonical/reverse freshness and performance remain OPEN. There is no
current application coverage claim. No tests, parser, compiler, translator,
preparer or generator ran; CI feedback remains uninspected.
