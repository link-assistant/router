# Owned static output source draft

All compiler, parser, receiving, strict TypeScript and native oracle execution is
**UNRUN**. This complete copied-source successor remains uninstalled. Existing
canonical roots and every0713/literal/nominal-edited source snapshot stay frozen.

The positive domain is an explicitly qualified synchronous, parameter-free unit
caller of `crate::translation_core::output_literal_write`, `_result` or
`_passthrough`: a literal bool channel and an actual move-only LiteralArguments
constructor, used immediately or through one immutable local. Constructor source,
static storage, Unicode, ownership, original raw parser nodes, exact function
binding/reexport, facade/leaf bytes, private checker and complete flow all rejoin.
No name, shape, flag, metadata hash or backend callback grants source authority.
The existing inspector branches remain intact. The output branch returns unit
and remains effectful/nonconstant. Async calls, escaping tasks, dynamic formatting,
borrows, extra uses, mutable locals, unknown aliases and custom carrier construction
remain refused. The same private runtime WeakMap consumes the original carrier;
no owned-String replacement carrier or borrowed as_str API is introduced.

The native bridge calls the exact original operation_output write/write_result/
write_passthrough functions with the actual carrier's Display implementation.
Native formatting and output internals stay untranslated. The JS counterpart
requires an explicit matching owned backend and implements the actual routing:

- write probes launcher capture first. A captured message stops this route.
- Otherwise stderr with a diagnostics scope invokes diagnostic before transport.
- An operation context captures its selected channel even when quiet is true.
- Unscoped quiet stderr is suppressed; remaining transport IO errors are ignored.
- Result/passthrough bypass capture, diagnostics and quiet suppression.

The source-owned bridge interface separates capture, diagnostics policy, diagnostic,
context write and process write. A returned owned IO-error is distinct from a
thrown backend failure; thrown failures propagate with exact identity. The memory
adapter implements all branches concretely on both sides, records ordered events,
and supports injected transport IO failure. Its finite contract is4096 event
occurrences, each at most2MiB scalar-valid UTF8, and8MiB aggregate event text. It
preserves raw braces, zero-piece/empty literal output, LF/CRLF/NUL and Unicode.
These explicit memory limits do not relax any compiler/profile DATA budgets.

The JS scope is a synchronous stack, deliberately not AsyncLocalStorage. It
restores the prior scope in finally, rejects async/thenable callbacks and backend
results, and has no Promise/timer/task inheritance after scope exit. The admitted
source caller has no async or task operations. The native dependency model uses
explicit borrowed backend references and shares no ambient state with child tasks;
the production bridge keeps native tokio task-local behavior. This is not a claim
of general JS async-scope equivalence to tokio::task_local.

Persistent host logger parity is an **OPEN dependency**. The memory capture adapter
records unredacted text so tests can establish routing, rather than pretend to be
the launcher logger. A real target host backend must still implement the actual
launcher record/sanitize/truncate/mirror sequence, operational timestamp/pid/logging,
redaction, private file locks/rotation/unlock and write_failure behavior. The native
bridge preserves those existing paths. No generic console replacement, fully
executable production logging or completed output migration is claimed.
