lexically scoped type reader used for local value obligations. The actual value
must retain that complete native domain, ownership and every borrow root. A type
argument may select a bounded integer literal representation; it cannot change
an existing value's domain, skip a native range or authorize an unsupported cast.
Nongeneric operations still refuse type arguments, and wider instantiations stay
explicitly unsupported.

JSDoc assertion around its actual argument. Thus a genuine signed instantiation
survives JS erasure and nested local/type-wrapper substitutions. Both targets
still pass the original whole-source CST/semantic transport, and native inversion
must reproduce the complete inferred Rust application. Shared type/doc helpers
are reused directly; their public DATA results never grant executable authority.

inverses. The former single explicit-argument refusal is preserved historically
and replaced by a true excess-argument control, with the valid case added to
independent positive source. JS, strict TS, native inverse, nested alias/wrapper,
