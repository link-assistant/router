# Original native explicit discard draft

The explicit native source path now records actual untyped wildcard let
boundaries. A discarded checked call keeps its whole original expression as an
effect statement; the existing checker establishes its operation, arguments,
ordering, return domain, ownership and cleanup. Closed primitive literals can
be removed as no-op statements after original parsing and bounds checks. No
wildcard value binding is created, and complete original trivia stays in source
inverses.

This is a narrow explicit discard rule. Results, owning values and resources
continue to require their complete existing effect/drop rules. Typed wildcard
patterns, unknown effects, unbound wildcard references and malformed literals
retain refusals. Complete normalized source/meta/native reproduction and the
existing cancellation, disposal and unit contracts remain mandatory.

Three complete originals, both ordered phases and full inverses are retained.
Independent JS/strict TS/native, repeated cancellation effects, unit/disposal,
literal boundaries, source/refusal and real native oracle cases are drafted and
unrun. No tests, experiments, compilers, translators, preparers, generation,
local Rust tools, pushes or CI ran. Wider discard/drop semantics, namespace and
producer closure, actual production adoption/parity and every unfinished bulk
requirement remain open.
