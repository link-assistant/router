# Formatting source boundaries

The source-backed formatter retains a complete function when an unresolved body
macro or local producer could inspect rewritten tokens or introduce a later
macro binding. This includes an unknown enclosing macro, an earlier statement
macro, a qualified external macro and local attributes or imports. Comments,
strings and character literals remain data. Nested calls to the selected
formatting family can still receive the existing explicit owned API adoption.

`macro-adoption-function-boundary.mjs` records original token spans and reasons.
Its output is candidate DATA; it grants no macro, type or executable authority.
`prepare-source-backed-formatting.mjs` inserts the check into its actual copied
function through the language sequence, and attaches the helper through the
repository source layout. The packet producer copies that complete current
function. Both producers serialize/reparse whole CSTs and verify full inverses.
The original ordinary formatting API remains unchanged.

The five complete receiving cases preserve unknown macro payloads, possible
