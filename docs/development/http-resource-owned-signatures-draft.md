# Original owned and settled signatures: source draft

All implementation, receiving cases and native oracle source remain unrun.
Public source parameters now use the same fresh original-operation type reader
as callback and return obligations. Actual Parameters/ReturnType queries can
describe owning String, JSON, JSON lists and complete owned Option/Result
containers. Inputs with resource disposal or borrowed nested payloads remain
refused. Bare strings still describe shared strings; querying an owning producer
does not convert a shared argument into an owned call-site value.

The Awaited rule accepts only an actual imported operation future descriptor.
It describes its settled value and does not poll a future, admit a stored future
or erase an async boundary. Every bare or operation-derived public u64 still
requires its actual dominating original entry guard. Awaited, Parameters and
ReturnType cannot be shadowed by portable bindings. A copied descriptor grants
no source, runtime or semantic authority.

Explicit ordinary cold-wrapper returns now require the actual complete future
descriptor and inferred inner flow domain. Synchronous returns retain their
existing whole-body obligations. Recursive signatures can name complete owned
non-resource domains and accept immutable/shared or owned non-resource inputs;
every body in the actual recursive group is still checked. Borrowed recursive
results, async recursion, generic type parameters and resource-state recursion
remain open.

Native projection and paired-source-unit proposals share one domain-to-written-
type mapping. It selects real current imported operation signatures, then fresh
whole-source checks establish moves, roots and complete outcomes. Native owned
recursive returns receive reusable complete source annotations before the
original full token reproduction check. No annotation creates ownership or
waives the original library/source closure checks.

Full original source, native, annotation and paired-unit copies retain both
ordered substitution sequences, original native-selected spans, serialized and
reparsed lossless CST and full inverses. Independent unrun JS/strict TS/native
source covers moved inputs, empty and owning containers, recursive ownership,
settled control Results, paired proposals, double use, shared-to-owned misuse
and forged meta. Production adoption, namespace/bootstrap, full generic/method
signatures, runtime parity and every other unfinished ledger row remain open.
