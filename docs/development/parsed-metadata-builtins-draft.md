# Parsed metadata builtin source draft

This implementation and all new cases are UNRUN. Only source construction and
review occurred. No parser, translator, preparer, generation, compiler, test,
experiment, local Rust tool or CI-triggering push ran.

Three complete existing consumers are copied with their bounded grammars: inner
allow/warn/deny/forbid lists, empty outer macro_use on actual modules, and inner
or outer documentation literals, lists and positive equality expressions on
actual root items or impl/trait members. Genuine original header receipts supply
the parsed path and argument form. A private caller receipt joins that header to
the correct native parser and builtin registry domain. Raw, qualified, unknown,
unsupported or forged headers do not gain permission from public flags.

Each domain retains its own complete native conditional premises. Native frames
are shared only within the explicit synchronous parsed operation, every scope
rechecks its original headers at finish, and the operation closes abandoned
scopes and clears all frames on success or failure. Receipt reads rejoin current
original header and native sources; private state stores source associations,
not native source, hash or verdict caches across operations. Every native frame
receives its final current-source check even when another frame fails.

The positive result is limited to the parsed builtin name lookup and conditional
exclusion of custom attribute selection. Caller ownership, availability and scope
remain unqualified. For documentation expressions, argument macro resolution,
visitor effects and global exports remain pending even when the outer doc name
is selected. Module macro_use does not thereby qualify imported macro owners or
global exports. Literal/list interpretation, runtime behavior and original-source
equivalence remain separate obligations.

The existing factories dispatch only inside the explicit parsed operation. Its
complete project copy therefore receives these consumers without changing the
default API domains. Three full compiler source equations retain original owner
spans, separately ordered language and repository substitutions, CST/meta
transport and whole inverses. Independent unrun cases cover all three domains,
actual members, unknown argument macros, forged receipts, getter refusal,
source changes, scope cleanup, JavaScript/strict TypeScript behavior and a native
namespace oracle. Actual resolver/hygiene/global/type-prefix closure, wider
production/reverse/synchronization/CI/receiving requirements remain unfinished.
