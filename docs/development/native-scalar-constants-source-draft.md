The native scalar observation lane now drafts finite constant-reference expansion
using the fresh original lowerer's complete actual dependency declaration map.
Only actual zero-argument constant declarations returning a registered by-value
fixed primitive or bool are selected. Result/argument types and the original
constant evaluator's source-linked root identity remain joined. Proof fields and
public tables alone do not supply permission: the enclosing genuine original
checker/source carrier and independent receiving/native check remain mandatory.

Each constant body re-enters the existing scalar observation rules with an empty
caller lexical environment. Nested constants retain a bounded acyclic active
stack of at most 32 entries, cleared on every exit. Expanded work still uses the
complete native function's original tree/depth budget. Runtime effects are refused
because compile-time evaluation cannot be replaced by a new runtime effect.

or arbitrary const-function bodies gain no new rule.

Automatic projection emits the supported expression at each caller, and source-
authoritative edits update selected function bodies while preserving original
constant declarations outside their function spans. This does not synchronize a
shared JavaScript constant declaration or qualify unsupported constant bodies.
