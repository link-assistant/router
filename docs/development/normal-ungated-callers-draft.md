# Genuine normal ungated builtin caller source draft

All new implementation and independent cases are UNRUN. Only source construction
and review occurred. No captor, reader, parser, registry, macro expander,
translator, preparer, test, experiment, generation, local Rust tool or
CI-triggering push executed.

Private original header receipts can now join the automatically discovered
ordinary ungated native registry domain. Three explicit issuer paths retain
root/member item, function parameter/generic parameter and data generic/field/
variant/variant-field header families. The actual private header reader supplies
the original ordinary single-segment outer name. Detached ASTs, public flags,
copied receipts, raw/qualified/inner/unknown names and excluded unsafe or gated
constructors cannot become new caller receipts.

Each private caller record stores the original header/parent/options/selector
association only. A read reconstructs the actual header association and current
native registration; no native source, hash, owner or result cache is stored
across invocations. A bounded explicit parsed operation can share one complete
normal native frame across its callers. All current-source checks remain, the
frame receives its final check on every operation exit, and every reference is
cleared with the existing operation cleanup. Outside reads construct fresh
complete native sources.

The positive result is a conditional native builtin-name lookup branch, requiring
the actual native-parsed original caller to be present. It is not native grammar
or attribute legality qualification. Caller ownership, availability, scopes,
argument expansion, cfg_attr transformations, macro exports, types, layout and
runtime behavior remain unresolved. Every corresponding authority field stays
false; even a known builtin name leaves global macro effects pending. Existing
scopes retain their previous domains, so no new name is silently treated as inert
by namespace resolution or executable lowering.

Three complete compiler source equations preserve the full original operation
and cleanup, native owners, ordered language/repository substitutions, physical
CST/meta boundaries and complete source inverses. Independent unrun cases cover
new root names and macro values, both function parameter domains, data sites,
foreign/private family refusal, source changes, excluded names and unchanged
default scopes. Behavior/effect consumers, native resolver/hygiene/global closure,
actual production lowering, parity, reverse synchronization, freshness/CI and
receiving qualification remain unfinished.
