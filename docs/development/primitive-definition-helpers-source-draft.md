# Primitive definition helper source draft

SOURCE ONLY. All new source/meta, interpreter, strict paired, insertion,
nonempty extension, refusal and source-history cases are UNRUN. Whole drafting
and all qualification remain OPEN.

The explicit primitiveDefinitions family now follows actual same-module native
JavaScript/TypeScript function symbols, including forward declarations. Each
callee recursively enters the same private original source issuer. Actual
parameter names, argument count, exact Boolean/fixed integer domains, immutable
body, qualified total operations and return type remain independently checked.
All ten fixed integer domains are covered by regression source. Implicit bigint
helper ABI, unit/borrowed/aggregate/mutable/effectful helpers, unresolved imports,
shadowed names and recursive call graphs retain refusals.

Existing operation-local recursion and expanded-work bounds apply to the whole
source-call closure, including serialized/reparsed checked meta and emission.
The small closure summaries record local definition Rust names until actual
native insertion creates qualified bindings. These summaries are DATA only.
The original private checker reissues every function before summaries can be
consumed, so a missing or changed callee cannot be replaced by saved metadata.

The complete existing insertion/append implementations now accept such closed
new-function groups. Every inserted function still requires an actual exported
ordinary declaration and complete emitted native body. The whole proposed
Rust/Cargo project and actual new ABI are independently checked. Once those
native functions exist, the ordinary receiving issuer recreates actual qualified
source-helper edges and independently checks complete original native models.
No native placeholder, signature-only declaration or runtime execution is used.

New-to-existing dependencies during a nonempty addition remain a separate
bootstrap requirement: partitioning the new-only source does not silently
include or acquire an older function. Cross-unit helpers, private-only inserted
helpers, broader aggregates/loans/effects, mixed same-module reconciliation and
full translation remain OPEN. Independent source cases include forward helper
graphs, Boolean short circuit, ten exact domains, total complements, cycle/depth,
missing and forged closure data, and empty/nonempty insertion in both languages.
Seven complete source equations retain all originals/inverses under language then
repository. Coverage, parity, freshness, resources, receiving export, platforms
and CI remain OPEN. Rust stays CI-only after eight same-SHA JavaScript gates.
