# Owned JSON state operation draft

Twelve shared operations have matching native Rust and JavaScript source:
array replacement, append, shared/owned extension, vector/JSON conversion,
explicit vector copying, field removal, shallow merge, object keys, array
length and membership. One catalog supplies argument/result domains,
qualified names and TypeScript declarations. Rust library internals remain
intentionally untranslated. Existing JSON bounds and UTF8 key ordering stay.

Forward rules select the actual active native state module from a genuine
parser frame, retain its complete CST and join the original facade context.
They check owned Json, genuine shared references/slices and Vecs, borrowed
text and native u64 identities. The original private caller/frame issuer,
source/layout records, ownership pass and emission reissuer remain required.
Only a genuine private state boundary can admit the parser's exact owned
Vec<Json> marker; ordinary arrays, foreign payloads, unknown generic identity
and later moves still refuse. A spelling, hash or public flag grants nothing.

The additive `owned-state.mjs` reverse profile retains five complete previous
implementations: source checking, emission/interpreters, full document codec,
paired types and source entrypoints. Fresh contexts require complete native
core/iteration/state sources, actual module edges, original Cargo/JSON inputs
and the registered runtime closure. Native imports and operation-derived
`Parameters`/`ReturnType` constraints feed the full body checker. TypeScript
keeps its original native annotation projection and full inverse. Every meta
decode and emission reconstructs the original source-bound caller again.

JavaScript inputs retain their shared immutable public ABI. Rust binds operands
once in source order and explicitly copies at owned JSON/vector boundaries.
This preserves reusable JavaScript values without claiming recovery of original
Rust parameter ownership. Complete aggregate result checks and both independent
interpreters remain. Generic mutation, arbitrary Clone/Drop, unknown containers,
callable effects and unresolved ownership stay refused.

`prepare-json-state-core.mjs` retains the complete prior Rust root and both CST
module-publication sequences. `prepare-json-state-sources.mjs` retains six full
JavaScript originals and native-selected substitutions for private issuance,
flow, emission, packaging and producer composition. `prepare-owned-state.mjs`
retains all five reverse originals. Earlier producers compose their exact
successors. The reusable composer checks complete adjacent source/inverse
equations without a saved semantic verdict or cross-invocation cache.

Independent source covers ten actual Rust callers, JS and strict original/target
TypeScript, both interpreters, source histories, Unicode order, null, empty
arrays, collisions, moves, wrong types/kinds, u64 bounds, forged metadata and
changed native/runtime bytes. Four native Rust oracle cases call the actual
new APIs. All sources are drafted and unrun. Native Rust grammar/behavior stays
in gated CI. No coverage, timing, freshness or full parity result is claimed.

General mutation/iterator adoption, persistent shared state, concurrency,
async/HTTP/streaming, full production synchronization and remaining native
Router gaps still need their implementation drafts. Current bank/export/output
refresh stays deferred until every remaining source draft exists.
