# Native scalar TypeScript projection source draft

All implementation and regression source in this checkpoint is UNRUN. The
ordinary standalone and tracked-project forward paths now carry already checked
by-value Rust integer identities into TypeScript signatures and checked locals.
The same renderer projects array elements and recursive data fields. It uses
relative import types for the actual primitive runtime declaration, avoiding new
local import names. The ten signed/unsigned 8/16/32/64/128-bit aliases retain the
BigInt ABI and each native range precondition; they are not runtime brands.

The presentation selector requires the matching existing fixed-primitive guard
and declines borrowed, owned, unresolved, pointer and identity-free domains.
Ordinary abstract integer types keep their prior rendering. Existing callers of
the layout and annotation APIs retain their default output unless they select
the explicit declaration module. The forward entry points select the module
from their actual runtime output path. Runtime guards and checked source/meta
issuers remain independent; a projected annotation grants no executable permit.

All seven reverse source paths recognize the corresponding static import-type
annotations only in the explicit primitive profile. They join the actual native
TypeScript qualifier symbol to the current exported type-alias node from the
independently authenticated receiving declaration. Separate declaration/runtime
folders retain their source counterpart rules. Wrong modules, missing exports,
typeof imports, altered declarations and unqualified bigint stay refused.

Twelve full compiler/library equations retain complete originals, native owners,
ordered language/repository stages and whole source/CST inverses. Unrun cases
cover exact aliases, arrays, recursive fields, function/local/future types,
standalone and project emission, strict TS execution, semantic-meta reparsing,
all seven receiving contexts with separate roots, and import/source refusals.
The adjacent native bitwise oracle remains a gated CI obligation.

This closes a source-drafted loss of integer identity in forward annotation. It
does not establish complete recognition of whole generated forward modules:
startup/guards/export tables, wider operations, production callers, native owner
closure, source-bank/export materialization and freshness, synchronization,
parity, all source requirements, receiving checks and delivery remain open.
No implementation, parser, translator, preparer, test, experiment, generation,
Rust tool or CI-triggering push ran for this checkpoint.
