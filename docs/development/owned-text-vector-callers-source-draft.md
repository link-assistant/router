# Owned text vector caller source draft

This additive continuation follows the [root source draft](owned-text-vector-root-activation-source-draft.md).
Every implementation and independent case below remains **UNRUN**. This is not
an executable coverage result, a native owner theorem, a completed receiving
qualification or a complete Router synchronization claim.

`owned-text-vector-outcome.mjs` and `owned-text-vector-cancellation.mjs` copy the
complete original caller implementations into distinct explicit profiles. The
original profiles, their String cloning behavior and their refusal domains stay
unchanged. Each new profile keeps its own private contexts, issued items,
runtime tokens and meta document label. Public shape data, serialized items and
source metadata cannot issue an item or substitute for fresh original checking.

The profile requires `primitiveOperators: true` and all eight current paired
String-vector ABI sources. Each context/currentness check joins the complete
original native source, actual receiving root, JS implementation, strict
declarations and transitive validator sources. Configurations are narrowed to
the original receiving paths rather than trusting arbitrary context fields.
New outer source scopes compose the existing primitive and failure-aware scopes.
Synchronous source closing and resource limits remain in place; asynchronous
runtime preparation rechecks the complete program after imports finish.

The copied native JS/TS checker resolves the actual import symbols and written
`ReturnType`/`Parameters` utilities, traverses the actual complete function and
issues IR only after its new move pass accepts that body. A Vec of String does
not enter the primitive Copy classifier. Owned String/vector/optional-String
values move; lookup clones its payload and returns no loan. Leading actual
truncate, len and from_slice calls independently qualify owned, shared and
slice inputs. Helpers use their freshly checked bodies and signature queries.

The invocation-local move pass versions owned places, records live roots of
borrowed String views and preserves argument evaluation order. Earlier argument
loans remain active through later argument evaluation. Moves or replacement
cannot revoke such a loan and then restore it before the call ends. Reassigning
a moved binding creates a new version and cannot revive a borrow of its former
value. Owned temporary loans end with their statement. Borrowed String views
and borrowed Result/Option carriers retain their actual tracked owned roots;
borrows of function-owned places cannot escape. No source/hash/owner/result
cache survives this analysis invocation.
State clones and joins are charged before allocation against the same bounded
analysis work allowance, including copied bindings, roots, loans and versions.

Control-flow rules join only continuing branches, conservatively join versions
and borrowed roots, and require every loop backedge to preserve the availability
of outer owned places. Returning or breaking paths are considered separately.
The pass refuses operations containing a tracked value until that operation has
an explicit role rule. Existing refusal/resource bounds and complete function
checking remain independent of this pass; it is not a second public IR issuer.

Both interpreters and runtime preparation contain actual new call handling.
Rust emission uses qualified paired native calls, native moves and explicit
shared argument borrows. Strict TypeScript uses the actual new paired String,
vector, slice and optional-String ABI witnesses. Meta is serialized and reparsed,
then its complete original sources are freshly checked before emission.

The additive canonical Rust inverse preserves the full original CST/meta
boundary, canonical support prefix, complete original source/path checks,
freshly issued JS program and exact complete Rust reproduction obligation.
Its syntax/type/call observations remain proposals. Native library leaves,
including the new String-vector leaf, cannot be rewritten as application code.
Old inverse APIs and optional-field/Result fallback behavior remain unchanged.

Independent source cases cover both profiles, Unicode and NUL, JS/strict TS,
both interpreters, meta readback, complete canonical Rust inverse, owned/shared/
slice parameters, helpers, aliases, conditional exits, loops, lookup lifetime,
owned String views, borrow invalidation, double moves, nested call-duration
loans, missing sources, forged metadata and original-profile refusals. Rust
oracle source uses the actual public library edge. All cases and the complete
source-substitution profile remain UNRUN.

Broader original Rust caller lowering and production adoption remain OPEN.
Additional owned aggregates, captures, callback ownership, mutable references,
all original type/namespace owners, platform/profile freshness, full receiving
export qualification, complete parity and bidirectional synchronization remain
OPEN. A source draft or canonical inverse proposal does not complete them.
