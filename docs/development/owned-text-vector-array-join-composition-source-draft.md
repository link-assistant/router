# Ordinary array and String-vector join composition source draft

One explicit request now composes the full original dense-array/literal,
discarded-push and length syntax substitutions with the full join/helper pass.
The syntax-only intermediate has no typed program. A complete new private
source check of the final module and every helper supplies the final program,
serialized/reparsed semantic meta and Rust/TS candidates. No original body,
namespace, ownership or ordinary Array coercion equivalence is inferred from
either syntax phase. Old public APIs and source refusals remain unchanged.

`proposeOwnedTextVectorArrayJoins` accepts exact family/sourcePath/arrays/joins.
Array selections carry explicit text-owned domain hints; join selections carry
function/local names only. Both are inert source-selection data. Construction,
text-copy and join helper contracts retain 64 source literal operands, 4,096
runtime vector values and the 1 MiB UTF8 text input/output boundary. Source
rules are language then repository; logical subpipelines retain their actual
chronology rather than inventing additional phase names. Original, intermediate
and final full sources, CST transport, comments, nested edits and inverses remain
available. Dense descriptor guards reject proxies, holes, getters and duplicates.
Metadata is bounded to 200,000 cells, depth 192 and 32 MiB text.

`proposeOwnedTextVectorArrayJoinDiscovery` composes automatic original-module
array discovery with an original AST census of matching joins. Every changed
supported module is independently reissued. Modules with arrays but no joins
also receive the full private check; unchanged and unsupported modules retain
their exact original source/inverse. Private checker, parser, source, resource
or inverse failures stay fatal rather than becoming a successful partial batch.
Syntax unsupported observations remain explicit and do not count as checked
modules or executable coverage. Original domain, owner, effect and full global
parity obligations remain open for every candidate. Original source bounds,
32-module batches, 128 join selections and 200,000 token/AST visits stay intact.

The paired API copies the complete existing paired proposal: require the exact
original TS-to-JS projection, compose written TS once, derive JS, and match the
private checked source to that exact projection. Both original source histories
remain present; concurrent differing JS is a conflict. No source is installed,
no synchronization ledger or coverage percentage is promoted, and no across-
operation cache is added. The portable join fold's repeated runtime validation
and performance qualification remain explicitly OPEN.

Independent both-family ordinary source/strict TS/full targets/interpreters,
meta/canonical inverse, default separator, construction-only, automatic mixed
module batch, pairing/conflict, source/domain/data refusal and CI-only Rust
oracle cases are drafted. All are UNRUN. No parser, compiler, translator,
preparer, tests, benchmarks or experiments ran locally; no CI/review feedback
was inspected. Wider original producer/namespace/owner, capture/reference,
async/network/state, receiving/freshness/performance and full parity remain OPEN.

Join discovery groups selected locals by function and traverses each original
function body once, preserving candidate order and the existing 200,000-visit
budget. Construction-only private reissue retains an explicit identity source
equation for its intermediate-to-final step. A 32-local single-function source
case covers this batching shape without executing it during drafting.
