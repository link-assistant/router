# Original-root HTTP borrowed text source draft

The HTTP caller checker now drafts the `body_base64` borrowed Result contract.
All new implementation and independent source cases are unrun.

The actual registered accessor must borrow a direct immutable public JSON input.
Its Result and extracted text retain that exact original root through local
bindings, checked meta and every return branch. Local owned JSON copies and
borrowed JSON aliases cannot supply escaping roots. No caller-supplied root
record or type annotation can issue a loan.

The emitter computes returned roots from the whole checked flow. A returned
borrowed string, including nested Results, introduces the actual native `'a`
parameter; only the required input roots receive that lifetime. Multiple
terminal branches join their real roots. Owned String results and unrelated
input loans retain their distinct types. Source, guards, roots and full meta are
freshly reconstructed after serialization.

The canonical native inverse may propose the accessor only through its complete
qualified original path. The independent source checker reissues roots and must
reproduce the entire original lifetime and return syntax. An elided or stronger
unproved native lifetime cannot be accepted from a token observation alone.

Complete original flow/emitter/projection sources, native-selected substitutions
and full CST inverses are retained. The earlier refusal now uses a local owned
JSON root, with new positive public-root cases and independent negative cases.
The handwritten native pointer/Unicode oracle remains reserved for gated CI.

General local loan graphs, borrowed resource escapes, broader lifetime syntax,
mixed-error conversion, production adoption, namespace closure and all other
unfinished requirements remain open. No translator, preparer or test was run.
