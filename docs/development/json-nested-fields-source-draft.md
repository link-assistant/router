# Nested JSON field source draft

Implementation and independent case SOURCE is drafted and entirely UNRUN. Full
translation, production coverage, parity, synchronization, freshness and receiving
qualification remain unfinished. No local parser, translator, preparer, generator,
test or compiler was executed, and no CI feedback was inspected.

General substitution rules copy all nine existing string-key native field reader
and default forms for depths two, three and four:27 added interfaces,37 total.
Complete originals retain actual native parameter, Option and borrowed-result
signatures. Rules add the next str parameters and bounded native get/and_then
chains, then repository rules rename actual function-name tokens. Named output
lifetimes depend only on the JSON receiver. Numeric array indexing remains its
separate original operation; the string key "0" never becomes an array index.

Matching JavaScript wrappers reuse original scalar readers and exact bool/u64/
i64 Option validators. One shared traversal checks the complete canonical root
once per call and every Unicode scalar key, even after a missing prefix. It
copies the complete actual private getMap implementation from the original JSON
runtime. Literal slash, tilde, Unicode and numeric object keys keep their exact
string semantics. Existing domain bounds, eager fallback checks, absent versus
Some(Null), false, zero and full-width integer behavior remain explicit.

The reusable source-copy producer now retains complete source dependencies for
copied private functions. It freshly compares full immutable source, native
selected original and target declarations and exact copied function text, then
serializes/reparses the original CST. Parent and adjacent histories carry these
original guards into their own exit checks. Only operation-local syntax sharing
is allowed; no source/hash/owner/verdict/result cache crosses operations. These
records grant no namespace, type, ownership, grammar or executable authority.

Both original adoption APIs and the fixed bulk stage select only closed literal
nested get callbacks with the same actual closure binding, optionally enclosed
in braces. Up to three nested steps combine with existing canonical scalar and
closed-default rules. Other callback/key/fallback expressions retain source and
evaluation order. Longer chains may retain a suffix after an admitted bounded
prefix; this does not claim a complete translation. Actual whole-function source,
type, primitive, ownership and receiver-root checks remain mandatory.

Three reverse checkers consume all actual key/fallback parameters and borrow
owned extra key strings in Rust emission. Twelve complete JS/TS equations join
27 native function copies and every earlier JSON source history. Export retains
the implementation, full originals, rules and native template archive. All eight
same-SHA JavaScript gates before fatal CI-only Rust remain unchanged.

Independent unrun source covers every depth/form, Unicode and numeric object
keys versus arrays, absent/wrong-kind/null, exact scalar boundaries, eager
fallbacks, invalid unused keys/noncoercion, both adopters, fixed bulk emission,
JS and strict TS targets, reverse dynamic keys/arity/domains and owned-key
