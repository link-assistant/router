The original complete derive-context receiving file exceeded its unchanged
60-second deadline (100,280 ms). The joined profile identified repeated native

This draft removes one concrete duplicate preflight on a subset of large proof
values. It does not claim that the complete deadline is repaired.

`prepare-negative-budget-proof-json.mjs` copies the actual complete native-owner
bootstrap, fresh guards and scoped logical census from
`private-native-proof-json.mjs`, using installed TypeScript 5.9.3 declaration
spans. It preserves both original helper modules byte for byte. The language
phase adds a negative witness; the repository phase wraps the builtin proof
consumer's existing serializer. All complete source proposals pass serialized,
reparsed CST boundaries and whole inverses. Unknown original source bytes or
changed original source pins refuse preparation. The historical comparison
fixture reverses the additional import and wrapper; original test bodies,
baselines and deadlines remain unchanged.

The new internal format records a per-call negative witness only when the
logical occurrence count exceeds the actual original 200,000-cell limit or the
actual original 160-level depth limit. Fresh parsing compares those constants
with the original composer and checks its original primitive, object, saved
subtree and recursive logical charges. Conservative 8,388,608-unit estimates
never grant this witness. A unit-only failure or an unknown shape retains the
complete original composer. Completed immutable arithmetic may be reused in
the current synchronous retained frame, with at most 4096 admissions in this
new factory-private scalar store. The original shared cost store and its own
4096-admission budget remain unchanged. No source, owner, verdict, digest,
encoded bytes or scalar record survives the original frame's lifetime.

A cell/depth witness proves that the old composer must ultimately use its
whole-value JSON fallback. It says nothing about an unvisited tail. That branch
still performs the dynamic `JSON.stringify(value)` lookup and full native root
operation. Unscanned getters, proxies, `toJSON`, native lazy stacks and thrown
exceptions therefore remain live. The new format may omit the necessarily
failing composer's internal plan allocations, arithmetic and private warming;
those observations are explicitly outside this new format's contract. The
original composer and serializer factories retain their existing contracts.
Outside a retained frame the wrapper invokes the consumer's original serializer
closure, preserving existing receiving instrumentation and scope behavior.
Hashing and its complete fresh string payloads remain unchanged.

original sources and limits, repeated logical aliases and depth, unseen native
