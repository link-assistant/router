# Complete installed TypeScript source transfer: draft

`exportCompactInstalledTypeScriptVault` and its optional CLI draft complete
portable source DATA for the actual lockfile-installed TypeScript5.9.3 package.
They resolve metadata only and never load or execute the SDK. No package was
installed, exported, parsed, compiled or tested during this source-only batch.
The new SDK facade composes the unchanged earlier complete transfer facade.

The actual source reader scopes original `js/package.json` and
`js/package-lock.json`, exact selected index/HEAD/physical closing and caught-
failure invalidation. The package census selects every installed file, including
nested resources, declarations, command wrappers, LICENSE and third-party notices.
Missing required original SDK files, differing version/lock integrity/resolution,
links, unsafe names, nonordinary files, changing census/identities and over-budget
input refuse. Positive no-follow/nonblocking support remains required.

All installed files are re-read as full bytes under exact original nanosecond/
identity/mode stamps before finishing and on every exit. All closing checks run,
including original source metadata/index checks; exact falsy primaries survive.
The codec records each package-relative path, mode and complete original bytes
under the TypeScript domain. Original package/lock and a complete DATA receipt
travel alongside them. No path points back to the original checkout after
materialization. The output must be fresh and separate from repository/package.

The original lock's exact version, resolved URL and integrity are checked. The
receipt honestly records `tarballIntegrityVerified:false`: installed directory
bytes alone do not establish the original npm tarball SHA512. No metadata pin,
source hash or fake package version supplies a genuine TypeScript/private caller
issuer. The eventual receiving compiler must independently load and check actual
installed source/loader origins and reject forged package implementations.

Storage retains the explicit compact contract: package files up to32MiB,
8192 package paths,64MiB package input,64MiB encoded vault including metadata;
original source package/lock add their bounded complete bytes. Full current
package bytes are retained only in this synchronous collection for complete
closing and cleared on all exits. RSS/speed/platform/whole receiving fit are
unqualified. This separate SDK bank is not permission to add multiple64MiB
banks outside an original aggregate receiving bound. A later acquisition manager
must account for every bank, raw source, object store and retained result.

Three independent source cases cover full package/license/nested resource/raw
lock preservation without SDK execution; independent lock/version/license/link
refusals; and all falsy primaries with a simultaneous installed-source closing
failure. Fixtures are deliberately storage-only invalid compilers; they do not
replace the future real pinned TypeScript receiving/compiler cases.
