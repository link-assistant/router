# Original attribute invocation source draft

This implementation and every new case is UNRUN. Only source construction and
review occurred. Tests, experiments, compiler diagnostics, translators,
preparers, generation, local Rust tools and CI-triggering pushes remain paused
until the complete remaining source draft exists.

Seven complete private issuer/reader implementations are copied into a distinct
attribute-expression family: invocation position batches and facts, original
invocation input capture/current read/facts, and expression-argument capture/
facts. They reuse the genuine direct attribute AST and exact original token
stream. Root, module-inner and actual member source associations retain their
whole source item, profile, attribute span, physical CST and current native
parser source-plan checks. No generated function wrapper is constructed.

Every position, input and expression receipt has a separate private identity
map. Function receipts cannot substitute for attribute receipts or vice versa.
Every read rejoins the complete current original attribute frame and its actual
private AST node. Captured argument trees must be the exact contiguous original
objects from that invocation. Detached trees, foreign frames, changed sources,
partial input and unsupported expression grammar remain refused. Positive
argument parsing requires the full original token range and EOF.

All source, token, depth, node and dense-tree bounds are preserved. The whole
existing documentation consumer retains these fresh position receipts alongside
its private expression frame and complete conditional native visitor premises.
This also reaches the copied full project and actual x86 metadata paths through
their existing consumer imports. No additional source/hash/owner/verdict/result
cache spans operations.

Positions remain syntax observations. Native visitor dispatch, ordinary import
confinement, argument macro ownership, attribute value semantics and global
exports stay unqualified; no new positive visitor theorem is inferred from the
copied function-family schema. Macro translation still requires actual native
owner and expansion joins. Four complete compiler source equations retain
original implementations, native owner spans, separate language/repository
substitutions and full serialized/reparsed CST inverses.

Independent unrun source cases cover root/inner/member inputs, actual argument
spans, nested Expr/Ty/Stmts observations, private-family separation, fake/foreign/
changed-source refusals and real documentation consumer integration. Existing
native documentation-expression oracle source remains. Actual macro/visitor/
export closure, wider attributes, production admission, parity/freshness/CI and
every other unfinished ledger requirement remain open.
