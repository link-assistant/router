# Selected scalar source-call composition draft

SOURCE ONLY. Source, graph cases, codec/runtime/native composition and all six
full source equations are UNRUN. CI feedback is uninspected. Full source drafting,
actual coverage, freshness, performance, runtime parity and delivery remain OPEN.

Actual named function symbols in the same complete source unit may select a
freshly checked primitive-scalar callee. Every callee is reconstructed from its
actual paired body and original native ABI in the same traversal. A bounded
operation-local function map avoids recursively rechecking shared callees; active
frames refuse recursion and all maps/sets clear on exit. Complete current input
fences run after source-call work, preserving primary errors. No source/hash/
owner/verdict/result state crosses operations or supplies a semantic issuer.

Call arguments retain actual bool/u64/i64/borrowed-str domains, evaluation order
and checked literal narrowing. Native calls use their genuine selected Rust
qualified name; standalone candidates use the corresponding emitted local name.
Only the same Rust module is admitted initially. JSON-derived text arguments
remain refused until a separate readonly loan proof qualifies that transfer.
Callees remain closed pure scalar functions; arbitrary calls/effects do not gain
permission from a name, ABI descriptor or saved source history.

Every emitted/decoded/serialized program requires its complete selected source
callee closure, matching original source spans, native names and signatures.
Small bounded codec summaries preserve the existing full source/CST envelope
and byte limits. Graph checks retain subtree height as well as cost, refusing
cycles, depth above 32 edges, over 16384 edges or expanded work above 100000 cells.
Native whole-function comparison joins each actual resolved call to the fresh
lowered function declaration and compares every selected callee body separately.
The interpreter reuses only this invocation's freshly checked program and rejoins
it on exit. Paths without source calls keep their original checks and avoid the
new graph walk/closing interpreter compilation. Graph summaries are inert DATA.

Cases draft six-function forward/nested call graphs under both authorities,
signed literal/alias arguments, JSON vector/value/scalar callers, omitted callees,
meta closure, recursion, shadowing, unsupported bodies, unselected/cross-module
callees, derived-text refusal,
cached-height/expanded-DAG bounds and repeat synchronization after proposed
installation. All remain unrun. Cross-file/module visibility, readonly loan
transfers, aggregates, recursion, async/effectful callees and all broader
namespace/trait/ownership/synchronization/receiving/race/platform/performance/
CI obligations remain OPEN. Eight same-SHA JavaScript stages still precede
fatal CI-only Rust. No local test, compiler, parser or translator ran.
