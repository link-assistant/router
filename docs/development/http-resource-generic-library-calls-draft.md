# Qualified generic shared library calls draft

All implementation, regression and native oracle source is drafted and unrun.
No tests, experiments, compiler diagnostics, preparer/translator execution,
regeneration, Rust tools, push or CI ran. Every unfinished [ledger row](bulk-draft-requirements.md)
remains open. This batch supplies no measured coverage or parity result.

Actual imported Option and String-error Result identity calls reuse the complete
three-language library proofs already required by their qualified signatures.
Only the matching original import and invocation-local source selection can
select a value operation. The existing end-of-analysis current-source joins and
fresh whole-source meta recheck still run. Public descriptors, generic flags and
source histories grant no executable or namespace authority.

The unchanged-value rule now retains full payload domains, moves and borrowed
roots for concrete calls and genuine generic carrier helpers that forward into
those libraries. Wrong carriers, type arguments, arities, shadowed imports and
consumed values retain refusals. Explicit TypeScript arguments preserve their
whole original qualified carrier docs when erased for JavaScript. Arbitrary
library calls, unconstrained carrier inputs and other generic effects remain
outside this closed unchanged-value theorem.

Native projection resolves only the exact registered qualified paths and emits
actual JS import aliases. Generic native helper bodies can forward to the same
actual carrier library; fresh JS source proofs independently check that proposal.
Original Rust turbofish obligations join both inferred and explicit qualified
calls in source order, with lexical slot and payload checks before full native
source reproduction. Original constructor contexts needing generic argument
proposal hints remain a separate prerequisite.

Operation descriptors are indexed once per invocation in native normalization,
projection and explicit-argument checking. These maps hold source DATA only and
are discarded after the call. No source, type, owner, verdict or result survives
across invocations. Existing node/depth, source, receiving and CI bounds remain.

Nine complete source equations retain native owners, both substitution sequences
and full inverses. Independent unrun JS/strict TS/native/refusal source covers
opaque values, absence/errors, nested carriers, actual ABI changes, borrowed
roots, exact original type arguments and 128 qualified calls. A separate actual
native library caller oracle drafts drop and boundary behavior for gated CI.
Architecture/producer closure, wider types/effects, production adoption/parity,
complete receiving, freshness/performance repairs and all gates remain open.
