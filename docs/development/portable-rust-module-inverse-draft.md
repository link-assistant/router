# Canonical Rust module inverse draft

The portable Rust entrypoint now has a separate source lane for the complete
private module envelope emitted by portable module packaging. Bounded Rust
syntax selects the actual module, named public uses and closed public scalar
type aliases. It accepts no additional outer application items. All complete
original bytes cross the serialized/reparsed CST boundary before checking.

The inner program receives fresh scalar decoding, semantic meta serialization
and reparsing, independent TypeScript/JavaScript checking and complete canonical
Rust reemission. Exact original emitter helpers used only by public type aliases
may be absent from the inner normal form. Only those complete known helpers can
be removed for the inner comparison; every application item must still match.
This option is internal to the enclosing translator, not a public source flag.

Repository rules reconstruct runtime aliases from the actual freshly checked
exported declarations. Closed scalar type aliases become native TypeScript
declarations. The existing public module packager then freshly emits the whole
Rust module, support types, visibility, aliases and outer type API. Its complete
noncomment syntax must equal the original Rust before any output is returned.
The outer full source equation retains the exact original inverse. A name,
copied program, helper hash or envelope selection grants no semantic permission.

Independent alias identity, Rust body edit, absence-only API, strict consumer,
forged outer item and full source-history regressions are drafted and unrun.
`prepare-portable-rust-module-inverse.mjs` retains the complete previous inverse
and its native-selected language/repository substitutions. Earlier source-copy
layers compose this successor. No local Rust, compiler diagnostics, tests or
translator qualification have run. This closes an implementation draft for the
emitted scalar module envelope; general Rust modules, constrained generic type
APIs, paired multi-file API restoration and production synchronization remain
unfinished.
