its exact inner/outer classification, the original parser's opening/closing
slice, and the existing AST payload constructor. A fresh source scope describes
actual whole-source tokens without inferring layouts or namespace authority.
Nested comments, multiline payloads, tab, quotes, backslash and Unicode remain
exact; CR and other unsupported controls retain explicit refusals.

The copied attachment and project adapters use that scope for both line and
block docs. Their complete original/doc/configured/expanded domains, actual
module positions, enclosing/target attribute checks, budgets, profile/source
rejoins and full CST inverses remain required. Old line-only scope/normalizer
APIs keep their narrower domains. Macro token projection now correctly ignores
ordinary `/**/` and `/*** ... */`, and retains actual block doc features/spans
while the existing macro engine and generated literal-attribute checks remain.
This lexical projection supplies no generated owner or executable permission.

lexical boundary, nested/multiline payload, attachment, generated macro and
refusal case source are drafted. Function-local attachment, wider conditional
producers, architecture/type/bootstrap closure, production adoption/parity,
receiving and all remaining ledger requirements remain open. No tests,
experiments, compiler/preparer/translator, generation, Rust, push or CI ran.
