# Independent Node evidence writers — source proposal

This proposal retains full original run-node-tests.mjs and node-case-deadline-reporter.mjs before/after pairs. The active scripts are unchanged until Root integration. Project verification, case execution and subprocess qualification are UNRUN.

The parent runner captures actual fixed policy at the executable source root and the original public selected test root, coalescing identical canonical roots. A public root option cannot replace executable-root protection. Genuine general async scopes retain every active root's veto across the original awaits. Policy is captured before source production and writes. The original selected-file, case/deadline, command, process-group, raw-output and audit machinery remains; no workloads, flags, concurrency or timeouts are changed.

All seven known output file names are preflighted before the first request write. Request/command/terminal/refusal files use owned exclusive FDs with actual post-open alias admission. Raw logs have lexical ownership across stream awaits, actual FD admission immediately after acquisition and before every write chunk, and independent closure even when source policy is revoked. The original full partial raw bytes,256MiB stop threshold, no-progress refusal, chunk forwarding, exact readback and identities remain. Original stdout/stderr forwarding remains unchanged: inherited stream descriptors may be pipes/TTYs and the existing native FD observer only admits regular files. Forwarding FD admission is explicitly OPEN pending an additive observer that preserves these original stream domains. No borrowed descriptor is closed by this helper. Digest finalization moves inside the existing FD-closing try so it cannot bypass close. Leaked owned FDs are attempted independently at invocation exit. Existing source64MiB accounting now includes retained policy bytes for both roots; this explicit accounting can refuse a run exactly at the prior source-only boundary.

The child reporter independently captures actual fixed policies at its executable source root and the original parsed request.root before audit production. It retains them across its original builtin TAP generator forwarding. No parent ALS state, public flags, caller policy object or sourceRoot override grants permission. The original receipt128MiB cap and wx0600 intent remain. The exact receipt path is admitted before open, then its actual owned FD is admitted before writing. Every captured policy closes on receipt success/refusal; a capture or source-epoch failure prevents receipt emission while TAP forwarding and original failure reporting continue.

The fixed helper derives executable root from its own physical source module URL in the same package as both scripts. Receiving cases retain the entire module and only relocate actual native import nodes with full language-then-repository inverses. Cases cover actual and selected roots, protected hard-link aliases and policy-self, FD custody across awaits, closure after revocation, expiration, and an actual separate child reporter receiving module with a spoofed empty public test root attempting a missing protected executable source destination. These are unexecuted case sources.

The default native fs.mkdtempSync complete- directory creation remains exactly the original operation. Fixed parent observations and post-created exact entry admission do not prove its generated child name was admitted before creation. That pre-creation namespace clause is explicitly OPEN; this batch does not claim that default generated directory sink qualified. Supplied outputDirectory mkdir and all actual file/FD targets have pre-mutation admission. A later dedicated fixed builtin exclusive-temp operation may address the native generated-name boundary without treating the whole parent as renamed or taking public freshness flags as authority.

Python/Bun launchers and arbitrary transitive test/application subprocess writes remain independent OPEN sinks. The wrapper does not qualify child test workloads. L04/S03 and complete production function/writer denominators remain OPEN/UNKNOWN. No persistent verdict or source-permission cache is introduced.
