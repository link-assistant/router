# Primitive scalar core call source draft

All implementation and independent case SOURCE is UNRUN. No local parser,
translator, generator, test or compiler ran; CI feedback is uninspected. Full
production translation, parity, synchronization and delivery remain open.

Integer source rules now recognize exact current JSON field, text, integer,
Option and Result helpers that return a native fixed-width scalar. Written
lexical input roles expose only the known operands needed by those calls;
ordinary complete local initializers can seed a later integer receiver. Inline
qualified calls retain their complete original receiver expression and execute
once in the substituted source. Unknown effects, wrong widths, borrowed/text
results and unmatched arguments remain unselected. No source role grants real
owner, type, trait or executable authority.

The bounded composition runner can revisit the earlier integer family after a
later JSON field family introduces a scalar helper, avoiding manual restaging
for that common prerequisite. Existing ordered rules, actual final whole-function
checks, arithmetic semantics, target/native bounds and borrowed ownership rules
are unchanged. This adds no runtime API and changes no semantic type checker.
Generic/noncanonical carrier spellings, aliases of nonprimitive input carriers,
inline binary expressions containing helper calls, chained methods requiring
further rounds and wider source forms remain separate obligations.

Four complete compiler equations and independent unrun parameter-role/callee/
width/refusal cases, both original integer adopter APIs,4 direct helper callers,
actual JSON-to-integer fixed-point composition, JavaScript/strict TypeScript,
native standard-expression oracles and exports are drafted. Every source/native/
production/sync/freshness/parity/delivery requirement remains OPEN, with all eight
same-SHA JavaScript gates before fatal CI-only Rust unchanged.
