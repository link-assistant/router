# Canonical scalar Rust inverse draft

`translatePortableRust` reconstructs complete Rust source through the actual
CST boundary, parses the supported scalar functions/constants, checks and
serializes/reparses their meta program, and requires complete syntax equality
with a fresh Rust emission. Known compiler support declarations must match
their complete actual source. Nothing is admitted from a function name, hash,
stored meta document or omitted source item.

The resulting TypeScript passes the independent written-type/source pipeline
to produce JavaScript and a second checked semantic document. That checked
JavaScript must emit the same complete Rust syntax again. Original comments
and whitespace retain a full source equation and inverse. Robust Rust CST
tokens keep nested comments opaque. There is no new persisted source, hash,
owner, verdict or encoded-result cache.

This additive inverse supports the canonical scalar output subset. It refuses
arbitrary Rust normalization, unknown declarations/attributes/macros, duplicate
bindings and source the existing parser/checker cannot represent. It does not
silently treat transparent-method parsing as proof: any lost operation changes
the final complete Rust syntax and fails the roundtrip. General Rust ownership,
classes/state, async, collections and the emitted absence/generic envelope
families remain separate obligations.

Portable source units try this explicit profile for Rust changes. Only its
specific unsupported-profile error falls back to the original complete forward
translator, whose existing source refusals remain required. Infrastructure and
native checker failures propagate. Accepted inverses retain both meta documents
and the complete original Rust history in the synchronization proposal.

`prepare-portable-rust-inverse.mjs` retains the entire original frontend and
synchronizer. Native-selected substitutions make a frontend copy, accept the
compiler's exact formatting attributes and bind existing checked scalar
builtins. Separate repository rules integrate synchronization. Complete CST
inverses and physical original joins remain required. This family and its
behavioral, source-edit, nested-comment and refusal regressions are drafted and
unrun. No local Rust compiler or verification has been executed.
