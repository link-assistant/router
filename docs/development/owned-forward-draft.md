# Forward field and owned carrier source draft

The existing forward owned-call parser, private whole-function checker/emission
issuer and flow analysis now have source rules for the six field readers and
nine owned JSON carrier operations. A shared catalog retains each complete
native leaf, module, runtime, signature and return domain. The original twelve
state operations remain in that catalog. The private call receipt and fresh
whole-function/source/layout recheck remain mandatory for every family.

Qualified native source paths select active original module views and full
serialized/reparsed leaf CSTs. Language rules check actual JSON, standard
Option/Result, String, shared-reference and fixed-integer identities. Field
loans retain their live receiver root through optional payloads. Carrier inputs
are borrowed, while library copies produce owned outputs. Current original
source and canonical layouts determine the allowed carrier domain; a profile,
operation spelling or public metadata cannot authorize a caller.

The shared flow analysis tracks field roots, exact carrier borrows and native
owned String payload destruction only in a function with a genuine checked
carrier boundary. Existing move, lifetime, branch, callback, effect and unknown
aggregate refusals remain. Result conversions and Try behavior outside the
existing independently checked source lanes remain separate obligations.

Repository rules group runtime imports by the actual state, field and carrier
modules. Both complete host asset builders include the carrier runtime and
declarations. The main host extension stays at its existing 999 lines; new
domain rules live in separate modules. Nine complete original implementations
and preparation consumers retain ordered language/repository substitutions,
source spans, serialized/reparsed CST equations and full inverses.

Independent actual native caller source, strict JS/TS behavior, wrong type,
borrow escape, counterfeit leaf and forged-emission cases are drafted. No
implementation, compiler, translator, history producer or case has been run.
Production application/adoption, full native namespace closure, generic flows,
remaining effects, CI/freshness repairs and every larger open ledger row remain
unfinished. No measured coverage or runtime parity claim follows from this draft.
