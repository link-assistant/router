# Temporary-client profile and settings draft

SOURCE ONLY; no profile preparation, child process, compiler, translator,
preparer or independent case has executed. Full requirement drafting continues.

A shared template produces actual paired process-local settings and profile
preparation. Claude defaults to a private persistent Router-owned profile and
extends normal settings only when requested. Codex/Grok extend normal settings
unless explicitly isolated. Gemini, OpenCode, Qwen and Agent use Router-owned
persistent profiles or disposable profiles when requested. Normal profile contents
and login files are never copied. Environment routing carries the prepared token;
client configuration carries only the existing environment-key indirections.

Persistent profiles use a finite one-second acquisition of the existing native
file lock for the complete callback. Disposable directories are random/private,
live through the callback and are removed only after checking their filesystem
identity. Replaced roots are preserved. Cleanup walks at most 10000 entries and
32 levels before recursive removal; exceeding that budget retains the directory
for explicit cleanup. System temporary directory aliases are canonicalized before
the existing symlink checks; explicit temporary-root links remain refused.
Concurrent persistent profile scheduling and crash/lease recovery remain OPEN.

Claude settings retain exact picker IDs, disagreement-safe capability metadata,
provider ordering, unavailable labels and built-in family visibility. Saved or
inherited model choices are checked against the live authorized catalog before
fallback pins. Privacy defaults are mechanically copied from the complete native
constant arrays and never overwrite inherited user choices. Codex receives an
isolated process provider, complete model projection and environment PAT aliases,
while normal TOML bytes remain untouched. Reasoning metadata absence is unknown;
contradictory selected defaults and unsupported configured efforts refuse. The
existing codecs supply OpenCode/Agent/Qwen provider files; Gemini gets API-key
selection and only one-shot runs receive the native workspace trust setting.

Five complete source equations retain both phases/full serialized-reparsed CST
inverses and six complete original native files. Independent unrun JS/strict TS/
native source covers all profile modes, picker/metadata disagreement, saved models,
private modes, exact normal file preservation, environment-only credentials,
disposable failure/identity cleanup and real Codex projection fields.

The temporary process dispatcher, run credential mint/model policy/heartbeat/
revocation, ephemeral bridge composition, Claude version/profile migration/reset,
Codex isolated-vs-extended discovery differences and platform/CA/terminal behavior
remain OPEN. This component adds no semantic/source owner or executable authority
and closes no wider forward/reverse/sync/parity/receiving/delivery requirement.
All verification remains deferred; Rust stays CI only after all eight same-SHA JS
gates, with no local Rust tools and no CI feedback inspection during drafting.
