# Freshly checked iterator adoption draft

Implementation, source history and independent regression sources are drafted
and unverified. No application proposal has been produced or installed; no
tests, experiments, translator/preparer execution or Rust tools have run.

`planCheckedJsonIterationAdoption` recomputes the actual source adoption against
the complete physical Rust tree and package/workspace Cargo inputs. Maintainers
can select a bounded set of actual file/function names or the complete current
candidate set. Selected source spans are replayed through full serialized and
reparsed CST equations. Every selected complete function must then survive the
existing fresh project parser, original private source/type/ownership checks,
checked semantic meta and both target emitters. Any unresolved selected body
fails the complete proposal and leaves the source untouched.

The resulting plan retains exact original source, full inverses, function
coordinates, complete semantic metadata and emitted JS/TS for review. Apply
recomputes all of that from current physical inputs before calling the existing
bounded source transaction. Changed native/workspace Cargo inputs, source,
Git baseline, metadata output or proposed bytes refuse installation. Metadata
cannot replace a captured source or Cargo file. Existing byte limits, ordinary
file capture, atomic per-file writes, modes, readback and rollback remain.

The transaction's installer and bounded source reader are also exposed as
ordinary DATA utilities for these actual producers. They grant no compiler,
source-owner, semantic or runtime permission; each compiler consumer must still
use its private fresh checks. Full prior runtime/producer implementations and
their successor equations remain under `prepare-checked-iteration-adoption.mjs`.
The original independently reviewed JSON-reader application API stays intact.

This validates proposed replacement callers through the existing compiler. It
does not prove original standard Iterator/Clone dispatch, native behavior,
whole Router translation or runtime parity. Independent JS/strict-TS cases,
standard/native Rust oracle checks, receiving review and the full same-SHA gate
remain required after the complete draft. A plan with no closed candidate is
refused rather than interpreted as complete source coverage.

Unrun regression source covers selected whole-function checking, actual JS/TS
behavior, complete source/CST inversion, sibling preservation, unresolved
selected bodies, forged and stale plans, workspace protection and source history.
No application coverage or performance gain is claimed.
