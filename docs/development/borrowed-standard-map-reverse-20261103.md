# Standard borrowed map reverse source draft

The actual original owned-core and vector-candidate source readers, emitters and
independent interpreters now contain a separate shared standard-map predicate
path. The four complete original modules, complete successor sources, inverses
and counted substitutions are retained in the fixed source archive. Its language
rules describe checked inputs, literal operands, evaluation and shared native
types; repository rules attach fixed runtime imports, input prefixes and module
bindings. Each complete stage transports serialized/reparsed CST separately
from the original private native parser, import symbol, type and whole-body
checks. None of the source recipes qualifies a caller by itself.

The additive native source operation accepts a complete receiving Rust tree
within a separately declared 4096-file/16MiB domain. The old opaque-map API keeps
its original 512-file/8MiB limits. Every selected call reconstructs the actual
root/module graph, Cargo edition/dependencies, private parser and source ABI.
The native receipt remains inside its synchronous operation and is checked at
all closing boundaries. No receipt or native owner verdict is saved on the
reverse source context. Unknown producer/namespace/source states still refuse.
This does not prove an invoked rustc unit, actual sysroot or runtime parity.

Input types are selected through the original imported predicate's actual
`Parameters<typeof predicate>[0]` declaration owner. The whole caller must use
that actual input parameter, a checked scalar string key and at most 64 pure
scalar string literals. Local map aliases, mutation, escape and returned map
loans remain refused. A returned boolean has no loan. Rust emission evaluates
the map and key once, in order, into fresh private temporaries and emits a
qualified native helper call with an explicit shared literal slice. TypeScript
emission retains a source-bound operation-derived input annotation and the
same native Map input-shape prefix as the forward boundary. The prefix certifies
native Map slots only; it never scans or certifies unobserved entries. There is
no entry-count or value-byte limit on the predicate's standard map input.

Both original runtime evaluators select the actual predicate module and validate
native Map input shape independently of emission. The old runtime modules,
opaque-map representation and old API domains remain separate. Literal array
spread, holes, computed elements, excess literals, unpaired surrogates, forged
imports/declarations and copied checked-body DATA cannot grant this path.

All execution and cases are **UNRUN**. In particular direct forward-generated
`ReadonlyMap<string, string>` annotations need their own genuine TypeScript
standard-library declaration selection: the old noLib traversal must not treat
that name alone as a type-owner proof. Full forward-target reverse regeneration,
paired receiving, source-epoch continuation of the four changed parents,
strict target compilation and current coverage remain open. Complete production
tree cases are drafted without replacing the application with a miniature root.
