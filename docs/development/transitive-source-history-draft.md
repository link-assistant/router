# Transitive source history composition draft

Source review found that the complete source-copy producer joined only each
immediate child plan's direct file list. If an intermediate family did not edit
a shared facade, profile or driver, a later genuine edit to that file could not
reach the older ancestor's full source equation. This could reject the complete
current source despite every adjacent source history being present.

The drafted producer forwards a separate `descendantFiles` vector. Each plan's
original direct `files` membership and the writer's direct installation contract
remain intact. Older ancestors can join a child's direct or forwarded source
row by exact path, complete before/current-after strings and full CST inverse.
Skipped files retain their original source, both substitution phases, native
selections and all intervening history. No checksum or public metadata becomes
a source, owner, type or executable permit.

Each ancestor freshly rejoins complete physical descendant source and retained
original snapshots before returning. Duplicate paths, missing originals,
accessors, sparse rows and broken adjacent inverses refuse. Existing per-file,
archive and direct-plan limits remain; forwarding adds a 4,096-source limit and
a 128 MiB sum of retained descendant original/final raw strings. This is not a
measurement or bound for every history object's allocation. All storage stays
inside the current producer invocation; no persistent result cache is added.

Complete original producer source and its native-selected language/import
substitutions are retained in the new source profile. Independent unrun cases
cover an actual three-plan gap, direct-list stability, full inverse joins,
changed physical/original sources and malformed DATA. The complete current
source-family history chain and receiving exporter still require qualification
after every source requirement has been drafted. No preparer, compiler, test,
experiment, Rust tool or CI ran for this draft.
