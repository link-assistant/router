# General qualified callback function source draft

All implementation and independent cases are SOURCE only and UNRUN. No tests,
compilation, compiler/preparer/translator execution or CI feedback review occurred.
Full translation, reverse/sync qualification and verified coverage remain open.

The reusable rule reifies an exact original qualified callback function path
through a closure calling that same path. It does not redirect standard spellings
or infer a native owner from a name. The existing closed core-signature adapter
keeps its prior behavior and runs first; other compatibility-core paths cannot
fall back to the general adapter. Bare values, function pointers, casts, turbofish
and unresolved output contexts remain unsupported by this source adapter.

All three Option/Result selectors provide only a closed expected return-role
candidate from their original method and enclosing declaration. General path
roles are explicitly contextual DATA. No return annotation is inserted, and no
type, ownership, capture, binding, trait, effect or executable proof is issued.
Every whole original function and actual replacement callback must pass the
existing independent checks, including missing/incompatible callee refusals.

The complete original layered CST source engine is copied, preserving all its
old APIs. A separate language rule retains original path/comments and introduces
a fresh neutral callback parameter; the repository sequence binds its fresh
actual name. Complete before/after CST serialization/reparse, parent and child
inverses and an explicitly synthetic source wrapper remain required. Original
paths are bounded to8 components and65536 characters; whole function bounds,
4096 collision attempts and32 shared successful body plans remain unchanged.
No source/hash/owner/verdict/result cache survives an operation.

Five complete compiler equations and independent unrun path/domain/context/
refusal/hygiene/budget/six-API/fourteen-caller/JS/strict TS/native/export source
are drafted. Existing reverse obligations remain mandatory; the general source
adapter alone does not prove arbitrary named-call reverse support or receiving
qualification. Global namespace/producer/hygiene/type-prefix closure, wider
production language/native parity, reverse/sync/freshness and delivery remain OPEN.
