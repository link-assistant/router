# Closed import alias and type parenthesis source draft

All implementation and independent cases in this checkpoint are UNRUN. The
existing TypeScript alias substitution reader now retains closed static import
types as source leaves. A leaf must have a literal module and a single type
identifier without typeof, type arguments or attributes. Local/generic alias
substitution keeps its original native symbol, cycle, constraint, span, CST and
full inverse checks. A retained import leaf grants no module or type admission;
the complete expanded body still enters the original private receiving checker.

All seven source paths now share bounded transparent parenthesis handling for
written native types. The helper preserves the exact inner native node and
limits wrapping to 160 levels; it neither resolves a type nor caches a result.
The existing actual runtime/declaration/Cargo inputs, native qualifier-symbol
joins, explicit primitive flag, source body checks and checked meta reissuance
remain required. Plain bigint aliases, unknown exports and wrong modules cannot
supply a native scalar domain merely because their syntax expanded.

Ten whole compiler equations retain complete originals, native owners,
language/repository stages and complete source/CST inverses. Independent unrun
cases cover every receiving profile, actual alias/generic/import/parenthesis
checking, primitive behavior, source history and malformed/unknown/typeof/
generic/namespace/depth refusals. Existing native scalar Rust oracles remain
required in gated CI.

Public native scalar export aliases remain a separate open source requirement.
All actual native owner/global/effect closure, wider language and complete
production translation, source-bank/export materialization and freshness,
whole synchronization, parity, receiving checks, remaining source and delivery
gates remain unfinished. No implementation, parser, compiler, translator,
