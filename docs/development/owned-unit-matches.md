# Owned unit-enum matches candidate

This source-only candidate extends explicit owned API adoption. It does not prove
an old bare `matches!` owner, install application edits or establish new executable
coverage. Root must materialize and independently qualify it.

`crate::translation_core::matches_unit!` re-exports the existing qualified
`::std::matches!` wrapper. The library implementation remains native. Its forward
parser accepts only unguarded zero-field constructor alternatives, then reuses
`checkedOrderedMatch` and the complete private Copy/no-Drop unit layout from
`unit-enum-cast.mjs`. Payloads, bindings, guards, wildcard and scalar patterns
are outside this operation. Unknown attributes, macro producers and ownership
remain refusals. No Host, target runtime or runtime-asset body changes are proposed. The original
parser correspondence scan additionally records ordered-match nodes; this is
source custody only and never const or namespace authority.

Const lowering requires the unchanged original parser-issued declaration/node
association, its exact parser and a freshly rechecked owned facade. Public const
flags, checksums, cloned or foreign nodes cannot issue that association. The new
WeakMap retains parse custody only; it holds no source verdict, digest or encoded
payload. Existing ordinary standard and owned literal matches keep their domains.

The separate source-backed adopter copies the complete original literal corpus
producer through native TypeScript nodes, retaining whole parents, attributes,
active/inactive bytes, Cargo inputs, other-macro barriers, CST stages, mappings
and inverses. It selects original bare calls only. Constructor alternatives adopt
`matches_unit!`; exact original scalar-pattern alternatives retain the existing
owned `matches!` API, including functions with enum formals. Mixed alternatives,
guards and opaque producers remain unchanged. A fresh checker decides every
rewritten function. No public proposal field grants admission.

A second opt-in copy of the original primitive adopter selects the existing
same-issuer enclosing context. All original typed-position, named-lifetime,
escaping-borrow, mutable-reference and unresolved producer checks stay unchanged.
This may close supported attributes before `&str` adopts qualified `&Str`; it
cannot make an unknown source scope harmless.
