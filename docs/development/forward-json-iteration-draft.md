# Forward predicate and fold source draft

The actual forward collection path now has coordinated source rules for the
five predicate/fold library APIs. Native parser frames select the qualified
module and its complete active source view, retain its full CST, and join the
existing genuine compatibility-facade context. Complete source equality,
current frame/cursor/view checks and every original private caller issuer remain
required. The shared operation table chooses a domain; it grants no permission.

Language rules check actual shared JSON slices, original inline lambda arity,
boolean predicate results, owned fold initial values and owned accumulators.
Any/all return bool, filter returns an owned vector, find returns the complete
canonical Option<Json>, and fold returns owned Json. All explicit expected
types and original primitive/ownership checks still run.

The original whole-function ownership pass retains its genuine call check,
live slice roots, callback capture refusal, single cell/depth budget and
independent checked callback walk. A fold-owned lambda input exists only in the
private child state for that genuine library operation. Its local bindings
remain linear; later moves and captured owned/mutable state still refuse.
Lifetime analysis separately binds shared item origins, rejects borrowed
accumulators and keeps owned outputs free of borrowed source origins.

Repository emission reserves all helper names and selects the registered
runtime imports after the original emission reissuer has checked the complete
actual function, call, source spans, layouts and dependencies again. Legacy
map/filter-map paths retain their original behavior and source hash API.
The original generic source-copy selector also has a narrowly extended native
class-owner rule, so the actual emitter class can retain exact selected edits.
All originals, recipes and both complete CST inverses are stored in the two
source profiles. No source/owner/verdict cache was added.

Independent regressions cover six actual Rust caller bodies, empty identities,
owned folds, strict JS/TS output, wrong predicate/initial domains, changed
library bytes, wrong namespaces, forged emission contexts and complete source
history. They are unrun. Native module/library oracle source remains CI-only
after every required same-SHA JavaScript stage passes. General standard
iterator adoption, nested combinations, mutation/state, async/HTTP/streaming,
production coverage and full synchronization remain open. No global coverage,
performance, freshness or gate result follows from this unverified source draft.
