# Source-qualified signed integer family draft

The resource lane now composes actual i64 integer, primitive Option, Result and
Option/Result callback operations from their complete existing matching sources.
Positive literals get signedness from actual operation/callback contracts or a
freshly resolved original return query. Negative literals retain exact i64
bounds, including the minimum value. Primitive `bigint` spelling alone does not
establish a public signed input domain.

A complete copy of the original guard/body selector accepts distinct actual
u64/i64 entry ranges and errors. Each guard must match its actual parameter
domain. Native inverse proposals emit the matching original signed guards and
operation-derived signed signatures. Return and callback obligations retain
the original body checks; signed scalar captures, mutable locals, comparisons,
recursive returns and cold value types compose the same checked meta path.

One source-local numeric constraint pass follows real parameter domains,
qualified operation arguments/results, return obligations, assignments and
comparisons to select literal representations. It neither grants a type permit
nor skips any whole-body/source/state check. Constraints are bounded and local
to one analysis; conflicts refuse. Nested callback scopes receive their own
actual contracts. No source/hash/owner/verdict/result cache is introduced.

Public signed payload containers still refuse until recursive payload guards
exist. Unresolved lexical numeric constraints, general casts, mixed-domain
arithmetic and wider numeric/language domains keep explicit refusals. Ordinary
native grammar, namespace/producer closure and whole-Router parity remain
separate obligations.

Full original guards, contracts, caller/checker/projection sources, two ordered
substitution sequences and complete CST inverses are retained. Independent
unrun JS/strict TS/native source covers both signed limits, saturation, wrapping,
checked division, callbacks, recursion, positive locals, original range guards,
wrong domains and forged meta. A fifteenth independent native oracle joins
existing gated CI discovery. No compiler, translator, preparer, diagnostic,
test, runtime or Rust tool executed for this draft. Every remaining bulk
requirement and receiving/freshness/CI qualification stays open.
