SOURCE ONLY. All implementation, equations, cases and receiving obligations are
UNRUN. Whole drafting, coverage, parity, freshness, resources, platforms and CI
remain OPEN. No implementation, parser, translator, test or compiler ran locally.

The actual private source traversal now drafts no-else guards in a source-bound
unit-returning function when the original then block genuinely terminates. The
remaining actual original AST statement nodes form the false continuation; no
fabricated node or copied syntax marker receives original-source permission.
Condition refinement, binder symbols, moves and original branch/tree limits stay
in the private checker. A final unit continuation may fall through to the same
explicit canonical unit return used for whole functions.

Source emission reuses the existing complete if/else model and serializes/reparses
its full CST/meta before fresh native comparison. Ordered effects before and after
the guard retain their branch location. Nonterminating then blocks, nonboolean
conditions, mixed return types, shadowed roots and unregistered discarded calls
remain refused. This is not a general arbitrary fallthrough or effect rule;
original native statement-control forms still need their own observation rules.

Two complete source equations preserve originals/inverses under exactly language
then repository phases. Independent drafts cover explicit/final implicit guards,
multiple guards, immutable continuation locals, branch-specific qualified JSON
validation, both source authorities, strict typed behavior, independent interpreter,
exact ordered effect prefixes and refusal/source boundaries. All are UNRUN.

receiving/CI remain OPEN; fatal Rust stays CI-only after eight same-SHA JavaScript
gates.
