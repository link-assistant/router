# Automatic primitive Result method adoption source draft

Four complete source copies provide Result method selection, corpus proposals,
compressed packets and fresh selected installation. The new fixed packet
sequence is `primitive-result-methods`. Ordinary immutable closed primitive
Result inputs support predicates, unwrap/expect/default, success/error Option
conversion, map, binding, error mapping and lazy recovery/default chains.
Callback bodies remain intact for independent checking; proposed output types
and method spellings grant no executable permission.

The source selector retains original module/import/producer refusal rules,
closed native String error identity, exact edits, ordered language/repository
substitutions and complete inverses. Selected installation rechecks complete
current bodies and native dependencies, recreates both targets, and compares
the entire fresh proposal before atomic installation. No cross-invocation
semantic/source/owner result cache is introduced.

Independent regression source covers strict typed output, false/zero/empty,
signed/unsigned boundaries, error ownership, mapping/binding chains, unchanged
unselected callers, complete packets, forged installation and bad callback
bodies. It is unrun, as are all new producers/translators. Arbitrary Result
success/error types, residual conversions, wider control/effects, production
application and the rest of the complete requirement ledger remain open.
