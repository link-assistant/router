# Copy the offline Rust → meta-language translator

Run `node scripts/export-router-translator.mjs --output /absolute/path/new-bundle` from a committed compiler checkout. The parent directory must exist and the destination must be new, separate from the source repository. The command reads only committed regular compiler inputs and refuses changed source bytes, a changed index, missing inputs, source links, or existing output paths. Each Git command has a ten-second limit; collection is bounded to 2,048 files, 4 MiB per file and 64 MiB total. It builds no Rust code and downloads no dependencies.

The bundle includes the forward CLI, compiler modules, extensions, vendored meta-language and complete checked-in original-source profiles and licenses. `translator-bundle.json` records the source commit and every relative input path, Git object, mode, byte count and SHA-256. A fresh unborn Git index enumerates those exact original modes and object IDs for bounded compiler-profile discovery; it contains no source commit or receiving application sources. Inherited Git environment overrides are ignored. Object ingestion bypasses attributes, filters and line-ending conversion. Generated drafts, repository application source, the repository fixture checker, test evidence and installed dependencies are excluded. The bundle retains the original compiler's capability limits; its inventory is not a proof of complete runtime parity.

Use `node /absolute/path/new-bundle/scripts/translate-router.mjs --root /absolute/path/target-repository` to bulk draft the target's Git-tracked Rust sources into meta-language, JavaScript and TypeScript. `--check` checks output freshness, `--entry TRACKED_RS` selects a tracked crate root, and `--profile-matrix` creates the declared neutral, Unix-family and Windows-family drafts. Review Cargo/dependency, source namespace, platform and effect assumptions for the target. Refused source remains recorded with its complete original text; generated callable behavior is limited to checked constructs.

Compile emitted TypeScript strictly and execute shared behavior fixtures against both targets in the receiving repository. Keep its Rust CI behind its complete JavaScript gate and strict parity contract. The existing relocated translator fixture compares the complete ordered compiler fingerprints, exercises independent tracked module resolution and both emitted runtimes, and rejects altered pinned-source archives. Each CLI child is bounded to 30 seconds, each receiving-repository Git child to 10 seconds, strict TypeScript compilation to 30 seconds and export to 180 seconds; the complete fixture is bounded to 600 seconds. The export draft's new controls are source-only until its own complete verification receipts are recorded.
