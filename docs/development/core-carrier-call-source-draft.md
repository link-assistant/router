# Shared qualified core call source draft

All implementation and independent case SOURCE is UNRUN. No local parser,
translator, generator, test or compiler ran and CI feedback remains uninspected.
Full source translation, parity, synchronization and delivery remain open.

A reusable language source reader splits complete bounded qualified calls into
their actual path and argument token views, preserving literal punctuation and
nested delimiter groups. Repository rules then select only current qualified
text, integer and primitive Option contracts. Exact current lexical roles,
closed matching native literals, explicit owned-string borrow views, canonical
Some/None and recursively bounded known helper calls determine result source
roles. Generic/captured/effectful/unknown calls remain unselected. No syntax,
spelling or result metadata grants a real binding, type, borrow or permission.

Both original Option selectors, their invocation-local carrier initializer
tracker, and the text selector/local tracker reuse that reader. A prior helper
result can therefore feed another source rule in the same or a later stage;
there is no across-operation value, source, hash, owner or result cache. Whole
original function checks and normal runtime bounds remain mandatory. This adds
no new runtime or native operation and changes no semantic ownership checker.

Eight complete source equations retain language then repository phases and full
serialized/reparsed CST inverses. Independent unrun source covers three core
families, nested helper calls, exact widths, explicit borrowing, Some/None,
delimiter/literal punctuation, captures and wrong domains, six original adopter
APIs,7 composed caller functions, consecutive actual stages, JavaScript/strict
TypeScript, complete resource reverse and native inverses, native standard-
expression oracles and exports. Wider generic types, callbacks, unknown calls,
shared owning-Option inspection, production namespace closure and every ledger
source/native/production/sync/freshness/parity/delivery obligation remain OPEN.
All eight same-SHA JavaScript gates before fatal CI-only Rust remain intact.
