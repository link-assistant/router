# Source-bound adoption without derives

This entire source batch is unverified and its cases are unrun. No tests,
experiments, diagnostics, translation, regeneration, Rust tools, push or CI ran.
Every unfinished requirement in [the ledger](bulk-draft-requirements.md) stays
open; this source proposal does not measure executable application coverage.

The additive `createSourceBoundToolAwareCoreAdoptionProducerContext` handles
ordinary original source modules with no derive invocation. Its existing private
issuer retains complete original source/profile/module identities, configured
tool ownership, original standard host inputs and genuine namespace resolution.
If the complete original item scan finds a derive, it delegates to the genuine
tool-aware enclosing derive creator. Older creators retain their no-derive and
no-Cargo behavior. The new lane also requires complete own primitive Cargo source
fields, but does not parse dependency archives for the no-derive branch.

Cargo strings in that branch are retained source inputs only. Its finish result
explicitly records a null dependency digest and `deriveDependenciesVerified:false`.
It cannot certify any package owner, generated output or trait implementation.
Unknown macros, unknown attributes, unresolved external imports, globs and live
tool-prefix shadows remain visible to original binding/tool closure and candidate
refusals. A copied public token is never accepted by the shared private issuer.

Complete copied namespace, closed-span, named nontrait selector and finalization
operations support this lane while retaining source/profile/owner checks. Actual
ordinary struct, const and function imports can be classified through their
original crate-local declaration. All returned candidates keep executable and
complete namespace authority false. Stability metadata remains in native source;
only genuine tool attributes and existing certified derive/helper spans can be
projected. No graph/source/verdict/result cache is introduced across invocations.

The explicit primitive candidate and selected base64 producer now use this same
source-bound context family. Full original source equations preserve both ordered
substitution sequences, original owner spans, complete CST transport and inverses
through the tool-aware adoption history. Independent JS/strict-TS, native and
refusal regression source covers no-derive imports, unused Cargo data, getter
refusal, real derive delegation, profile/graph changes, shadowing and body values.
All source is unrun. General executable generics, architecture and producer
bootstrap, broader effects/resources, production adoption/parity, export receiving
qualification and every required CI/freshness gate still require completion.
