# Fixed-width integer source draft

Thirty explicit native interfaces cover i64/u64 saturation, wrapping, checked
addition/subtraction/multiplication/division/remainder, min/max/clamp and signed
absolute values. The same operation data drives declarations and both directions;
implementations preserve fixed-width primitive validation without coercion.
Independent expected boundary values do not come from this catalog. Native
library internals remain intentionally untranslated behind the matched interface.

The actual complete native leaf, root edge, runtime and declarations bind every
operation. The existing private whole-function issuer handles forward application
calls. Reverse checking narrows literals using each actual operand domain,
preserves checked numeric Options and feeds both independent interpreters.
Canonical Rust synchronization still requires complete fresh reproduction.
Physical owned-outcome source units may add the logical native input
`src/translation_integer_core.rs` to their existing complete native mapping;
ordinary paired signature proposals already retain i64/u64 domains.

Eight complete JavaScript source predecessors and adjacent full native root
histories retain both ordered substitution sequences and complete CST inverses.
The original native preparation implementation is also retained in full. Shared
runtime materialization/export imports include the numeric assets. No source
hash or catalog row grants type, owner, loan or executable permission.

Independent source covers signed/unsigned limits, zero divisors, i64 MIN/-1,
truncation/remainder signs, absolute-value overflow, invalid input hooks, immutable
Options, actual native caller bodies, JS/strict TS/interpreters, all three unit
authorities and source tampering. All are **unverified and unrun**; no translator,
compiler, test, experiment or Rust tool was executed. Clamp's invalid-bound panic
and runtime RangeError are outside successful-result parity; this draft does not
claim general cross-language exception equivalence.

Standard method adoption, production installation, generic arithmetic, records,
HTTP/streaming/state, full parity/freshness and the other bulk requirements remain.
