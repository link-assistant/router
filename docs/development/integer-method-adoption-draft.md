# Primitive method adoption source draft

The integer adopter, bounded packet producer and checked installer copy three
complete existing carrier implementations. Repository substitutions select
qualified fixed-width interfaces from the shared thirty-operation catalog.
Actual immutable i64/u64 parameter declarations, same-domain operands, bounded
decimal literals and primitive MIN/MAX constants supply source proposals.
Repeated Copy inputs may be used in several proposals. Shadowed types or local
patterns, arbitrary operands, generic receivers, unknown producers and incomplete
namespaces remain refused. Source scans retain their original work bounds.

Every proposal retains complete before/after CST, substitutions and inverses.
Proposals remain candidate-only. Selected installation independently rechecks
the entire original physical source/Cargo/Git snapshot, translates every selected
whole function and recomputes the proposal before the existing guarded transaction.
It does not accept a source hash, catalog spelling or copied meta as permission.

The copied packet API and CLI accept the `integer-methods` sequence. Existing
packet limits, original function workloads and source protection stay required.
Independent native-caller, strict-target, repeated-input, source-refusal, packet,
selected-installation and complete source-history regression sources are drafted.
All checks, adopters, translators, experiments and Rust execution are **unrun**.
Production application, general numeric expressions/local inference and every
other unfinished bulk requirement remain open.
