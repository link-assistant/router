# Actual owning and scalar Result callbacks: source draft

All implementation, receiving cases and native oracle source remain unrun.
The resource caller lane now composes existing native/JS Result combinators
whose complete callback input and return domains are already supported. Mapping,
chaining, error mapping, recovery and fallback operations select their actual
immutable registered ABI, independently checked inline bodies or complete local
function items and fresh full native/runtime/declaration source censuses.

Whole Results still move once. Native callback parameters retain their actual
scalar, borrowed-text or owning String domains; a callback cannot return a
local loan as an owned value. Read-only enclosing captures, nested callback
annotations and every resource exit reuse the original complete checker.
Borrowed-output callbacks and wider numeric domains remain refused pending
their own lifetime/numeric source rules. No ABI descriptor supplies a type,
signature, effect, source, owner or executable permit.

The shared callback source rule now also represents an empty parameter list
without treating it as a missing contract. Native reader/projection copies
retain empty closure syntax for independently qualified future operation
families; no new operation is admitted solely by that syntax. All existing
collection callback descriptors keep their original domains.

Complete original contract, source, flow, annotation, native reader and projection
copies retain native-selected language then repository substitutions, complete
serialized/reparsed lossless CST and full inverses. Independent unrun JS/strict
TS/native cases cover callback selection, skipped Err callbacks, saturation,
owning errors, Unicode, helper references, wrong domains, double moves, async
refusals and forged meta. The native fixture joins existing gated integration
discovery. General Option callbacks, borrowed-output callbacks, generic/method
signatures, namespace/bootstrap, production parity and every unfinished
requirement remain open.
