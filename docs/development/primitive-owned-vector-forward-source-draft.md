Status: SOURCE DRAFT ONLY. All receiving execution, strict TypeScript, native
oracles, source freshness and performance checks remain UNRUN. No CI feedback
was inspected while drafting this change. This does not certify executable
coverage or complete synchronization.

The native lane joins the actual active root, vector and sequence source views,
resolved declaration bindings and compilation profile to all ten fresh paired
core inputs. Its ordered language and repository substitutions reuse the
original parsed-call and complete private function/caller/layout/emission
issuers. Spelling, operation catalogs, public metadata, spans and source pins
alone grant no type, owner, namespace or executable permission.

All eleven primitive domains share the eight existing bounded compatibility
operations. Owned operands move; len/get require an actual written immutable
borrow; get returns an independent copied Option. Argument evaluation remains
left to right. The complete lexical flow rejects duplicate consumption and
rechecks shared roots after later arguments. From-slice copies an actual shared
primitive slice and returns no loan. The explicit 4,096-value compatibility
bound applies in both implementations; ordinary Vec remains unbounded outside
this library contract.

The source draft deliberately refuses public owned/shared Vec inputs, mutable
vector locals, callback operations/captures and unresolved element identity.
Ordinary vector literals and arbitrary library methods do not gain admission.
Native same-module helper closures and broader mutation/input contracts still
need their separate source implementation. Physical root activation and the
complete native history successor remain OPEN for the next source batch.
