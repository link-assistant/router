# Shared UTF-8 text translation draft

Twenty explicit shared text interfaces now have source drafts for native-bound
JS/TS operands, fresh whole-body checking, serialized and reparsed meta, both
independent interpreters, TS/Rust emission and canonical Rust inverse projection.
The forward catalog maps the same full native source and exact argument domains.
Borrowed output origins come from actual live inputs or literals. A declaration,
catalog row, hash or detached expression cannot establish a loan or body proof.

Complete original implementations and language/repository substitution sequences
are retained by `prepare-owned-text-sources.mjs`, composed after the alias family.
The ASCII receiving context includes the current shared operation closure while
preserving its original base assets. Owned receiving assets explicitly retain
the bounded integer interface instead of an older same-named host library file.

Independent source cases cover actual JS, strict emitted TS, both interpreters,
canonical Rust reproduction, Unicode byte offsets, borrowed slices, literal
replacement, invalid domains, changed sources, detached programs and three-way
source-unit edits. No implementation, test, compiler, translator or preparer has
run during this phase. Automatic method adoption, complete bulk packaging,
production coverage and the broader requirement ledger remain open.
