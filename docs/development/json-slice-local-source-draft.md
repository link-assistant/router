# Shared JSON slice and vector source draft

The implementation, complete source equations and every independent case are
drafted and unrun. No current coverage, native/target parity, source freshness
or complete translation/synchronization result is claimed.

One complete original map/filter_map selector is now shared by its ordinary and
source-bound adapters. That selector and the existing predicate/fold iterator
selector use the common chronological source engine for immutable Json slice
aliases, written Vec<Json> inputs and explicit as_slice views. A vector receiver
is passed through an explicit once-only as_slice bridge to the existing shared
slice core operation. Bare aliases and real semicolon/scope events retain their
source spans; unknown/annotated/forward/ended-scope locals remain unproved.

Original callback bodies and normalization, result-domain constraints, source
producer/effect/loop/shadow refusals, complete current core/dependency/module
checks and whole-function semantic/ownership/emission checks remain. Unique
local declarations do not shadow themselves. Source-role DATA proves no native
Vec layout, borrowing, Clone, trait dispatch, Drop or executable behavior. No
mutable iteration or consuming into_iter path is introduced.

All four adapters use real shared neutral language calls followed by exact
repository prefixes; twenty-two existing ordinary/source-bound adapters now
share that planning path. Original source/token/cell/frame/binder and workload
limits stay fixed, as do phase names, fixed stage membership and complete
serialized/reparsed CST/source inverses. No source/hash/owner/verdict/result
cache crosses an operation.

Eight complete source equations retain original helpers, the complete shared
selector, four adapters and history edge with native owners and both inverses.
Independent unrun sources cover alias/view/vector input forms, current lexical
scopes, unchanged callbacks, empty/order/Unicode/false/null values, short-circuit
callback counts, four proposer APIs, both fixed bulk stages, fresh receiving JS
and strict TS, native boundaries and source histories. Every wider source/native/
production/sync/freshness/parity/delivery requirement remains unfinished.

The later [shared declaration draft](local-alias-binding-source-draft.md) keeps
unrelated mutable locals opaque while preserving independent immutable alias
facts. It supplies no mutable-value facts or type/owner/executable permission;
all new cases and whole-project requirements remain unrun and unfinished.
