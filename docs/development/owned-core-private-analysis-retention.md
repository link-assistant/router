# Retaining the already private owned-core analysis

The unchanged three-build corpus case exceeded its 60-second Node deadline at
65,489.91 ms in the reversible default-DATA trial. This source proposal removes
one redundant complete DATA copy inside each fresh owned-core item-check group.
It makes no measured speed or deadline claim.

`prepare-owned-core-private-analysis-retention.mjs` proposes changing the default
`owned-core-operations.mjs`, with `--emit`, guarded `--write`, and `--check` modes.
The complete original module is retained in a pinned compressed archive. Native
TypeScript 5.9.3 selects the actual second `canonicalCopy(analysis)` declaration,
its immediately following refusal branch, and their lexical symbols. Complete
native AST copies, language then repository CST substitutions, both phase
inverses and a complete native edit inverse remain in the returned proposal.
The installer accepts only the exact original or proposed full module.

The original `check` closure first makes `analysis=canonicalCopy(analysis)` on
every newly reconstructed group. That DATA object has no accessor, proxy,
cycle, exotic prototype or public issued-row alias. Only that new object feeds
selection. The result is copied separately before equality; equality receives
the result and a separate input snapshot. Neither argument aliases the private
analysis. After equality both original intrinsic guards run again. No caller
callback occurs between that guard and the retention census. The private
analysis is never returned, issued through the public WeakMap, or supplied to
an external callback. The group maps are private and cleared in `finally`.

The removed copy therefore traverses an unchanged private ordinary-data object
already accepted by precisely the same cell, depth, array and string limits.
The second traversal cannot discover a new refusal under those native guards.
Retaining the first copy preserves its complete values, key order and ordinary
descriptors. The independent retention cost census still runs, with its exact
group/cell/string bounds and saturation fallback. Every reconstruction, source
check, Hash callback, issuer call, equality check, returned-item copy, intrinsic
guard, final source fence and fallback remains in place. There is no retained
object, source, verdict, digest or encoded result across invocations.

The proposal exposes `composeOwnedCorePrivateAnalysisRetention(prior, options)`
as a later source-equation layer. The current primitive boundary, checked source,
lifetime, matches, ASCII assets/reverse and vector CLI compositions append it
after their existing final layer. Their complete source controls compare physical
operations with the final composed map, including a fresh full-source Hash and
