# Owned Option and Result source draft

The additive `owned-outcome` profile copies the complete current owned-state
source checker, private item issuer, semantic document reader/writer, entry
points and canonical Rust inverse/projection. Six complete original modules
remain unchanged. `prepare-owned-outcome.mjs` retains those originals and three
source-history consumers, language substitutions, repository import/export
substitutions, complete serialized/reparsed CST equations and exact inverses.
Original source copying and metadata supply no executable permission.

Nine matching Rust/JavaScript operations construct owned JSON success/error
values, copy results, convert owned Options and Results, and select eager
fallback values. The result domain is `Result<Json, String>` and the optional
domain is `Option<Json>`. Native library internals remain native. Canonical
JSON copies preserve independent storage; `Some(Null)` remains present and an
error string remains an error payload. Rust panics, allocation failures and
invalid adapter values are outside the successful-resource contract.

Actual runtime imports and complete native module/leaf/Cargo inputs bind each
operation and written domain. Written `ReturnType`/`Parameters` expressions
must refer to those imports. Arbitrary structural unions grant no permission.
The copied source checker handles constructors, public owned carrier inputs,
strict tag tests, dominating payload access, branches, early returns and owned
reassignment. Assignment clears variant facts; branch joins conservatively
discard facts invalidated on either continuing path. Mutation cannot turn an
old guard into permission to read a different payload.

The actual JS/TS entry performs lossless source CST transport and separate
fresh checked semantic meta serialization/reparsing before emitting strict
TypeScript and canonical Rust. The Rust entry reconstructs an ordinary source
proposal, freshly checks it and requires complete authoritative Rust token
reproduction, including guards and helper bodies. Unknown Rust forms, custom
error conversions, general `?`/Try dispatch and generic carrier layouts remain
refused. This canonical inverse does not admit all standard native Rust callers.

Public APIs are `createOwnedOutcomeContext`, `ownedOutcomeRuntimeSources`,
`translateOwnedOutcomeJavaScript`, `translateOwnedOutcomeTypeScript`,
`readOwnedOutcomeMeta`, `emitOwnedOutcomeRust`, and the two independent
interpreters in `js-to-rust/owned-outcome.mjs`. The Rust inverse is
`translateOwnedOutcomeRust` in `js-to-rust/owned-outcome-rust.mjs`.
The original state profile retains its separate private context and issuer.

Independent complete runtime, compiler, strict-TS, canonical-inverse, refusal
and native oracle source is drafted. None has run. Standard native caller
adoption/forward lowering, source-unit integration, generic Result/Option,
effects, async behavior, production parity, receiving qualification and the
remaining full requirement ledger are still open. No coverage increase or
performance gain has been measured.
