# Committed compact source transfer: source draft

The additive `exportCompactCommittedSourceVault` and opt-in
`scripts/export-compact-router-translator-20261102.mjs` connect the compact
store to the actual committed production selection. The original standalone
exporter and every original receiving command/limit remain unchanged.
All new implementation/case/CLI sources are UNRUN. E01/E03 stay OPEN.

The collector reads real HEAD, complete tree and current stage-zero index,
requires exact selected path/mode/blob equality, and refuses absent committed
required CLIs, vendor, profiles, native compatibility sources and LICENSE.
It reads one ordinary no-follow physical file at a time with bounded descriptors,
full Git blob checking, exact mode and nanosecond/identity closing. Source
parents, root, complete tree/index and every original file reclose independently,
including failures; all closers run and exact primary values survive.
The stored inventory receipt retains the original HEAD and complete selected
path/mode/blob records. These are provenance DATA, never private source proofs.

Selection uses the original compiler predicate plus complete source-profile,
extension, vendor/license and declared CLI/native inputs. Explicit extra paths
must exist in both committed tree and unchanged physical/index closure. This
is not a guessed dependency scanner: missing fixtures, case helpers, application
owners and pinned TypeScript remain explicit unresolved receiving obligations.
The collector reports `completeReceivingClosure:false` and
`typescriptDependencyIncluded:false`. Generated receipt source has a null Git
blob; it is not passed off as an original committed source input.

`materializeCompactSourceSelection` restores an explicit bounded selection to
fresh actual paths. The default API cannot silently choose missing dependencies.
It preserves whole raw bytes and modes, uses exclusive no-follow writes, retains
at most64MiB complete decoded source occurrences for full closing comparisons,
and removes only unchanged owned partial files/directories after failure.
Independent cases draft falsy primaries and preservation of a replacement
neighbor. It creates no Git index/HEAD and opens no compiler epoch. Compiler
fingerprint/source/private dependency guards must independently reissue against
the actual materialized files. A separate checked index/bootstrap remains open.
Peak RSS and platform behavior are unqualified; original receiving aggregate
budgets still apply and no existing test is replaced by this new API.

worktree/index changes, missing/unsafe extra paths and source/output symlinks.
Four materialization cases cover complete selected bytes, modes, refusal before
