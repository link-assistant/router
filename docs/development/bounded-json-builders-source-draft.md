# Shared bounded native JSON constructor source draft

SOURCE ONLY; all implementation, independent script cases, native oracle source
and source equations are UNRUN. CI is uninspected; full drafting remains OPEN.

The shared canonical JSON library adds seven constructors: null, bool, borrowed
Unicode string, u64, i64, an owned canonical JSON vector, and an empty object.
Their native internals deliberately stay in the compatibility library. Paired
JavaScript exports call the existing defensive canonical constructors. Array
construction checks the added root against the existing node/depth envelope;
empty objects compose with the existing bounded field-update boundary.

Actual qualified calls retain the same complete native module/view/namespace,
sealed dependency features, original caller custody, canonical host layout and
private JSON operation issuer. Scalars retain their genuine widths/signedness;
array arguments must be owned canonical Vec values. The whole JSON linear-flow
checker consumes each input vector once and refuses duplicate moves, borrowed
vectors and retained loans. Public contract data grants no source/type authority.

Eight complete source equations retain full originals, CST inverses and language
then repository substitutions. One appended native helper history step retains
the earlier helper, all prior archives/pins and every old native source equation.
The default complete history now has 19 steps across 17 paths; old pinned helper
inputs join to the current bytes through that explicit full history. Existing
canonical Rust/JavaScript library exports retain their original contracts.

Independent source cases draft all constructors through actual complete forward
callers, ownership/move refusals, scalar/Unicode limits, added-root budgets,
complete source changes and native history. A separate Rust oracle is CI-only
behind eight same-SHA JavaScript gates. No Rust tool ran locally. Native reverse
constructor emission/comparison, reader normalization, full generated source
re-entry/synchronization and all broader delivery requirements remain OPEN.
