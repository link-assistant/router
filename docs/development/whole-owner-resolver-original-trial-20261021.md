# Three-source whole-owner original derive trial

This separate explicit trial selects independently fresh creator and resolver
operations for the complete unchanged original twelve-case derive workload.
It retains the existing canonical codec selection. It makes no performance
claim, changes no default implementation, and leaves the creator-only trial
available under its original module and two-source wire schema.

The source generator's explicit `--resolver` lane copies the complete actual
original canonical trial harness with the same native declaration selection,
two CST phases, serialization/reparse, copied-binding check and whole inverse.
Only its finite proposal/packet/preparation/inspection functions and distinct
schema/support import differ. Full actual source discovery, stat-only bounds,
all original test bytes and deadlines, native source-position/deadline joins,
Bun raw completion/resource joins and source readbacks remain complete.

The fresh proposal has exactly three original physical targets:

| Physical module | Trial selection |
| --- | --- |
| `builtin-source-meta.mjs` | Existing complete actual canonical candidate |
| `derive-bang-context.mjs` | Actual complete whole-owner copy with the native original public creator body explicitly routed to the additive creator |
| `module-bindings.mjs` | Actual complete resolver copy with the native original public resolver body explicitly routed to the additive resolver |

The resolver's actual original parameter/default evaluation and argument object
are retained. Its public body routing comes from the actual native wrapper
call, not a manually maintained signature. The repository phase relocates two
actual import spans back to the original physical creator and effects modules.
Those physical effects obtain their complete private outputs through the
physical creator, so they use the physical creator's actual context WeakMap.
The standalone candidate resolver keeps its separate copied creator/effects
imports. Mixing these issuer domains is refused, rather than credited with
successful type closure after a caught foreign-issuer TypeError.

The authored input predicate receives the resolver's actual lexical private
issuer import. No caller flag or serialized metadata chooses that predicate.
All original source/item/owner validations still run in the complete actual
unscoped resolver. Its fresh bootstrap uses the copied exact original wrapper
and actual unscoped entry, avoiding recursion through the routed public entry.
The creator frame is closed before a later resolver call; the resolver captures
its own complete source program and binding digest. There is no cross-call
source, program, owner or digest cache.

The complete original eight-output producer, separate three-output resolver
producer and both runner equations must be current. The creator-only proposal
also now freshly verifies the resolver producer because its bootstrap is a
direct dependency; that does not select the additive resolver in the two-source
trial. All complete source producer evidence remains in the three-source
proposal. Required input records supplement the unchanged full original source
universe and must join it exactly. They never substitute for discovery or
become compiler authority.

The new packet schema accepts exactly the three physical source targets. Every
original byte is retained once; unchanged trial source has an explicit original
association, and all three changed files retain their complete candidate bytes.
Independent gzip readback reconstructs and checks complete original and trial
bytes, mode, length, hashes, source associations, finite overlay identities and
both physical roots. A forged third-file alias, missing overlay, extra overlay,
unlisted delta or changed nested field refuses. Existing source input limits,
64 MiB proposal readback, 384 MiB storage and 240,000 ms enclosing execution
bounds are unchanged. All twelve original cases, including both 60,000 ms
declarations, remain unchanged and unfiltered.
