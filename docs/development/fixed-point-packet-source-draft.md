# Fixed-point source packet and installation draft

All implementation and independent case SOURCE is UNRUN. No local tests,
compilation, parser/preparer/translator/installer execution, generation or CI
feedback inspection occurred. Full production synchronization remains unfinished.

The bounded whole-stage composition runner now has an additive physical source
packet, readback and installation route. It copies the complete original packet
writer, every original graph/CST/source section and the original async guarded
installer. Each complete round repeats the exact unique requested stage order;
a completed index requires a terminal receipt from a full unchanged round.
A changed fourth round still refuses completion. Full original physical source,
Cargo/workspace, profile and native input guards are freshly rejoined throughout.

The explicit fixed-point sequence prefix separates this protocol from the old
one-pass protocol. Each stage record carries its original round and stage index;
a final descriptor binds the complete unchanged-round receipt. Fresh readback
reruns all actual original proposers and compares every complete packet. Public
hashes, final source bytes or a stored stabilized flag cannot replace that replay.
The plan captures the actual Git baseline, inputs and every target inverse;
application uses the original exact-fresh-plan comparison and guarded replacement/
rollback transaction. No source/data cache is added across operations.

The additive commands are drafted as:

```sh
node scripts/router-core-fixed-point-stages.mjs --mode propose --root ROOT --output NEW_DIRECTORY --stages integer-methods,json-fields
node scripts/router-core-fixed-point-stages.mjs --mode review --root ROOT --output DIRECTORY
node scripts/adopt-router-core-fixed-point-packets.mjs --root ROOT --packets DIRECTORY --plan NEW_PLAN
node scripts/adopt-router-core-fixed-point-packets.mjs --root ROOT --packets DIRECTORY --apply REVIEWED_PLAN
```

These are source proposal/installation commands, not qualification commands.
They retain the original child-process heap, timeout, output and source bounds.
The full packet writer refuses logical or physical evidence beyond500MB; plans
remain bounded to64MiB and the original complete source/file/packet limits stay
unchanged. Repeated full-corpus evidence may exceed those limits and must refuse;
whole-corpus storage, performance and receiving qualification remain OPEN.
Existing canonical CI commands and the one-pass entrypoints are unchanged.

A stabilized source sequence does not prove complete language support, executable
body admission, runtime parity or reverse synchronization. The real final forward/
reverse checks and every eight-stage same-SHA JavaScript gate before fatal CI-only
Rust remain required. Existing unsupported sources/refusals and all unfinished
namespace, production, reverse, sync, profile/freshness and delivery obligations
remain OPEN. This API does not silently install or regenerate generated assets.

source owners and full serialized/reparsed CST inverses in both ordered phases.
Independent unrun source covers a real three-round JSON-to-integer prerequisite,
