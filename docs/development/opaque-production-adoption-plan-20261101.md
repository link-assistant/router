## Private issuer and source view

The public entry should accept only the existing validated corpus configuration and a synchronous delivery observer. It enters the actual `withActualPolicySourceUniverse` operation and creates a new invocation-local private WeakMap handle containing that real context, exact entry/path order, complete original Cargo coordinates, fixed stage cursor and produced overlays. Only this driver mints the handle. Each copied kernel rejoins that handle while its original source operation is active. A returned description, callback answer, digest, source array or reconstructed token cannot recreate it.

Original reads go through `policyOriginalSource`; overlays can be inserted only by the fixed actual adopter after its complete selection and CST checks succeed. The source view has no public `readSource` callback, source-map setter, producer-function argument or override flag. The internally supplied `project` reader is bound to that private view and refuses uncaptured paths. An observer is delivery only, may not issue a source transition, must return bounded ordinary synchronous DATA, and cannot catch and clear a poisoned source operation. Expired/foreign handles and reentrant mismatched stage use refuse.

Preserve every captured file, including files outside the reachable library graph. The real module graph determines candidate owners; unvisited/inactive/unknown modules retain their original full file and explicit residual diagnostics. Do not construct a smaller owner-only project, extract functions, synthesize ancestor imports, drop derives or silently add a replacement core module. Crate-relative `src/...` literals in old algorithms remain logical coordinates mapped by the existing `crateModuleSourcePath`/repository layout helpers; actual physical paths come from the captured graph.

If physical transport must use the new split-index-safe reader, construct a NEW complete source-universe copy with the original corpus/required-owner/selection/closing contract and explicit source equations. Reuse the committed selected-reader lifecycle and new forward corpus bridge consistently; never invoke old original-index readers inside the new index image. The old issuer and its pure legacy getters remain authoritative for incoming genuine old handles. This transport is a separately reported precise source-copy dependency, not an edit to the published corpus or forward profile. The initial implementation can retain the existing actual opaque issuer and report its original discovery/platform refusals honestly.

## Accounting and lifetime

Keep three separate contracts: opaque original bytes20k/8MiB/64MiB plus captured Cargo; old standalone maps1024/2,000,000/32,000,000 UTF16 units (or local fixture128/2MiB/4MiB); and ordinary public DATA accounting16MiB/2,000,000 cells/depth160. Passing a64MiB full corpus or a global graph to `accountData` will fail even though opaque ingress accepted it. Never omit accounting or raise16MiB. Keep full source texts and graph/private contexts out of public request/result DATA; apply the DATA checker per bounded event/header/control receipt.

A full8MiB file with complete before/after strings and both CST metas can itself exceed a16MiB event. Therefore define an explicit bounded source-event bank/visitor before claiming the full domain: detached complete-source chunks with exact coordinates and full CST/meta components, each DATA event within the old16MiB bound, plus an invocation-private full reassembly/verification obligation. Full histories cannot be replaced by digest or span inventories. If actual CST APIs require a contiguous metadata string, retain the complete string under the original CST/representability domain, stream its serialized chunks and report that contiguous-memory requirement honestly. No new public bank can grant source authority. The precise event schema and whole rejoin need independent source cases before implementation is complete.

Retain the original corpus once, produced full overlay texts for changed files only, and one stage graph/context at a time where the original APIs permit it. Process physical files sequentially, release complete per-file equation work after delivery, and dispose private view/overlay and frame state in finally. The original graph still contains all modules, source views, tokens and concrete metadata; this is streaming history delivery, not a claim that the compiler becomes a one-file parser. Original and adopted output/meta coexistence, multiple stage graphs accidentally retained by context tokens, source strings/CST aliases and consumer-retained events count separately. WeakMap reachability or future GC is not an RSS bound, and no across-invocation cache or saved semantic verdict is allowed. Aggregate RSS/duration and storage fit stay OPEN/UNRUN until actual checks are authorized.

No source installation, cleanup of application files, new persistent cache or publication is proposed. Any temporary source-history bank would need a separately reviewed fixed bound, owned directory lifecycle, exact unknown-retention cleanup and closure; an in-memory visitor avoids adding a filesystem writer just to prototype this lane.
