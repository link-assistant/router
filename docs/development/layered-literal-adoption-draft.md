# Shared scalar and compatibility call source draft

The implementation, complete source equations and independent cases are source
drafted and unrun. This establishes no current coverage, native/target parity,
source-history qualification, freshness or complete translation result.

The shared planner now copies text's complete existing scalar-literal rebasing
algorithm. Scalar pattern rules run first within the language sequence, then
whole selected neutral call rules, followed by the repository sequence's exact
prefix bindings. Original character spans, complete intermediate scalar source
history, changed-byte/overlap/owner refusals and final whole-source inverses are
retained. No third phase is introduced; the two names remain language then
repository. Rule lists can grow inside those phases.

Both text adapters use that shared implementation, including their existing
character/literal history fields. Both base64 adapters consume its ordered
source plan through their original complete CST and inverse paths. Original
base64 progress callbacks, current dependency/module/producer/context checks,
selections, full inverse loops and final freshness checks remain intact. No
cached plan or public DATA receipt can replace those checks or issue native
type/owner/trait/borrow/executable authority.

Twelve existing adapters now use the same operation/prefix rule planning. The
original integer/Option/Result path keeps its old no-scalar metadata domain;
text retains its separate scalar evidence. New selection bounds remain within
the original source/token/cell limits; no workload, deadline, file or export
budget is increased and no cross-operation cache is introduced.

Six complete equations retain the shared helper, complete text/base64 adapters
and previous source-history edge. Independent unrun sources cover multiple
Unicode scalars, nested calls, exact offset rebasing, language rule ordering,
repository prefix edits, full source/CST inverses, unowned/overlapping/changed
patterns and source-only plan boundaries. Existing family receiving JS/strict
TS/native oracles remain separate and unrun. All wider source/native/production/
sync/freshness/parity/delivery requirements remain unfinished.
