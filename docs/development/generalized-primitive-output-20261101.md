# Generalized synchronous primitive output source draft

This is an additive uninstalled copied-source successor to dynamic4d3. Every
original131 source version, complete chronology, inverse and physical original
is retained. The only changed virtual compiler roots are Host's helper import
and original env/path observer handoff, plus owned-json-flow's helper import.
All physical predecessors, old APIs, runtime, native facade, contracts, source
allowlists, metadata schema and static-lifetime domains remain unchanged.
Every new case and native oracle is **UNRUN**; native oracle is **UNSCHEDULED**.
No compiler/parser/preparer/runtime/CI experiment or coverage measurement ran.

The complete new helper reuses the existing move-only by-value standard String
consumer, real native String Drop and the same private scoped backend. The
previous one-output helper/API remains frozen with its exact original source
fence and domain. Only the explicit new installed profile selects this helper.
It adds multiple outputs, primitive lexical locals and ordinary immutable range
binders, if/else, early unit return, scalar local mutation and the original finite
for/while/break/continue ownership fixed point. Eager formatting/allocation
before capture/quiet is still an explicit both-side application migration;
original builtin/std Arguments equivalence remains false.

Each format keeps its original raw parser/node identity and actual qualified
macro source interval. A private scope walk of the genuine whole parsed owner
respects let initializer versus continuation, for input versus loop body, and
outer continuation. It retains actual binder identities, never public names
as permission. Reads rejoin the private parent declaration, original let node
association or actual ordinary native for pattern, parser token source and
binder interval. Only then may the original checker env supply the resolved
primitive/borrowed-str/owned String type, with exact ownership/primitive checks.
The complete checked body and original namespace remain independently required.
Unknown globals, static-array expressions, custom Display, closures, helpers,
aggregate producers, mutable parameter assignment, async and unsupported
ordered/aggregate matches refuse.

Every static output must carry its own private original call/source/signature
proof. The finalizer checks the entire function, every actual String producer
and all output records, then runs the existing complete linear/loan/control
walker. String values move once along each live branch; loop backedges cannot
revive a moved value. Fresh per-iteration format allocations remain allowed.
The original source signature is synchronous unit with borrowed-str/fixed/bool
parameters. No generic effect/Drop/type/namespace flag opens a broader domain.

Only after whole-function checked-source handoff may each output enter the
operation-local transport Map. Locators are DATA; every lookup rejoins the
actual same-checker original owner and complete current source/function body.
Emission reproduces the complete actual hygienic rename and checks every call
in the full static census, including all branches. Closing requires each
static output to have been emitted exactly once. Nested/caught-failure source
poisoning, original primary errors, expired proof refusal, weak lookup indexes,
operation cleanup and all original resource bounds remain mandatory.

The copied profile delivers every full original/successor source equation,
CST serialize/reparse, inverse and ordered language then repository trace, while
retaining bounded receipts rather than every CST simultaneously. Full checked
meta, native source, paired targets, inverse proposals and fresh candidate
reproduction remain occurrence-accounted. Original bounds are unchanged:
2MiB/source,4MiB raw archive,2MiB packed archive,16MiB DATA occurrence budget,
128 native source files/4MiB request,512 tokens/256 closers,100000-node/depth160
whole-flow census and the original128-round loop fixed point. Overflow refuses;
no split archive or omitted ancestor is used in this checkpoint.

`translateGeneralizedPrimitiveOutputProject`,
`compileGeneralizedPrimitiveOutputProject`, `readGeneralizedPrimitiveOutputMeta`,
`invertGeneralizedPrimitiveOutputTarget` and
`invertGeneralizedOutputFormatTarget` use fresh real compiler frames. Edited
primitive and format literals lower back into original complete Rust source;
whole native candidates and both paired outputs recheck. The entire requested
selected output must match exactly; quote normalization or inserted comments
cannot be silently accepted. Physical source/CST restoration is distinct from
that semantic edited-native lane. No general Rust emitter is invented.

Complete receiving/strict-target helpers retain original60s case/20s child
limits, installed lockfile TypeScript5.9.3 version and diagnostics, full source
closure, disk/input/output limits and primary-preserving cleanup. Independent
cases cover branch and partial-failure order, shadowing, fresh loop locals,
zero iterations, break/continue, early returns, exclusive branch moves, capture
short-circuit before diagnostics, quiet/context/process branches, metadata
reissue, native edits, source restoration/failure/reentry and move refusals.
Native oracle uses the actual owned facade and original persistent context;
its explicit scheduling remains the coordinator's obligation after JS gates.

Whole actual lib, token_report, tokens_remote and accounts_cli source owners
remain in the production proposal. Both the real print_table header and loop
row statements receive explicit eager Text migration equations. These are full
owner attempts with every returned residual, never extracted successful owners
or executable production coverage. HEADERS indexing, row(&Json)->Text and
Option/JSON/owned-helper source closure are **still open**. The separately
proposed private JSON closure bridge is not implemented here. Full logging,
URL/IDNA, environment/platform/provider parity and general async remain open.
