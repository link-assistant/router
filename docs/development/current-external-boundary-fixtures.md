# Current external source receiving boundaries

The private Cargo parser graph controls now relocate every actual relative module
import with the installed native parser. The two ordered rule phases retain full
CST round trips and byte inverses. Resource URLs deliberately remain local so the
original changed, missing and linked vendor controls still execute. The old
whole-module relocation helper retains its original resource behavior.

The modeled-library test distinguishes the genuine source-only producer ABI from
the foreign producer route. The former already has independent complete provider
controls; two original data items and six slots carry no actual caller, native,
whole-trait, package or standard namespace permission. A complete relocated
foreign issuer must retain the original unproved-attribute refusal. Copied modeled
tokens must refuse as well. Original case deadlines remain unchanged.

This source draft requires the complete receiving files under Node and Bun. It
adds no default compiler admission, application coverage or Rust verification.
