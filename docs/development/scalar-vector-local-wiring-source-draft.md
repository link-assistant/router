# Scalar-return primitive vector local wiring source draft

All implementation and cases UNRUN. This selects the earlier native observer
prerequisite in the actual receiving/discovery/comparison paths. Full drafting,
complete translation and every verification obligation remain OPEN.

Both private source capture copies join the actual original/lowered scalar ABI
and bounded complete local-vector observer, retaining its DATA observation in
the fresh native origin. The source checker enables finite vector locals and
move tracking for that source-backed shape. Boolean, fixed primitive and unit
results retain their exact return type. Explicit new-definition insertion also
accepts a scalar-only exported set when actual checked bodies contain primitive
vectors; a purely scalar set still uses the original separate insertion family.

The finite source definition validator and complete helper graphs now permit a
scalar caller to receive a same-module Vec helper result as an owned local.
Every callee body, ABI, original coordinate, complete graph, cycle/arity/depth and
expanded-work check remains. Actual native discovery and refresh carry the local
observation through their complete unit transports and source projection. The
native graph accepts Vec result edges only in the bounded scalar-container or
existing vector family. Unused helper calls remain ordered events, preserving
their failures; pure unused container representation may normalize under the
existing successful-resource primitive-vector envelope.

Both complete native comparison paths recompute the actual scalar container
observation and reject a mismatch with the freshly issued receiving origin.
Their local array/conditional rules use that independent actual-domain result.
The public observation flag, source records and graph summaries are DATA; none
can create a source, type, namespace or runtime permission. Original scalar ABI
and same-result vector observer APIs remain unchanged.

Both original and header TypeScript emitters write exact primitive vector local
types from the checked IR. Empty/literal-only native locals therefore retain
actual widths when their complete source is reissued instead of guessing a
width from JavaScript constants. Final public argument validation, source
census, whole-body/native comparison, atomic inverses and closing source fences
remain mandatory. No cross-operation cache or limit increase is introduced.

Thirteen complete source equations retain whole originals, lossless CST/meta
serialization/reparse, inverses and language then repository phases. Draft cases
cover actual native source re-entry, scalar-only container insertion, JS and TS
unit/scalar batches, all ten return widths with eager Vec helper failures,
native discovery/refresh, exact local annotations, bulk dispatch, ownership/
input/mutation/recursive refusals and independent CI-only Rust oracles. Nothing
was executed and CI feedback remains uninspected during drafting.

Vec length/index/iteration/mutation/input operations, borrowed aggregates,
cross-module helpers, broader native attribute/macro producer closure and full
Router bodies remain OPEN. Strict parity/freshness/performance/platform/current
compiler export/receiving repository and CI evidence also remain OPEN.
