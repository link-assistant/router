# Ordered primitive failure source draft

SOURCE ONLY. All body comparison, receiving, paired runtime, strict TypeScript,
helper insertion/append, bulk, source-history and CI-only Rust oracle sources
are UNRUN. Whole task drafting and complete translation/parity remain OPEN.

A separately named finite closed-operation rule extends the actual receiving
source consumers with checked add/sub/multiply and primitive Ord clamp. The old
total-operation APIs retain their exact implementations: possible failures are
not called total. Actual private source checking, current complete runtime and
declaration bytes, original source types and native signatures remain required.
Both the ordinary native-function profile and explicit definition bootstrap
receive this rule; all actual copied insertion/removal/reconciliation/helper/
unit-adoption gates share it through complete source substitutions.

Both complete native body observers now record each checked operation as an
ordered event after its independently checked operands. A result reference
identifies that one event. Actual native checked semantics, domain and clamp
contract are checked independently of the receiving source metadata. The
original JSON ownership visitor separately traverses failure operands and
requires Copy values without retained JSON loans; the new rule does not permit
aggregate moves or borrowed primitive selection.

Every actual source helper call also becomes an ordered event. An unused
result therefore cannot discard a helper panic, repeat a helper, or move it
after another failure. Complete helper dependency discovery follows those
events and retains its bounded acyclic original-source closure. Paired source
projection emits immutable ordered locals, including unused failure/helper
results, plus original statement branches. Existing whole native/receiving
body comparisons and source fixed points remain mandatory. The old pure
source-call DATA projection stays readable; it grants no admission permission.

Statement branches retain separate ordered prefixes and execute only their
selected arms. Eager scalar conditions may themselves fail before a pure
conditional or short-circuit result. Effectful right operands and ternary arms
remain explicit refusals until a separate guarded-expression rule preserves
their execution. Division/remainder zero ordering, negation, shifts, constants,
cross-unit helpers and general effects remain unfinished. Existing clamp error
and platform parity obligations remain open.

The preparer retains seventeen complete original-source equations with exact
inverses and language then repository phases. It joins the current source-copy
history after the fresh Option expect adapter. No parser, translator, preparer,
regeneration, runtime, test or Rust tool was executed locally.

The subsequent [guarded continuation draft](guarded-primitive-failures-source-draft.md)
now supplies the separate scalar ternary/short-circuit source rule described
above. Its complete cases are also UNRUN; broader guarded transfers and full
qualification remain OPEN.
