`Option<T>`. Precise Option headers come from actual qualified type queries on
the shared unchanged-value ABI. Import selection reopens the complete original
native, JS and declaration source proof; the per-invocation current-source guard
rechecks selected inputs. The ordinary scalar source observer stays separate.

arbitrary resource disposal or borrowed payload domains. Numeric ingress checks
retain their existing native bounds.

one input, linear immutable aliases, already checked acyclic helper calls, one
returned value, no discarded values or other effects. A raw generic helper can
forward a whole Option. A carrier helper cannot consume an unconstrained raw
slot or satisfy a scalar callback contract. Explicit carrier call arguments name
the payload type while retained argument docs name the complete carrier. Local
annotations must match the complete independently checked signature domain.
