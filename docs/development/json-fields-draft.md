# JSON field and Option draft

These implementation, source-history and independent regression sources are
drafted and unverified. No preparer, translator, test, compiler diagnostic or
Rust tool has run. The complete bulk draft and requirement ledger remain open.

Six matching native/runtime APIs cover immutable field/index lookup and typed
string, boolean, u64 and i64 fields. Absence stays different from present null,
false, zero and empty text. Native library internals delegate to serde JSON;
JavaScript reuses the existing canonical readers. The shared finite catalog
drives declaration and emission mappings. It grants no callable or type permit.

The owned state source checker binds the actual native root/leaf, native import
symbol and complete materialized runtime/declaration source on every use. Scalar
Option results retain native numeric domains. Borrowed JSON/text Options need a
live actual input root; a mutable or owned local cannot supply an escaping loan.
Both independent interpreters, checked semantic documents, JS/TS emission and
canonical Rust inversion have source rules. Natural native helper definitions
also remain available to the ordinary forward project checker, which must
admit their complete actual source before callers count as executable.

Source review also joins the reverse profile's existing `usize` index domain
with its documented emitted Rust `u64` ABI at the fixed u64/index operations.
This does not widen original Rust primitive dispatch. Genuine u64/i64 values
can use strict equality and bounded integer literals in comparisons; signed
literals must fit i64. JSON number construction can reuse a genuine u64 payload.
Other numeric, ownership and identity refusals stay in place.

Emitted TypeScript now writes operation-derived Option and u64/index signatures.
Their actual registered imports supply written domains when the emitted source
re-enters the reverse frontend; an unproved structural union or bare bigint
does not acquire a new domain from type erasure. The complete body still gets
its independent source, root, loan and result checks.

The complete original native root and nine prior source implementations remain
under the source-profile archive. Earlier native state and source producers
compose the exact later equations. Both rule sequences, serialized/reparsed
CST, full inverses and original private source issuers remain. No regenerated
artifact, current coverage result, native grammar check or parity is claimed.

Unrun independent source covers every field operation, scalar/absence/index
boundaries, Unicode/proxy refusal, original/emitted strict TS, both interpreters,
full Rust inversion, native/runtime/root changes, local-loan refusal and source
history. Native oracle source also checks floating zero and integer limits.
Generic Option/Result combinators, broader effects/state, source adoption and
all other production/synchronization/CI obligations still need their full draft.
