The source producer extends Clone and Debug tuple-struct syntax together.
It copies complete original compiler helpers through native source selections,
separate language/repository substitution sequences, serialized/reparsed CST
stages and complete inverses. Existing public data-syntax and Debug route
domains remain unchanged; the actual private issuers explicitly select the
new tuple routes.

Clone constructs its original tuple constructor with ordered shared field
clone calls and retains both resolver branches. Debug retains None, Shallow
and Full modes, including the original five-field cutoff and the tuple
formatter's single values array for larger layouts. Both join the pinned
Rust compiler's tuple field parser and numeric field-identifier construction.

These connections close namespace uncertainty only for an independently
qualified original derive invocation. They do not implement Clone or Debug
trait execution, infer Copy or no-Drop, or admit an unknown sibling derive.

their existing refusals.

20.19.4 and Bun 1.4.3 with their original deadlines, including nine new cases,
generated JavaScript and independently strict-compiled TypeScript execution.

source proof; every other input and refusal remains. The earlier six parser-contract
