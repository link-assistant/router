# Default issuer proof byte proposal

`prepare-default-proof-byte-adoption.mjs` proposes byte composition around the
actual enclosing namespace creator and its Default enrichment. It preserves
their existing private issuers. This is source-only work: native generation,
receiving tests, performance and complete production admission remain unrun.

The existing fifteen-overlay whole-owner candidate is not a suitable default
substitution. It omits the enclosing creator, uses a separate classic creator
without the original repeated-call cache, and has callback-free bulk eligibility
that does not cover Default's enriched external bindings. This proposal does
not install those alternatives or change their guards.

The nine proposed complete source rows contain five exact serializer import
specifier substitutions, two creator call wrappers, one internal adapter and
one source-producer census adjustment. Both wrappers call the original private
function once. The enclosing call remains inside its original retained DATA
cost scope. The Default call retains its original resolver and external table
construction. No original issuer, WeakMap, source validation, owner resolution
or native Hash update/digest call is replaced. The classic creator stays exact.

All five consumers use the existing single `operation-proof-byte-bridge.mjs`
instance. A second copied bridge would give nested operations separate active
serializer state despite a shared byte scope. The internal adapter uses the
old operation only if optional bridge setup refuses before entering it. Once
entered, returns and exceptions belong to that invocation and are never replayed.
The existing byte scope clears storage on return/throw, restores nested state,
suspends consumers before native JSON callbacks, and refuses async results
without invoking `then` getters. It grants no source, owner or checker fact.

The new producer pins eleven complete original inputs and the authored helper.
It selects actual import declarations and creator calls with TypeScript 5.9.3,
joins each selected private callee to its original native binding, and retains
complete detached native AST copies, checked lexical bindings, both CST phases
and full inverses. The Schemars import adoption is a historical predecessor:
the byte layer's complete before source must equal that import layer's after
source. Applying the byte inverse first restores that exact predecessor; its
own inverse restores the original `651093...` context. Unknown physical later
layers are refused.

`prepareDefaultProofByteEnclosingHistory({root})` reissues that same enclosing
row alone for downstream current-source pin adapters. It uses the same private
complete archive, native callee selector, bridge/helper inputs, detached copies
and CST inverses; no other physical consumer rows are generated. Its full row
must equal the enclosing row in the complete nine-row proposal. This avoids
building unrelated source equations merely to verify the known wrapper before
restoring the Schemars import history. No arbitrary restoration callback or
caller eligibility flag is accepted.

Root must first materialize the Schemars dispatcher/import proposal. Then:

```sh
node tools/translation/prepare-default-proof-byte-adoption.mjs --emit
node tools/translation/prepare-default-proof-byte-adoption.mjs --write
node tools/translation/prepare-default-proof-byte-adoption.mjs --check
node tools/translation/prepare-batched-proof-byte-source-candidate.mjs --write
```

Root must also regenerate and check the complete current whole-owner/Core/byte
closures whose inputs now contain the adopted factory imports. The source
census adjustment accepts only the existing exact native/frozen factory named
imports from the same bridge; it preserves the original five-consumer census.
No generated candidate output was edited manually in this draft. Root owns
source-bank, class birth and export freshness after the final source batch.

`default-proof-byte-adoption.test.mjs` adds seven whole receiving cases with
the existing 60-second per-case bound. They retain complete source equations,
original-context DATA, Default's genuine enriched binding result, native Hash
and observed JSON tapes, once-only fallback, copied/foreign context refusals,
classic repeated-call identity, nested/exception/async closure and unsupported
JSON callbacks. Separate source-derived baseline modules have independent
private tables; their contexts are expressly refused by the installed issuer.
The only receiving import/root substitutions are selected by native AST and
retained through complete CST inverses. An optional complete evidence archive
uses `ROUTER_DEFAULT_PROOF_BYTE_EVIDENCE_DIR`.

This format may reduce private cache warming and measurement counters. Those
counters are not claimed equivalent; complete JSON bytes, observable original
callbacks, Hash payloads and namespace/source checks are required. Before any
default installation, Root still needs this whole file, the complete original
twelve cases on both engines under their original limits, and fresh actual
production diagnostics. There is no measured speed or executable coverage gain.
