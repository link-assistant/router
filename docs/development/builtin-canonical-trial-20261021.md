## Preparation and storage

Preparation discovers the fresh full Git tracked/unignored Rust, Cargo,
compiler, profile and scripts universe. Compiler selection composes the existing
`isCompilerSourceInputPath` and `isIsolatedCompilerSourcePath` contracts. Both
complete source families, every Rust/Cargo input, all scripts and the actual
source-profile/vendor archives stay included. It adds every physical file in the actual installed TypeScript
5.9.3 package. Missing physical sources and linked inputs refuse preparation;
there is no projected Rust subset or stale sparse-blob substitute. The native
source producer must use that same root's actual installed compiler instance.

Before reading any source body, a stat-only census rejects more than 8,192 files,
any file over 32 MiB, or total input bytes over 256 MiB. These are the unchanged
compiler-source input limits. Bounded fd reads then enforce each allocation size
and reject source growth or replacement after the census.

`canonical-trial-source-closure.mjs` then adds the entire unchanged original
derive test and its actual test-side helper/resource closure. The installed
native TypeScript parser and lexical symbols follow original static imports,
exports and literal dynamic imports. Full helper sources, native spans and
literal file-read expressions are retained as DATA. Direct path parameters
must close over every actual call site; original Git reads join the actual
HEAD and complete tracked Rust path census. The actual repository path mapper
is rejoined to its complete current source before using its physical layout.
Unknown dynamic paths, escaping input functions, unresolved dependencies and
unproved input providers refuse. Each newly analyzed helper receives the same
stat census before reading; the complete final union is censused again before
capturing all source hashes. This extraction runs afresh at every existing
source-vector boundary; it retains no across-invocation source or verdict cache.

Compiler import edges terminate at the two complete existing compiler source
families, whose modules and resource archives remain retained in full. Other
test/fixture archives are not added just because they share a directory name.
Every omitted Git inventory path has an explicit DATA record stating that it
is outside both compiler contracts and the native original-test input closure.
The full closure sources, edges, read targets and compiler boundary records
explain that exclusion; neither they nor the omission records grant semantic
or runtime authority. The older broad `isCanonicalTrialSourcePath` public
inventory predicate stays compatible; discovery uses the new base predicate
and the fresh native closure instead.

Each source has a separate version-two gzip frame with its complete original
bytes. An unchanged trial records `same-original-source` plus its complete byte
length and SHA-256; it reconstructs the exact retained original bytes rather
than encoding those same bytes twice. The codec frame instead requires
`complete-candidate-source` with the complete distinct candidate bytes. The
reader reconstructs the whole packet equation, rejects an aliased codec,
forged association, extra field or noncanonical/corrupted encoding, and checks
both reconstructed sources against their actual physical files. This is
lossless source transport with no encoded source/verdict cache. One file packet
is live at a time. Every frame is independently reopened and decoded; every
mirror file is reread. The complete vector, file modes, HEAD,
candidate equation and original physical sources are rechecked. Exactly one
file may differ in the mirror. Initial mirror, frames, proposal and manifest
must fit Root's 384 MiB mirror/evidence monitor cap. Test runners retain their
existing raw-stream and resource bounds; outer monitoring still applies to
preparation, execution, receipt joins and their combined retained evidence.

Preparation and checking execute no tests or Rust. Run only with the shared
resource lease, an immutable integration head, physical original sources and
the installed dependencies. Example argument vectors, with task-specific
`TRIAL_ROOT` and `TRIAL_OUTPUT` variables:

```sh
ROUTER_NATIVE_TS_SOURCE_ROOT="$TRIAL_ROOT" node --max-old-space-size=2048 "$TRIAL_ROOT/tools/translation/prepare-builtin-canonical-trial.mjs" --prepare --root "$TRIAL_ROOT" --output "$TRIAL_OUTPUT"

```

The source proposal is available separately through `--emit --root ROOT`.
The manifest declares `productionSelected:false`, `trialSelected:true`,
`runtimeExecuted:false` and `performanceQualified:false`.

## Original Node and Bun receiving runs

The separate opt-in Node operation invokes the mirror's actual
`runAuditedNodeTests`, selecting only the complete unchanged original file with
one worker and a 240,000 ms enclosing cap. It retains the existing independent
source-declared duration audit and complete raw streams. It restores environment

```sh
ROUTER_NATIVE_TS_SOURCE_ROOT="$TRIAL_ROOT" node --max-old-space-size=2048 "$TRIAL_ROOT/tools/translation/prepare-builtin-canonical-trial.mjs" --run-node --output "$TRIAL_OUTPUT"
```

The mirror uses the original Git directory with the mirror as `GIT_WORK_TREE`,
so the unchanged original test reads the same index and HEAD while reading the
complete mirrored original files. No repository is cloned or initialized.
The installed TypeScript files are physically copied; the manifest records the
explicit mirror compiler binding. An existing TypeScript override must resolve
to the captured installed compiler before it can be mapped to its exact copy.

`--join-node --output OUTPUT --receipt-directory DIRECTORY` independently joins
an already completed audited Node run. Both joins reread the original and trial
source universes and every complete frame. Node requires actual reported source
spans and the independent audit's exact unchanged test source/deadlines. Bun
reports names and durations rather than positions: the join explicitly retains
that difference and maps exact unique reported names to the unchanged native
source calls. Missing, duplicated, unknown, skipped, untimed, failed or overdue
cases fail qualification. Full original receipts and raw bytes remain retained;
the join is not a coverage or runtime-parity claim.
