# Original attribute literal concat source draft

Every implementation and new case is UNRUN. Only source construction and review
occurred. No parser, consumer, translator, preparer, generation, compiler,
experiment, test, local Rust tool or CI-triggering push executed. All unfinished
source requirements remain open before verification resumes.

The explicit source successor copies the complete existing native concat source
selector and successful ASCII-literal expansion implementation. Existing default
and sealed APIs remain intact. The new route parses its manifest freshly,
checks its exact pin, reopens all sixteen complete original inputs and retains
both licenses. Each Rust file keeps a full CST roundtrip and inverse. Every
selected callback retains its entire original source at the original span;
registration, parser, literal decoder, visitor, collector, placeholder, output
constructor and complete unsupported branches remain source inputs.

No new enduring source or expansion cache is created. The new route retains
native sources inside one request only and rejoins all current original inputs
before returning. Complete retained native bytes stay within eight MiB. Literal
eligibility is checked before expensive native construction, so malformed or
unsupported source cannot initiate unnecessary full native CST work. A successful
candidate always performs the complete current native source checks.

The input must come from genuine original attribute invocation/position receipts
and an actual private documentation expression frame. Detached, foreign,
changed-source or accessor inputs cannot replace those associations. The exact
old selected domain remains: unescaped printable ASCII string literals,
unqualified concat spelling as a conditional input, at most 128 arguments,
optional trailing comma and at most 4,096 output bytes. Empty concat is retained.
Nested eager macros, escapes, Unicode literals, numbers and other input kinds
remain unsupported in this narrow rule sequence.

Language rules derive the literal candidate and replace only the exact original
invocation span through serialized/reparsed CST substitutions. Repository rules
retain the complete original/after physical source equation and full inverse.
The output literal has its own independent full CST roundtrip. Current original
attribute and invocation inputs are checked again after native source rejoin.
The API returns a proposal and does not install or admit it.

Actual builtin caller ownership, attribute owner and value semantics, native
visitor confinement, global exports and original-source equivalence remain
unqualified. A matching spelling cannot select a custom or builtin macro owner.
Three complete compiler equations retain original implementations and native
owner spans. Independent unrun positive/empty/trailing/whole-native/refusal/
private-input and stable native oracle cases are drafted. Wider macro/language/
namespace, production/parity, reverse/synchronization/freshness, CI repairs and
receiving qualification remain unfinished.
