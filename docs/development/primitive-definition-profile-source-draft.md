behavior and strict TypeScript cases are UNRUN. Whole drafting and qualification

The source checker now has an explicit primitiveDefinitions request for the
new-function bootstrap path. It also requires the existing primitiveOperators
request and complete actual paired runtime/declaration closure. The mode selects
a finite additional source family; it grants no source, type, namespace, ownership
or execution permission. Default APIs retain their original owned-call rule.

Every source still enters the actual original native syntax, lexical binding and
type/flow checker and serialized/reparsed CST and checked meta. Before issuance,
the new mode independently requires root-free Boolean/default unsigned-64 or exact
fixed integer parameters/results and a complete bounded pure body. Qualified
total operators retain their original actual import, metadata and operand checks.
Borrowed/aggregate values, mutation, unit-return definitions, arbitrary helpers,
effects, shifts and checked-failure calls retain separate refusal paths.

The new profile retains exact fixed local aliases in emitted TypeScript, so its
whole canonical source can recover the same scalar domains. Context mode data
is serialized in the existing complete context header and must match on re-entry.
Neither a detached body that passes the DATA family filter nor a context flag
can replace the private original-source issuer. Both insertion and nonempty
extension bootstraps explicitly select this new family before independently
emitting and checking complete proposed native bodies and actual native ABI.

preserve originals/inverses under language then repository. Independent unrun
cases cover Boolean and JS/JSDoc definitions, all ten fixed domains/local witnesses,
strict paired behavior, meta re-entry, context/runtime mismatches, default-mode
refusal, DATA tampering and unsupported effects. This source correction addresses
the legacy owned-call guard found by code review; it is not execution evidence.
