## Worklist semantics and costs

`collectSourceBindingGapPlan20261103` owns a real fresh physical source operation.
Its language sequence obtains the original detached observation; its repository
sequence retains every original graph/binding diagnostic, true unresolved type/
macro/bang/attribute flag, unresolved/ambiguous binding, nonactive scope condition
and physical source outside the original graph's binding closure. Duplicate or
overlapping original observations stay separate. No substring classifier can
clear a native gap. Each row requires L02/B05 review and stays OPEN.

Original diagnostic fields are retained in full. Located spans carry actual
UTF16 and UTF8 endpoints tied to the complete physical source's byte length and
SHA256. Missing, conflicting or out-of-census source identities and unsupported
span shapes remain explicit location gaps. Full originals/CST stay in the
original operation during construction; the output carries source locators,
not copied diagnostic source bodies or private tokens. Sparse endpoint batches
scan disjoint source segments once per file, avoiding repeated whole-prefix
UTF8 scans. Profile/census locator hashes are computed once per operation.
These are implementation cost choices, not measured performance results.

The complete census/profile participates in bookkeeping IDs. A changed or added
physical source changes the context locator, without pretending a hash grants
namespace/type/body authority. Original traces, profiles and diagnostics remain
available. Counts describe scopes and gap rows only; production denominator,
translation coverage and drafted requirements remain null. Even a zero-gap
report keeps `scopeReviewComplete:false`: Cargo/feature/producer/native-type,
application-role, target-binding and receiving qualification still need review.
The report is not an automatically approved L02 implementation assignment.
Its locators cover the selected path/content census and profile, not inode/mode
identity or a checked immutable Git origin. Physical fencing still belongs to
the original source operation; collected-scope assignments need their own
complete original evidence joins.
