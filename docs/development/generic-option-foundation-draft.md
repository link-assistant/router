# Shared generic Option ABI foundation draft

All implementation, producer and regression source in this batch is drafted and
unrun. No test, experiment, diagnostic, compiler, translator, preparer, exporter,
regeneration, Rust tool, push or CI ran. All unfinished [ledger requirements](bulk-draft-requirements.md)
remain open. The [carrier compiler successor](generic-option-carrier-draft.md)
now drafts the generic lowering prerequisite described below; it is also unrun.

The existing primitive Option library gains one complete generic unchanged-value
operation in Rust, JavaScript and its strict TypeScript declaration. It returns
the whole carrier without observing or manufacturing its payload. Reusing these
existing files adds no runtime asset file, native module edge or package
requirement. Shared source fragments define both implementation additions and the
parametric `GenericOption<T>` declaration. Original scalar operation descriptors
remain separate and retain their closed domains.

A separate signature-only descriptor prepares actual imported type queries for
the forthcoming generic carrier rules. Ordinary runtime calls to that descriptor
are explicitly refused by the existing whole caller flow checker. This table and
its public fields grant no generic caller or executable authority. Bare `T → T`
forwarding remains distinct from the precise `Option<T> → Option<T>` source
signatures and bodies in the carrier compiler successor. The new if-let generic
regression remains unrun; it is not skipped or counted as coverage.

The optional generic source observer verifies complete pinned original library
files plus their exact ordered source additions. It independently checks actual
native function syntax, the sole unchanged returned parameter, complete JS body,
unique declaration namespace, generic slot binding and readonly None/Some fields.
Original module-edge, full mirror, source CST, scalar census and current source
checks remain. Generic proof work is separate from the default scalar observer;
the carrier compiler selects it only through genuine generic type-query imports.
No source or result cache crosses invocations.

The persistent library producer captures all three complete originals, retains
both source-rule phases and full Rust/JS/TS CST inverses, and proposes exact current
mirrors with bounded regular-file reads. Eleven compiler source equations retain
native owners and both ordered phases. The original primitive Option preparer's
CLI now calls its actual function; source review found the previous unrelated
function name before any execution. Independent unrun source covers opaque
payloads, mirror tampering, source-only call refusal, historical receiving files,
full source histories and real Rust generic movement/drop timing.

Generic carrier capture/emission, symbolic type queries, dependency compatibility
and source-unit signature composition are drafted in the successor. Whole
receiving/parity, architecture/producer closure, broader executable language/effects
and every original CI/freshness gate remain unfinished. This unrun ABI foundation
and its compiler successor are not completed generic translation.
