# Cold future and resource caller source draft

The explicit async-control caller API reuses a complete source copy of the
existing filesystem control adapter through ordered language and repository
substitutions. Its new source checker covers the thirteen actual cancellation,
deadline and bounded-channel interfaces together. Existing synchronous owned
profiles and filesystem APIs retain their domains. All new source is unrun.

The checker binds named relative imports against complete current runtime,
declaration and native library sources, including the actual unique root module
edge and full public operation census. Resource parameters use native parsed
`Parameters<typeof actualImportedOperation>[index]` queries. Primitive Boolean
and string inputs remain explicit. Counts currently require exact bounded u64
literals; a bare bigint annotation supplies no range proof. Every translation
rechecks complete original source after semantic-meta serialization/reparsing.
Complete original and paired source CST, annotations and inverses are retained.

Deferred wrappers keep their actual cold runtime constructor. Direct forwarding
of an actual cold operation is supported; eager async root functions and stored
unawaited futures refuse. Sequential awaits retain real shared/exclusive operand
roles. Local cancellation, sender and receiver aliases move once. Channel tuple
splits consume one actual guarded successful payload. Pending results require
immediate failure propagation, and source branches must terminate completely.

Native receiver Drop has observable cleanup. Every locally owned receiver must
therefore be returned or explicitly disposed on each success and failure path.
Error guards may perform actual receiver disposal before returning their whole
original error. Native emission preserves that branch and uses real mutable
reborrows; a JS object spelling grants no exclusive loan or move permission.

Deadline callbacks are one actual async tail operation, using their exact child
cancellation. They cannot perform post-await side effects. Shared and exclusive
captures are reborrowed before the native move closure; unrelated owned values
cannot escape through that callback. This restricted shape is necessary because
the native deadline can immediately drop its future, whereas a JavaScript
continuation can still settle after cancellation. General async callbacks,
pending future storage, exclusive future concurrency and arbitrary Drop require
additional independent rules.

Rust emission in this lane is a source projection from freshly checked control
meta. It does not claim the older filesystem Rust semantic checker supports
opaque cancellation/channel types. `nativeRustGrammarChecked`, `rustExecuted`
and `receivingExecuted` stay false. Native grammar and behavior require gated
Rust CI after all eight original same-SHA JavaScript stages pass.

Independent unrun regression source covers JS and strict TypeScript, cold
wrappers, cancellation, nested deadline results, channel data/cleanup, exclusive
captures, complete sources/meta/CST inverses and refusal boundaries. A native
Rust oracle is drafted for gated CI. General Rust forward/inverse integration,
source-unit synchronization, public numeric guards, HTTP resources, producer
closure, production adoption/parity and the remaining ledger stay open.
