# Original native unit spelling draft

The explicit native binding successor now records omitted unit return types,
empty native bodies and bare return token boundaries. Exact substitutions add
the established unit signature and expression tail, or retain an earlier unit
return with its original function target. A synthesized final unit tail prevents
an earlier conditional return from being treated as a final branch value.
Empty typed callback bodies similarly retain their actual native unit value.

The whole reconstructed source still re-enters the independent checker, and
every emitted native token must reproduce the normalized source. A non-unit
value in an omitted-unit function, a missing Boolean result, unknown effects,
opaque patterns or changed source cannot gain admission. Actual cancellation,
disposal and cold boundaries continue through their existing complete contracts.
Original native authority bytes, comments, scopes and full inverse histories
remain retained; JavaScript uses the existing null representation of Rust unit.

Three complete original sources, both rule phases and exact inverses are
retained. Independent JS/strict TS/native, empty/early/cold/callback/cleanup,
source/refusal and real native library oracle cases are drafted and unrun.
No tests, experiments, compilers, translators, preparers, generation, local Rust
tools, pushes or CI ran. Wider unit/control syntax, namespace/producer closure,
actual production qualification/parity and all unfinished bulk requirements
remain open.
