# Complete original data item source draft

All new implementation and independent cases are UNRUN. Only source construction
and review occurred. No parser, captor, selector, translator, preparer, test,
experiment, generation, local Rust tool or CI-triggering push executed.

A bounded source grammar composes the existing private attribute, name,
visibility token-tree, generic, where-bound, type and expression parsers for
whole named/tuple/unit structs and enums. Genuine DataItem, DataField and
DataVariant AST nodes retain exact source spans, attributes and original opaque
type/discriminant macros. Whole item EOF and original source/token/node/depth/
member bounds apply. The new grammar describes parsed source; native rustc
legality, field visibility, layout, discriminant values and type/trait semantics
remain unqualified.

Complete function issuer/reader patterns are copied into a separate private data
family requiring actual original module item identity. Every read rejoins the
complete original source/view/profile/item, private parser and AST, current
native parser inputs, serialized/reparsed whole physical CST and source inverse.
No copied item, public flag or detached AST can issue a genuine data receipt.

Nested metadata enumerates actual generic parameters, struct fields, enum
variants and fields inside those variants. Complete header issuer/reader copies
select those actual private AST owners and attributes by bounded indices; a
variant field retains both variant and field indices. Genuine parsed path and
empty/delimited/equality arguments require exact original token trees and full
header EOF. Distinct private header/data/function families and the existing
operation-local checked physical CST reuse remain intact. Owner, availability,
macro, visitor, global export, type, namespace and runtime authority remain false.

Three complete compiler source equations preserve original full parser/issuer
bodies, native class/function owner spans, explicit ordered language/repository
substitutions, CST/meta boundaries and whole inverses. Independent unrun cases
cover all data shapes, attributes at all four nested sites, generic/array/raw
field syntax, opaque Ty/Expr macros, source changes, private identity and malformed
or unsupported items, plus native data/attribute oracle source. This is not
lowering or executable coverage. Native builtin/derive consumers for these sites,
macro/owner/effect closure, production/reverse/synchronization/freshness/CI and
receiving qualification remain unfinished.
