## First whole-corpus edited-target inverse

`proposeOpaqueCorpusLiteralInverse(configuration, submitted)` drafts the first
explicit corpus edit family. It supports one literal constant-array cell or
literal index in the actual generated JavaScript or TypeScript module. It does
not support arbitrary edits, multiple edits, computed constants or inferred
normalization. Unsupported/ambiguous original relations refuse.

The source sequence is:

1. Capture the real original/native/adopted project through the genuine compiler
   and all original source closers. Retain all physical and adopted native files,
   complete paired targets, the real emitted constant-origin record and complete
   executable/refusal/unlowered/method identity lists.
2. Parse the actual original and submitted targets with the genuine pinned TS
   grammar. Require the same entire token/symbol skeleton and exactly one changed
   semantic literal in its actual emitted function/array/index relation.
3. Join the adopted slot to one original physical literal. A const cell requires
   its complete original declaration to match uniquely. A source index requires
   the actual enclosing function and unique original constant-index token. Full
   byte/token preimages are checked; spelling alone grants no admission.
4. Apply that one physical native candidate to a new real source view and freshly
   run the whole project/adoption again under the still-live original input epoch.
   Require unchanged whole admission/method identity lists and exact reproduction
   of the entire requested target. Regenerate the paired target independently.
5. Retain full physical Rust and both target CST histories/inverses. Return a
   read-only source proposal; do not install files or call a native Rust compiler.

Origin/census records are invocation-local DATA used for candidate selection and
comparison. They are never submitted as checked parser/type/ownership objects.
The changed complete native program independently receives all actual checks.
Exact restoration of an unchanged target is refused, as are unrelated bindings,
imports, calls, ambiguous original slots and changed admission populations.
