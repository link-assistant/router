# Primitive operand domain source draft

SOURCE ONLY. The reader, private checkers, whole paired/native synchronization,
boundary refusals, source-history, definition insertion and helper case sources
are UNRUN. All freshness, receiving, runtime, CI and application coverage
qualification remains OPEN.

The original primitive operator reader retains its complete implementation and
one-argument callback behavior. A separate complete copy provides an optional
second callback argument containing only the finite exact primitive domain from
the operation's literal metadata. The actual core, vector, collection, iteration,
state, outcome and cancellation source checkers now select that additive reader.
Their actual imported runtime symbol, full runtime/declaration bytes and private
source/ownership/type checks remain mandatory.

The checkers preserve that domain through parentheses and both independently
checked conditional arms. Direct literal construction uses the actual domain
before a narrower default literal bound can discard valid i128/u128 values.
Out-of-range literals are rejected even in an unselected arm. A nonliteral
variable or nested call keeps its independently checked type: the hint cannot
recast it, erase ownership, change signedness or invent a compatible runtime
result. Existing conditional loan/move checks and exact final operand-domain
checks remain intact. This is contextual literal interpretation, not implicit
numeric conversion.

The reader copy and all seven real source consumers are retained as nine
complete source-copy equations with exact originals and inverses. The original
total-operator reader copy stays unchanged. The fixed language then repository
phases join the current source-preparer history. No implementation, parser,
translator, preparer, test or Rust compiler was executed while authoring it.
