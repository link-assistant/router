outgrown the original exporter’s 2,048-file cap. A separate complete exporter
copies the original implementation and retains its Git/index/physical source,
no-follow read, byte/mode, fresh destination and repeated original checks. The
original bounded API and every existing refusal remain available.

of at most 2,048 files. Its logical census uses the existing compiler source

source file remains physically present, byte-identical and indexed in the fresh
unborn receiving Git repository. No original implementation, profile or license

inventory exactly once and retains the original source commit and whole census.

bounds stay fixed. Source plus all partition metadata must fit the same global
byte bound. Complete metadata receives bounded byte/mode/blob rechecking after
writing. Packaging supplies no source, native namespace, ownership, semantic,
runtime or synchronization permit. No cross-invocation cache is introduced.

operation. Every original workload, byte check and deadline is retained, while
small fixtures and negative controls continue to exercise the original API.

profiles/licenses, exact partition reconstruction, the old 2,048-file refusal,
