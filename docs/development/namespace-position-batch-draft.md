# Native function invocation-position batch source draft

The new batch copies the original private single-position issuer and selects
all actual opaque invocation nodes from one genuine complete function frame.
It performs the original full source/module/profile/native parser/positive AST
checks before and after collection. Every node still belongs to that private
parser, has a checked Expr/Ty/Stmts position and receives its own original
private proof association. The original facts API accepts those receipts through
the same current-input checks; old single-position APIs remain unchanged.

Returned rows and facts are frozen DATA. Block-local imports/procedural stubs
remain separate from unresolved global macro exports and attribute effects.
No namespace, macro owner, type or runtime authority is inferred. Existing node,
token, source, depth and member bounds remain, with no new persistent cache.
This prepares actual generated-function source consumers without repeating full
frame validation for each receipt during collection. No measured timing result
or semantic/runtime qualification is claimed.

Three complete source equations and independent unrun mixed-position, legacy
facts, empty/member, fake/foreign receipt and changed-source cases are drafted.
No tests, experiments, diagnostics, draft compiler/preparer/translator,
generation, Rust, push or CI ran. Complete architecture output/owner/export
closure and every unfinished bulk-draft requirement remain open.
