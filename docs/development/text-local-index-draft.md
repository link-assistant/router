# Shared text scope and optional index source draft

All implementation, source history and independent cases are drafted and unrun.
This establishes no new executable coverage, current strict TypeScript result,
source freshness, native parity or complete source synchronization.

Both text adopters now use the shared chronological source selector for actual
immutable text aliases. Simple parameter/raw/ordinary literal aliases, explicit
owned as_str views and the existing borrowed annotation grammar retain source
spans and become visible only after the real initializer semicolon. Actual
selected text results can supply later text aliases. Facts disappear with their
lexical block; unknown/future/ended-scope bindings remain unproved. Whole-function
namespace/producer/type/ownership checks still apply. Source DATA grants no
trait, move, lifetime or executable permission.

The selector also recognizes complete original find/rfind calls immediately
followed by map(|index| index as u64). Only the exact bound identifier copied
through that primitive cast is selected; arbitrary callbacks, return types,
effects, block bodies and unknown receivers remain unsupported. Existing paired
text-core operations implement optional UTF-8 byte indices. Existing scalar
character language rules also apply to these pattern arguments. Matching whole
Rust functions still need all independent semantic and ownership checks.

The fixed source-bound bulk stage now retains the same separate scalar language
substitutions and rebased repository substitutions as the ordinary proposer,
including complete serialized/reparsed CST, intermediate source equations and
whole original-source inverses. The operation catalog, paired runtimes and
existing reverse helper mappings remain the source of actual compatibility
behavior; no hand-written generated application files are introduced.

The new local lane keeps 200000 token/cell, 4096 binder and 256 lexical-frame
bounds. Its annotation grammar scans at most 64 following type tokens. Original
no-local behavior stays separate. No source/hash/owner/verdict/result state is
cached across operations. The entire selected application body must qualify.

Four complete equations retain the original helper, selector, source-bound
adapter and previous history edge. Independent written cases cover typed/raw/
owned/scoped aliases, real selected results, exact closure refusals, both APIs,
the fixed bulk stage, Unicode byte offsets, empty patterns, source/CST inverses,
fresh receiving JS and strict TS, and original/adopted native boundaries. Every
case and wider source/native/production/sync/freshness/parity/delivery requirement
remains unverified.
