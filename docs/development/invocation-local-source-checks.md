# Invocation-local source checks

Source preparation keeps the complete CST boundary and the two ordered rule
sequences while reducing repeated work within one invocation. This changes no
public concrete transport, semantic admission rule or application coverage.

`prepare-invocation-cst-reuse.mjs` derives the two original private source
workflows from complete pinned modules. Each phase retains its complete
serialized canonical representation and compares every code unit with an
independently built, serialized and reparsed source transport. The complete
inverse wire must equal the original canonical wire. Source equality alone,
hash equality and a preserved body do not establish that equation.

`prepare-source-phase-transports.mjs` captures the three complete original
phase sources in the existing bounded source-only CST batch. Forward edits
must produce exactly those complete canonical representations. An inverse
whose complete canonical bytes equal the already reparsed original uses that
invocation's existing transport; it still runs the actual inverse substitution
and complete serializer. There is no source, hash, owner, verdict or encoded
result cache across invocations. The original batch/node/source/byte limits
and all original test deadlines remain in force.

`prepare-native-source-binding-batch.mjs` copies the original TypeScript 5.9.3
compiler options and complete diagnostic checks into an additive batch API.
Ordinary modules share one invocation-local program while retaining their
original filenames and module scopes. Script inputs use the unchanged original
checker separately; another source cannot supply a missing binding. The
complete actual source producer runs these checks before its unchanged final
source fingerprints and returns no partially checked proposal.

Each producer records native selections, language/repository source equations,
serialized/reparsed full CSTs and exact inverses. Their installed source history
joins complete original and successor strings, rather than accepting a matching
hash or a projected source. Regenerate the five dependent files with the actual
`prepare-batched-proof-byte-source-candidate.mjs` producer. Preserve every
original whole test body, callback and refusal control. A late synchronous TAP
pass remains a failure; isolated controls do not qualify full translation,
generation performance, profile freshness, runtime parity or Rust CI.
