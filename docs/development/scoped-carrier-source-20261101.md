# Scoped carrier source-role ledger

**SOURCE ONLY / UNRUN.** This opt-in helper drafts source-selection DATA for
ordinary immutable block locals, parenthesized operands and block-tail roles.
It grants no original namespace, type, capture, lifetime, ownership, trait,
library or executable authority. No Root/Host/checker, old helper API, native
library, default compiler domain or Sync adopter is changed or installed.

The new main contains the **complete** original chronological implementation
as a private renamed copy plus the new synchronous wrapper. Its explicit
successor fixes an initializer-order problem: the original helper puts an
unknown new binding in its frame before reading the initializer, which hides
the prior `x` in `let x=x+1`. The new copy preserves the prior source binding
until the actual initializer terminator. A recognized result publishes its
new role there; an unknown result hides the prior role there. An annotation
never invents a concrete initializer result. The published old implementation
and every old caller/refusal remain unchanged.

The existing written-local initializer reader and source carrier readers are
reused. The new operand layer peels only balanced complete parentheses and
reads ordinary immutable let prefixes plus one complete block tail. It
preserves actual source intervals and never evaluates an operand or block.
Qualified operation catalogs select declared source roles only; later actual
whole-project checking must independently prove owner/type/loans/effects.

`withScopedCarrierSource({source,functionSpan}, callback)` requires a whole
bounded original source and one actual complete function item interval. It
derives original tokens and ordinary written parameter roles. The callback
receives source-only `at(position)` and `operand(position,span)` readers;
the latter requires that the operand starts at that actual current token.
Results are immutable plain role/evidence DATA. Actual original block frames
keep repeated `key`/`used` names in sibling scopes separate. Local evidence
includes the complete declaration/initializer intervals. Unknown aliases and
result domains remain absent, not promoted by a public type/name/hash flag.
An additional immutable `provenance` census includes **every** visible binder,
even an unknown local omitted from `bindings`. It distinguishes actual header
parameters from local shadows, with original declaration/initializer intervals
and a DATA-only `roleKnown` field. A null role/evidence never establishes
parameter identity. Future header-role fallback must require explicit current
parameter provenance and rejoin its original header interval; unknown locals
must continue to hide a prior parameter after their terminator.

Only ordinary synchronous source is selected. Mutable/destructured/pattern,
unknown callback, loop and producer scopes refuse. Existing complete finite
carrier callback source regions stay opaque, and a query inside an excluded
callback refuses. Their names never become bindings in the surrounding frame.
There is no generic closure/callback or standard-method owner permission.

The readers expire synchronously. Initial full input/source validation remains.
Later reads compare captured exact own-DATA descriptors, key/prototype and
extensibility structure, source primitive, coordinate-array identity and both
coordinate descriptors. They invoke no getters/proxy traps and do not repeat
whole-source accounting or metadata copying. Actual token starts use one
operation-local Set, cleared at exit. This is an unmeasured source-review
optimization, not a speed or resource qualification.

Input/source/interval mutations close at every read and on every exit; caught failure followed by restoration still
poisons enclosing shared source operations. Every closer runs and falsy/frozen
ordinary callback primaries keep exact identity. Private copied frame maps,
annotations, token vectors and captured source are cleared at exit. No live
checker/emitter facade, source-verdict cache or mutable frame escapes.

All original limits remain: 2 MiB source, 200k token/source work, 256-token
initializer, 256 chronological frame depth, bounded 32-level role recursion,
4096 local bindings and 16 MiB complete occurrence accounting. This new
source-only family may conservatively refuse unknown grammar; it does not
raise a production/fixture cap or claim aggregate CPU/RSS qualification.

`visitScopedCarrierSourceHistory` delivers the full original chronological
module → full copied successor equation, fourteen complete source prerequisite
identity equations and the complete new operand source equation. Every event
contains both full sources, serialized/reparsed CST, the actual language then
repository trace and complete inverse. The archive keeps all images, not just
digests. `withScopedCarrierSourceInputs` checks those exact actual physical
inputs on entry and closes all successfully read bytes/file identities and
stable ancestor identities on exit. Pins are DATA custody, not semantic proof.
The history helper is self-excluded from its archive, as with earlier source
profiles. This prerequisite history is not a qualification of the complete
exported compiler or every transitive library/runtime implementation.

Independent source cases cover sibling blocks, prior-binding shadow
initializers, unknown shadow results, parenthesized literals, typed block
locals, exact qualified-field tail roles, nested tails, opaque callbacks,
pattern/mutation refusals, expiry, caught-restoration poisoning, falsy/frozen
primaries and every complete source history. None was executed. Compiler,
parser, translator, preparer, JS/strictTS/native runtime and CI evidence remain
UNRUN/uninspected. No native oracle or receiving compiler is qualified here.
