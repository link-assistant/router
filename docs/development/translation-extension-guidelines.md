# Translation extension contribution contracts

These requirements supplement [CONTRIBUTING.md](../../CONTRIBUTING.md).
The active source-only phase and all original gates remain mandatory.

Generic derived outer-attribute source facts must retain the complete generated
attribute definition/use suffix, actual method implementation owners, inherited
predicate defaults, original ungated registration expansions and complete
collector body. A registry-name list or an `Impl` discriminant alone cannot
discharge that obligation. Join a single per-invocation shared source proof to
every actual registered common callback. Keep caller ownership, nested/exported
macro effects and full producer closure separate and retain their false flags
until their independent proofs exist. See the
[unrun source draft](builtin-derived-outer-attributes-draft.md).

Resource loop analysis must keep nearest-loop boundaries separate from function
return summaries. Backedges, breaks and continues preserve incoming ownership
and type state and clean iteration locals; actual returns clean all locals and
join their complete domains, roots and exclusive-input states at the enclosing
function. Result and Option propagation inside a loop returns from the function.
Never use a loop boundary as helper-release evidence, append an outer source
continuation into a continuing inner lexical scope, or infer unconditional moves
and releases from a short-circuited Boolean operand. Preserve original complete
deadlines and the independent unrun
[loop-exit cases](http-resource-abrupt-loops-draft.md).

Continuing branches retain real lexical scopes. Capture only their actual
incoming bindings, clean new local resources before fallthrough, join every
continuing ownership/disposal/guard/domain/root state, and discard scope-local
names before analyzing following outer source. Scope fallthrough is neither a
function return nor a loop boundary. Assignment and exclusive-use discovery must
respect child declarations when a later outer binding reuses the same spelling.
Keep exact substitution spans inside their native owner, including complete
function replacements; trailing trivia cannot widen that owner. See the
[unrun scoped continuation draft](http-resource-scoped-branches-draft.md).

Compose existing matching JSON storage implementations through their real
current native/root/facade/runtime sources and closed domains. Mutable JSON
state requires a genuinely owned constructor, copy or carrier payload; a shared
input annotation cannot transfer ownership. Preserve whole moves, reinitializing
assignments, loop/branch state joins, Some(Null) versus None, and the existing
bounded successful-resource contract. List and callback shapes need independent
rules. See the [unrun JSON resource draft](http-resource-json-state-draft.md).

Borrowed JSON projections and aliases retain their actual original input or
local owned roots, including every possible helper-result root. Local JSON-backed
text/JSON views may be copied into owned results, but cannot escape their owners.
Moves and replacements must check every live view; completed lexical scopes
remove only their own views. Native returned lifetimes follow the checked root
set through the separate structural shared-reference query. Preserve the old
text-only query and refuse unproved temporary loans. See the
[unrun JSON view draft](http-resource-json-views-draft.md).

Owned JSON lists and shared slices have separate ABI domains. Require an actual
imported list operation for public slice types, original owning operations for
owned locals, and complete moves/roots when lists cross calls, scopes or loops.
Keep native Vec fully qualified and slice lifetimes tied to the actual checked
input roots. Paired-source-unit type proposals must re-enter the complete
source checker. Array shapes, proxies, copied metadata and unproved iteration
cannot supply ownership or a list domain. See the
[unrun JSON list draft](http-resource-json-lists-draft.md).

### Source synchronization exports during issue #759

Keep every public synchronization CLI in the shared
`tools/translation/translator-entrypoints.mjs` list. Preserve all original entries
in order and retain the complete compiler/runtime/declaration/profile/license
closure through the committed-source exporter. Source preparation must compare
complete pinned original vectors against their exact retained prefix, rather
than assuming there will always be only one added command. Keep original
resource limits and all eight full JavaScript gate stages unchanged.

The source synchronization facade forwards to fresh original issuers. Never
accept a saved proposal, public semantic flag or source hash as admission. For
bulk inverse edits, parse complete JS/TS, retain serialized/reparsed CST and
whole Rust/JS/TS inverses, resolve actual checked source origins, refuse an
ambiguous or incomplete batch and recompile the whole modified project before
guarded installation. Work within one invocation instead of adding persistent
source or verdict caches. The current literal families do not establish broad
expression or whole Router support.

Independent exported receiving cases, complete original histories and behavioral
regressions must be drafted with implementation. Under the user's active bulk
draft instruction, execute none until every requirement has its full source
draft; no CI-triggering push or local Rust tool is allowed during this phase.
Record exported source, receiving evidence, whole-gate evidence and production
parity separately. See the [export draft](synchronization-export-draft.md).

For forward-derived literal synchronization, use the original compiler's actual
emitted function mapping together with its fresh checked source association.
Repeated values require complete source/target multiplicity and full modified
project reproduction. Preserve each fixed integer's actual native name, width
and signedness. Reject unmatched code edits, out-of-domain values and incomplete
batches; do not treat a matching source order or target name as semantic proof.
See the [scalar inverse draft](forward-literal-synchronization-draft.md).

Primitive slice source rules must preserve each actual numeric domain through
registered operation-derived types; bare bigint array shapes do not distinguish
Rust u64 and i64. Retain readonly input roots, Copy item checks, fresh complete
body checking and whole canonical Rust reproduction. State the ordinary dense
immutable array runtime domain explicitly, and keep exotic iterator/getter,
mutable array and unqualified generic/Clone uses outside the admitted source
subset until their own matching rules and independent cases exist.

Whole return-expression inverse proposals must obtain actual compiler-issued
parameter/local source associations, preserve every unchanged native prefix and
header, recompile the entire modified Rust project through checked semantic
meta, and reproduce the complete JS/TS target. Structural comparison may ignore
only proven harmless grouping/trivia inside the supported expression grammar.
Keep operators, identifiers and literal values exact; do not normalize away
observable guards, effects or error strings. Release original checked program
closures before the modified compile and keep any AST reuse invocation scoped.
See the [whole formula draft](forward-return-expression-draft.md).

For project synchronization, derive direction from complete current sources
and immutable Git HEAD blobs within one invocation. Capture the whole native
source universe and Cargo/workspace inputs, including committed native files
that were deleted. Reject concurrent language edits, implicit source deletion
and explicit authority that would overwrite another edited language. Use
physical `js/src` and `ts/src` outputs and retain truthful original partial and
refusal metadata. Match registered per-language runtime implementation and
declaration closures exactly, retain licenses/notices and refuse modified
runtime files. Relocate only actual native module-specifier spans, preserve
literal delimiters and complete inverse equations, and reuse fresh guarded
all-or-nothing installation. Do not introduce a persistent source/owner/verdict
cache or treat successful packaging as production parity. See the
[project source draft](forward-project-unit-draft.md).

When composing enclosing producer outputs with tool-attribute resolution, use
the exact genuine input/output context and complete original module set, source
views, compilation profile, external tables and item carriers before inspecting
candidates. Keep legacy APIs distinct, retain ancestor and competing type-prefix
checks, and never use a non-trait import census to prove tool-prefix absence.
A consumer connection cannot supply a missing original input-owner proof. See
the [enclosing tool draft](enclosing-tool-context-draft.md).

Inverse call rules must resolve actual compiler-issued source and target
associations, retain complete selected callee bytes and recompile the entire
modified project. A target name, observed arity or syntactic native path is
candidate data only; the original semantic checker still owns visibility,
borrowing, effects and types. Reproduce the complete requested target, including
conditional statement shape and all arithmetic guards. Keep callee observations
invocation scoped and release original checked declaration closures before the
modified compilation.

Scalar local-body inverse rules must preserve declaration names, order, counts,
type annotations and all target bytes outside selected actual initializer and
return spans. Rejoin the complete original checked scalar let chain with native
assignment/terminator intervals; preserve typed prefixes and surrounding trivia.
Only parameters and earlier locals are available inside an initializer. Retain
self/future-name and incomplete-prefix refusals, complete native/paired source
inverses, original resource bounds and fresh whole-project target reproduction.
Keep the old final-return API separate. See the
[scalar body draft](scalar-body-inverse-draft.md).

Whole scalar control-body inverse rules must preserve actual function headers,
complete body membership and original parameter guards. Keep lexical locals
immutable and scoped, require complete terminal values in every admitted branch,
and reject unsupported fallthrough/effect/loop constructs. Recompile the entire
modified native project, reproduce complete changed target bodies and retain
unchanged bodies byte-for-byte. A syntactic body proposal cannot waive native
types, ownership, source provenance or any CI requirement. See the
[control body draft](control-body-inverse-draft.md).

Scalar imperative inverse rules must track lexical mutability and current loop
boundaries, preserve exact original parameter guards, require value-returning
function paths and refuse unknown or unreachable statements. Derive native
integer hints only from actual original checked scalar locals; a name, bigint
shape or caller-provided map supplies no type or owner authority. Keep exact
native TypeScript type syntax and complete native/target reproduction. Normalize
an empty else only when its admitted block contains no statement or effect. See
the [imperative body draft](imperative-body-inverse-draft.md).

Range inverse rules must observe complete actual emitter generator sources and
retain every bound, inclusive flag, reverse retreat callback and error string in
whole target reproduction. Use original checked scalar binding observations
only to propose native fixed domains and literal suffixes; a helper name or
bare bigint supplies no range, step or ownership authority. Let the original
native checker reissue standard range/reverse contracts. Preserve endpoint
order, once-only evaluation, empty/min/max paths and current loop exits. See the
[range body draft](range-body-inverse-draft.md).

Floating inverse rules require actual source-qualified native f64 observations,
original checked source and full native/target reproduction. Keep earlier
signature formats unchanged, reuse the bounded exact binary64 decoder, retain
signed zero and IEEE classes, and preserve distinct checked integer guards.
Compare complete TypeScript types exactly; no public shape or numeric spelling
supplies type or owner permission. Materialize standard runtime pairs through
the original complete registered closure validator under unchanged bounds. See
the [floating body draft](floating-body-inverse-draft.md).

Standard runtime inverse calls require the actual original qualified import and
registry path, complete lexical shadow checks and fresh native frontend owner,
type and refinement checks. Keep public import observations separate from
semantic permission. Reuse native-selected function extraction and shared source
mechanics when new rules would otherwise grow full copies; retain complete
originals, exact native selections, both CST equations and final binding closure.
See the [standard floating draft](standard-floating-inverse-draft.md).

Numeric inverse proposals must join the original named factory import, immutable
native-selected instantiation, exact registered operation/primitive encoding and
whole-function lexical bindings. Keep `usize`/`isize` distinct from equal-width
fixed types. Inherent-call proposals still need fresh complete Rust-source
checking and exact paired target reproduction. The registry/AST observations are
data only. See the [numeric inverse draft](standard-numeric-inverse-draft.md).
All new cases remain unrun until the entire bulk source draft is present.

Text predicate method substitutions must preserve complete original operands,
compiler-generated temporaries and surrounding source. Join actual checked Rust
operation spans to native target method tokens, then freshly reproduce the full
modified target. A JavaScript property spelling grants no receiver/trait proof.
Retain full emitter/table source and invocation-local indexing; see the
[text predicate inverse draft](text-predicate-inverse-draft.md).
All new source and oracle cases remain unrun during the complete drafting phase.

Compose eligible source substitutions in complete rule-family batches. The
`composite-bodies` inverse mode stages existing literal, text-method and numeric
control rules, rejoins each complete current source and retains adjacent full
inverses. Native AST scheduling is data only; require a new full final compiler
and semantic-meta check, unchanged census and whole target reproduction. Keep
three deterministic layer batches, existing deadlines and a 192 MiB retained raw
source budget. See the [composition draft](composite-inverse-draft.md).
The implementation and all new cases remain unrun during bulk source drafting.

Opaque cancellation callers use the separate synchronous profile and actual
native/runtime/declaration source joins. Track owned local moves across branches;
shared synchronous operands require the current original lexical handle. Require
operation-derived public borrow types. Owned captures, stored shared aliases,
mutable handles, futures and exclusive channel/HTTP resources need their own
rules. Keep the original private issuers and codecs separate; see the
[cancellation caller draft](owned-cancellation-draft.md). All new
caller, strict TS and Rust oracle source remains unrun during bulk drafting.

Canonical resource Rust inverses must restore JS proposals through the same
private source profile, reissue all move/borrow checks after semantic meta
serialization/reparse and reproduce the complete original Rust syntax. Preserve
support code and native library exclusions. Catalog paths and erased borrow
syntax are candidate data only; see the
[cancellation inverse draft](owned-cancellation-inverse-draft.md).
All source and receiving cases remain unrun during bulk drafting.

The `owned-cancellation` source-unit profile keeps physical JS/TS/Rust paths,
complete current native/Cargo mappings and matching opaque runtimes. Treat paired
borrow signatures as proposals, recheck complete callers and use the original
fresh recompute/atomic installation and conflict rules. Runtime-only installation
never qualifies a caller. See the
[cancellation unit draft](owned-cancellation-unit-draft.md).
All new integration and receiving source remains unrun during bulk drafting.

Tool-first derive input composition must recompute genuine original tool proofs
from the complete current source/profile/external tables. Caller-provided tool
certificates cannot select this stage. Consume actual proofs in both ancestor
and item attribute closures and keep unknown producers, globs and same-scope
circular inputs refused. See the
[tool-first derive draft](tool-first-derive-draft.md). All new
proof/receiving regression source remains unrun during bulk drafting.


Local declarative source expansion uses actual prior textual definitions and
private same-engine input/output forwarding. Preserve original definitions,
refused invocations and full CST inverses. Plain rendering must refuse captured
and literal identifier collisions, generated definitions/attributes, unknown
surviving nested macros and unproved dollar-crate ownership. Original sources
and the compiler expanded-source domain stay distinct; no application coverage
or owner authority follows from preprocessing. See the
[local declarative draft](local-declarative-source-draft.md). All new source
and independent oracle cases remain unrun during bulk drafting.

Cold control callers require actual native/runtime/declaration imports and
operation-derived resource parameter types. Store no unawaited future, preserve
the real cold constructor and enforce linear owned aliases and exclusive
receiver reborrows. Dispose local receivers on every nonmoving exit, including
propagated errors. Deadline callbacks require their actual child cancellation
and a single cancellable tail; no post-await side effect is admitted. Keep native
Rust grammar/execution flags false until gated CI supplies evidence. See the
[async control caller draft](async-control-callers-draft.md). All new source and
independent regression/oracle cases remain unrun during bulk drafting.

Canonical Rust resource inverses may erase syntax only to propose JS. Reissue
all real source-bound control checks, round-trip checked semantic meta and
reproduce the complete authoritative Rust syntax before returning. Preserve
actual tuple moves, receiver cleanup, mutable reborrows and deadline captures.
Reader observations and temporary substitution supply no semantic permission.
See the [async inverse draft](async-control-inverse-draft.md). General native
qualification and all new receiving cases remain unrun during bulk drafting.

The async control source-unit profile must preserve complete native/Cargo input
mappings, mirrored runtime trees and original Git conflict/atomic installation
rules. Paired input annotations are proposals from fresh complete TS checking;
recheck the entire edited JS body before emission. Runtime-only initialization
does not qualify application translation. See the
[physical async unit draft](async-control-unit-draft.md). All independent source
and receiving cases remain unrun during bulk drafting.

Composed source-copy families must forward complete descendant histories even
through intermediate plans that do not edit that path. Keep direct file lists
and installation semantics intact, join every original/final string and CST
inverse, and freshly compare physical sources and retained originals at ancestor
return. Descendant metadata remains DATA and supplies no semantic permission.
See the [transitive history draft](transitive-source-history-draft.md). Whole-chain
receiving and all new source regressions remain unrun during bulk drafting.

Public async u64 inputs require actual dominating original entry guards. Written
bigint/query types and copied metadata grant no range proof. Keep guard source,
spans, polling position, maximum bounds and operation-specific limits separate;
recheck the complete original body after checked meta round trips. Canonical
Rust inverses must propose real JS guards before fresh checking. See the
[guarded numeric draft](async-control-u64-draft.md). All new source and native
oracle cases remain unrun during bulk drafting.

HTTP deadline resource callers must not return exclusive loans before actual JS
abort/finally cleanup finishes. Fixed native/JS operations may wait for their
known HTTP child and close a late owned stream or an interrupted borrowed read.
Keep general arbitrary-callback deadline behavior intact. Unstarted timeout or
preexisting cancellation must not consume the original stream. Retain full
root/library CST histories, fresh runtime closure and independent native cases;
see the [closed HTTP deadline draft](http-deadline-core-draft.md). All new source
and receiving qualification remains unrun during bulk drafting.

HTTP callers must keep native string errors separate from cancellation errors,
retain nested Results and release local clients/streams on every original exit.
Bind imports to their complete actual module sources; freshly recheck entire
JS/TS bodies after semantic meta serialization. Canonical native proposals must
reproduce the entire authoritative Rust source through the independent caller
checker. Unknown borrowed roots and generic HTTP deadline callbacks remain
refused until complete rules exist. See the
[resource caller draft](http-resource-callers-draft.md). All new source and
receiving cases remain unrun during bulk drafting.

An Option tag guard must inspect the same original container, check its complete
absent exit and release every live owned resource on that exit. Success payloads
move once; fallback and success return domains and borrowed roots must join.
Use native `?` only for actual unchanged same-Option propagation. Every other
fallback needs its complete explicit match and fresh inverse reproduction.
See the [Option guard draft](http-resource-option-guards-draft.md); all new
source/native qualification remains unrun during bulk drafting.

Local resource helper interfaces must come from whole freshly checked actual
callee bodies, preserve real import/local binding identities and retain cold
await, move, cleanup and returned-root rules at every call. Keep descriptors
inside one source analysis and rebuild them after meta serialization. Recursive,
input-release and multiple-root cases need complete separate joins; native
signature DATA cannot waive them. See the
[local helper draft](http-resource-local-functions-draft.md); all new receiving
and native qualification remains unrun during bulk drafting.

Numeric resource callers must bind complete original fixed-width/Option native
and runtime sources and retain distinct wrapping, saturation and checked error
behavior. Strict comparisons require matching actual primitive domains; do not
infer unsigned ranges from bigint annotations or allow string/Number coercion.
Keep original public entry guards, recursive body checks and whole inverse
reproduction. See the [fixed-width caller draft](http-resource-numeric-draft.md);
all new source and native qualification remains unrun during bulk drafting.

Scalar loops must preserve every incoming ownership/resource/loan and primitive
type fact at every loopback, clean iteration-local resources and distinguish
fallthrough from whole function exits. Only real mutable Boolean/u64 locals may
receive checked same-domain assignments. Keep lexical mutability scopes and
complete native reader/projection reproduction; abrupt and exception paths need
separate complete joins. See the
[scalar loop draft](http-resource-scalar-loops-draft.md); all new source and
native qualification remains unrun during bulk drafting.

Owned String mutation must retain a freshly checked owned domain, refuse every
live backing loan and reinitialize moved slots only after complete RHS checking.
Borrowed inputs/literals need an explicit matching ownership operation. Preserve
loopback initialization/type state and complete native inverse reproduction;
do not promote these rules to general lifetime or unwind authority. See the
[owned text state draft](http-resource-owned-text-state-draft.md); all new source
and native qualification remains unrun during bulk drafting.

Returned helper loans must retain every possible actual argument root through
branches and nested Result/Option values. Protect every backing local owner
from moves and refuse any borrowed return that may outlive one. Static literal
roots need no local owner; source choices cannot narrow a root set without a
separate complete proof. See the
[returned-root set draft](http-resource-root-sets-draft.md); all new source and
native qualification remains unrun during bulk drafting.

Recursive helper types must come from actual written signatures on complete
ordinary source declarations. Check every original body in the group and
require its actual return/ownership domain before emitting anything. Restricted
synchronous scalar typing does not supply Rust namespace/producer ownership,
termination, async recursion or resource effects. Preserve real annotation
spans and fresh full native reproduction. See the
[restricted recursion draft](http-resource-recursion-draft.md); all new source
and native qualification remains unrun during bulk drafting.

Helper resource release summaries must join actual mutable-input state at every
original exit. Mark a caller argument disposed only when all checked exits
release that same exclusive input; partial releases need outcome-sensitive
state joins. Keep immediate-await boundaries, alias refusals and whole fresh
callee/caller rechecking. See the
[helper release draft](http-resource-helper-releases-draft.md); all new source
and native qualification remains unrun during bulk drafting.

HTTP physical source units must capture complete native/Cargo and mirrored
runtime inputs, retain the original Git conflict/atomic installation rules and
freshly check all three authority directions. Paired annotations propose domains
from a whole checked TS source; they never supply ownership or range authority.
Runtime initialization alone cannot certify application translation. See the
[physical HTTP unit draft](http-resource-unit-draft.md); all new receiving
qualification remains unrun during bulk drafting.

Borrowed HTTP text results must retain their actual public immutable JSON input
roots through complete checked flow/meta and every returned branch. Local owned

See the [borrowed HTTP text draft](http-resource-borrowed-text-draft.md); all new
source/native cases remain unrun during bulk drafting.

Mixed HTTP/control error callers require explicit matching native/JS by-value

original provider errors and owned payloads. Whole source checking must move

runtime closure histories with the original bounds. See the
[deadline Result draft](http-deadline-results-draft.md); all new receiving and
native qualification remains unrun during bulk drafting.

Compose common operation families through their actual fully checked native and
runtime sources, retaining callbacks/numeric domains with their original checker
when unsupported. Option/Result containers move once. Local borrowed string
views must retain their original owner, cannot escape and must prevent that
owner from moving while the view remains live. See the
[common resource draft](http-resource-common-draft.md); all new source and
receiving cases remain unrun during bulk drafting.
