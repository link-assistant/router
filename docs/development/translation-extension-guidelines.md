# Translation extension contribution contracts

These requirements supplement [CONTRIBUTING.md](../../CONTRIBUTING.md).
The active source-only phase and all original gates remain mandatory.

Bulk source packet installation must replay every original proposer and compare
all complete physical packets, sources, graphs, CST and inverses before building
its plan, then repeat that complete review when applying it. Preserve original
Git/source guards, byte/worker bounds, atomic file replacements, rollback and
external edits. Export the entire CLI/source dependency closure and qualify an
offline receiving repository. Installation receipts retain runtime parity false
and executable coverage gain null until independent whole application evidence
exists. See the [unrun adoption draft](owned-packet-adoption-draft.md). During the
active bulk draft phase, author the implementation and cases without running the
planner, installer, CLI or validation.

Generic derived outer-attribute source facts must retain the complete generated
attribute definition/use suffix, actual method implementation owners, inherited
predicate defaults, original ungated registration expansions and complete
collector body. A registry-name list or an `Impl` discriminant alone cannot
discharge that obligation. Join a single per-invocation shared source proof to
every actual registered common callback. Keep caller ownership, nested/exported
macro effects and full producer closure separate and retain their false flags
until their independent proofs exist. See the
[unrun source draft](builtin-derived-outer-attributes-draft.md).

Resource loop analysis must keep nearest-loop boundaries separate from function
return summaries. Backedges, breaks and continues preserve incoming ownership
and type state and clean iteration locals; actual returns clean all locals and
join their complete domains, roots and exclusive-input states at the enclosing
function. Result and Option propagation inside a loop returns from the function.
Never use a loop boundary as helper-release evidence, append an outer source
continuation into a continuing inner lexical scope, or infer unconditional moves
and releases from a short-circuited Boolean operand. Preserve original complete
deadlines and the independent unrun
[loop-exit cases](http-resource-abrupt-loops-draft.md).

Continuing branches retain real lexical scopes. Capture only their actual
incoming bindings, clean new local resources before fallthrough, join every
continuing ownership/disposal/guard/domain/root state, and discard scope-local
names before analyzing following outer source. Scope fallthrough is neither a
function return nor a loop boundary. Assignment and exclusive-use discovery must
respect child declarations when a later outer binding reuses the same spelling.
Keep exact substitution spans inside their native owner, including complete
function replacements; trailing trivia cannot widen that owner. See the
[unrun scoped continuation draft](http-resource-scoped-branches-draft.md).

Compose existing matching JSON storage implementations through their real
current native/root/facade/runtime sources and closed domains. Mutable JSON
state requires a genuinely owned constructor, copy or carrier payload; a shared
input annotation cannot transfer ownership. Preserve whole moves, reinitializing
assignments, loop/branch state joins, Some(Null) versus None, and the existing
bounded successful-resource contract. List and callback shapes need independent
rules. See the [unrun JSON resource draft](http-resource-json-state-draft.md).

Borrowed JSON projections and aliases retain their actual original input or
local owned roots, including every possible helper-result root. Local JSON-backed
text/JSON views may be copied into owned results, but cannot escape their owners.
Moves and replacements must check every live view; completed lexical scopes
remove only their own views. Native returned lifetimes follow the checked root
set through the separate structural shared-reference query. Preserve the old
text-only query and refuse unproved temporary loans. See the
[unrun JSON view draft](http-resource-json-views-draft.md).

Owned JSON lists and shared slices have separate ABI domains. Require an actual
imported list operation for public slice types, original owning operations for
owned locals, and complete moves/roots when lists cross calls, scopes or loops.
Keep native Vec fully qualified and slice lifetimes tied to the actual checked
input roots. Paired-source-unit type proposals must re-enter the complete
source checker. Array shapes, proxies, copied metadata and unproved iteration
cannot supply ownership or a list domain. See the
[unrun JSON list draft](http-resource-json-lists-draft.md).

Collection callback domains come from the actual selected matching library.
Require a complete checked local helper or recheck the original inline arrow
body in its own actual parameter scope. Add forward callback references to the
dependency graph; no outer binding may enter a capture-free callback. Preserve
every return domain, owning accumulator move, element loan, Some(Null), original
order and short-circuit behavior. Keep callback descriptors immutable DATA and
reissue actual source semantics after the meta round trip. Native closure
emission must respect binding references, avoid unused-name collisions and
reserve standard Result/Option constructor bindings. See the
[unrun callback draft](http-resource-callbacks-draft.md).

Explicit arrow annotations remain original-source obligations. Resolve their
operation queries, nested callback parameters and list elements against actual
imported APIs, and compare every written type with the native contextual domain
before checking the complete callback body. Keep owning accumulators distinct
from shared elements and Future returns distinct from their inner values. Erase
only original native-selected annotation spans in the JavaScript target, retain
the complete TypeScript target and both CST/source inverses, and keep annotation
sinks outside checked semantic meta. See the
[unrun typed callback draft](http-resource-typed-callbacks-draft.md).

Ordinary written returns constrain complete inferred bodies; they never create
ownership. Preserve actual borrowed/owned strings and exact owning JSON/list
operation domains. When original TypeScript types are erased, the JavaScript
target must retain actual reusable input annotations. Use canonical native type
printing with comments removed, correct mismatched existing type tags in the JS
target, and combine all necessary input/return tags into one new block. Keep
complete original TypeScript and source inverses, do not duplicate blocks on an
unchanged round trip, and preserve restricted recursive obligations. See the
[unrun function return/source doc draft](http-resource-function-returns-draft.md).

### Source synchronization exports during issue #759

Keep every public synchronization CLI in the shared
`tools/translation/translator-entrypoints.mjs` list. Preserve all original entries
in order and retain the complete compiler/runtime/declaration/profile/license
closure through the committed-source exporter. Source preparation must compare
complete pinned original vectors against their exact retained prefix, rather
than assuming there will always be only one added command. Keep original
resource limits and all eight full JavaScript gate stages unchanged.

The source synchronization facade forwards to fresh original issuers. Never
accept a saved proposal, public semantic flag or source hash as admission. For
bulk inverse edits, parse complete JS/TS, retain serialized/reparsed CST and
whole Rust/JS/TS inverses, resolve actual checked source origins, refuse an
ambiguous or incomplete batch and recompile the whole modified project before
guarded installation. Work within one invocation instead of adding persistent
source or verdict caches. The current literal families do not establish broad
expression or whole Router support.

Independent exported receiving cases, complete original histories and behavioral
regressions must be drafted with implementation. Under the user's active bulk
draft instruction, execute none until every requirement has its full source
draft. No local tests, compilation or Rust tools are allowed. The user now
authorizes periodic source checkpoint pushes even if CI starts, while CI
feedback inspection and repairs remain deferred until drafting is complete;
see [the publication policy](bulk-draft-publication.md).
Record exported source, receiving evidence, whole-gate evidence and production
parity separately. See the [export draft](synchronization-export-draft.md).

For forward-derived literal synchronization, use the original compiler's actual
emitted function mapping together with its fresh checked source association.
Repeated values require complete source/target multiplicity and full modified
project reproduction. Preserve each fixed integer's actual native name, width
and signedness. Reject unmatched code edits, out-of-domain values and incomplete
batches; do not treat a matching source order or target name as semantic proof.
See the [scalar inverse draft](forward-literal-synchronization-draft.md).

Read [the additional source contracts](translation-extension-source-contracts-1.md)
as part of these guidelines. They retain every detailed rule, source-origin,
ownership, export and verification requirement previously included here.

Source expression invocations require their actual native AST/file, complete
fresh body checks, read-only captures and child-return-safe native closures.
Keep explicit checked text conversion witnesses and every unsupported capture/
output refusal. See [the unrun expression block draft](source-expression-blocks-draft.md).

All-width unit counters must preserve actual strict dominating bounds, immutable
matching limits, full unassigned-body census and the current typed native update.
Keep original loopback resource state and nearest continue/break order. See
[the unrun counter draft](resource-width-loops-source-draft.md).

Source text concatenation requires two actual text operands; retain operand order,
owner loans and exact checked primitive conversions. General coercion, format
templates and metadata cannot supply admission. See [the unrun concatenation draft](source-text-concat-draft.md).

Borrowed text Into adoption needs an explicit actual owning destination context;
preserve ambiguous targets and owning transfers until separately implemented.
Written String spelling proves no trait/type owner. See [the unrun Into draft](contextual-text-into-source-draft.md).

Whole emitted-module inverse rules must preserve the original adjacent type/range
parameter guards byte for byte, authenticate the actual helper against complete
current source and reproduce the entire requested target after fresh checking.
A prefix observation grants no type or helper authority; see [the unrun fixed ingress draft](forward-fixed-guard-source-draft.md).

Owned formatting inverse proposals must recheck actual original ownership and
Display, keep guards/helper/export sources exact and reproduce the whole target.
Avoid formatter temporaries only for stable checked Copy/borrowed operands when
all explicit argument sources are stable; retain computed/owned argument order.
See [the unrun whole-module format draft](forward-owned-format-source-draft.md).

Mixed owned formatting synchronization uses separately checked whole-source
layers and adjacent inverses; preserve the original complete input/census,
retained-source limits and final fresh whole-target comparison. See [the unrun mixed draft](owned-composite-source-draft.md).

Callback source wrappers may retain an explicit expected owning text destination
only as temporary DATA. Keep complete block bodies, avoid inheriting an outer
target into nested callbacks, and recheck the entire original caller independently.
See [the unrun callback target draft](callback-text-target-source-draft.md).

Expected text source context may propagate only through complete explicit String
expression roots and their exact branch tails. It grants no Into/type/ownership
permission; preserve missing/ambiguous destination refusals and whole caller checks.
See [the unrun branch target draft](text-branch-target-source-draft.md).

Text constructor source candidates must retain false original trait/drop/owner
flags and recheck actual complete source independently. Preserve owning transfer
and wrong-owner refusals; reuse chronological local events and existing core ABI.
See [the unrun constructor draft](text-constructor-source-draft.md).

Mutable String builder proposals require a complete receiver-use census and
whole-function refusal on unsupported aliases/mutations/suffixes. Preserve original
order and false owner/drop flags; no allocator/capacity/runtime parity is implied.
See [the unrun builder draft](text-builder-source-draft.md).

Character builder substitutions must use the original scalar decoder and retain
both literal normalization and whole statement inverses. Byte/variable/wrong-
arity refusals remain; see [the unrun character builder draft](text-builder-character-source-draft.md).
