# One complete native source operation: source draft

All implementation and receiving cases remain unrun. Source review identified
repeated identical syntax parsing across original source-copy families. A
private operation scope now surrounds each of the 146 actual preparers before
their eager later-plan arguments are evaluated. Reuse is limited to complete
identical path/source strings parsed with the original JS grammar, parent links,
target and genuinely current installed compiler. Native syntax trees never
leave the module or enter public plans.

Each outer synchronous operation releases its private trees on return or error.
Changed native compiler operations disqualify and clear reuse for that operation.
The private retained-source budget is 4 MiB and 64 trees; reaching either bound
evicts syntax and uses original parsing. Every original source/line limit,
grammar check, binding program, diagnostic, library read, physical/original
source join, archive pin, workload and deadline remains. Candidate semantic
ASTs and compiler programs stay fresh. No owner, binding, semantic verdict or
source result is cached, and nothing persists into the next outer invocation.
Default-library AST reuse is not implemented by this family. No speed or memory
qualification is claimed before full receiving checks.

Three complete-original source profiles preserve the producer's unchanged
64-direct-file limit. Each native-selected source substitution retains ordered
language and repository phases, full serialized/reparsed CST and complete
inverses. Existing direct file membership remains intact. Native member-call
selection identifies actual original CLI comparison nodes; it grants no binding
or semantic authority. CLI status now includes complete current descendants.

The separate typed source producer retains its original typed grammar and
binding checker while copying the complete original descendant forwarding and
fresh source guards. Repeated byte-identical inert histories can share one DATA
row. A suffix reaching the same final source can join only at an actual retained
source-equation boundary; its full parallel history and every original snapshot
remain retained and freshly checked. Unknown or conflicting histories refuse.
Deep equality never invokes nested getters, proxies or toJSON hooks. These DATA
joins cannot supply namespace, owner, source or executable permission.

All older native-copy leaf preparers join the common source history. Subsequent
source families must extend `prepare-native-source-operation-part-3.mjs`, use a
new complete original snapshot and preserve the existing operation wrapper.
Their new leaf must not import part one: that would create a preparation cycle.
Do not rerun the historical source author over later edits. Preserve all older
producer IDs, direct rows and independent complete receiving workloads.

Independent unrun source covers nested operation cleanup, physical/original
freshness, grammar changes, async/thenable/proxy refusal, complete overlapping
histories, nested original guards, typed descendants, CLI status and all three
full source groups. Original parser/binding/timing obligations, namespace and
producer bootstrap, application coverage, production parity and every unfinished
requirement remain open.
