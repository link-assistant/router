# Scoped output binding source draft

All implementation, receiving cases and native oracle are SOURCE ONLY and UNRUN.
No parser, translator, preparer, interpreter, compiler, tests or CI ran. There is
no production output execution, original macro equivalence or coverage claim.

The actual root `extern crate self as link_assistant_router;` is already handled
by both genuine module binding resolvers and owned-adoption self-alias selectors.
The 47 Rust source files containing that path and 64 containing output macro
calls were read-only source prioritization counts on 2026-11-01, not executable
coverage. No new alias, public name permission or root API widening is added.

The new `proposeScopedOutputBindingSources` retains the unchanged complete
module-macro-use source proposal, including every original refusal. Fresh
private engines compile actual original declarations from genuine module views.
Body candidates join exact original raw invocation spans in actual function
bodies. A bounded traversal follows actual tracked edges and original declaration
order; child-local shadows stay inside children and word-only macro_use imports
the final child scope. Selection exists only inside one synchronous operation.
No selection token, callback, owner flag or reusable authority escapes.

This deliberately restricted body source domain also refuses composition with
predecessor root edits until their generated namespace is independently closed.
It rejects imports, exports, unknown
attributes/configuration/producers, qualified calls, function-local definitions,
items/imports and all unknown nested bang calls. Renderer hygiene checks remain;
introduced body identifiers additionally require a separate proof and are
refused (boolean literals are supported). Captured identifiers retain actual
input token-tree custody. Any unsupported body invocation discards all new body
edits, preserving its refusal and every predecessor result. There is no partial
new body expansion through an unknown producer. Root expansion from the existing
proposal remains separately visible and unchanged.

Language rules perform original graph/CST capture, raw invocation selection,
actual engine expansion, whole physical Rust source equations and independent
expanded-project checking. Repository rules retain original and expanded domains
separately, paired JS/TS CST equations and complete results. Complete returned DATA
has occurrence-based UTF16/UTF8/cell/depth bounds, including repeated aliases,
predecessor data, full CST/equations, programs and trace. Checked facades remain
exact outputs of the original compiler. Shared source failure and complete closing
fences recheck every captured original on every exit and poison enclosing source
operations even when a nested failure is caught and original text restored.

`translateScopedOutputBindingProject` uses the unchanged flat enclosing project
checker and checked meta serialization/reparse. Its physical inverse restores the
complete original macro-containing files; this is not semantic reverse emission.
Without an explicit target edit the semantic reverse lane is unsupported.
`synchronizeScopedOutputBindingExpandedProject` accepts one real edited JS or TS
source and composes the existing expression inverse over the complete expanded
universe. That original inverse joins real checked function/literal origins,
edits native source, reparses/rechecks the entire native project, compares the
complete executable/refusal census, reproduces edited target tokens and retains
native plus paired target CST inverses. This is expanded-domain synchronization;
it does not map edited literals back to original macro arguments/definitions,
and does not assert full native rustc grammar qualification. The receiving source
independently checks both edited languages against value8 and their full native
source inverse; the original native oracle checks original values7/9/11 only.

The production source helper retains complete immutable current lib.rs,
operation_output.rs, auth_remote.rs and auth_import.rs owners with bounded physical
identity/byte closing and full Rust CST inverses. These four owners are DATA and
not a complete production module graph. Their actual println/eprintln/print
transcribers still contain unsupported nested format_args, Arguments lifetimes
and scoped write transport. They acquire no runtime implementation or original
source equivalence. Whole actual production graph/configuration/dependency closure,
macro hygiene/native ambiguity resolution and transport compatibility remain open.

All files are additive under this prefix; no earlier source snapshot, root,
predecessor or public export hub changed. Coordinator integration must explicitly
export the three APIs and register the independent receiving/oracle source if
wanted. Standard compiler export already includes the author modules and profile
originals; no exporter exception is proposed. Older histories remain immutable.
