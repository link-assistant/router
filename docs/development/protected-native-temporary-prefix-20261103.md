# Native temporary-directory admission draft

The actual Node test runner's implicit evidence-directory creation now calls
the additive general lease `makeTemporaryDirectory(prefix)`. Its original
output base, prefix, native randomness, recursive base-directory preparation,
explicit-directory branch, payloads and deadlines remain. There is no supplied
creation callback or public fresh-directory witness. The native builtin is
captured and called only after source admission.

Every retained/current async and synchronous source root contributes its own
original policy names, actual symlink/negative endpoint observations, existing
ancestor identities and native parent inode. The fixed executing adapter root
must also belong to the genuine route. A missing protected name or ancestor
that the native generated basename could create refuses before the call.
A disjoint missing peer does not block an otherwise healthy namespace.
Existing protected directories block mutations inside their namespaces.

The matcher conservatively allows case and trailing-dot/space aliases, and
refuses ambiguous Unicode, short-name or device-stream names when they share
the generated parent. Its native stem accounts for trailing X replacement;
it assumes at least six appended characters rather than exactly six, following
[Node's native naming contract](https://nodejs.org/api/fs.html#fsmkdtempprefix-options-callback).
It does not replace the native exclusive creation operation with a random loop.
The new API accepts bounded normalized absolute primitive prefixes. Existing
native/direct/descriptor/entry APIs retain their previous domains.

The complete observer cohort has a separate16MiB retained metadata budget,
bounded paths/nodes/steps/symlink hops, and invocation-local observations.
Every acquired observer closes even after a sibling veto. All original policy
roots are independently checked afterward. Native creation failures remain
ordinary failures when source observations are healthy. Source veto causes
are sticky and separate from an earlier ordinary primary, including falsy or
frozen primary values. Created entries are owned immediately and checked by
actual directory identity. A later veto retains the path in caller diagnostic
DATA for explicit recovery; no source-veto bypass or replacement-entry deletion
is attempted. This is an observation fence, not atomic namespace isolation
against arbitrary concurrent adversarial filesystem changes.
