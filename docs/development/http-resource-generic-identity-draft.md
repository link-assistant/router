# Original executable generic identity draft

One unconstrained generic function now has a whole-source rule: its sole input
and return name the same actual lexical type slot, and the complete actual body
returns that input exactly once with no other statement. This is a closed
unchanged-value theorem for any type, including a move-only resource; it does not
admit arbitrary generic bodies, effects, drops, constraints or recursive calls.
The source checker independently validates each actual JS JSDoc or TS signature.

At a concrete call, the existing whole argument checker still establishes the
actual domain, move state and every borrowed root. The identity returns exactly
that checked value. Original owning arguments move once, shared references keep
their actual roots, cleanup remains required, and contextual bounded integer
literals preserve their real domain. Genuine equal bool/u64/i64 callback contracts
can specialize the same checked identity. Explicit generic call arguments and
wider higher-order instantiation remain separate refused syntax.

The native reader retains a real single generic parameter and requires the
complete same unchanged-input body. Its proposed JS template is freshly checked
through serialized/reparsed semantic meta and exact full native reproduction.
TS/JS annotation substitutions retain actual template docs and source inverses.
Physical source-unit input proposals can recover missing identity docs from the
current fully checked TS pair; the resulting edited JS body is still checked
again by the original transaction, never admitted by its old signature alone.

Eight complete prior implementations are retained with separate ordered language
and repository substitutions and full CST/source inverses. Independent JS,
strict TS, native inverse, scalar/owned/borrowed/callback, forged-meta, refusal
and Rust oracle sources are drafted and unrun. No compiler diagnostics, tests,
experiments, preparers, translation, generation, local Rust tools or CI ran.
General executable generics, methods/classes/interfaces, explicit instantiation,
namespace/bootstrap, production parity and every unfinished requirement remain open.
