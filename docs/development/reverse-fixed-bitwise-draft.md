# Explicit fixed-width bitwise reverse source draft

Every new implementation and independent case is UNRUN. The existing explicit
primitive context now retains ten imported native scalar ABI aliases for signed
and unsigned 8/16/32/64/128-bit values. The physical shared declaration exports
their BigInt representation; each alias has its Rust input-range precondition.
Only a genuine type-only import from the complete current declaration can select
a native domain. Plain bigint/number annotations, local lookalike aliases and
runtime calls to type aliases grant no such permission.

Helper calls require a literal registered width/sign, a fixed operator and
matching checked operand domains. Canonical decimal BigInt literals are accepted
only inside that qualified helper boundary and checked lexically against exact
domain bounds, including signed minima and unsigned maxima. Literal parsing uses
bounded ASCII text and comparison without evaluating a source expression or
coercion hook. Existing unsigned-64 internal ABI values retain their old mapping;
no Rust pointer-width authority is introduced. Other literal bases/formats stay
unselected for a separate explicit source-normalization rule.

All seven source/checker/emitter paths retain original import symbols, runtime/
declaration/Cargo inputs, paired source checks, private reissuance and source/meta
round trips. Rust emits absolute primitive types for this explicit profile and
binds operands in order; TypeScript imports actual scalar aliases and keeps the
same helper metadata. Both interpreter paths use the exact current domain.
Default profiles keep their existing type/output behavior. The shared physical
declaration automatically reaches both forward asset factories.

Eighteen whole compiler/library equations retain complete original modules,
native owners, language/repository sequences, CST/meta and inverses. Independent
unrun cases cover all ten domains in seven receiving contexts, strict TS,
interpreters, decimal extrema, aliases, metadata, range and coercion refusals.
The separate native primitive Rust oracle remains required in gated CI.

No runtime, compiler, parser, translator, preparer, test, experiment, generation,
Rust tool or CI-triggering push ran. Automatic native type projection in complete
forward outputs, wider source forms, actual whole production callers, native
namespace closure, source banks/exports/freshness, synchronization, parity and
all complete delivery gates remain unfinished.
