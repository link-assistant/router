# Genuine TypeScript library owners for borrowed map inputs

This source draft connects `ReadonlyMap<string,string>` input annotations to
both original private reverse source readers. It preserves the existing noLib
Program domain: the receiving input must explicitly carry the complete actual
standard-library declaration set. No fake interface, injected default library,
public shape tag or name match supplies a type owner. Other input domains keep
their original checks and limits.

The source API first requires the actual TypeScript5.9.3 compiler selected at
the original private loader's genuine fresh birth, including its extended
source-scope export association. Its actual private origin getter identifies
the complete original installed SDK cohort. Declaration files are read using
real precise no-follow descriptors, joined to original physical identities and
strict UTF8, and transported through serialized/reparsed TypeScript CST. The
operation rechecks the native association, original full cohort and every
retained declaration byte independently at closing. Ordinary falsy primaries
are retained. All resources and observations are invocation-local; no source,
digest, symbol or owner verdict cache is created between calls.

The original private traversal still creates the actual native source files,
Program and checker. The new selector requires every carried library source
to match the current genuine SDK bytes and requires every declaration of the
actual resolved ReadonlyMap symbol to be an original interface in that same
native source-file set. A merged foreign interface, local alias/shadow, edited
library or missing closure refuses. Both generic arguments must be the actual
written string keyword. Afterwards the separate receiving Rust/Cargo/module
and standard BTreeMap native ABI check remains required. A returned domain tag
alone never registers an original checked function.

The additive library DATA budget is8MiB within the existing512-file SDK origin
domain. Existing reverse input4096-file/16MiB limits stay unchanged. Inputs that
do not fit still refuse. Actual SDK export, invocation flags, native sysroot,
string/map runtime input validity, whole caller and whole project checks remain
independent. No tarball-integrity or standard-library implementation parity
claim follows from installed bytes or lock metadata.

The complete source profile retains both original reverse readers and the
original receiving source before its explicit later-source join. The first
reverse4 archive stays immutable. Full production-tree positive and refusal
cases are drafted for both actual readers/evaluators. All cases, strict target
compilation, source-epoch adoption, end-to-end target reverse regeneration,
resource/deadline fit and native/runtime parity remain **UNRUN** or open. The
complete-draft checklist and executable function coverage are unchanged.
