# Automatic native module discovery source draft

SOURCE ONLY. All new code, source equations, regression cases, receiving checks
and target execution remain UNRUN. CI feedback remains uninspected. The whole
requirement set is not fully drafted; runtime parity and actual coverage are OPEN.

`proposeOwnedNativeBulkDiscovery` starts with complete current Rust, Cargo and
qualified compatibility-runtime source inputs. It obtains its own fresh forward
project, joins each actual executable declaration to the original source/hash,
qualified name, module and checked span, and derives supported signature families
from that invocation's actual original/lowered declarations. No caller can supply
a checked project, saved discovery verdict, source-call grant or ownership permit.

The reusable language sequence substitutes closed ordered body observations into
receiving source. Its current draft covers bool/u64/i64/string values, qualified
JSON construction/copy/update/field/index/reader/predicate operations, fixed text
scalar operations, standard Some tests/payloads, vectors and complete branching.
Positive signed literals acquire actual constructor-domain local annotations.
Name allocation avoids receiving parameters, functions and generated imports.

Ordered effects must each have one source execution. Owned JSON producers remain
inline when that preserves order; duplication, dropped producers, reordered
operands and movement across a branch refuse. Conditional effects without a
preserving control rule also refuse. This path does not use the older canonical
Rust reader that skips guard statements. Original unknown effects cannot disappear
through a textual source projection.

Repository rules group by the actual original Rust file and module, and propose
deterministic modules below the receiving `js/src/translated` and
`ts/src/translated` equivalents. The existing complete type erasure supplies both
source files. Discovery refuses to overwrite an existing receiving module; an
existing module needs explicit source synchronization. Rules remain exactly
`language` then `repository` and retain complete originals and source inverses.

Every generated selected module enters the genuine private source checker and
serialized/reparsed meta path. Its complete ordered bodies must reproduce the
original native observations before fresh canonical paired-source and native
synchronization checks. Neither observation tables nor generated source can issue
checked IR. The result records complete CST representations, new-file absence
baselines, original inputs, per-module native proposals and preserved refusals.
It installs nothing and reports execution, production selection, freshness and
runtime parity as unqualified.

The proposal currently retains per-module native edits separately. Combining
multiple module edits to one Rust file, atomic physical adoption, automatic source
call closure, additional ABI/ownership/control/operator families, production
selection and the complete exported receiving/performance/platform qualification
remain OPEN. Forward refusals and unsupported source remain visible. Discovery
counts do not establish executable application coverage. Eight same-SHA
JavaScript CI gates still precede fatal CI-only Rust; no local Rust tool runs.
