# Original written builtin attribute namespace draft

A separate registered-builtin enclosing resolver now handles the original
single-segment `stable`, `unstable` and `automatically_derived` attributes.
The owned enclosing wrapper selects this successor; the original unscoped and
ordinary enclosing APIs retain their prior admission domains. A caller cannot
supply the internal source frame through resolver options.

This rule retains three complete original Rust 1.89 parser files and twelve
whole parser callbacks: written outer attribute construction, ordinary path and
segment parsing, identifier retention and literal/empty argument collection.
Their original Parser implementation owners join the actual normal Attribute
constructor, single-segment `AttributeExt::ident`, original ungated registration
expansions, full builtin map initializer and whole `take_first_attr` callback.
The latter excludes registered builtin names before selecting a custom
attribute. Original source spellings and bounded payload syntax select these
branch preconditions; a public name, digest or returned flag supplies no proof.

The caller frame joins the complete original item tokens and exact attribute
span. Stability fields require ordinary literal strings and the original
feature/since or feature/issue fields. Qualified/raw paths, macro-valued
arguments, unknown fields/producers and unresolved cfg_attr alternatives retain
uncertainty. The selected resolver reparses full original item sets rather than
accepting a caller's truncated item carrier. Unknown siblings and all other
macro/export/derive/tool obligations still accumulate normally.

Complete source construction and namespace issuance remain separate. The source
proof records retain false namespace/runtime/caller-owner flags; the actual
resolver independently joins their sources and written caller preconditions
before issuing its existing private scope identity. Each synchronous resolver
frame shares its source work only within that invocation and physically rejoins
all inputs at return. Public source facts reissue their complete source closure.
No new source/hash/owner/verdict/result cache survives between invocations.

Four complete original implementation copies, ordered language/repository rules
and full CST/source inverses are retained. New parser files keep original Git
blob and SHA-256 identities, full gzip sources, URLs and both Rust licenses;
existing upstream pins remain unchanged. Independent namespace, original API,
unknown producer, exact span/view/item, private token, source classifier and
ordinary Rust automatically_derived oracle sources are drafted and unrun.
No compiler, test, experiment, preparer, translator, generation, Rust tool,
push or CI ran. Complete architecture exports, other attribute producers,
same-scope derive/tool bootstrap, production adoption/parity and every other
unfinished bulk requirement remain open.
