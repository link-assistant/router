# Original function returns and JavaScript source annotations: draft

Every implementation and independent case remains unrun. Ordinary synchronous
TypeScript functions can retain explicit scalar or operation-derived return
annotations when the complete checked body proves the corresponding native
domain. A `string` declaration can describe an already-proved String or borrowed
str result; the actual body and root checks choose ownership. Operation-derived
owned JSON/list results must match exactly and cannot manufacture a copy from a
shared return. Existing restricted recursive-signature obligations remain intact.

The original callback annotation reader is now shared as a fresh invocation-local
DATA factory. Actual imported APIs, Parameters/ReturnType, callback signatures
and element domains retain their original source obligations. The ordinary
function verifier compares an annotation with an independently inferred complete
body. Generic aliases and explicit future-return contracts remain open.

Source review identified a shared synchronization gap: stripping original
TypeScript parameter types could leave the JavaScript target without the input
annotations required by the source checker on its next pass. The new source
packaging retains complete canonical JSDoc input types and applicable return
types. Existing mismatched type tags are corrected in the JavaScript target.
When a new doc block is necessary, it contains every actual parameter and the
known return together, including recursive signatures. Repeating an unchanged
round trip does not intentionally add another block.

Canonical type spellings use one original native TypeScript printer per source
analysis, with comments removed; raw source trivia never enters a generated
JSDoc field. No printer or annotation verdict is cached across invocations.
Original annotation and doc-type spans retain full source inverses. TypeScript
targets preserve their complete original source. Private doc plans and source
files do not enter checked semantic meta or grant namespace/ownership authority.

Full original annotation-reader and caller-source copies retain native-selected
language then repository substitutions, serialized/reparsed CST and strict owner
boundaries. Independent unrun JS/strict TS source covers borrowed/owned strings,
operation-derived JSON/list returns, recursive Boolean signatures, canonical
comment handling, original doc correction, repeated source round trips and
invalid ownership/type claims. Existing independent native value/oracle source
remains required. Generic/owned/future signatures, namespace/bootstrap,
production parity and every unfinished requirement remain open.
