# JavaScript-authoritative vector pairing source draft

SOURCE ONLY. All implementation and independent cases remain UNRUN. No tests,
compiler, parser, translator, preparer or experiments were executed, and CI
feedback remains uninspected. Every delivery requirement stays OPEN.

Vector module reinput and native source synchronization now draft one explicit
JavaScript or TypeScript authority per operation. For JavaScript authority, a
source-derived native AST traversal selects only written parameter and return
type spans from the actual baseline TypeScript module. Function names and
ordinary parameter identities must match; ambiguous, missing, renamed, default,
rest/destructured or added function headers need independently written types.
Current JavaScript body text, imports and comments remain exact.

Baseline type-only imports are retained as TypeScript source. They grant no
JSON/native namespace permission. The unmodified paired checker independently
rechecks complete JS/TS CSTs, native AST topology, erasure and parameter/local
spans. The private reverse checker then resolves actual type imports and original
Rust domains, checks every function and emits/rechecks the canonical full pair.
Scalar native source proposals still require fresh whole-project forward
checking, exact condition/leaf reproduction and the original complete census.
Header text cannot turn a bool into an integer or a nominal name into JSON.

Only complete source DATA is proposed. Both authorities together, unknown
options and unsupported header erasure fail. The proposal retains the actual
requested source language/text, all original inputs and complete source/CST
inverses. No native source is installed, no local Rust tool runs, and no
cross-invocation source/hash/owner/verdict/result cache is introduced.

Four complete source equations preserve language then repository rule phases
and both preparation roots. Independent unrun cases cover JavaScript body and
condition edits through paired/native proposals, comments/header spans, current
runtime imports with JSON type imports, domain mismatches and missing/changed
headers. General new-signature inference, f64/text/JSON native installation,
source transactions and all broader namespace/caller/receiving/platform/
performance/runtime requirements remain OPEN. Rust remains CI-only after all
eight same-SHA JavaScript gates.
