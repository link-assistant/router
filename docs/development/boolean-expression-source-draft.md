# Boolean source expression composition draft

All implementation and independent case SOURCE remains UNRUN. No local tests,
compilation, translator/preparer/runtime execution, generation, experiments or CI
feedback inspection occurred. Full translation and verification are unfinished.

One bounded shared source reader composes existing bool inputs/literals, known
qualified bool predicates and native numeric comparisons through parentheses,
logical negation, conjunction and disjunction. It classifies original operands
without executing, coercing, folding or replacing them. Both arms must remain
source classified even when a literal would skip a runtime branch. The original
source body keeps its actual operator precedence and short-circuit order.

The existing carrier expression adapter delegates otherwise unmatched boolean
source to this reader. Existing chronological locals and all three Option/
primitive Result/owned Result callback selectors reuse it. Raw supported text
predicates still go through the existing complete callback text engine first.
The final original whole-function checker keeps every real type, operator,
ownership, capture, move, effect and executable admission requirement. A source
role, true literal or known helper spelling grants none of that authority.

The new reader retains256-token,64-depth and4096-source-work bounds. Existing
numeric expression, complete-call, whole-function and callback budgets remain.
Unknown calls, unknown short-circuit arms, wrong numeric widths, unsupported
operators and malformed groups remain refused. No runtime API, semantic checker,
CI workload or deadline changed. More general expression/type/callback source
and production qualification remain separate obligations.

Three complete compiler source equations retain whole immutable originals,
actual native owners and complete serialized/reparsed CST source inverses in
separate language/repository phases. Independent unrun source covers all logical
forms, eager source classification of both branches, bounds/refusals, carrier
locals/constructors, six original adopter APIs, seven actual callers, independent
truth tables/Unicode/absent/error cases, JavaScript/strict TypeScript, both source
languages and native inverse receiving, native standard truth/short-circuit order
oracles and export closure. Every unfinished namespace, production, reverse,
synchronization, profile/freshness, parity and delivery obligation remains OPEN.
