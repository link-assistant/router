# Owned JSON predicate and fold draft

Five matching Rust/JavaScript library boundaries now have implementation source:
filter, any, all, find and fold. A shared operation description supplies stable
IDs, input/result domains, callback contracts, ordering, short-circuit behavior,
module names and TypeScript declaration emission. The native Rust internals
remain untranslated. Find distinguishes `Some(Null)` from `None`; filter/find
and fold preserve owned canonical storage. Empty any/all retain false/true.

The Rust library is a separate `translation_collections_core` module. Complete
Rust root and host-asset originals remain in the source profile used by
`prepare-json-iteration-core.mjs`. Language and repository sequences retain the
private/public module additions, both asset registrations and complete CST
inverses. Native Rust grammar is explicitly unverified; no Rust tool runs here.
The original compatibility facade and its full source pins remain intact.

The additive `owned-iteration.mjs` reverse profile copies all five complete
preceding collection implementations: private source checking, emission and both
interpreters, full document codec, paired type reader and source entrypoints.
Native-selected substitution recipes preserve every original and inverse.
Separate private issuers and a distinct meta profile prevent detached/copied
data from granting caller permission. Actual source contexts require the new
complete native leaf, real public module edge and registered runtime closure,
in addition to every original core, Cargo and JSON check.

The rules carry predicate booleans, owned accumulator inputs, shared item
parameters and actual result types through checked meta. Callback branches,
written paired types, source bindings and ordering are freshly checked. Rust
binds the receiver and initial expression once in source order, explicitly
copies borrowed public initial JSON at the owned boundary, and validates input
and result domains. Owned native Option<Json> reads use explicit clone rather
than silently moving a reusable JavaScript local. Both independent interpreters
invoke the matching short-circuit runtime operation. The TypeScript source lane
retains its original native projection and complete source inverse.

Independent source covers actual callers, strict original/generated TypeScript,
both interpreters, empty and short-circuit cases, Null versus absence, fold order,
Unicode, owned projections, written domains, forged meta/native edges, callback
refusals and complete source histories. Four additional native Rust oracle cases
call the actual new APIs. None has executed. The JS and JSON resource bounds,
all eight original same-SHA gate stages and fatal JS-gated Rust jobs remain.

Forward Rust caller registration/adoption, nested iterator combinations,
general mutation/state, async/HTTP/streaming, production synchronization and
current bank/export/output qualification remain open. A complete core function
or reverse profile is not a whole Router coverage claim. All new source and
regression drafts remain unverified until every remaining implementation draft
exists and the deferred checks are permitted.
