# Signed numeric and map ABI source draft

The owned-state source path drafts bounded negative bigint literals,
operation-derived signed parameters and returns, numeric Option constructors,
and borrowed map parameters through both translation directions. Actual native
syntax and imported runtime bindings select their domains. Bare `bigint`,
structural map spellings and shadowed `Parameters` supply no domain authority.
Negative variables, arithmetic and out-of-range literals remain refused.

The canonical Rust reader retains signed suffixes, minimum i64 values and
nested generic delimiters. Its projection proposes types through the actual
imported JSON constructor/map reader. The consumer still serializes/reparses
the complete original CST, freshly checks proposed JavaScript and semantic
meta, and requires complete Rust token reproduction. Previous paired bodies
remain spelling proposals with full original source retained.

`prepare-owned-numeric-abi.mjs` retains seven complete original implementation
files, native-selected substitutions, ordered language/repository sequences
and full CST inverses. Existing field and mutable-flow histories compose these
successors, including files absent from an intermediate history. Source
equations issue no private checker, namespace, runtime or parity permission.

Independent JS/TS/Rust source covers signed endpoints, zero, conditional joins,
Option payloads, map loans, native behavior and refusals. All implementation,
history producers and cases are unverified and unrun during bulk drafting.
General arithmetic, arbitrary TypeScript types, production adoption and the
larger requirement rows remain open.
