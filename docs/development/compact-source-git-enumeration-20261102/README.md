# Compact materialized Git enumeration: source draft

`indexCompactMaterializedSourceSelection` connects a complete explicit physical
selection to a real fresh unborn Git index. The additive transfer facade exports
this API alongside the existing compact DATA author/store/collector/materializer.
No import executes Git, filesystem writes, translation or compiler issuance.

All selected physical files must be present, ordinary and byte/mode-identical to
the full restored vault contents. Complete directory/file census refuses extra
neighbors, missing paths, accessors, duplicates, symlinks, existing or nested Git
control paths. Original physical descriptors, source bytes and directory identity
are rechecked before returning, including failure exits. Every closer is attempted
and the original thrown value remains primary. No source/verdict cache survives.

A real empty-template Git init uses an explicit compiler-DATA branch/object format,
no inherited Git environment/configuration, disabled hooks and no maintenance.
No-filter hash-object batches hold at most128 paths/64KiB; the raw update-index
records retain actual original executable modes and complete object IDs. The
closing stage compares the entire real index with the complete selected source,
checks that no committed refs exist and retains an unborn symbolic HEAD.
Object IDs are byte-integrity DATA; they grant no native namespace/caller proof.
No commit or application source HEAD is invented to satisfy a source reader.

Raw files plus conservatively reserved loose-Git/index overhead must fit64MiB
before init. Actual complete Git bytes are checked during batches and on closing.
The whole index operation has20 seconds; individual Git calls have at most10
seconds or the remaining operation time. These explicit new API bounds do not
replace any original receiving aggregate/file/deadline obligation. Large selections
may honestly refuse. No whole compiler fit, speed or RSS qualification exists.
On failure the caller-owned materialized root remains for guarded cleanup and
raw evidence retention; this API does not recursively remove replaced trees.

Four independent full case sources draft both real SHA1/SHA256 indexes, complete
physical/index/UTF8/CRLF joins, absent committed refs, extra/missing/changed sources,
source symlinks and accessor/duplicate selection refusal. No case has run.
