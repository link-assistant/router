# Packaged owned Rust reverse source draft

The packaged reverse path copies the complete original canonical owned inverse.
It reads the original private implementation module and public function aliases,
then reuses original body parsing, source proposals, fresh private JS checking,
serialized/reparsed meta and complete inner Rust reproduction. Repository rules
reconstruct the public namespace and require complete authoritative outer Rust
reproduction before returning any result.

Paired JavaScript public names supply spelling proposals only; they do not
authorize bodies or aliases. Missing/private targets, extra root effects,
unknown support, malformed wrappers, duplicate aliases and reserved native names
refuse. Full original Rust CST, public source rows and all before/after inverses
remain retained. Native library caller paths remain protected.

Three complete source predecessors and their ordered language/repository rules
compose the earlier project copies. Independent source covers original and
unpaired public names, actual JS execution, body/root reproduction, forged
support, root effects, source changes and full histories. All implementation,
translator, compiler, test, experiment and Rust execution is **unrun**.

Distribution back into original module files, multi-module source-unit
transactions, broader application types/effects and full production qualification
remain open. Packaged source reproduction alone is not whole-repository syncing.
