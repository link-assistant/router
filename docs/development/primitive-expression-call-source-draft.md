# Primitive numeric expression and call source draft

All implementation, independent regression, target and native oracle SOURCE is
UNRUN. No tests, compilation, translator/preparer execution, generation,
experiments or CI feedback inspection occurred. Full translation is unfinished.

The general token rules now read one complete bounded qualified call prefix in
an expression while preserving the existing complete-call grammar and limits.
The original primitive precedence reader consumes these unevaluated call atoms.
Integer adoption accepts complete numeric expressions in method arguments and
complete grouped receivers, retaining every original receiver and argument once.
The source proposal preserves actual arithmetic precedence and evaluation order;
real overflow, type, source, ownership and body checks remain independent.

A shared carrier expression adapter exposes actual numeric lexical inputs and
known qualified helper results. It recognizes one fixed-width numeric comparison
with matching operand widths and carries its boolean source role through local
aliases and Option/Result callback inference. Both original callback paths and
both Result selectors use it. Original input scopes, local chronology, source
budgets, selected-call histories and complete checker admission remain required.
The numeric source reader retains its 256-token,64-depth,1024-cell expression
bounds. Carrier constructor source may now contain a complete expression within
that 256-token bound; actual helper calls keep their original128-token limit.
Callback source work charges attempted operand lengths to its original budget.

No numeric expression is evaluated or treated as a semantic theorem. Unknown
calls, casts, mixed widths, missing type evidence, unrecognized operators and
chained comparisons remain refused. Wider boolean composition, grouped whole
comparisons, raw method chains and broader closures remain separate obligations.
No native/runtime API, semantic arithmetic operation or compiler gate changed.

Ten complete compiler equations retain full originals, native source ownership,
serialized/reparsed CST inverses and separate language/repository phases.
Independent unrun cases cover generic call boundaries/refusals, arithmetic and
all six comparisons, carrier constructors/locals, six original adopter APIs,
nine complete application callers, JavaScript/strict TypeScript execution,
paired JS/TS/native reverse receiving, native standard-expression/branch/order
oracles and export closure. Every unfinished source, namespace, production,
reverse, synchronization, freshness, parity and delivery obligation stays OPEN.
