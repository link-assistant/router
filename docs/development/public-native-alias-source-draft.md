# Public native scalar alias source proposal draft

All implementation and independent cases in this checkpoint are UNRUN. A new
source/interface proposer rebuilds a fresh native TypeScript program from a
complete typed source proposal and the private context's actual current runtime
sources. Only the explicit primitive context enables work. Native scalar leaves
must resolve to their exact exported canonical or complete byte-equal mirrored
declaration symbols; matching BigInt spelling or a local similarly named alias
cannot select a Rust width.

The bounded local alias walk handles direct import types, named imports,
parentheses and acyclic non-generic local chains. Generic/native optional/union
public aliases remain separate unsupported source forms. It returns DATA with
original spans, native width/sign/target descriptions and target-coordinate type
import proposals. Full original source/CST, the complete rewritten source, both
language/repository phases and a complete inverse are retained. Source inputs
cannot replace captured runtime paths. All context inputs are freshly rechecked
at operation boundaries; no source/symbol/result cache crosses invocations.

The proposer grants no source, type, namespace, body, runtime or executable
permission. Public Rust/TS packaging, root native type observation/reproduction,
scalar template formatting and module redistribution still need integration.
This checkpoint therefore does not complete public native scalar exports.

Two full compiler equations retain originals, native owners and complete source
inverses. Independent unrun cases cover actual direct/chained/public leaves,
native widths, canonical/mirrored symbols, altered mirrors, BigInt/local/wrong-
module/generic/cycle refusals, private flags, coordinates and source limits.
No implementation, parser, compiler, translator, preparer, runtime, test,
experiment, generation, Rust tool or CI-triggering push ran. All remaining source,
actual native owner/global/effect closure, production translation, whole sync,
source-bank/export freshness, parity, receiving qualification and delivery stay open.
