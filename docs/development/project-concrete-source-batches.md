# Complete project CST ingress

The tracked Rust module graph first discovers its bounded reachable physical
input sequence. This planning traversal reads each original source once and
retains the existing lexical progress events. Its views, path proofs and
diagnostics are discarded; they are not independent semantic-check inputs.
Inline views retain their parent's complete source and original coordinates.

`createRustConcreteSyntaxStages` transports complete physical sources through
the existing private native CST issuer. A transaction contains at most 256 rows
and 2,097,152 source code units. Each source is independently built, serialized,
reparsed, classified and reconstructed. Native before/after authentication and
all existing source, UTF-8, node and canonical bounds remain enforced.
An ordinary lexical estimate partitions dense inputs before transport. That
estimate grants no classification or admission: only the independent native
transaction's actual complete document and aggregate checks can accept a row.

If several individually valid sources exceed the native aggregate node or
canonical bound, the failed transaction supplies no output. Both complete
halves are authenticated and transported afresh. Splitting is finite and
preserves row order; it never enlarges a bound or accepts an unrelated failure.
Malformed source retains its original opaque/error CST and diagnostics.

The actual module graph is then rebuilt from the reconstructed complete source texts,
with fresh original views and path proofs. Its physical input sequence must
exactly consume the captured sequence. No planning proof is reused and caller
source/progress callbacks are not run a second time. There is no cross-call
source cache or authenticated epoch. CST reconstruction grants no type,
ownership, macro-expansion or executable authority; independent semantic
checking still follows module graph construction.

Receiving tests cover complete Unicode and trivia reconstruction, row and
aggregate partitions, independent single-source equality, full CST inverse
checks, inline coordinates, inactive and unknown module conditions, changed
source on a fresh call, malformed text and non-string refusal. The original
whole project, module-path and payload tests remain separate verification.

Both traversals share the initial tracked-path set without iterating caller
inputs again. Root-only module graphs retain their existing support for one-shot
iterables. External-module path planning keeps its original bounded-array
requirement; the snapshot does not admit previously unsupported path carriers.
