# HTTP resource caller source draft

All implementation and independent test source described here is unrun. It
does not establish native grammar acceptance, executable application coverage,
receiving qualification, runtime parity or complete synchronization.

The separate `http-resource` caller lane copies the complete original cold
control source adapter, flow implementation and Rust projection/reader. Full
original source snapshots and native-selected language then repository
substitution recipes are retained in the two source profiles. The earlier
control and owned APIs retain their original domains and runtime roots.

Actual imports must resolve to their complete registered runtime module. A
fresh private original source context captures every source, Cargo input and
base runtime dependency under its original 4,096-file and 16 MiB limits. The
HTTP checker additionally joins complete protocol, transport, network policy,
deadline, declaration and native module bytes, unique native module edges and
the unchanged cold-flow implementation. No source/hash/verdict cache spans
invocations. Observation tables alone supply no semantic permission.

The language rules independently check each entire JS or TS function, including
all return branches. Source and generated targets use serialized/reparsed
lossless CST. Checked flow meta is serialized, reparsed and compared with a
fresh whole-source analysis before qualified native emission. The repository
sequence retains original source, annotation spans and complete target inverses.

Named shared and exclusive client/stream inputs use actual operation-derived
types. Local clients, streams and channel receivers must be returned or
explicitly released on every exit, including earlier error exits. Moves cannot
be reused; disposed inputs cannot be borrowed again. Immediate awaited cold
operations finish each exclusive loan before the next statement. Conflicting
loans within one call refuse. Actual mutable uses determine native bindings.
Borrowed resource inputs cannot escape through an owned return.

String-error HTTP Results and `ControlError` Results remain separate. A guard
returns its original whole error, and every propagated error family must match
the complete function return. Nested deadline Results are retained, including
direct whole return or move. Arbitrary callbacks and pending futures remain
refused; HTTP deadline callers use the fixed settled operations. Borrowed
protocol text results remain refused pending their complete root/lifetime rule.

JSON requests, responses, heads, copies and scalar/empty-array constructors use
the actual existing compatibility library. Public counts require the original
dominating u64 guard; copied annotations cannot establish numeric ranges.

The canonical Rust inverse proposes operation-specific source using the full
original reader copy, then enters the independent whole JS checker. It must
reproduce every authoritative Rust syntax token. Unknown attributes, unqualified
native operations, wider JSON aggregates, arbitrary async bodies and any source
whose complete reproduction fails remain explicit refusals. A successful CST
transport alone does not qualify Rust grammar or ownership.

Independent source cases cover real loopback Unicode responses, strict target
TypeScript, full source/CST/meta joins, native inverse reproduction, actual
runtime/native tampering, leaked/moved/disposed resources, missing error cleanup,
mixed errors, borrowed escape and pending futures. The handwritten native
loopback oracle is reserved for JavaScript-gated CI.

Physical source-unit integration, broader loops/generics/async domains,
borrowed protocol results, mixed-error adapters, original namespace/producer
closure, full Router adoption/parity and all remaining ledger obligations are
open. No tests, translator, preparer, generated output or installer was run.
