# Primitive Result translation integration source draft

The 88-interface Result family now has source registrations, actual native
standard Result owner/success/error checks, inline callback checking, canonical
Rust proposals, both independent interpreters, Rust/TS emitters and receiving
runtime packaging. Sixteen complete original integration files retain inverse
source equations and ordered language/repository source preparation. Every new
implementation, case and producer remains unrun.

Closed public bool/u64/i64/borrowed-text Result inputs and owned-error Option
outputs are tied to actual native-bound runtime type queries. Optional locals
and Result locals preserve their tagged TS interfaces. Reverse emission uses
explicit clones for immutable Result values, following the existing immutable
owned JSON profile; it does not infer arbitrary native Copy or Drop permission.
Forward checking still enforces by-value transfer of actual native owned errors.

Borrowed success and owned error payloads have separate equations. Map takes its
output origin from the freshly checked callback. Binding uses the returned
Result origins; error mapping retains the original success; recovery joins the
original and callback successes. Owned unwrap/default/error outputs retain no
borrow. An actual error-only borrowed Result carries no success loan, including
through fresh immutable local bindings. Callback return state and return-origin
collections are isolated from their enclosing function. Owned or mutable outer
captures remain refused.

The new forward checks also repair the Option callback syntax ingress to inspect
actual parsed parameter lists, reserving checked arity for checked callbacks.
Independent regression source covers actual JS, strict TS, both interpreters,
canonical native reproduction, tagged constructors, variant guards, lazy faults,
error mapping, captured lifetimes, complete native/runtime changes, domain
mismatches and detached metadata. None has executed. Automatic Result method
adoption, broader residual/control constructs, production application and all
other incomplete requirement ledger rows remain open.
