# JSON clone chain source draft

All implementation and independent regression sources are UNRUN. This source
batch executed no translator, preparer, runtime, test, generation, experiment,
local Rust tool or CI-triggering push.

The complete existing copy selector now follows bounded canonical shared JSON
reader chains and their internal Option question marks before a zero-argument
clone. It also selects zero-argument cloned on a known Option of shared JSON,
including immutable aliases. All original producer, Cargo, scope, source,
configuration and complete native facade guards remain in force. Unsupported
owners, unknown callbacks, mutation, shadowed aliases and effects stay original.

Optional copies first expand through a reusable language equation: capture the
receiver once, match fully qualified standard Option constructors, clone the
Some payload once, and leave None without a copy. Repository rules then replace
only four generated constructor/clone path spans with the existing paired Maybe
and json_copy abstractions. Receiver bytes are never searched for these paths.
Generated local names avoid every identifier spelling in the actual physical
source; both stages cross serialized/reparsed lossless CST/meta boundaries.
Direct copies are rebased around language expansions, and the complete original
source, intermediate source, final source, edits and inverse remain available.

Four whole compiler source equations retain their complete originals, native
owner spans, ordered language/repository edits and inverses. The original index
mode and its rule identifiers remain intact. Existing paired json_copy behavior,
runtime, declarations and forward/reverse mappings are reused without a new
runtime API or hand-edited generated artifact.

Independent unrun source cases cover mixed substitutions, Unicode/CRLF,
misleading path text inside receiver literals, hygiene, unchanged index mode,
try chains and refusals. JS plus separately strict-compiled TypeScript cases
require real emitted behavior for absent/null/empty/nested payloads. Native
CI-only oracle source compares ordinary clones, the language equation and the
paired copy, including nested storage independence and receiver order.

Original trait dispatch, native owner/borrow equivalence, actual complete caller
admission and production gains remain unqualified. Full source-bank/export
freshness, strict parity, all reverse synchronization, the eight-stage
JavaScript gate, CI-only Rust and receiving qualification remain unfinished,
along with every open bulk requirement.
