# Shared Option and Result local source draft

The implementation, complete source equations and all independent case sources
are drafted and unrun. There is no new measured executable coverage, target/native
parity, source-history qualification, freshness or complete synchronization claim.

Three existing selectors now share chronological source DATA for primitive
Option methods, Option callbacks and Result methods/callbacks. Their ordinary
and source-bound adopters, including the three fixed bulk stages, use those
same selectors. Existing family contracts, paired runtimes, reverse mappings,
whole source captures and full semantic/ownership checks remain required.

Actual immutable aliases and selected complete direct initializer results gain
their concrete role only after the original semicolon and inside their lexical
scope. Closed Some/None/Ok/Err constructors, bounded primitive literals, genuine
known payloads, owned error text and existing JSON scalar readers can establish
candidate roles. Some belongs to Option; Ok/Err belong to Result. Numeric
literal inference requires an explicit suffix or matching actual declaration.
None and Err require the matching written carrier domain. Unknown annotated
initializers no longer supply a candidate role solely from that annotation.

The shared engine exposes a bounded snapshot of currently visible bindings for
the existing callback inference paths. Captured local roles and each callback's
own binder remain separate, while unknown and ended-scope names stay absent.
Snapshots consume the original cell budget and exist inside the actual source
operation. No source/hash/owner/verdict/result cache survives an operation.

All receipts remain DATA with false source/semantic/trait/executable authority.
They do not prove native dispatch, borrow/move/drop behavior or a callback body.
The entire adopted source function still has to pass the independent current
checks. Unsupported patterns, mutation, shadowing, arbitrary constructors and
unknown annotated initializers remain unproved. The new local lane retains
200000 token/cell, 4096 binding and 256 lexical-frame bounds and at most 64
following annotation tokens; no original deadlines or workloads are enlarged.

Seven complete source equations retain original compiler modules, native owners,
both rule phases and complete source/CST inverses. Independent written cases
cover constructor kinds and ranges, annotation mismatches, scope/timing/spans,
iterable captures, all six proposer APIs, three fixed bulk stages, receiving JS
and strict TS, native callback counts/error ownership and source-history joins.
Unsupported initializer walks continue monotonically at their original RHS;
the shared text selector retains the same source-order rule. Every case and wider source/native/production/sync/freshness/parity/delivery
requirement remains unverified.
