# Conditional generic derive outer attributes: source draft

This unrun source family closes a conditional original-source attribute-name
obligation. It does not select a caller's derive owner or establish an enclosing
namespace. Every implementation, regression and native oracle remains unverified.

The original registered callback range supplies the complete generic dispatcher,
its actual `Impl` constructor and every normal output route. The new source
lemma requires the complete suffix from the generated `attrs` definition to the
returned item, including the intervening reference and builder call. A matching
substring elsewhere in the constructor cannot supply that definition/use join.

The attribute constructor chain retains the complete original `attr_word`,
`mk_attr_word`, `mk_attr`, `mk_attr_from_item`, `Ident::new`, `Path::from_ident`
and `PathSegment::from_ident` bodies. Attribute lookup retains the original
`AttributeExt` implementation, its `ident` method, both default name predicates,
the inherent forwarding methods and the absence of corresponding overrides.
Original implementation owners are checked separately from a method spelling.

The six copied names are `allow`, `warn`, `deny`, `forbid`, `stable` and
`unstable`; the generated constructor also supplies `automatically_derived`.
Each has a real unconditional `ungated!` array element and a freshly computed
declarative expansion whose actual `BuiltinAttribute.name` field preserves that
symbol. The complete builtin map initializer and original `take_first_attr`
body supply the lookup and custom-attribute exclusion routes. Caller metadata
or a returned `registeredBuiltinOnly` flag cannot stand in for these sources.

The finite producer analysis joins one shared conditional source proof to the
complete common callbacks of every actual generic derive. It does not recompute
that same shared closure independently for each registration. Source reads,
decompressed inputs and EOF byte comparisons remain per invocation. Private
tokens retain only the requested dependency identity and registered name; their
readers recompute the source facts. No new cross-invocation verdict cache exists.

The shared ancestor catalogue and producer edits retain full original snapshots,
native syntax selections, ordered language then repository substitutions,
serialized/reparsed CST and complete inverses. Each original Rust input in the
new lemma also retains its complete concrete source and inverse. Existing range
flags remain unchanged. The new conditional source conclusion grants neither
caller ownership nor complete generated-output, macro-export or runtime proof.

Independent JS regression source covers every retained name, full source joins,
private token copies, changed dependencies and requests, the exceptional
`CoercePointee` refusal and truthful producer flags. A separate Rust test source
provides scalar and nested enum behavior under copied lint attributes. These
cases have not been executed. Architecture type-prefix exports, producer
bootstrap, nested effects, all other translation requirements and final
receiving/CI verification remain open.
