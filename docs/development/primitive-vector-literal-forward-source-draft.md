# Primitive literal native caller draft

Five complete source equations extend the actual qualified core from_slice
caller. A genuine parser-issued `&[exprs]` consumed by that copy call becomes
the paired variadic literal runtime call. Each expression receives the actual
primitive domain check in source order. Empty arrays and up to 64 individual
operands are supported; repeat arrays, wrong widths and mutable borrows remain
outside this rule. The runtime core retains its separate 4096 value bound.

The actual active root/module/resolved source binding, original complete caller,
current paired core/wrapper bodies, private projection record, ownership flow,
emission membership and CST/meta paths remain mandatory. No static promotion
proof, borrowed array IR or escaping temporary loan is invented. The result is
an owned linear Vec; its scalar operands are Copy. Import grouping selects the
literal wrapper module separately from ordinary core operations.

Independent all-domain native caller, empty/one/pair/64 argument, nested helper,
mutable rebinding, copied Option/length, wrong width/move/borrow, changed source,
asset and counterfeit projection case source is drafted. All execution,
strict target qualification, freshness and Rust CI results are UNRUN. Existing
Rust oracle source independently covers literal copy order and extrema.

Reverse JS/TS import/type/call handling and canonical Rust inverse integration
remain OPEN. This source draft does not qualify broad production adoption,
original global namespace closure, full synchronization or receiving export.
