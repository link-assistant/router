# Shared layered core source substitutions draft

The implementation, complete source equations and every independent case are
source drafted and unrun. This establishes no current coverage, target/native
parity, source-history qualification, output freshness or complete translation.

Eight existing integer, primitive Option, Option callback and Result adapters
now share a complete copy of the original integer source-substitution and
inverse algorithm. Each adapter retains its actual family operation selection,
current native core/module/dependency/producer checks and independent whole
function obligations. The helper produces candidate source DATA only.

The language phase substitutes complete selected expressions with neutral
compatibility call paths. The repository phase binds only those introduced
prefix spans back to the actual repository core paths. Nested Option/callback
families can bind separate roots in the same expression. Native Rust token
positions select call paths; strings, raw strings, characters and comments do
not become path matches. Original prefix trivia and callback source remain
verbatim when the repository phase restores the exact selected prefix.

Offsets are rebased within each replacement and across all original edits
using UTF-16 source coordinates. Both original phase names and family rule IDs
remain fixed. Full serialized/reparsed CST checks, final mapping, hashes and
whole original-source inverse checks remain in the copied algorithm. Neither
syntax nor a public helper proposal grants type, owner, trait or executable
authority; the actual entire function still has to qualify independently.

The new reusable selector allows at most 16 distinct root pairs and 200000
tokens/cells per selected replacement, within the existing two-million-unit
source expression bound. No resource workload/deadline is raised and no
source/hash/owner/verdict/result cache survives an operation. The adapters keep
their complete original inputs and final freshness checks.

Ten complete equations retain the original algorithm, eight complete adapters
and preceding source-history edge, with native owners and both CST inverses.
Independent unrun source cases cover nested/multiple roots, Unicode offsets,
real phase edits, literal/trivia preservation, conflicts and source refusals.
The existing independent family JS/strict TS/actual-bulk/native-oracle sources
continue to apply and remain unrun. All wider source/native/production/sync/
freshness/parity/delivery requirements remain unfinished.
