# Whole original ClientKind static accessor producer draft

This additive source adapter selects the existing full flat-enclosing compiler
under the committed policy209 source/compiler frames. It adds no Host rules,
source permits, producer tables, namespace exceptions, or profile substitutions.
The older extracted `clientkind-static-projection.test.mjs` remains unchanged.
All new cases and native oracle are **UNRUN**. Native oracle source is
**UNSCHEDULED** until the coordinator attaches it after all eight same-SHA JS
gates. No execution or admission count is claimed.

`inspectClientStaticProducer(configuration, consume)` acquires the original
opaque whole repository corpus through the policy source issuer: up to20,000
tracked Rust files,8MiB per owner,64MiB source total, original Cargo bytes and
complete physical/current closing. The library, clients, route contract,
route_contract_types, submodules, imports, derives, configuration and const
initializers remain intact. There is no projected successful owner and no
manual ClientKind/integration command table in product code.

One immutable description of nine actual methods emits additive qualified
caller proposals at the end of the whole library: integration, command,
display_name, dialect, token_env, base_url_env, setup_limitation, canonical_name,
and legacy_name. Their real source signatures retain borrowed static strings,
Option borrowed strings, and the shared static ClientIntegration owner. The
existing compiler must independently prove CLIENT_INTEGRATIONS, `self as usize`,
static fixed-array indexing, const dependencies and all original declarations.
No metadata marker, target name, public hash or submitted snapshot admits them.

The compiler snapshots only selected original checkedSource/targetBinding
readers inside the original nominal callback. Every privately checked whole
body/signature/source/span/namespace and current source closer therefore runs;
no live lower/parser/emitter closure escapes. DATA report snapshots provide
inspection only. If a probe is unsupported, inspection retains its identity and
all original residual indices. All original metadata fields (including flat
checked/target programs and concrete syntax) use the unchanged canonical field
storage64MiB-per-field/512MiB-total domain. The required-positive
`prepareClientStaticProducer` refuses with the complete adoption report when
any of the nine probes is absent. Source review has not established whether
all original declarations currently admit in the whole crate. Other production
functions and references are never counted as covered.

Every original Rust owner traverses the real CST meta serialize/reparse boundary
and a complete before/after equation, full inverse and actual ordered language
then repository trace. Consumers synchronously receive every complete event;
returned reports retain bounded receipts rather than all CSTs simultaneously.
Targets receive the same whole-source equations. Complete checked project meta
streams independently. Callback declared-async/proxy refusal, exact primary
errors, caught input failure poisoning, closure expiry, all source identity
closing and all original source/resource budgets remain in their original APIs.

`invertExactClientStaticTarget` checks the entire requested JS or TS source
against fresh emitted bytes and delivers ALL original native source bytes.
That is physical restoration; it does not emit a semantic Rust inverse.
`translateEditedClientStaticTarget` offers a narrow genuine semantic edit: the
appended command probe calls `display_name()` instead of `command()`. Both real
methods return a static borrowed string, but have different actual values. The
closed description regenerates only this native caller, retaining the complete
original library prefix. The whole original project is freshly checked twice;
both paired outputs and selected caller snapshots must reproduce exactly, and
the requested authoritative whole target bytes/path must equal the new output.
Comments, alternate target bytes, other callee/field edits and stale output
refuse. This is closed source-callee regeneration, not a general IR-to-Rust
emitter or a reinterpretation of unchanged original method bodies.

The receiving helper is a complete additive copy of the policy receiver,
including actual temporary Git original/installed native cohorts, every profile
leaf, bounded ordinary reads, strict TypeScript5.9.3 package/lock/compiler
version, diagnostics, source modes, deadlines, aggregate disk/source accounting
and primary-preserving cleanup. It installs the complete existing209 compiler
profile; these additive adapters are copied as compiler source inputs. Each new
required-positive case is allowed to fail honestly if the whole original
producer remains unsupported. The inspection case always retains the original
residuals when the compiler returns. Independent JS/strictTS and native test
literals pin all eight real variants, Options, static metadata and the edited
callee; expectations are not read from the source declaration table. No target
pointer identity guarantee or new owned-reference ABI is promised. General
static aggregate borrowed slices, arbitrary field edits, dynamic allocation,
custom traits, unrelated cfg/producer gaps and production coverage remain open.
