experiments, diagnostics, translators, preparers, regeneration, local Rust tools,

[the ledger](bulk-draft-requirements.md) remains open.

architecture output pipeline into an explicit original x86 source domain. It
retains actual private declarative definition/expansion lineage, complete output
rendering, generated and synthetic-item CST domains, native function/member and
invocation-position issuers, every original output refusal and full physical-file
substitution inverses. The earlier architecture APIs keep their existing scope.

a private request identity. Legacy token/fact APIs keep their fresh behavior.
