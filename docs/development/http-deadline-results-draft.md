# Explicit HTTP deadline result adaptation draft

All new native/runtime/rule/source-unit implementation and independent cases are
unrun. No native grammar, receiving, runtime parity or coverage claim follows.

The existing three settled deadline operations keep both Result layers and all
their contracts. A separate matching native/JS library supplies three fixed
by-value adapters for their open/read/send results. An outer control error maps
to one of five independently specified stable strings. A successful outer
Result returns its whole original inner transport Result without changing an
owned stream, optional chunk, JSON payload or original provider error.

The JS library accepts complete ordinary own-data variants and refuses proxies,
accessors, inherited fields, unknown tags and malformed string errors. Library
internals remain explicit untranslated abstractions. Static caller qualification
independently proves the actual nested Result domain and each by-value move;
the same Result cannot be adapted twice. No cross-invocation result cache or
caller-supplied semantic permit is introduced.

The closed caller grammar supports direct nested operation expressions and
unguarded whole Result locals consumed by an adapter or returned. Guarded error
propagation still requires the actual return error family. The explicit adapter
therefore enables one string-error caller around deadline requests, ordinary
HTTP value helpers and explicit client/stream cleanup. It cannot silently
flatten an original operation or invent Rust error conversion. Nested operation
source checking now also retains an explicit recursion-depth bound.

Full original root/library source, runtime closure, source observations and
source-unit integration are constructed by native-selected ordered language and
repository rules. Complete original modules and inverse equations are retained.
The old native root preparer composes the exact adjacent result-library root
history while keeping its direct file list. The additive receiving closure
retains original roots/dependencies and the original 128-source limit. Physical
HTTP units require the new full native library and mirrored modules; original
non-HTTP profiles and the original deadline receiving fixture remain unchanged.

Independent source cases cover all five error strings, retained provider and
success results, malicious variant shapes without getter invocation, complete
source histories, missing/tampered native/runtime sources, duplicate owned
Result moves, missing stream release, canonical whole native reproduction and
actual JS plus independently compiled strict TS timeout callers. Handwritten
Rust source supplies an independent error/payload oracle for JavaScript-gated CI.

Production adoption, general state/loops/async/generic domains, original
namespace/producer closure, complete receiving/CI repair and all other unfinished
requirements remain open. No translator, preparer, installer or test was run.
