# Resource collection callbacks: source draft

All implementation, receiving cases and native oracle source remain unrun.
This family composes the actual existing map/filter-map, filter, any/all, find
and fold libraries with the resource caller checker. Matching native/runtime
sources, complete original root/facade edges and native function censuses remain
mandatory. Immutable callback descriptors are DATA and cannot issue source,
type, ownership, effect or namespace authority.

The actual selected operation supplies each callback's complete input and return
domains. Local function references require independently checked complete bodies,
including forward references and parenthesized arguments. The dependency graph
now includes actual callback references. An identifier alone is insufficient.
Inline arrows retain their original block or expression body; that complete
body is independently checked in a fresh parameter scope with no outer local
bindings. Every outcome must meet the actual synchronous owned return contract.
Fold supplies its actual owned JSON accumulator input. Captured locals, async
callbacks, borrowed mapper results, dynamic function values, incompatible arity
and explicit arrow type syntax without its own inverse rule remain refused.

The matching libraries retain input validation, order, eager ownership and
short-circuit behavior. Shared element loans do not become owned mapper values
without an actual copy or owning carrier. Existing standard allocation, serde
and Drop internals remain intentionally native under the existing bounded
successful-resource projection. Exceptional/unwind equivalence remains open.

Native emission supports genuine checked function items and typed closures.
Unused arrow parameters receive collision-free underscore names based on their
actual checked binding references and local function names. Nested callbacks
cannot make an unused outer binding appear used. Standard Result/Option
constructor names are reserved against portable binding shadows. The complete
original native reader/projection copies reconstruct typed callback proposals
and still require fresh whole-source analysis and exact native token reproduction.

Full originals retain native-selected language then repository substitutions,
serialized/reparsed CST and complete inverses. Independent unrun JS/strict TS
source covers helper and inline callbacks, nested branches, fold ownership,
Some(Null), empty input, invalid captures/types and forged callback meta.
Separate Rust oracle source supplies finite values, ordering and exact
short-circuit counts. General captures, typed-arrow inverses, generic iterators,
namespace/bootstrap, production parity and every unfinished requirement remain
open. No coverage, speed or native execution gain has been measured.
