# Unit-returning source helpers

All implementation and cases are source drafts and UNRUN. Complete source
drafting, executable coverage, full translation and qualification remain OPEN.

The copied source-call family now includes unit results from actual complete
same-module primitive helpers. Scalar/bool/vector callers may discard such a
call, bind its unit value or return it from a unit function. Arguments retain
their actual primitive/borrowed-text ABI, left-to-right evaluation and all
source/loan checks. A unit result grants no permission for arbitrary effects.
The callee must independently pass the same finite complete body rules, source
census, native comparison and bounded acyclic dependency closure as its caller.

Reusable language rules select a copied complete call-summary/result-domain
implementation, native continuation observer, immutable tail observer and
guarded-failure evaluator. Repository rules retain the actual compatibility
runtime, qualified source/module routes and existing output layout. Actual
receiving, graph, comparison, discovery, projection, definition lifecycle and
emission consumers select the copied rules. The old source-call DATA module,
old native observer and old guarded evaluator retain their original domains;
the original scalar-only definition insertion family is unchanged.

Discarded unit calls become local continuation observations of actual checked
native IR. These reconstructed nodes are DATA and never enter a native issuer
as original source. The complete comparison still resolves every target in the
fresh original/lowered declaration graph and checks its real parameter and
return types. Symbolic evaluation retains each call as an ordered event and
normalizes only its empty unit value. Native discovery can therefore emit a
statement for that event without inventing a used result. Earlier failures and
unselected branch behavior remain independently observable.

The new finite vector-definition family permits these calls without allowing
unit input parameters, unknown host effects, async calls, recursion, missing
callees, cross-module calls or mismatched arguments. Its existing local, edge,
depth and expanded-work limits remain. Existing scalar-container native origins
can select the explicit operator context when the complete original container
census proves that shape; the old non-container scalar-profile refusal stays.
No source, hash, owner or result cache is added across operations.

Twenty-two complete source equations preserve frozen whole originals, full
lossless CST/meta inverses and exactly language then repository phases. Source
cases cover JavaScript and strict TypeScript insertion, all ten integer widths,
unit tail/local/discard values, eager and guarded failures, native discovery and
refresh, complete synchronization, original API refusals and DATA boundaries.
Independent Rust oracle source covers ordering and unit evaluation; it may run
only in CI after all eight same-SHA JavaScript stages pass. No source preparer,
translator, compiler or case was executed during this drafting batch.

Current compiler/export receiving, all platform profiles, performance, full
