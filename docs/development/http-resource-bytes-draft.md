# Owned octets and shared byte slices: source draft

All implementation, receiving cases and native oracle source remain unrun.
The resource caller lane now adds the two actual standard filesystem read
operations to the eighteen string-path operations. Their successful payload is
an owned native Vec of u8 values, represented by the existing runtime's bounded
immutable octet array. Matching JSON byte parsing reuses the actual core facade,
complete original native primitive source and existing validating runtime.

Owning byte vectors and shared byte slices remain distinct domains. Moves,
reinitialization, local aliases, all-root replacement protection, input-rooted
returns and native lifetimes reuse the complete original flow obligations.
General bigint arrays cannot supply an octet domain; actual operation-derived
types still require valid original library inputs. Arbitrary iterator methods
and byte-scalar arithmetic remain outside these source rules.

The written-type reader adds only successful Result/Option Extract queries
with one actual tag predicate and the actual field0 projection. A query must
start from an independently bound operation descriptor, retain Ok or Some and
match the complete contextual domain. Error-tag payloads, extra structural
predicates and arbitrary conditional types refuse. Native owning-byte signature
proposals use this exact successful read payload; shared-byte proposals use the
actual JSON parser input. Queries grant no runtime, source or ownership permit.

Complete original filesystem, contract, annotation, recursive, flow, reference
and native projection copies retain ordered language/repository substitutions,
native-selected spans, serialized/reparsed lossless CST and full inverses.
Independent unrun JS/strict TS/native source covers UTF8, malformed sequences,
empty input, Some(Null), original byte identity, cold reads, escaping local loans,
live-view replacement, double moves, wrong tags and forged meta. Full Result
fallbacks, generic byte iterators, namespace/bootstrap, production adoption and
parity and every other unfinished requirement remain open.
