# Optional JSON field and terminal source draft

Every new implementation and independent case is UNRUN. Shared reader adoption
now covers closed `and_then(|child| child.get(key))` callbacks and zero-argument
canonical reader callbacks. The callback must contain one exact ordinary call,
optionally inside one complete tail block. Written scalar keys retain their
bounded source roles. Mutation, capture ownership, custom methods, callback
return/try/control flow and arbitrary bodies remain refused. Known receiver,
namespace, configuration, original Cargo/graph and shadow checks remain intact.

After a canonical reader, `unwrap_or` becomes an explicit eager fallback binding
before payload selection. Both Some and None evaluate that fallback exactly once.
Presence checks also work on bounded optional JSON field chains without requiring
a prior scalar reader. These equations operate on shared borrows and trivial
scalar payloads; they do not widen owned Option/Drop or generic trait authority.
Trailing argument commas retain their original inverse without entering the
fallback expression. Removed comments and unknown argument shapes stay preserved.

Three complete compiler equations retain original modules, actual owner spans,
language/repository sequences, generated-only path joins, staged CST/meta and
whole inverses. Composed reader paths rebase through each new wrapper; original
receiver and fallback strings are never searched for generated path spellings.
Materialized and detached packet entry points share the same selector. Native
and emitted JS/strict TS regression sources cover nested fields, wrong kinds,
Unicode, integer extrema, eager effects, presence and refusal cases.

No proposal, parser, model, translator, preparer, test, experiment, generation,
Rust tool or CI-triggering push ran. This does not qualify any complete production
caller or original dispatch/ownership theorem. Actual forward/reverse lowering,
broader callbacks/collections/effects, source banks/exports, native closure,
freshness, synchronization, full parity and all gates remain unfinished.
