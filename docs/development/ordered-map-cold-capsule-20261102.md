# Cold source and semantic-meta transport for ordered-map callers

SOURCE DRAFT ONLY. Every new boundary/receiving/child case is UNRUN; CI feedback
is NOT_INSPECTED. The complete reviewed map caller source afterimages must first
be installed in an independent copied compiler. No full translation, complete
module/Router synchronization, native execution/parity or receiving qualification
is claimed. The capsule transports DATA and never serializes private receipts.

`ordered-map-cold-capsule-20261102.mjs` provides four additive APIs:

- `createOrderedMapForwardSourceCapsule(canonicalSourcePacket)`
- `readOrderedMapForwardSourceCapsule(canonicalCapsule)`
- `createOrderedMapReverseSourceCapsule(canonicalSourcePacket)`
- `readOrderedMapReverseSourceCapsule(canonicalCapsule)`

Inputs are bounded primitive canonical JSON strings, not callbacks, parsers,
compiler objects, checked-body permits or public provenance flags. Closed source
packet schemas retain every supplied original file and complete Cargo/profile
inputs. File paths are unique ordinary relative names; the forward entry is
explicitly `src/lib.rs` or `rust/src/lib.rs`. Runtime/declaration roots are explicit
nonempty ordinary relative names. The reverse packet retains the complete original
paired JS/TS/runtime/native source context and existing vector-binding DATA.
Unknown fields, duplicate JSON keys, noncanonical text, proxies/coercion objects
and out-of-domain structure cannot supply a source context.

Forward import reconstructs the source graph, complete lossless CST, original
Cargo/derive/JSON proofs and actual Host parser/checker through the real installed
map project API. The saved semantic document must exactly equal the freshly
qualified original target program. That document is then independently reparsed
through the actual semantic-meta reader, which reissues map source observations,
and emitted by the actual Host JavaScript emitter. Its complete emission must
match the fresh original project's target prefix. Generated JavaScript and strict
TypeScript remain produced by the original project pipeline; no target body is
hand patched. Bare semantic JSON or a public source key cannot warm a cold process.
The source graph reconstructs genuine original context before meta is accepted.

Reverse import recreates the complete original private native source context,
import/type/body checking and original meta reader from the retained actual
JS/TS/runtime/native/Cargo files. The original reader replaces decoded meta DATA
with its freshly checked source program. Rust and TypeScript emission run through
the original reverse emitter/checker. Source type witnesses, checked functions,
loans, errors and native source owners retain the original private obligations.
Changes to application behavior require new original source qualification; editing
saved meta alone does not authorize a new body. Named lifetime/source reconstruction
and every original reverse lane's remaining gaps stay explicit until completed.

Exactly language then repository sequences compose each real source/meta operation.
Every applicable whole source in either packet passes serialized/reparsed CST
before checking; source packets remain immutable through original source closers.
Installed compiler/profile/native artifact custody stays with the existing genuine
map operations and shared failure protocol. No cross-operation checked-body,
source/hash-verdict or parsed-program cache is introduced. A saved source capsule
is an explicit transport artifact, not a cached authority decision. Every read
reconstructs source and performs its independent checks again.

The new API has an explicit domain:4096 files,8MiB per file,64MiB original source
strings including Cargo/profile DATA,16MiB semantic document,192MiB complete wire,
250000 decoded cells and depth128. JSON must pass decoded accounting before
canonical reserialization. These limits do not raise or shrink an old API. Actual
underlying original parser/checker/export/source limits and refusals remain.
Bounds do not promise a total heap bound, native conformance or measured runtime.

Four default-discovery DATA-boundary case sources refuse coercion callbacks,
noncanonical/duplicate-key/deep input, over-bound files, bare public permits and
wrong-direction documents before entering a source-profile producer. Two explicit
receiving case sources create actual forward/reverse capsules and launch fresh
children with no warm private parser registry. Five child probes execute real
forward target map behavior, reverse checked interpretation, and independent
semantic/native-source tampering refusals. They retain the original60-second
receiving cases,20-second children and bounded16MiB output. No Rust is executed.
Original strict TypeScript and gated native oracle cases remain mandatory.

The receiving entry and child live directly in the compiler source directory so
the actual full committed compiler selector copies them. They are explicitly
TEST ORACLE source, not production functions or coverage. They register/run only
when explicitly invoked. The map worker must add the receiving entry to its
fixed installed-profile driver while retaining every original case. Until that
source integration and future receiving execution, scheduling/freshness is OPEN.
The original default compiler is not silently upgraded to the proposed14-parent
map profile by adding these additive modules.
