# Invocation-only source read leases and FD ranges

This separate three-parent source packet follows the frozen SDK backend epoch. It retains complete original compact-vault/physical-IO modules and the complete SDK backend successor as BEFORE images, complete AFTER images/inverses, and language then repository sequences. The original public callback vault API and its domain are unchanged. All execution, resource fit, performance and semantic qualification are **UNRUN**.

The concrete source finding was repeated whole-vault work: one complete encoded snapshot/copy for each individual profile read, plus entire physical volume rereads at each selected use. A6,409-file traversal could repeat up to64MiB of encoded copying thousands of times. These are source-derived upper bounds, not benchmark measurements.

The additive DATA lease API keeps one private snapshot/retained encoded copy and logical index until close. It charges every decoded occurrence, including repeated reads, against the original64MiB limit; there is no decoded result cache. Foreign, copied, failed or expired tokens refuse. Snapshot, full metadata, encoded byte, decoded object and original blob checks remain. Ordinary synchronous callback/result fencing and first-failure poison preserve null/undefined primaries. Closing releases every retained model/byte/index reference, including on failure. A lease issues no source-origin, compiler, namespace, type, body or runtime permission.

The backend owns one such lease only inside its genuine live root operation. It closes the old lease before a next read would exceed64MiB, validates every complete source at that boundary, and then creates a fresh lease. Root close also attempts that lease and every original independent source closer. No lease survives operation close, and no source/hash/verdict cache survives between operations.

The additive FD range reader uses real O_NOFOLLOW/O_NONBLOCK descriptors, complete original file identity (including nlink and nanosecond clocks), before/after fstat and named-path checks. It reads only the requested exact byte interval; zero-length reads still validate actual FD/path identity. No NodeStats or physical identity is synthesized.

Each selected use independently rereads the actual compressed object's segments, selected metadata record, and header with the original complete FD stamps. A metadata-record range is selected only when the complete original physical part independently equals its canonical byte equation; valid noncanonical parts retain the original full-part read fallback. Descriptor and Git controls get actual no-follow FD identity checks on every use. Full descriptor/Git bytes, complete model metadata, every physical volume/metadata byte, namespace/absence and all ancestor checks remain at lease and operation boundaries. No former full-byte guard is silently deleted.

Matching roots are found through the invocation-only active-root chain. A→B→A reuses the genuine ancestor A token, including its caught source-failure poison. Each independently opened root still closes independently; callback and result boundaries stay synchronous. There is no lookup across completed operations.

The explicit optimization resource profile limits live roots to64 and aggregate retained encoded/serialized-model/control resources to256MiB. Control admission reserves its finite44MiB worst case before reads; store/model retention is reserved before full capture; actual smaller reservations are released after complete sizing. Lease copies reserve their actual bounded footprint before allocation. Every failed constructor and successful/failed close releases its reservation. These counters bound named byte resources and record counts, not a measured V8 heap size. Existing decoded occurrence/metadata/per-file limits still bound transient work. A profile exceeding aggregate admission refuses; no old physical API limit is raised.

Independent receiving source covers decoded occurrence exhaustion and expiry, unchanged old callback behavior, non-invoked thenables/falsy primary closure, real FD ranges and same-byte replacement, complete real A/B/A compiler-root copies with caught inner-A failure, aggregate admission/release and complete reparsed source equations. No case or data fixture stands in for compiler/type/body qualification. Driver scheduling and producer continuation across this new epoch remain separate followups, as do other direct physical readers. Full receiving can still refuse honestly.
