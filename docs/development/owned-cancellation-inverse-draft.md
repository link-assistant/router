# Canonical synchronous cancellation Rust inverse source draft

`translateOwnedCancellationRust` now drafts canonical Cancellation functions
through Rust CST to JS proposals, fresh checked semantic meta, and Rust/TS
emission. All source preparation, translators and independent cases remain unrun.
General Rust application translation, async resource callers and production
qualification remain separate open requirements.

The complete original canonical inverse and projection implementations are
retained as immutable physical source snapshots. Separate language substitutions
add only the four registered synchronous cancellation call paths and explicit
borrowed/owned Cancellation type equations. Repository substitutions connect
the existing parser to the separate private cancellation source context,
operations and codec. Full native source selections, CST equations, original
bytes and source inverses remain inspectable.

The original source reader already retains ordinary qualified paths, shared
borrows, types, declarations and complete control blocks. Those observations
supply candidate JS syntax only. An exact native Cancellation parameter type
proposes the actual imported `Parameters` borrow domain; an owned native return
proposes the genuine new-operation `ReturnType`. Actual source checking still
rejects unsupported owned public inputs, stored shared aliases, moved resources
and invalid borrows. An erased syntactic borrow or catalog path grants no loan,
resource, callee, type or semantic permission.

The consumer reconstructs each complete function through the cancellation
profile's private original source checker, serializes/reparses its semantic meta,
and requires the entire emitted Rust to reproduce the authoritative input.
Missing shared references, extra clones, altered support, unknown native calls
and use after move cannot pass merely because a projection was constructed.
The original native-library path exclusions, complete support prefix, paired
source conflict data and fresh current-context checks remain mandatory. Source
proposals still receive guarded project installation only through their
separate integration; this API does not write receiving files.

Independent unrun source restores owned returns, shared clones, public borrowed
parameters and local ownership moves. Both interpreter behavior and paired
TypeScript restoration have independent expectations. Refusals cover source
mismatch, moved aliases, missing native borrows, unknown resources, changed
canonical support and attempts to rewrite native libraries. Complete export and
ordered original source history cases are drafted. General forward/project
resource integration, futures, exclusive receivers, HTTP streams, Drop behavior,
production adoption/parity and all other unfinished ledger rows remain open.
