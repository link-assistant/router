# Clone enclosing namespace source draft

This family adds a dimension-specific `Clone` namespace issuer. It invokes the
existing original-source Clone AST route, including all actual field type
roundtrips and both `has_derive_copy` outcomes, before retaining a bounded model
for the enclosing-name consumer. It does not translate the Clone method body,
prove Copy eligibility or admit a derive from its spelling alone.

The private issuer rechecks the original invocation, registered compiler owner,
source/profile, active helper and generated attribute owners, and the original
Impl namespace resolver. Every consume/reissue retains the original native DATA
guards and final source fence. Whole invocation closure still requires every
sibling owner. The existing complete Clone and Debug APIs remain available.

`prepare-clone-enclosing.mjs` declares the family through the reusable
`prepare-native-substitution-copy.mjs`. Its archive contains all three complete
original implementation sources and exact edit recipes. Native AST selections
bound edits to their original functions/imports or module ends. The preparer
applies separate language and repository sequences, serialized/reparsed complete
CST equations, full inverses, native lexical binding checks and fresh physical
source guards. Neither source hashes nor public model fields grant semantic
authority.

The regression source covers large records, nested field types, tuple/unit
layouts, both resolver outcomes, immutable models, copied/foreign inputs,
complete sibling closure and unsupported types/layouts. Nothing in this family
has been executed during the bulk drafting phase. It makes no measured coverage
or performance claim: construction still uses the complete existing Clone AST
route, and remaining namespace/producer obligations stay open.
