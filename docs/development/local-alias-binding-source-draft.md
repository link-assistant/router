# Shared local declaration source draft

The implementation, complete source equations and independent cases are drafted
and unrun. No current coverage, native/target parity, source-history freshness
or complete translation/synchronization result is claimed.

One complete copy of the original bounded local census now supplies general
declaration rules with separately supplied repository/family protected names.
It recognizes one ordinary immutable or mutable identifier while preserving
parameter/namespace/repeated-name/pattern refusals and original bounds. Base64
retains its original ASCII binding domain; existing Unicode families retain
theirs. Original no-let results keep their prior shape and fast path.

The chronological engine installs an unknown slot for every mutable local and
does not record its initializer or infer its result. An unrelated mutable local
therefore does not erase independent immutable alias facts. Mutable values,
aliases derived from them and selected mutable initializer results remain
unknown. No mutable receiver, mutation, type, owner, borrow or executable permit
comes from the declaration reader. Actual original declarations and mutation
statements stay intact for independent whole-function checking.

Four family censuses share these declaration rules. Five text/Option/Result
selectors use the same ordinary binder reader in their source preflight, while
JSON field/slice helpers retain the actual local names for their old shadow
checks. Family protected names, producer/macro/pattern refusals, source phase
names, fixed stage membership, full CST/inverse and currentness checks remain.
The original 200000 token/cell, 4096 binder and 256 frame limits are unchanged.
No source/hash/owner/verdict/result cache survives an operation.

Fourteen complete source equations retain original modules and native owners.
Independent unrun source covers seven actual family trackers, mutable result
non-promotion, scope/protected-name/pattern refusals, complete original text and
Option callers, retained scalar mutation, fresh JS and strict TS behavior,
native expected boundary values and whole source histories. Every broader
source/native/production/sync/freshness/parity/delivery requirement stays open.
