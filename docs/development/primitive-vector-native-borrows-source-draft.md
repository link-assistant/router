# Native explicit shared helper Vec borrow source draft

Four complete source equations draft actual written shared Vec operands of
ordinary same-module helpers. Both the borrow and parent call must be actual
original parser nodes in the current private caller. The actual resolved callee
parameter object supplies the expected shared Vec domain; the checked operand
must have the actual owned primitive Vec type. Single immutable ampersands,
exact domains, source spans/tokens, current checker/function and unchanged
complete signatures are rejoined. Locals and fresh owned temporaries are allowed.

An additive result qualifier independently rejoins that same original borrow,
parent and signature slot, plus the checked pointee identity. The generic
ownership qualifier and its prior explicit aggregate-borrow refusal remain
unchanged. No public verified/owner flag or cached verdict bypasses it. The
new borrowed value still has to pass the existing complete original helper
body graph, leading shared entry guards, source closing and emission checks.

Flow keeps bounded pending argument loans for the whole synchronous call,
including later argument evaluation, nested calls and branch states. A move or
write to a root under an earlier shared argument refuses immediately; restoring
its availability later cannot erase that conflict. Finally blocks release the
interval on success/failure, so a later legal move/rebinding is allowed. The
same interval applies to existing primitive core shared arguments. A raw-parent index is built once per active function check, still rejoins
the whole original source on every use, and clears in finally; it records no
type or owner verdict. Each flow operation owns its transient state; no source/owner/result cache crosses calls.
Retained shared aliases, escaping shared results, mutable/double borrows,
foreign-module calls and unresolved original source stay outside this route.

Independent eleven-domain native/JS/strict TS caller cases cover repeated roots,
owned temporaries, copied results, nested reads, later legal moves/writes,
missing guards, stale pairs and counterfeit source frames. Move/write/restore
conflicts are drafted for ordinary helpers and direct core calls. The existing
public-core Rust oracle adds shared helper calls followed by a legal move,
without creating another native test crate. All execution, freshness, parity,
receiving/platform/performance qualification and Rust CI remain UNRUN/OPEN.
Full original global namespace/producer closure and whole synchronization remain
unfinished. Reverse ordinary helper borrowing is separately source drafted.
