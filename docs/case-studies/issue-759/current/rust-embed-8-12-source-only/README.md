# Locked RustEmbed sources for translator work

[receipt.json](receipt.json) indexes the complete original `rust-embed`,
`rust-embed-impl` and `rust-embed-utils` version 8.12.0 crate archives, all original
members and licenses, acquisition scripts and HTTP headers. Their archive
checksums match the actual Cargo lock. [complete-source.tar.xz](complete-source.tar.xz)
also retains the initial certificate failure metadata, the successful acquisition
with ordinary TLS verification and the source-only analysis.

No RustEmbed compiler profile or namespace certificate is implemented by this
packet. It grants no code admission or runtime parity. Further work must trace
the complete original derive return/delegate closure and interpolation domains,
bind actual features and exports, and verify generated output grammar with
negative controls before changing translation decisions. No Rust was executed.
