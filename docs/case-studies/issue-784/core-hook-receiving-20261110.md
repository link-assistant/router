## Cause and source change

The fixture still expanded complete JSON observations while other large
observation files used the existing lossless closed JSON DAG transport. Switching
only the Core imports to that transport allowed both complete files to finish
below the unchanged container guard. Five Core cases passed, but the sixth
still failed its original Hash child timeout under both engines.

A finite, separately traced legacy child spent 5,345 ms in Core workloads and
5,824 ms encoding their observations. The existing encoder enumerated every
Buffer byte as an object key. The additive native Buffer JSON encoder instead
checks the fresh direct native byte domain, pinned native owners, inherited
toJSON boundary, storage and length, then retains every numeric byte in the
same canonical DAG. Extra Buffer own fields are ignored as by native
Buffer.toJSON. Length/toJSON overrides, stack, proxies and shared storage still
refuse without invoking input callbacks. Other byte objects retain the complete
original own-key census.

The candidate is a complete source-derived copy in
`complete-native-buffer-json-dag-hook-wire.mjs`. The original codec and its
producer remain byte-identical. An intermediate in-place source proposal was
rejected during contract review; its full source, inverses and restoration are
retained. The actual permanent producer is
`tools/translation/prepare-native-buffer-json-dag.mjs`. Its declared language
rules and empty repository sequence serialize and reparse both complete CST
stages before passing reconstructed source to fresh native binding checks.
The producer requires the unchanged complete original and a whole-source inverse.
Its data and public metadata grant no compiler or runtime authority.

Core changes only its observation import and child observation encoding. All
original test assertions, three cold/warm/same-context workloads, payloads,
case and child deadlines, 64 MiB child output cap and transport bounds remain.
`ROUTER_COMPLETE_CORE_HOOK_TRACE=1` enables scalar phase/RSS diagnostics on
stderr; default-off behavior retains the original empty-stderr assertion.
