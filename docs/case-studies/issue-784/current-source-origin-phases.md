# Complete-source CST substitution domain

[PR #785](https://github.com/link-assistant/router/pull/785) profiles repeated
CST object inspection and cloning in source-generator equations. The new
separate source-origin entry accepts primitive complete sources and rule names;
it cannot accept caller-supplied document nodes, authority fields or saved
validation results. The existing stored-document, named and sequential APIs
remain byte-identical. The new private kernel is derived from the complete
pinned sequential kernel through its owning generator, with whole source/CST
inverses. Three generated files remain below 1,000 lines.

Each actual whole-span substitution checks its source, language, exact expected
text and root boundaries. The existing private source-origin transport then
builds, serializes, parses, independently rebuilds, compares the complete
partition and reconstructs every UTF-16 code unit. Each inverse repeats that
complete transport and must recover the preceding canonical document. The
operation preserves both fixed phases, exact rule IDs, complete documents,
traces and aggregate budgets. Full parser packet authentication and final
physical identities, native host guards and caller descriptor joins remain.
It avoids routing privately constructed source documents through the separate
untrusted-object edit API's repeated inspections. This is a distinct primitive
source operation, not a relaxed stored-document reader or semantic permit.

The complete seven-case receiving file passes under Node 20.20.2 (10.370
seconds observed, peak sampled cgroup use 2,418,069,504 bytes) and Bun 1.4.4
`--smol` (10.690 seconds, peak 2,358,661,120 bytes). Node uses an inherited
384 MiB old-space limit; the installed TypeScript compiler is 5.9.3. The Node
independent deadline audit passes with every original case deadline unchanged.
No resource guard is reached.

Controls compare complete original public/default/private results across Rust,
JavaScript and TypeScript, BOM, CRLF, supplementary characters, lone surrogates,
empty sources, identity edits and opaque slash contexts. Malformed targets retain
their full original diagnostics and false authority fields. Missing/extra fields,
stored documents, getters, proxies, sparse arrays, changed source/aggregate/row
bounds, mixed languages, late caller/rule/source-byte mutations and replaced
native JSON/traversal functions refuse. Recovery calls match the original.

The [whole receiving packet](evidence/current-source-origin-phases.json.gz)
retains all complete original/generated source, reports, resource receipts and
the independent Node audit, with full length/SHA256 readback. This checkpoint
does not yet select the new domain in application producers. Newly executable
production functions remain **0**. Original ASCII deadlines, current compiler
registration, full generation and the mandatory gate remain unqualified.
