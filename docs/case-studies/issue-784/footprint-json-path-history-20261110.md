# Derive-footprint JSON receiving repair

All eight original JSON behavior cases reproduced the completed `e881` CI
failure: their complete historical source equation predated the genuine
path-index update. The runtime implementation itself remained the module used
by those cases. Delivery continues in
[PR #785](https://github.com/link-assistant/router/pull/785).

The receiving fixture now checks the complete physical source against the
existing path-index producer, its native TypeScript bindings, both fixed CST
phases and complete inverses. It retains that history and applies the unchanged
historical substitutions to the verified predecessor. Every original pin,
substitution, inverse assertion and 60-second deadline remains. The original
eight behavioral workloads still compare the old implementation with the
actual current module, including complete hash/callback tapes, mutable and
hostile inputs, JSON hooks, generated JavaScript and strict TypeScript.

The original baseline has eight failures and three independent freezer passes.
After the repair, **all eight JSON cases pass under both Node and Bun**. The
Node independent deadline audit passes with zero breaches; all eight Bun
durations fit the same original source deadlines with a 0.01 ms rounding
allowance. Node 20.20.2 takes 55.30 seconds and local Bun 1.4.4 takes 60.96
seconds for the entire file. Sampled total cgroup peaks are 1,880,219,648 and
2,008,481,792 bytes, below the unchanged 2,866,933,760-byte guard. CI's pinned
Bun is 1.4.3.

The complete authored source proposal receives native TypeScript 5.9.3 binding
checks, Node/Bun syntax checks and serialized/reparsed CST checks before
installation. Its complete review is 4,023,775 decoded bytes, SHA-256
`f28d6c30f42d3b01fc44cf97270a601ad68a13d9f24ff83d994c1123ede19fd0`.
