# Complete CST phase transactions

This investigation accompanies [PR #785](https://github.com/link-assistant/router/pull/785).
It reduces repeated authentication within one explicit source-equation operation.
The original whole compiler deadlines, missing owned matrix and strict parity
remain unresolved. It adds zero newly executable production functions.

The callback source producer previously opened a separate authenticated parser
operation for each transport, serialization, edit and inverse. The new
`transportConcreteSourcePhases` operation retains the complete before, middle
and after sources in one bounded transaction. Its actual language edit and
repository edit each serialize and reparse the full canonical document. Both
inverses do so independently. Every complete canonical result must equal the
independently transported original row.

The generated private sibling retains the complete 70029-byte original executor
as its prefix, plus a native-selected copy of its original transaction. The old
executor, source archives and APIs stay byte exact. Physical parser authentication
runs before and after the new operation; original aggregate bounds, intrinsic
checks, final source identities and complete input descriptors remain required.
There is no caller callback, private frame or new result/verdict cache. Traces
report the actual new complete edits rather than a previous producer's rule IDs.
