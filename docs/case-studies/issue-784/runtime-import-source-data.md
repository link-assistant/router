# Bun runtime-import source composition

This source draft accompanies [PR #785](https://github.com/link-assistant/router/pull/785).
The original runtime-import source producer pins actual installed TypeScript
5.9.3 callable text against its complete 9112572-byte source. Bun changes that
text. The first refusal is `Debug.shouldLog`; a complete native syntax experiment
also finds boolean and conditional rewrites in `createSourceFile`. Comparing
whitespace or accepting similar syntax would not establish original callable
identity. Both failed experiments and their complete source comparisons remain
retained. The direct producer's original Bun refusal remains exact.

Only source composition now obtains the complete original producer result from
a fresh Node process when its caller is Bun. The fixed child runs the original
public preparation API with its original native callable checks. Its compressed
source-data plan is bounded, decoded and checked against the whole installed
compiler, the four archived originals and current physical files. Both CST
phases are serialized and reparsed again in the receiving engine; full native
source grammar and final input joins are checked. No runtime loader identity,
private issuer, cached compiler verdict or executable permit crosses processes.
Bun's original runtime fallback remains selected.

The producer's internal source equation also uses the shared complete CST phase
transaction. Its original hash sites, native copied declarations, binding checks
and physical-source joins remain exact. All four generated runtime afterimages
stay byte exact. The entire original 31441-byte producer is archived with its
original pins; native-selected edits and complete native/CST inverses derive
the new producer. Tests compare every untouched function body to that original.

The two complete new cases pass in Node 20.20.2 with the independent deadline
audit: 23.17 seconds, peak sampled cgroup 2143219712 bytes. Bun 1.4.4 also passes
both cases: 33.10 seconds, peak 2684846080 bytes. Each case retains its original
60000 ms deadline. The source proposal is captured completely before install.
An earlier fresh-child probe against the original standalone CST operation
also retains the complete 23643872-byte plan and unchanged four output hashes;
that 42.46-second probe is not a parent-test performance qualification.
After the receiving guard also explicitly joins the intermediate language
source to its first CST phase, the whole Bun file passes again in 33.86 seconds,
peak sampled cgroup 2683641856 bytes. The generated producer remains unchanged.

The unchanged whole runtime-import parent file finishes in both engines. Node
has seven TAP passes but its independent audit fails the original final case:
163909.893825 ms exceeds 60000 ms. The complete command takes 248.39 seconds,
peak sampled cgroup 2237566976 bytes. Bun has six passes and the same final case
times out after reporting 120916.88 ms; the command takes 204.83 seconds, peak
2812198912 bytes. Neither attempt needs an owned resource stop. Their first
source-equation cases remain within 60000 ms at 47775.68 and 50059.05 ms.
These are failed parent qualifications, preserved with complete terminal streams
and Node's full independent audit. No assertion or deadline changes.

The integrated full gate still requires separate qualification. Source-only
checks add zero newly executable production functions and establish neither
complete parity nor CI readiness.
