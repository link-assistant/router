# Complete static-consumer generations

The original complete test failed because it compared frozen historical leaf
consumers with current consumers that have an independently changed producer
scope. The pinned historical files and their checksums remain unchanged. Each
generation now compares its complete unmemoized consumer with its complete
memoized consumer. Both directions retain exact lexical source equations,
serialized/reparsed CST phases and the lockfile TypeScript 5.9.3 syntax check.
Every original proof field, refusal, source byte and callback tape is compared.

Relocated leaves are foreign to the genuine private producer scope. A separate
case checks that the genuine current consumer retains its private producer ABI
and the foreign current copy still refuses the unproved attribute producer.
These leaf checks do not establish whole issuer or compiler bootstrap parity.

The cold child originally exceeded the operating system's argument-size limit
when its script included the complete Cargo lockfile. Passing the whole script
through stdin worked in Node but produced invalid gzip output under Bun. The
final harness writes the unchanged complete script to an owned temporary module
and runs that file. The original 10-second child deadline, transport bounds and
all original case deadlines remain unchanged. Temporary files are removed by
the existing whole-file cleanup.

All 10 cases pass in Node 20.20.2 and Bun 1.4.4. The independent Node deadline
audit passes. Node took 53.686 seconds with 2,714,394,624 peak sampled cgroup
bytes; Bun took 40.96 seconds. These are whole-file observations, not a measured
performance gain. The [complete evidence packet](evidence/current-static-consumer-cohorts.json.gz)
retains all failed drafts, original/current whole sources, complete logs,
resource receipts and Node audits with verified decoded lengths and SHA256s.
