# Shared f64 receiver repair

This local source batch repairs the shared receiver first reported for the
unchanged `safe_number` body in forward CI. It does not establish complete
production generation, strict parity or issue completion. Delivery remains
[PR #785](https://github.com/link-assistant/router/pull/785).

## Behavior and source boundaries

The reusable language rule admits `is_finite`, `is_nan` and `floor` on a
source-qualified shared `f64` reference chain. Each actual reference layer
uses the existing primitive Copy read. The receiver runs once, IEEE values
and negative zero are preserved, and capability exceptions retain identity.
The existing explicit-read profile still has `implicitMethodAuthority: false`.
Actual primitive Copy evidence also qualifies immutable `f64` pattern bindings;
this supplies no nominal, mutable or generic Copy authority.

Method lookup requires the original private caller scope, complete visible and
anonymous trait closures, inherited members and pinned common prelude members.
An applicable reference trait can precede the primitive inherent candidate;
therefore competing, unresolved, locally produced and anonymous imports remain
conservative refusals. The complete source evidence follows the original
[method lookup rules](https://github.com/rust-lang/reference/blob/9571d4d38cc580bd9fe926f97fccd98f215564a9/src/expressions/method-call-expr.md).
Both original licenses are retained with the reference and Rust 1.89.0 sources.

The caller witness is a canonical opaque JSON string. Original coordinates
survive relocation without adding fields to the existing relocation exception
tables. The string grants nothing without its exact privately issued value and
revalidation of the original caller scope. Whitespace changes, changed methods
and fresh unissued witnesses refuse. No public metadata is a semantic permit.

Plain joint `&&f64` types preserve the actual original token array. Other joint
forms keep the existing parser: named and static lifetimes, fixed integers and
borrowed strings remain executable. This does not newly qualify implicit method
selection on every named joint-reference form. Mutable references, `f32`, nominal
shadowing, unknown generics, borrowed UFCS operands, sign predicates, escaping
borrows and floating constants keep their existing refusals.

## Failed drafts and remaining requirements

the original-versus-draft joint-reference comparison remain in the archive.
That comparison caught four real parser regressions in the first draft; the
narrowed parser and complete named/static regression case preserve the original
behavior. Two authored lifetime fixtures were invalid and were corrected with
their failed streams retained. The first source producer omitted its required
rule error message; its next attempt exposed a terminal-newline line-count
mistake. Both attempts remain failed evidence. The final producer counts source
lines correctly and preserves the original below-1,000-line requirement.

`rust/tests/json_shared_f64_translation_test.rs`; it is **unrun**. No local Rust
tool is invoked. Actual exported-compiler receiving, whole-root production
generation, current canonical/matrix/owned outputs, strict parity, the complete
JavaScript gate and current-head CI remain unfinished. Rust CI remains gated on
all required JavaScript stages passing for the same SHA. The published
