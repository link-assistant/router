# Primitive-source producer adoption

[PR #785](https://github.com/link-assistant/router/pull/785) selects the separate
primitive-source CST domain through the actual owning generators for current
ASCII assets, Unicode predicates, unit matching, reverse ASCII, private-analysis
retention and current runtime imports. The generators retain complete original,
named and sequential source histories and independently serialized/reparsed
two-phase equations with full inverses. Generated consumer changes select the
new import; the runtime helper input vector includes its complete physical
dependency closure. Public stored-document and previous transaction APIs stay
exact. Native selection, binder checks and final source identities still run.

This also repairs the published CI refusal of the complete current named-core
and named-ASCII producers. Their owners now recognize the independently checked
complete sequential history rather than accepting arbitrary physical changes.

The original complete four-case ASCII file remains unchanged. Its initial
partial adoption reports four TAP passes but fails the independent deadline
audit: 74,399.735 ms against the original 60,000 ms. After all prerequisite
producer adoptions, the same complete file passes all four cases and its audit:
the first case takes **49,748.538 ms**. The observer records 52.123 seconds,
peak sampled cgroup memory 2,763,677,696 bytes, and no guard stop.

All four complete receiving files pass under Node with **13 cases**, their
unchanged original deadlines and the independent source/deadline audit. The
observer records 258.149 seconds and peak sampled cgroup memory 2,621,911,040
bytes. The tests compare whole original operations, source histories, native
copies and bindings, complete CST documents/inverses, and hostile predecessor
refusals. Node is 20.20.2 with inherited 384 MiB old space; TypeScript is 5.9.3.

The original whole Bun ASCII attempt stops at the unchanged cgroup memory guard
after 21.002 seconds, peak 2,867,032,064 bytes, exit 143, without a complete case
report. It remains **unqualified**. No test is filtered, moved outside its case
or given a longer deadline. Bun is 1.4.4 with `--smol`; CI's pinned 1.4.3 still
requires independent qualification.

The complete four-file Bun receiving attempt reports 12 passing cases before
the memory guard interrupts its final runtime-import file: 258.220 seconds,
peak sampled cgroup memory 2,868,260,864 bytes, exit 143. The final case and the
whole Bun cohort remain unqualified. All complete failed streams are retained.
