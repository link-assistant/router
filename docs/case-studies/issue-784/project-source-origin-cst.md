# Project source-origin CST adoption

[PR #785](https://github.com/link-assistant/router/pull/785) selects the existing
private source-origin transport for the complete physical-source batch in
the module graph resolver of `tools/translation/project.mjs`. A production CPU diagnostic attributed about 14 of its
40 seconds to the former CST batch path. The new path still builds every CST
twice, serializes and reparses canonical JSON, compares the complete partition
and reconstructs every source code unit. Private parser authentication, host
guards, aggregate limits and final caller/source joins remain mandatory.

The owning producer `prepare-project-source-origin-cst.mjs` derives the complete
new module from the pinned complete `forward-concrete-syntax.mjs`, and changes
the actual module graph resolver's batch import and call through separate language and
repository rules. Both complete file equations retain serialized/reparsed CST
phases and whole inverses. Independent native binding review uses installed
TypeScript 5.9.3. The original forward module is byte-identical; single-source
module graphs and standalone, ordinary batch and stored-document APIs retain their
original paths. The source-origin batch has its documented grouped observer
contract and accepts no stored document or caller validation verdict.

Four fresh Node 20.20.2 processes measured the entire production library module graph
and fresh derive context, with a 512 MiB heap. The candidate-first ABBA order
keeps complete Rust/Cargo inputs, source paths, module graph identities and compiler
sources. All four entire context outputs have 397 modules, 419 certificates,
10,137,192 bytes and SHA256
`2d37a69b9373a78fb1f40bfba3051e84699daf381f3efa584a8589aa612ad6a3`.

No production function becomes newly executable through this change.

The complete 12-case focused Node cohort passes its independent original
deadline audit in a 44.030-second command, with peak sampled cgroup use
1,754,136,576 bytes. The same complete files pass under Bun 1.4.4 in 40.806
seconds, peak 2,339,586,048 bytes. Neither reaches the resource guard. Controls
cover the complete producer, native bindings, both phases and full inverses;
changed original source, partial installation and altered generated bytes;
Unicode, CRLF, long trivia, lone surrogates, malformed input and chunk boundaries;
dense aggregate splitting, absolute bounds and forged inputs; actual module graph
callbacks, inline coordinates and changed sources; and replaced JSON/traversal
hosts refusing before replacement callbacks run.

The broader five-file original CST boundary cohort fails: 39 cases pass and the
complete three-build/JS/strict-TS case in
`corpus-native-parse-provenance.test.mjs:164` takes 251,086.706483 ms against its
unchanged 60,000 ms deadline. The command exits 1 after 479.017 seconds, peak
sampled cgroup use 2,093,510,656 bytes, without a resource stop. Its independent
deadline audit retains the failure. The broader Bun repeat is unrun; it cannot
repair this failed Node qualification. Complete generation, compiler
registration, strict parity, the mandatory local gate and current-head CI remain
unqualified. Rust is not executed. This change establishes no additional privacy
or universal client/account guarantee.

Complete input/output packets, the original full author proposal, CPU sampling,
raw test streams, resource receipts and all three independent Node audit
directories are retained in the source checkpoint's Git history. The subsequent
`project-source-origin-copy-retirement.json.gz` custody receipt identifies each
whole immutable blob and its full readback hash if an inactive working copy is
retired. It records storage cleanup only and supplies no compiler authority.
