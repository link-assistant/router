# Complete canonical output custody

The canonical producer now has an opt-in path that retains every complete
computed output before returning the original freshness result. The ordinary
`regenerate` function is unchanged. The CLI enables custody only when
`ROUTER_BULK_DRAFT_DIRECTORY=js/node_modules/.bulk-drafts`; retained and owned
CLI branches keep their original dispatch. The independent canonical CI job
uploads this complete directory even when its original check fails.

Each attempt records complete Rust/Cargo input fingerprints, the tracked source
selection and Git head, current compiler/profile fingerprints and the complete
installed TypeScript inputs. It checks freshness before and after custody,
checks every expected output against the private plan's complete byte census,
and reads back every compressed member and the manifest. Failed attempts remove
only their own new directory. These are unqualified output bytes: custody cannot
issue source, semantic, private-plan, executable or runtime-parity authority.

Both complete original bulk/CLI sources are pinned separately. A two-phase
source producer transports and reparses the complete CST, verifies the complete
inverse, and checks detached native ASTs and bindings using lockfile TypeScript
5.9.3. Existing retained/owned source producers derive their complete outputs
from the new bulk source. The workflow producer similarly retains its complete
source inverse. No mandatory command or original budget is removed or weakened.

Final complete custody receiving files pass all six cases under Node 20.20.2
(14.990 seconds) and Bun 1.4.4. The tests cover complete Unicode/CRLF bytes,
corruption, incomplete/duplicate/unsafe outputs, linked destinations, the actual
canonical producer, unchanged original failures and input mutation. The complete
Node workflow control file passes all 38 cases (35.757 seconds). Five original
source/workflow checks also pass in 8.451 seconds.

Failed attempts remain explicit. The first Node custody attempt hit the unchanged
container memory guard before running cases. An initial workflow control run
failed because a new diagnostic omitted the existing mandatory-evidence wording;
the corrected complete Node file passes. The additional complete Bun workflow
control file fails its original default 5-second deadline on the mandatory-stage
case (5.323 seconds). Another case reports 13.364 seconds under that implicit
deadline despite Bun reporting a pass, so the Bun control cohort is unqualified.
No test body or deadline was reduced or increased.

The [complete receiving packet](evidence/current-bulk-custody-receiving.json.gz)
retains the whole source proposal, complete pass/fail streams and resource
receipts, with complete member readback. Closing inactive task-owned Git object
descriptors and advising away only their closed pages reduced observed cgroup
usage from 2,665,082,880 to 2,226,487,296 bytes; no Git object was deleted.
