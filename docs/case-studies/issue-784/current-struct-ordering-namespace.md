# Original struct ordering namespace

[PR #785](https://github.com/link-assistant/router/pull/785) adds the ordinary
named/unit struct branch to the existing source-backed Ord/PartialOrd namespace
rule. The original unit-enum branch remains independently exercised. This is
construction syntax, not executable trait dispatch, Copy, Drop or constness.

The rule retains the actual Rust compiler struct expansion, field-access,
field-definition and right-fold recipes. Each field keeps its original type
round trip and source span. The emitted positive constructor tree closes every
comparison, immutable borrow, match and Equal/Some/cmp pattern. Zero, one,
three and 128 fields exercise Fieldless, Single and Combine. Packed, tuple,
generic, conditional, macro, unknown and competing-owner inputs remain refused;
copied private certificates cannot issue authority.
