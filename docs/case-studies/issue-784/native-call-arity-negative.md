# Native call arity: unsuccessful deadline candidate

This investigation belongs to [PR #785](https://github.com/link-assistant/router/pull/785).
The tested candidate was removed from active production sources because it did
not repair the original deadline. It grants no new executable coverage.

The candidate used the sole native call signature's declaration for arity;
overloads, absent declarations and JSDoc classes retained the original resolved
signature query. An additive checked source evolution followed all existing
producer layers and preserved their archived pins and original public APIs.

A finite installed TypeScript 5.9.3 diagnostic compared 12,711 current calls;
8,884 had one signature and every compared arity/rest and gap fact agreed.
Both queries shared one fresh program, so their query order establishes no
independent performance gain. Complete focused Node and Bun receiving,
inference, regeneration and composition files passed. The real producer's
freshness check passed for all 11,591,744 native output bytes.

The unchanged original nine-case Node file then passed its assertions, but
case 8 took **74,129.437676 ms against its original 60,000 ms**. The independent
complete-source deadline audit failed. The full invocation took 263.213897 s,
peaked at 2,401,984,512 sampled cgroup bytes and did not hit the resource guard.
Passing the focused files and freshness did not qualify the optimization.

The [complete evidence archive](evidence/native-call-arity-negative.tar.xz) and
[receipt](evidence/native-call-arity-negative.receipt.json) retain the candidate
production sources, additive profile, receiving cases, source patch, complete
proposal and comparison, all selected check logs and three full Node audit
directories. Every member was decoded and SHA-256 verified before restoring
the three active tracked files to `0e2341ac9505744e993bda69587b5777c1594849`
and removing the two new active profile/test files.

No original deadlines or whole-file scopes changed. The complete JavaScript
gate remains failed; strict parity, remaining current generation, original
source-size bounds and universal client/account privacy remain unfinished.
No Rust tool ran.
