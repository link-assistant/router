# Dependency scope and retained versions

The starting manifest scan used the tracked Git tree. In addition to the issue listing, it found the npm projects under `js`, `ts`, `ui`, and `scripts/ci`, the PyPI package under `packages/python`, the `rust/fuzz` Cargo workspace, standalone Rust experiments, and the Nix flake. Go, Java and PHP client material uses generated fixtures and downstream tooling. The scan found no consumer-owned `go.mod`, Maven or Gradle build, or `composer.json`. Terraform and Helm manifests were also absent.

The captured Proxypal input for issue #37 and the captured test-sharder incident for issue #759 are provenance records. Updating their copied dependencies would change the historical inputs. The active sharder is under `experiments/issue-725/test-sharder`. The standalone `experiments/issue-372` pins earlier versions to reproduce the behavior being investigated. The npm and Cargo inventories include the captures they scanned so their historical pins can be traced to paths.

The npm registry `latest` tag for `@iarna/toml` is 2.2.5. Both Router implementations intentionally use the publisher's newer 3.0.0 TOML 1.0 release, distributed under the `toml-1.0.0-rc.1` tag. Retaining 3.0.0 preserves the parser semantics used by the current sources. [Publisher dist-tags](https://registry.npmjs.org/-/package/@iarna%2ftoml/dist-tags).

The Node 20 and 24 jobs exercise supported consumers. The active TypeScript stage also uses Node 20.20.2, whose named `util.types.isProxy` matches the private compiler's source-integrity checks. The tested Node 22, 24 and 26 releases expose an anonymous native function. Node 26.13.1 serves the other three JavaScript stages and release tooling. The CI steps use the npm bundled with each Node release. npm 12.2.3 requires Node 22.22.2, Node 24.15.0 or Node 26 and later, so updating every job to it would lose the Node 20 check. TypeScript 5.9.3 still supplies the JavaScript compiler API used by the translation profiles. The public declarations use TypeScript 7.0.2. [npm 12.2.3 metadata](https://registry.npmjs.org/npm/12.2.3), [TypeScript API transition](https://devblogs.microsoft.com/typescript/announcing-typescript-7-0/).

The Python package continues to support 3.10. Only the audit tool group needs 3.11 and later. Restricting that group allowed uv to resolve a patched `filelock` across the audit environments. `importlib-metadata` on older Python resolves within `keyring`'s marker and version bounds. The Go checksum file also records the validator's upstream test dependencies, which are outside the probe's build graph. Maven selects transitive dependencies through the upstream POMs, including the Kotlin and Okio versions declared by OkHttp. The registry table records the selected versions separately from independent artifact releases.

The archived strict CI lane remains suspended under the maintainer instruction in #785. Its old fixed-gate source inventory and neutral compiler profiles need a separate qualification against the currently retained sharded workflow. Changes here keep the original stage partitions and commands. Dynamic Debian and Alpine packages continue to come from the pinned distributions' supported repositories so the image build receives their security updates.

The initial dependency table includes immutable incident captures and standalone probes. The active tables and checks cover package managers with maintained install roots. Publication credentials, live vendor accounts and default-branch release jobs remain controlled by their existing GitHub environments.
