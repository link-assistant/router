These generic pure time adapters use the semantic contracts of Rust 1.89.0 `std::time::Duration`, implemented in the official [core/time.rs](https://github.com/rust-lang/rust/blob/1.89.0/library/core/src/time.rs). Rust is licensed under MIT or Apache-2.0. This repository implements the contracts independently; it does not replace individual Router Rust functions with handwritten JavaScript.

The downloaded source SHA256, byte count, function const markers and Router lexical usage inventory are recorded in `../fixtures/time-contract-provenance.json`. The source was inspected without running Rust. The algebraic record is a lowering representation of exact u64 seconds and normalized u32 nanoseconds, not a claim about physical Rust memory layout or permission to access private Rust fields.

`time-contracts.mjs` registers stable pure method/type signatures, immutable Option/Result layouts, explicit `pure: true` and source-grounded `constEligible` metadata. Trait arithmetic, comparisons, `Default`, floating constructors and float-error string conversion are pure but not const in this pinned profile. ZERO/MAX constants are registered separately. The registry must preserve these distinctions instead of treating deterministic host calls as automatically const or allowing arbitrary source-private constructors.

`time-runtime.mjs` uses BigInt for fixed integers, throws on malformed checked values or source panic paths, and returns real typed Option/Result outcomes. Floating construction decodes the original IEEE-754 binary64 rational and rounds to nanoseconds with ties to even; it does not multiply a rounded JavaScript Number by a billion first. There is no clock, timer, filesystem, network or environment capability in the runtime.

Independent fixtures exercise the semantic checker layouts, u64/u32/u128 boundaries, borrow/carry, underflow, division remainder, saturation, source panic distinctions, immutable owner fields, binary64 ties, nanosecond carry, finite-domain errors and const metadata. These prove the adapter subset in Node/Bun, not whole Router execution. The frontend registry and generated-code integration are separate obligations. f32, unstable unit constructors, clocks, sleep, chrono, debug formatting, iterator Sum and assignment/borrow semantics remain explicit limitations.
