# Owned Unicode predicate source inputs

`originals.json.gz` retains eight complete predecessor rows: seven physical
Router core/compiler files and one empty preimage for the new Rust oracle.
The capture records Root's exact source HEAD. Every row retains its complete
UTF-8 source, byte length and SHA256. The producer checks both archive and
decoded hashes before applying its fixed source equations.

`application.json.gz` retains the complete original `login_pty_backend`,
`model_resource`, `subscription_usage_normalize` and crate-root sources, both
workspace/package manifests and the lockfile. These seven inputs preserve
the real parents of the selected functions. They are not a closed executable
crate graph or evidence that any complete parent is admitted.

Rust 1.89 Unicode 16 property sources are reused from the existing
`whitespace-iterators` and `utf16-fixed-f64` profiles with their existing pins,
URLs, MIT/Apache notices and licenses. The new source-property reader verifies
their complete original bytes and retains their serialized/reparsed CSTs.
It does not fetch upstream source or execute a Rust compiler.

Native Rust library implementations intentionally remain untranslated. All new
source generation, JavaScript/strict TypeScript receiving, Rust CI and actual
whole-project coverage measurement were unrun at the source checkpoint.
