# Shared f64 receiver source evolution

The two complete original compiler modules are copied from Router commit
`e88183bb894b9ea62c9d6ae170c3fc099047685b`. The three complete helper modules
are authored in this change. Router's repository license applies to these
modules. The manifest preserves every original byte and declares separate
ordered language and repository substitution sequences.

`prepare-shared-f64-method-receivers.mjs` verifies full archive hashes, both
serialized and reparsed CST phases, complete inverses, native grammar and fresh
TypeScript 5.9.3 module binding checks. These source equations supply no semantic
or runtime authority and do not qualify a complete receiving repository.
