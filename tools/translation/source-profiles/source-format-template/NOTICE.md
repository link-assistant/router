# Original bounded formatting helper inputs

The complete `rustc-literal-escaper` 0.0.2 and `unicode-xid` 0.2.6 source,
Cargo manifests and both Apache/MIT licenses are retained in their original
bytes. The capture receipts retain crate hashes and member hashes. The
literal escaper crate is also retained at `../cooked-byte-char/`; its existing
retrieval history is preserved. Unicode XID is the dependency pinned by the
Rust 1.89 workspace lock. The full original Rust 1.89 `rustc_lexer` library is
copied from the existing floating-standard source archive, with no download.

`manifest.json` pins every compressed archive, decompressed member and original
capture receipt. The template parser itself comes from the independent pinned
`format-arguments` profile. The executable control program does not grant
caller namespace, Display trait, compiler callback, allocator, Drop or complete
runtime authority. It interprets a bounded named-capture route and refuses
unresolved helpers, non-ASCII capture names and format specifications. Other
formatter contracts remain separately checked by the existing formatter.
