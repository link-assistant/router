# Original Rust parser sources

Complete original Rust 1.89.0 attribute, path and core parser files are retained as gzip archives. The manifest records their original Git blobs, URLs, decoded/encoded sizes and SHA-256 identities. Rust is copyright its contributors, dual MIT/Apache-2.0; both original licenses are retained. Existing upstream pins are unchanged. Loading these sources grants no namespace or runtime permission. Every proposed rule and receiving case remains unrun during bulk drafting.
