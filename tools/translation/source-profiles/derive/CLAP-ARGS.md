# Original bounded Clap Args source route

This frontend uses the unchanged, licensed Clap 4.6.7 and Heck 0.5.0 archives
already pinned by Cargo.lock. It audits two additional existing archive members:
clap_builder `src/builder/value_parser.rs` and Heck `src/shouty_snake.rs`. The
profile now contains 234 audited members. Original archive bytes, existing
member checksums, all 804 Router Rust files and Cargo inputs remain unchanged.

The route accepts original nongeneric module-level named structs with one to
32 `Vec<String>`, `Option<String>`, or primitive boolean/integer fields, subject
to existing fragment budgets. Bounded field helpers preserve literal strings,
booleans, decimal integer defaults, macro-free parser/default paths and closed
integer ranges. Bare `long` retains original casing. Arbitrary executable
expressions, generic/custom payload types and flatten/subcommand effects stay
refused. Default-feature ASCII documentation uses the separately source-owned
paragraph, period and short/long documentation route.

The complete original source and declaration span supply associated container
documentation, including the line immediately before the derive attribute.
Original field doc comments keep their token-tree attributes and precise source
spans. Documentation period removal and the otherwise absent `long_help` and
`long_about` methods are retained. Field IDs preserve the original written
identifiers; long flags use kebab casing and value names use shouty snake casing.

Original source rules and generator function spans verify the actual Args
feature reexport and registration, field kinds, helper/default/group bindings,
type extraction, action selection, documentation and method generation.
Private fragments instantiate every selected constructor, updater,
augmentation, group, parser, method and outer-impl quote template. Both original
`raw-deprecated` output branches are retained separately and roundtrip through
semantic syntax. The resulting syntax contains two trait impls and the original fixed `clap::value_parser!` and scalar `concat!` calls.

The actual original `value_parser` declarative definition is compiled and
expanded separately for each actual original default-parser type capture. Its output remains one expression
block containing no macro/attribute syntax or exported declarations. This
expansion does not execute the parser or resolve runtime trait dispatch.
Generated builtin attributes and the Clap macro path also require separate
original context checks. An unproved sibling Clap output or generated attribute
shadow cannot bootstrap another declaration's namespace certificate.

The token-tree delimiter lookup now checks own properties, so original
`constructor` and `toString` identifiers preserve their token identity.

The whole unchanged `src/verification.rs` gains its original VerificationArgs
declaration and seven executable owners: SCHEMA, SKIP_LOG, tests, unit, AREAS,
status and results. The bounded pre-Args gate comparison observed zero to seven
executables and 30 to 20 refusals. Tests execute the original status/results
behavior and constants in emitted JavaScript and separately strict-compiled
TypeScript. These observations concern that complete source entry, not full
corpus parity or CLI execution.

The certificate retains `generatedImplBehavior` and joined `bangMacroComplete`
as false. Generator error streams, other derive owners, richer input routes,
standard matches/formatting macro contexts, Args/FromArgMatches execution and
full runtime parity remain separate obligations.

The scalar source-output draft covers the complete unchanged ManagementArgs
and EmergencyArgs source entries. Constructor/updater missing-value branches,
primitive action selection, required/default selection, typed defaults, explicit
parser paths, ranges and complete documentation instantiate the original quote
slots. Both original raw-deprecated feature outputs remain separate. The historical draft initially withheld namespace admission because original
caller/ancestor bang closure was unproved. The separately audited bounded
`builtin-derive-bang/SCALAR-OUTPUT.md` route now closes the independently selected
Debug, Clone and Default outputs and the actual concat caller for these complete
source entries. A Clap quote alone still cannot close sibling invocations.

The separately licensed `source-profiles/clap-concat` inventory retains complete
Rust 1.89 original compiler sources. It proves a bounded selected builtin
literal route: ordinary unsuffixed unescaped printable ASCII string literals,
commas and optional trailing comma become an ExprKind::Lit string with no
attributes or child invocations. Original parser, eager expansion, collector,
placeholder visitor, literal decoding, accumulation, string AST constructor and
MacEager result sources are retained with precise source hashes and spans.
Unsupported literals, eager macros, escapes and error outputs remain refused.
This private expansion proof does not resolve the caller's macro owner, confer
namespace authority or execute generated Args traits. The source-scope guard
rejects concat shadows, unresolved relevant/glob imports and incomplete bang
ancestors, and requires a separately sealed builtin binding certificate. That private
caller certificate now follows the complete selected output and original
core/std prelude source chain; unknown sibling export effects remain refused.

Bounded tests preserve the formerly refused helper/doc strings as positives,
replace their obsolete refusals with executable/effectful inputs, and exercise
generated literal outputs in JavaScript and strict-compiled TypeScript. Exact
historical failed and successful vectors remain under
`/tmp/router-759-derive-cycle-20261013-scalar-v1`; they do not claim an original
scalar namespace/runtime coverage gain or whole-library completion.
