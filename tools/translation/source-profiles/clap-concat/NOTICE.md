# Original Rust concat literal source profile

Complete original source members are pinned to the Rust 1.89.0 release and
listed with official source URLs, byte lengths and SHA-256 digests in
`manifest.json`. Newly stored files use deterministic gzip containers; sibling
profiles supply unchanged original AST/core/build and license members.

Rust is licensed under MIT or Apache-2.0. The full original license files are
referenced in the manifest and retained in the existing licensed compiler
profile. No source member is rewritten or replaced by a JavaScript handler.

The source proof selects only unescaped printable ASCII string literal inputs
and the successful expression-literal sink. It retains complete unsupported
and error branches as source evidence without claiming to implement them.
Actual caller macro binding, joined ancestor output closure, generated trait
execution and whole-corpus parity remain independent obligations.
