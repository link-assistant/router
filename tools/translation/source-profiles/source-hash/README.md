# Original Hash output confinement

The pure Hash route consumes the complete original Rust 1.89 Hash entry,
callback, dynamic generic substructure pipeline and positive AST constructors.
Original path_std/pathvec_std declarations, imports and actual calls expand with
private original token lineage, including nested forwarding. Complete visitor
backing remains retained for bounded field TypePath traversal.

The original generated method has shared self, mutable state, one __H type
parameter with the actual Hasher bound, and unit return. Named fields produce
one borrowed field Hash call and expression statement each. A singleton unit
enum has an empty block. Multiple unit variants follow the original Unify route:
a discriminant Init local followed by a Hash call; no match is emitted. The
original singleton prefix/format recipe flows only into an Ident/Symbol leaf.
It does not grant format, intrinsic, Hash or Hasher execution authority.

Only bounded nongeneric named/unit structures and nonempty unit enums are
selected. Generic/cfg/repr/packed/tuple/payload/discriminant/default-field/type
macro inputs, unknown helper owners, caller shadows and compiler error paths
remain refused. Positive output comparison rejects copied issuers and changed
parameters, generic bounds, local initializers, expressions, items and macros.

The caller joins require a genuine existing input certificate. The complete
original lexical census finds ten Router Hash derives across eight files. On
this isolated predecessor lineage, only six have such input certificates: four
source-output proofs succeed and two retain exact helper-owner refusals. Four
standard-only declarations have no certificate under the existing issuer rule.
No certificate is fabricated to erase those obligations, and standalone complete
file observations do not prove whole-crate ancestor closure.

Runtime trait dispatch, mutable reborrows, intrinsic values, allocator behavior,
Copy, no-Drop and const execution remain uncompiled. No original or generated
method admission is added by this namespace route.
