# Original Rust ordered-map namespace inputs

Four complete original files from Rust 1.89.0, immutable revision
`29483883eed69d5fb4db01964cdf2af4d86e9cb2`, are retained as deterministic gzip
archives without rewriting their source. The manifest records original URLs,
full lengths and both compressed and decoded SHA-256 values. Nine already
retained complete Rust sources are reused by relative path.

compile the standard library, establish a receiving rustc sysroot, run unsafe
allocation code, or prove trait dispatch/runtime parity. All new routes UNRUN.
