# Rust prelude member evidence

These complete Rust 1.89.0 sources and both licenses are copied from rust-lang/rust.
Every source, original byte length, SHA-256 and upstream URL is in manifest.json.
Copyright the Rust Project Developers; licensed under MIT or Apache-2.0.

The selected traits cover the common core/std preludes and their 2021/2024
additions, with shared supertraits retained. Their complete member declarations
are checked only for absence of is_nan, is_finite and floor. Prelude sources,
reference Copy and primitive f64 source contracts remain distinct evidence.
This data supplies neither arbitrary trait execution nor a caller namespace.
