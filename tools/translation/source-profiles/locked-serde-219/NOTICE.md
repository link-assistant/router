# Complete locked Serde originals

These two complete crates.io archives contain Serde and serde_derive 1.0.219. Their checksums are those in the complete official Cargo.lock at Cargo commit c24e1064277fe51ab72011e2612e556ac56addf7. Every original archive member is retained, including both LICENSE-MIT and LICENSE-APACHE in each archive. The complete raw lock is retained losslessly in deterministic Cargo.lock.gz, with both raw and compressed pins. The adjacent manifest records all 54 file lengths, SHA256 hashes and original archive modes; it does not grant trait, derive, namespace, feature or runtime authority. No source was acquired for this change: the previously retained official lock and checksum-verified archives are copied byte for byte.

Upstream: https://github.com/serde-rs/serde ; archive URLs and the full official Cargo lock URL are in manifest.json.
