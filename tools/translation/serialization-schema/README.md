This draft extracts bounded serialization layouts from privately captured original Rust source, tracked module graphs, locked derive inputs, and checked namespace footprints. Written field types use the production source namespace resolver with consuming-module visibility; checked public reexport routes may retain private canonical targets, while new written suffixes receive their own privacy checks. Private DTO roots remain available for source introspection. It preserves qualified owners, written type paths, declaration/field/variant/attribute spans, helpers, original source hashes and actual Cargo dependency identities in a separate checked metadata grammar. Both JavaScript and TypeScript descriptor emitters consume that same source-checked metadata.

Supported projection: named structs; unit enums with pinned ASCII rename/alias rules; internally tagged named variants; checked prelude String/i64/u32/Vec and omitted Option fields with standard `Option::is_none`. Custom hooks/default functions, unproved namespaces, shadows, globs, tuple layouts, generics, nested Option ABIs and additional serde policies refuse explicitly. Source certificates establish layout and namespace inputs; they do not implement generated traits or establish whole serde/runtime parity.

`generateSerializationSchema` returns metadata and both descriptor artifacts without writing or replacing native code. Supply the actual existing `affinitySchema` as `expectedDescriptor`; equality must pass before a later coordinated native descriptor replacement. This source-only draft has not run its extractor, tests, generators, TypeScript checks or runtime regression suite. The verified native interpreter and its separate 140/149-case evidence remain unchanged. No output is labelled generated until the actual checked producer has executed under a Gate grant.

Focused future scope: `node --test tools/translation/serialization-schema/serialization-schema.test.mjs`, then the matching Bun suite. The authored 17 tests exercise the original seven reachable types, JS emitted runtime data, precise aliases and rename changes, source drift, forged contexts/metadata, shadows, unsupported hooks, duplicate leaf owners and original projection comparison. Strict TypeScript emission validation and the original 149-case runtime regression scope must be coordinated separately before replacing the native descriptor. Inputs require original tracked Rust sources, Cargo files, existing translation modules and pinned source-profile archives; no dependency installation or Rust build is needed.
