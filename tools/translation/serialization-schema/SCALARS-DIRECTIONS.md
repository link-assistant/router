This source draft extends the same sealed original corpus, Cargo lock and
consuming-module namespace checks. It adds `bool` and fixed-width signed and
unsigned integers through 64 bits. Original type aliases, imported masks and
unknown scopes still prevent primitive admission. Pointer-sized integers,
floats, 128-bit integers and custom conversion hooks remain refused.

An extraction can request `both`, `serialize` or `deserialize`. Every reachable
original data owner must have that actual locked Serde derive identity. Bulk
discovery selects the directions present on each original root; it does not
invent the opposite trait or infer a manual implementation. Registry entries
record those directions. The new generic codec factory requires privately
checked source metadata and exposes only the proven serialize/deserialize
callables. Copied registry JSON cannot create a source authority certificate.

The shared codec interprets descriptor data rather than emitting target
function bodies for particular records. Wire names are also the JS value ABI
keys. Scalars use Boolean/string values and exact safe Number or BigInt integer
values. Wide integer JSON is emitted as decimal numbers and parsed from its
original lexemes. Integer visitors refuse floating spellings, including `-0`,
`1.0` and `1e0`. Unknown object values are parsed without converting retained
typed integer fields through IEEE rounding; duplicate known fields refuse.

An ordinary `Option<T>` emits JSON null for None unless the actual checked
`Option::is_none` helper requests omission. Missing map fields deserialize as
None. Missing sequence fields require the original explicit default attribute;
the pinned derive sequence branch otherwise reports invalid length. The older
affinity descriptor, which already has explicit Option defaults and omission
helpers, keeps its exact ordinary ABI. Custom default functions, non-Option
defaults, nested Option ownership ABIs and opaque helper hooks remain refused.

`refusal-classification.json` accounts for every previously verified refusal
and manual header. Counts describe first refusal reasons, not guaranteed future
owner coverage. The full original attributes, qualified owners, source hashes
and spans remain in the immutable verified bulk inventory. The classification
records actual locked Serde 1.0.229 implementation and derive branch identities.
