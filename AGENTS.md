CI verifies broader Rust behavior only after the JavaScript gate.

Local commit hooks must not invoke Rust tools or automatically remove build caches. Keep Rust checks in the gated CI workflows and perform explicitly authorized cleanup separately. Use the repository's lockfile-installed TypeScript compiler, record its version, and preserve strictness, whole test files and original deadlines when repairing failures.
