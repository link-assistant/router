Reject ambiguous function lifetime elision, non-static values passed to static source parameters, and borrowed returns whose origin is unproven. Checked source references, borrowed strings, standard generic arguments and tuple fields retain per-use lifetime evidence. The verifier interprets checked expression structure solely to prove return origins; it does not replace source bodies or execute Rust.

The bounded profile covers actual static and elided shared lifetimes, input identities, source string literals, ordinary checked calls, checked branches and registered borrowed receiver operations. Named lifetime binders, lifetime bounds, mutable borrows, unknown operation origins and unproved moves remain explicit refusals. Original shared-method receiver evidence is required for the receiver elision rule. The rules follow the [Rust Reference lifetime elision rules](https://doc.rust-lang.org/reference/lifetime-elision.html#lifetime-elision-in-functions). Full repository runtime parity remains unproven.
