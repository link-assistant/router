Draft independent source type-refusal collection for the automated Rust to meta
to JavaScript/TypeScript project checker. A failed original data-layout or
function-signature phase collects its attributed errors together, then discards
the checker. Every surviving declaration and transitive caller is checked again;
body, recursion, lifetime, constant-evaluation and source-link obligations remain
mandatory. Generated layouts and internal/unattributed exceptions retain ordinary
first-failure behavior. Pinned vendor bytes remain unchanged; seven exact anchors
expose phase and declaration visitor hooks in the local class adapter.

Eight new behavioral cases are authored and UNRUN while the publisher owns the
compiler. No corpus producer, canonical/profile regeneration, runtime parity gain,
performance improvement or Rust verification is claimed by this source draft.
