Monomorphic type names distinguish actual Rust `usize`/`isize` from equally wide `u64`/`i64`, retaining the portable 64-bit assumption without asserting Rust primitive identity. Registered JSON, time, filesystem error, integer arithmetic/parsing and vector reader types retain their known Rust primitive identities; source pointer primitives use distinct standard method owners. Runtime integer descriptors continue to contain only validated width and signedness. Non-pointer canonical encodings remain stable. This does not establish full pointer architecture independence or complete runtime parity.
