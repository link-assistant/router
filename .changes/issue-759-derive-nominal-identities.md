Use the Rust Reference's derive-output rule to retain the exact original nominal definition when derive macros append items. This is identity evidence only: procedural scope, trait behavior and carried layouts remain unresolved. Conditional declarations and unknown attribute replacement refuse; implementation attributes that can replace the original target also block target proofs. Actual tracked proc-derived declaration spans are checked independently.
